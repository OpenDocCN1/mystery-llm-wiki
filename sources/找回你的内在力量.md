# 找回你的内在力量


# 序

这是一本基于生命体验同时超越生命体验的关系平衡之书。

作为一个女性，我们常常因为伤痛而进入内在探索的旅程。也许你体验过压抑、恐惧、无价值感与不安全感，你守护着重要的关系，却无法为自己发声；你为家庭和工作拼尽全力，却完全感受不到滋养。帕梅拉的这本书，从被禁和受伤的女性展开，帮助我们了解自己的阴影面相，并从中获得女性能量的智慧，同时我们也需要了解男性能量，彼此过程，真正地感受并显露两种人在不同层面的运作方式和驱动力，由此更清楚地在痛在之痛中，跳出相互争夺的“错误之爱”，在心灵层面认出彼此，在情感和身体层面，做有力量的爱的践行者。

每个人都想建立充满爱的关系，我们生命所经历的种种问题都来自关系的扭曲，而无论它是男性或者女性，我们之内都存在着男性能量和女性能量。当我们以整体性来对待自己和周围的人时，就是在调和这两股能量。刚开始，它们均用力敌、相互争夺或背道而驰，但是，它们必须彼此相认相知——最终，美满的一刻本属于你也终将呈现于你，那就是，当你与自己、与他人建立真实的连接，既和谐统一，又独立自由，让自己完全负责，让你的女性能量和男性能量在健康的关系中共舞，逐渐获得与他人连接，又能放下对方，由此你将享自身光芒的闪耀，活出自己。这就是找回内在力量的过程。

# 导言

《被禁的女子》（注：本书原版书名）书名可能会引发一些问题：如今什么是被禁的？在西方世界，女性解放似乎已经取得了相当进步，允许像男性一样工作，创建事业，积累财富，法律上也拥有同样的权利与义务。而且在现在的图书中，你会看到女性变得越来越有行动，越来越意识。难道女性是被禁的吗？本书对此的回答是：是的。尽管女性在形式上与男性相等，但在女性灵魂处却存在创伤，若干世纪以来对女性的误解与扭曲导致了这一结果。这一创伤便是本书的主题。首先，“被禁的女性”也是“受伤的女性”。一位能够像男性一样工作、建立关系的“强女人”，她们外表之下往往隐藏着自我怀疑与无价值感。受伤女性往往会大量付出，倾向于他人，却难以为自己而出，难以设定界限。这使得她们容易失去自我，缺乏稳固的内在，想与世界分享创造力、灵感与爱。在大学完成了哲学论文，即将与学术告别之际，我遇到了内在的“被禁女性”。那时我强烈感受到来自内心深处的呼唤，呼唤我以感知的方式而不是以理性的方式探讨人生、探索灵性。那段时间，我因为内在破裂感受到打击，无比绝望。理智层面的女性能量已经无法满足我对人生意义和对爱的渴望。我钻研各种神秘书籍，并有兴趣参加了“解读生命场”的课程。于是，人生的新篇章开始了，那时我30岁。几年之后，在遇到现在的伴侣之后，我创立了自己的工作室，帮助人们解读生命场并提供灵性咨询。不久之后，我陆续建立了一些连结。我会传导信息并将信息集成。将自己的工作展示于众，与之相伴的是极大的恐惧与迟疑。我们获得了许多关注以及肯定与温暖的。然而，我长期受困于内在的自我怀疑与不确定感。我内在的“被禁女性”是一个直觉极强的女性，她想要进入生命的核心，想要用心而非头脑去感受与理解。我非常害怕将这一面向展示在公众面前，我内在被避免冲突的部分害怕遭到拒绝与嘲笑。随着时间的推移，我开始慢慢适应。在举办工作坊和讲座面向越来越多听众时，我不再那么紧张。接下来，我还需要面对一个挑战：对于前来寻求的人，我无法说“不”。我无法明确地表明界限，而且我对前来找我的人所承受的痛苦与折磨非常敏感。这最终导致了一次危机，我患上了胃炎并且精神崩溃，我因为精神病症状和抑郁症住院治疗（详见《灵魂暗夜》）。在这次危机的谷底，我与这一切苦难的根源相逢——无价值、有罪以及错误的感觉。以此为出发点的我，时时刻刻必须竭全力做好一切以获得肯定与爱，与此同时，还要压抑自身的需求。这极具破坏性的无价值感为我带来了巨大的影响，我几乎为此失去了生命。

从灵魂暗夜中艰难地走回来后，我首次以“自爱”为基础看待和体验自己，爱自己如自己本然的样子，而非应该是的样子。这一基础虽不算坚实，但在很大程度上使我更加坚定，更有意识。如今，我心中常常升起一种幸福感与充实感，为我所的工作以及所拥有的生活。我内在那被禁的女性终于可以走出来，站在阳光下。

本书中，我与一位来自过去的“被禁女性”——抹大拉的玛利亚对话。在基督教历史上，她是一位被禁的女性。根据基督教传统的教导，她是妓女，一位不守规矩的野生女子，需要获得拯救。至少这一故事的官方版本是这样的。在与抹大拉的玛利亚相处的过程中，她给我的感觉是她是一位强而有力同时也充满爱心的导师。有时，她非常直率，有些咄咄逼人，但大多数情况下，她非常温柔，对各种情绪充满理解。在我眼中，她并非女权主义者，而是一位睿智且充满热忱的女性。她在探讨女性内在的创伤的时候，也不忽略男性所遭受的创伤，主张两性能量的合作。抹大拉的玛利亚说，无论男性还是女性，其内在都带有“被禁的女性能量”，此能量关乎于感受、直觉与心灵。这一时期，男性与女性身上的这一能量都要觉醒，这样我们才能位于自身、于各种关系以及社会层面，获得内在平衡。

我是如何与抹大拉的玛利亚相遇的？又是以何种方式与她对话的？十年前，我与格里斯·杰伦在南部举办以“灵性与内在成长”为主题的工作坊。那时，我也出版了几本信息集书（作者：帕梅拉）。“传导”即接收发生在内在层面上，也就是说凭借直觉而非头脑去接收。对我来说，“传导”并非由生理感觉而来，而是由内在而外的“感受”。当我将信息翻译成人类概念时，在这个过程中，总会存在某种程度的过滤或失真。这也是一个人，我的工作更是基于自己掌握的信息以及个人背景上的。传导信息最好以内容为主，看一看你是否受触动，使你感到放松、温暖。如果如此，来自各种渠道的信息对你有所帮助。传导信息中的评判与恐惧，我倾向于将其置一边。最终，判断某些信息对你是否有用。十年前，我们在举办工作坊（当时我们的书已出版），我以为将会传导。坐在许多有兴趣、满期待的听众面前，忽然感觉到一份全新的能量。由于这一事件，我的身体、心中升起一股感动。我开始以她的名义讲话，仿佛有什么古老而珍贵的东西醒过来——被禁的女性能量在室内弥漫。几位女士因椅子不够，在我的身边而坐，甚至不禁啜起来。即使我相当理性、富有怀疑，也被眼前发生的一切深深触动了我。

抹大拉的玛利亚在她带来的第一篇信息中谈论了“女性腹部的创伤”——她如此呼吁。她说，女性能量因压抑而变得衰弱，其留下的痕迹在腹部尤为明显。许多女性腹部都有一个空洞，这与缺乏自我价值感分不开。尽管在法律或社会层面上恢复女性的权益很重要，但仅凭这一点无法治愈这一心理创伤。深度的疗愈是必须之举，抹大拉的玛利亚信息以此为主题。最近几年，我收到一系列信息，其中的十五篇收录在本书下半部。这些文字源自我们举办工作坊时，在众人的陪伴下传导。这些信息主要讨论了两性能量、关系、性以及女性腹部的创伤疗愈。这些文字充满了爱与鼓励。阅读这些文字时，你所感受到的能量变化才是关键。这些信息的目的在于带你走进自己。它们不仅是为了传递信息，而是帮助你与内在的真相和智慧建立连结。本书的上半部分记录了我与抹大拉的玛利亚的对话，对话中我向她提出了各种问题，比如她是谁，关于我们内在被禁的女性能量，关于爱、激情与性。

写作过程中，我感到抹大拉的玛利亚自己也有想要讨论的议题。首先，她指出了辨别“基于心灵、充满爱的男性能量”与主宰近现代史的“基于抗争与掌控的男性能量”的重要性。她说，这一时期，更高的男性能量的觉醒尤为重要。接下来，她阐述了女性能量的阴暗面向：女性如果失去自我意识，可能会陷入操纵、占有或愤恨。关于女性能量，她帮助我们辨别“基于恐惧与抗争的女性能量”与“基于心灵、充满爱的女性能量”。她说，男性与女性如果不对自身的阴影面向负起责任，两性之间的战争就会不断滋生。人们在关系层面进行的复杂游戏中，女性与男性都有可能成为施害者或受害者。在通往平衡与和谐的道路上，关键的一步在于整合我们内在的男性与女性能量。只有这样，我们才能内在变得完整，建立连结，并以此为出发点进入与他人的关系中。

除了深入讨论女性腹部的创伤以及随之而来的缺乏根基和自我价值感，抹大拉的玛利亚还具体讨论了男性能量的创伤。她提到了男性心中的创伤，这使他们难以臣服于自身的感受与直觉。疗愈这一创伤与恢复女性的腹部力量同样重要。这两种不同的创伤也需要不同的疗愈方法。抹大拉玛利亚分别讲述了疗愈男性与女性创伤的三个步骤。尽管疗愈两种创伤的道路并不相同，但它们殊途同归：内在的自由，建立连接以及充满爱的体验。

## 第一章 被禁的女性

什么是被禁的女性？在西方世界，女性又是如何影响了你？我天生拥有很独立的意识，厌恶男人将他们的意志或观点强加于我。我随自己的意志而行，想要拥有属于自己的体验，以此为基础。我与男性能量有着紧密的连接。而在那时，我还是小女孩，因为社会已经明确了各种准则，要求女性作为妻子、成为母亲的准备。少女时期的女性在社会压力下，会成为一个被弃与排斥的人。

18岁时，年轻的我与一位年长的男性一起路上，在他身边感到开心。我们并没有结婚，而且也不打算结婚。我们过着自由、充满冒险的生活。在他身边我丝毫不觉得束缚。我心中充满了热忱与激情，对于社会上的不平等地位有着强烈的意见。随着成长，我经常从不同的灵性老师。那时，我已经是一个“被禁女性”了，因为我没有选择那个道路。一段时间后，我与一个比我年轻的男性建立了亲密关系，就成了眼中眼中被禁女人。

独立的渴望其实也是一种逃避，逃避与人的接近，害怕伤害。伴侣是不可或缺的。当时，我备感孤独与绝望。然而，我最终还是找回了自身的力量，并带着忍耐与信任的意识觉知度过了人生的最后阶段。

这一阶段，我自己也成为了导师。因自身的种种经历，我于内在对那充满智慧的宇宙源头渐渐开启了自己。它不仅能够带给我安慰，我发现他人也能从中受益。我将自己的感受与洞见写下来，并将它们分享给少数“有耳能听”的人。

占据属于自己的一席之地、接受而非给予、说“不”、为自己挺身而出等方面依然缺乏自信。男性能量会设定界限，以自我为本位，敢于特立独行，女性需要这一能量以获得平衡，成为自己人生的创造者。

女性需要男性能量来疗愈自身的内在创伤？这听起来有些吊诡（因为女性的创伤正是由于受到了男性的压制）。

是的，为了看清这一点，重要的是意识到每个人在本质上既拥有男性能量又拥有女性能量。比如，在肉体层面上，你是一位女性，这也影响了你的思维与行为方式，然而，在本质层面上，你是一个灵魂。灵魂可以选择轮回为男性或女性。灵魂本身是自由的，在体验与实践过程中，既可运用男性能量，亦可运用女性能量。让人们相信男性只拥有男性能量，女性只拥有女性能量，其实是一种压制。如果人们真的相信这一点，就相当于给自己“截肢”。事实上的确如此。若千世纪以来，女性被迫限于自己的女性身份，而用于定义“女性身份”的词汇往往在伴侣和母亲，而且还与“不理智”“情绪化”等特性联系在一起，这与“理智”“意志坚强”等男性品质恰恰相反。

不仅如此，男性也被迫穿上了束身衣，他们必须做一个“真男人”，也就是说，要抑制自身的情绪，关闭心扉，在某些领域中，甚至不在他们自己选择的领域中做出出类拔萃的成绩。

对“男性品质”与“女性品质”的片面定义，迫使人们去扮演这样的角色，无论在男性身上还是女性身上，都造成了内在的创伤。因此，倘若我说对于女性而言，拥抱自身的男性能量是至关重要的，我的意思其实是女性要与自己的内在建立更加紧密的连结。每个人都同时拥有这两种能量，而且，为了能够在地球上全然地影响自己，这两种能量都不可缺的。她们必须将自己从有限的定义与角色中解放出来，全然拥抱自己的个体性。

地球实相中的掌控者不爱内在。与自己的内在建立连接的人，会遵从自己的意愿，且意志坚定如磐石。被社会排斥的恐惧和肉身死亡的恐惧对他们的影响也变得越来越小。他们挣脱了外的权威的束缚，聆听内在的声音。这对于基于权力与掌控的权威而言具有相当大的破坏性。宗教权威、社会权威以及在婚姻、家庭、教育、科学等领域中权力的行使，都是借助被压制人们的恐惧而进行的。如果一个人能够破坏人们的自我认知，削弱人们的自信，那么相对而言，他很快就能够掌控这些人。而与内在的连结则会帮助人们冲破虚假的自我认知。无论是男性还是女性都如此。

也就是说，同样还存在着“被禁的男性”？

确实如此。因为你身处在基于权力与压制的体系，男性在情绪层面上也同样备受创伤。年少时期，一些品质在男孩身上就遭到了禁止，比如展示自身的脆弱、表达自己的感受、哭泣、显露情绪或者在某些方面出现类比，等等；而如果女孩子这样做的话，却被看作是非常自然、天经地义的事情。

我再次邀请你们关注自己的腹部。你们渴望爱，渴望爱情与友谊中那真诚的人与人之间的爱。当你变得彼此近距离之时，你会感觉到来自方的强烈吸引力，不过，请静心来，觉察对对方的哪些品质触动了你，这也是是非常必要的。请慎重这一过程，不要因为亲密关系有时会有带给你的痛苦而失望，甚至失去信心。至关重要的是，能够从中学习到什么，在哪些方面能够获得成长。对腹部层面的爱开启自己，敢于重新进入生活，对与他人的真正沟通持开放态度。即便你与对方的关系已经足够长久（你们已相守多年非常了解彼此）。

这可能是一些非常简单的事，很容易被你的脑袋忽略掉。请认真对待这些需求，你的身体想要你回归自己。身体并不是灵魂的对立面，它是灵魂的物质形相。借由尊重自己的身体、感官享受与腹部生命，你会将自己的灵魂带入地球，并允许其透过身体这一门户，照耀你的人生。
