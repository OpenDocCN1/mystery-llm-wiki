## 概述

本頁整理自《勸學齋紫微進階》（鄭景峰著）第三章「斗數命盤要務」，系統記錄紫微斗數排盤的完整實務流程。涵蓋命盤製作方法、干支換算公式、真太陽時修正原理與對照表，為紫微斗數排盤的核心技術規範。

> **書目資訊**：鄭景峰，《勸學齋紫微進階》，勸學齋主編。本章承接第一章「進階斗數命理基礎」（五行河圖洛書、干支象數、陰陽五行擇要）與第二章「進階斗數宮位概說」（十二宮定位、四生四墓四敗、三方四正、五行局），專注於排盤實作技術。

## 摺紙製盤法

### 原則與優勢
- **材料**：信紙或八開白報紙（可裁半），大小適中便於歸檔
- **操作**：連續對摺四次，展開即得十六格大小相同的命盤紙
- **佈局**：
  - 中央四格：填寫命造生辰與姓名
  - 周邊十二格：依序填入十二地支（子至亥）
- **效益**：簡便、快速、整齊、利於整理歸檔，避免手繪直線歪斜導致誤看漏看

### 掌上十二宮定位輔助
配合摺紙盤使用，以左手掌指對應十二地支：

|------|------|

| 無名指根部 | 午 |
| 中指根部 | 未 |
| 食指根部 | 申 |
| 小指指尖 | 辰 |
| 食指指尖 | 酉 |

## 年月日時干支換算公式

### 年干支
**年干**：民國年數減 2，取個位數對照天干序數（0 視為 10）
- 天干序數：甲1 乙2 丙3 丁4 戊5 己6 庚7 辛8 壬9 癸10
- 例：民國 77 年 → 77-2=75 → 個位 5 → **戊**

**年支**：民國年數除以 12，取餘數對照地支序數（整除視為 12）
- 地支序數：子1 丑2 寅3 卯4 辰5 巳6 午7 未8 申9 酉10 戌11 亥12
- 例：77÷12=6……餘 5 → **辰**
- 結論：民國 77 年 = **戊辰年**

### 月干支 —— 五虎遁月
**核心訣竅**：年干決定正月干，順推至目標月
- **月支固定**：寅=正月、卯=二月、辰=三月、巳=四月、午=五月、未=六月、申=七月、酉=八月、戌=九月、亥=十月、子=十一月、丑=十二月
- **五虎遁月起干口訣**（掌訣法見本書第二章）：
  - 甲己之年丙作首（正月丙寅）
  - 乙庚之歲戊為頭（正月戊寅）
  - 丙辛之年庚寅起
  - 丁壬壬寅順行流
  - 戊癸甲寅之上求

**實例**：戊辰年（甲己年）正月 = 丙寅、二月 = 丁卯、三月 = 戊辰……

> **關聯**：八字月柱起法同源，參見 [[bazi-mingli-xue-jichu-jiaocheng]] 中五虎遁月章節。

### 日干支 —— 陽曆換算陰曆干支公式
**適用場景**：無萬年曆時快速換算，精確度經驗證百試不爽

**公式步驟**：
1. `X = (民國年數 - 10) × 5 + (民國年數 - 10) ÷ 4 取商 + 該年 1 月 1 日至目標日總天數`
   - 閏年規則：能被 4 整除為閏年（二月 29 天），其餘平年
   - 月份天數：大月 31（1,3,5,7,8,10,12）、小月 30（4,6,9,11）、二月 28/29
2. `Y = X ÷ 60 取餘數`
3. **日干**：Y 個位數對照天干序數（0=10）
4. **日支**：Y ÷ 12 取餘數對照地支序數（0=12）

**實例**：民國 77 年 3 月 17 日
1. `(77-10)×5 + 67÷4(商16) + (31+29+17) = 335 + 16 + 77 = 428`
2. `428 ÷ 60 = 7……餘 8`
3. 日干：8 → **辛**；日支：8÷12 餘 8 → **未**
4. 結論：**辛未日**

**原理說明**：干支六十甲子循環，故除以 60；陽曆日期易取得，反推陰曆干支。

### 時干支 —— 五鼠遁時
**時支對照表**（固定）：
| 時辰 | 時間 | 時辰 | 時間 |
|------|------|------|------|
| 子時 | 23:00-01:00 | 午時 | 11:00-13:00 |
| 丑時 | 01:00-03:00 | 未時 | 13:00-15:00 |
| 寅時 | 03:00-05:00 | 申時 | 15:00-17:00 |
| 卯時 | 05:00-07:00 | 酉時 | 17:00-19:00 |
| 辰時 | 07:00-09:00 | 戌時 | 19:00-21:00 |
| 巳時 | 09:00-11:00 | 亥時 | 21:00-23:00 |

**時干起法**：日干決定子時干，順推十二時辰
- **五鼠遁五組天干**：甲己、乙庚、丙辛、丁壬、戊癸（河圖一六、二七、三八、四九、五十）
- **規則**：遇陰干（乙丁己辛癸）跳過不取，直接用該組陽干起子時
  - 甲己日 → 子時甲子
  - 乙庚日 → 子時丙子（跳過乙）
  - 丙辛日 → 子時戊子
  - 丁壬日 → 子時庚子
  - 戊癸日 → 子時壬子

**掌訣速查**：將五虎遁掌訣序數 35791 改為 13579，即可求時干。

> **交叉引用**：奇門遁甲同用五鼠遁時，參見 [[yin-pan-qimen-paipan-shi-yi-bu]] 排盤步驟；八字時柱起法同源，見 [[bazi-mingli-xue-jichu-jiaocheng]]。

## 經緯真太陽時修正原理

### 核心觀點
> **「時間是依太陽來定的，時辰代表著不同的五行之氣，每一時辰太陽太陰與地球之角度，使人之受氣有所差異。」** —— 鄭景峰

### 古法測時科學性
- 西晉左思《魏都賦》：「揆日晷，考星耀」—— 利用日影測時
- 「日晷儀」（日規）測定日影位置定時刻
- 地球東轉，東方先見太陽，**經度差導致真太陽時不同**

### 現代時區與真太陽時
- 全球 24 時區，以格林威治子午儀為本初子午線
- 每時區橫跨 15° 經度，區內共用區中央經線的**標準太陽時**
- **區內最東最西真太陽時相差 1 小時** → 論命須修正至出生地真太陽時

### 修正必要性
1. **時辰邊界敏感**：相差幾分鐘即換時辰，命格大異
2. **陳希夷《紫微斗數總訣》**：論斷不準時「以三時斷」（推前後一時驗證）
3. **出生地經度修正**：
   - 每 1° 經度 = 4 分鐘時間差
   - 東經 120°（臺灣中央標準經線）以東 → 真太陽時**早于**標準時間（減去時差）
   - 東經 120° 以西 → 真太陽時**晚于**標準時間（加上時差）
4. **跨國出生錯誤案例**：
   - 美國洛杉磯（西經 118°）中午 12:00 生產
   - 臺灣當時凌晨 0:00（子時）
   - **不可用臺灣時間排盤**—— 子屬水、午屬火，水火相衝，受氣本質錯置
   - 南北半球季節相反，差異更大

> **關聯**：八字排盤同須真太陽時修正，見 [[bazi-mingli-xue-jichu-jiaocheng]] 相關章節。

**使用方式**：
- 標準時間（鐘錶時間）± 時差 = 真太陽時
- 例：臺北出生 12:00:00 → 真太陽時 = 11:53:57（減 6'03"）→ 仍屬午時
- 若在時辰交界點（如 10:58 遇減 6'03" → 10:52 仍巳時；若 11:02 減 6'03" → 10:56 換巳時），須排前後兩盤驗證

## 完整排盤修正流程圖解

```
出生地標準鐘錶時間
       ↓
【夏令時間期間？】→ 是 → 扣除 1 小時 → 標準時間
       ↓ 否
標準時間
       ↓
【查詢出生地經度時差表】
       ↓
東經 > 120°：標準時間 - 時差 = 真太陽時
東經 < 120°：標準時間 + 時差 = 真太陽時
       ↓
真太陽時對照十二時辰表 → 確定時支
       ↓
以日干五鼠遁時起時干 → 完整時柱
       ↓
年柱（年干支公式）+ 月柱（五虎遁月）+ 日柱（日干支公式）+ 時柱
       ↓
四柱齊備 → 摺紙製盤 / 掌上排盤 → 安星佈宮（見 [[ziwei-doushu-an-xing-fa]]）
```

## 關鍵提醒與常見錯誤

| 錯誤類型 | 說明 | 正確做法 |
|----------|------|----------|
| 直接用鐘錶時間排盤 | 未修正經度、夏令時間 | 必經三步修正：夏令→經度→真太陽時 |
| 跨國出生用籍貫/居住地時間 | 洛杉磯生產用臺灣時間 | **以出生地真太陽時為準** |
| 時辰交界點單盤定論 | 如 11:00 前後未驗證 | 陳希夷「以三時斷」：排前後時辰各一盤驗證 |
| 五虎遁月/五鼠遁時混淆 | 月遁年干、時遁日干 | 口訣掌訣分開記憶：月用 35791，時用 13579 |
| 日干支公式誤用陰曆日期 | 公式專為陽曆設計 | 輸入陽曆年月日，自動換算陰曆干支 |
