# 道家秘传阴盘奇门遁甲十一步排盘实操流程

> 本页面依据《凤麟奇门风水学》第一章至第三章内容整理，系统梳理道家秘传阴盘奇门遁甲的理论特色、基础知识体系与十一步排盘实操流程，并附录八卦、十天干、十二地支象意速查表及疾病预测断验体系。

## 核心理论特色：与阳盘奇门的分水岭

道家秘传阴盘奇门遁甲（以下简称“阴盘奇门”）源于道家口传心授，其定局方法**依据月相变化**排盘定局（太阴星为阴），故称“阴盘”。市面流行的拆补法、置润法依节气（太阳黄道位置）定局，属“阳盘奇门”。

| 维度 | 阳盘奇门（拆补/置润） | 阴盘奇门（道家秘传） |
|------|----------------------|----------------------|
| 定局依据 | 节气（太阳运行） | 月相（太阴运行） |
| 转局频率 | 五天/六十时辰一局 | 每时辰演一局 |
| 信息量 | 较少 | 更丰富、精准细致 |
| 吉凶格局 | 繁多、固化 | **没吉没凶**，象意阴阳双面 |
| 空亡用法 | 单一 | 远空、近空、先天、后天多维断验 |
| 伏吟局 | 列为凶格 | **伏吟转宫有秘诀**，可精准断事 |
| 核心大法 | 格局吉凶判断 | **风水移星换斗法** |

### “没吉没凶”辩证观
阴盘奇门认为遁甲局中任何符号、格局皆有阴阳正反双面信息，**在特定时空针对特定人事方可定论**。
- **天辅星（文曲星）**：阳盘称“大吉、百事可为”，阴盘亦主“监狱、蹲牢房、被看管”。
- **朱雀投江（丁+癸）**：阳盘称“阴水克阴火，百事凶”，阴盘亦主“生意火红的鞋帽业、热恋婚姻”。
- **腾蛇**：既主“虚诈不实”，又主“灵活机动、聪明过人”（毛泽东终身挂腾蛇死门局，咬定青山不放松）。
- **死门**：既主“死心眼、顽固”，又主“执着、咬定青山不放松”。
- **戊+癸**：阳盘概念模糊，阴盘直断“投资癸水关联业（饮品、水产、液体、旅游）挣大钱，癸为鞋，做鞋生意蒸蒸日上”。

> **实践启示**：世传奇门吉凶格局缺乏辩证法，如鸟笼禁锢思维；阴盘奇门扫清障碍，体现“简易”内核，一招制胜，无招胜有招。如断升学考试，阳盘需参天辅、值符、值使、丁奇、景门等多因素生克纷杂；阴盘**只看用神落宫状态，参考天辅星即可**，一支枪一个准星。

### 风水移星换斗大法
阴盘奇门排盘反映宇宙能量场在地球分布，天人感应、“在天成象，在地成形”。**移星换斗法是根本大法**，运用盘中天地人神符号象意，设定风水物品摆放最佳方位，接收特定宇宙能量气场，一次性调整环境能量结构，提升能量层次，立竿见影改善居住者运势。详见 [[fenglin-qimen-fengshui]]。

## 基础知识体系速查

### 阴阳五行
- **阴阳**：对立统一、互根消长、转化。太极图直观反映阴阳特征。预测师须站在宇宙角度全面发展看事物，理论基础即“没吉没凶”。
- **五行**：水木火土金，五种基本物质运动互作形成万物生灭规律。
  - **性质**：水寒冷向下、火炎热向上、木发生条达、金清静收杀、土长养育化。
  - **相生**：金→水→木→火→土→金（母生子，促进滋生）。
  - **相克**：金克木、木克土、土克水、水克火、火克金（维持平衡）。
- **寄生十二宫**：十干在十二支十二种状态（长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养），反映万物生灭循环。

### 天干地支
- **十天干**：甲乙丙丁戊己庚辛壬癸（阳干：甲丙戊庚壬；阴干：乙丁己辛癸）。五行配属、冲合关系（甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火）。
- **十二地支**：子丑寅卯辰巳午未申酉戌亥。月建固定（正月寅…十二月丑），时辰固定（子时23-1点…亥时21-23点）。
- **六十花甲子**：阳干配阳支、阴干配阴支，六十组合循环，模拟任一时空。
- **地支关系**：六冲、六合、三合、相刑、相害。

## 十一步排盘实操流程

> 以下以 **2006年5月23日19时45分（农历四月二十六）** 为例，演示完整排盘过程。
> 四柱：**丙戌 癸巳 壬子 庚戌** → 阳七局，旬首甲辰壬。

### 第一步：排四柱
将起局阳历时间转换为干支（年柱、月柱、日柱、时柱）。
- **年柱**：以立春为界（立春前属上年），万年历查得。
- **月柱**：地支固定（正月建寅…十二月建丑），以节气“节”为界（立春-惊蛰为正月…小寒-立春为十二月）。天干由**年上起月法**推算：
  > 甲己之年丙作首，乙庚之岁戊为头，丙辛之岁庚寅上，丁壬壬寅顺水流，若问戊癸何方起，甲寅之上好追求。
- **日柱**：万年历查得，子时为日界（23点后属次日）。
- **时柱**：地支固定（子时23-1点…亥时21-23点），天干由**日上起时法（五鼠遁）**推算：
  > 甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途。
- **简便记忆**：生合者定月（甲寅年寅月，甲己合土，生土者丙），克合者定时（丙辛日子时，丙辛合水，克水者戊）。基础命理可参考 [[bazi-mingli-xue-jichu-jiaocheng]]。

### 第二步：定阴阳遁局数
- **阳遁**：冬至后至夏至前。
- **阴遁**：夏至后至冬至前。
- **局数计算**：`(年支序数 + 月数 + 日数 + 时支序数) ÷ 9` 取余数（余0作9）。
  - 例：丙戌年(戌序数11) + 四月(4) + 二十六日(26) + 戌时(11) = 52，52÷9余7 → **阳七局**。

### 第三步：画九宫格
- **必须用九宫格（大方格分小方格）**，不可用井字格（四面透风、气场不聚、能量消耗、注意力分散）。
- **心法口诀**：默念“无极生太极，太极生两仪，两仪生四象，四象生八卦，八卦定乾坤”。
- **要求**：线与线交接紧密，格与格不相通，否则信息混乱判断不清。心平气和，产生共振场效应，达天人合一。

### 第四步：布地盘三奇六仪
- **原则**：阳局顺布、阴局逆布。序列：**戊己庚辛壬癸丁丙乙**（九宫数：戴9履1，左3右7，二4为肩，六8为足，五居中）。
- **操作**：几局戊落几宫，其余顺/逆飞布。
- **例·阳一局**：
  | 辛(4) | 庚(3) | 丙(9) |
  |------|------|------|
  | 乙(8) | 壬(5) | 戊(1) |
  | 己(2) | 丁(7) | 癸(6) |
- **例·阴一局**：
  | 丁(4) | 己(9) | 乙(2) |
  |------|------|------|
  | 丙(3) | 癸(5) | 辛(7) |
  | 庚(8) | 戊(1) | 壬(6) |
- **例·本案阳七局**：
  | 丁(4) | 庚(9) | 壬(2) |
  |------|------|------|
  | 癸(3) | 丙(5) | 戊(7) |
  | 己(8) | 辛(1) | 乙(6) |

### 第五步：找旬首
- **六旬首**：甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸。
- **查法**：以**时柱**查六十花甲子记数表（或口诀）。本案时柱**庚戌**，属甲辰旬 → **旬首为壬（甲辰壬）**。

### 第六步：定值符与值使门
- **值符** = 值班九星，**值使** = 值班门。
- **规则**：地盘旬首落在哪宫，该宫地盘星为值符、地盘门为值使门。
- **本案**：阳七局地盘壬落坤二宫 → 坤宫地盘星**天芮星为值符**，地盘门**死门为值使门**。

### 第七步：排天盘三奇六仪与九星
- **核心规律**：**旬首和值符随时干**。
- **操作**：看预测时辰时干在地盘落宫，将值符和旬首直接写入该宫，同时将旬首原宫地盘九星随之移入该宫；余下三奇六仪按地盘顺序依次填入各宫。
- **本案**：时干庚，地盘庚落离九宫 → 旬首壬加离九宫庚上，坤宫地盘星天芮移入离九宫。
- **结果示意**（仅显示天盘层）：
  | 己 | 癸 | 丁 |
  |------|------|------|
  | 辛 | 丙 | **庚 壬 天芮** |
  | 乙 | 戊 | 壬 天英 |

### 第八步：排八神
- **八神序列固定**：值符 → 腾蛇 → 太阴 → 六合 → 白虎 → 玄武 → 九地 → 九天。
- **排布**：值符首先写入**时干所在宫（即天盘旬首落宫）**，余七神按阳遁顺时针/阴遁逆时针依次填入其他宫。
- **本案**：阳遁，值符落离九宫（时干庚宫），顺时针排布：
  - 离九：值符
  - 坤二：腾蛇
  - 兑七：太阴
  - 乾六：六合
  - 坎一：白虎
  - 艮八：玄武
  - 震三：九地
  - 巽四：九天

### 第九步：定八门
- **起点**：旬首地盘所在宫 = 值使门值班宫（旬首时辰内）。
- **推运**：按预测时辰在九宫顺序中推演值使门落宫。
  - 阳局按宫数顺序：坎1→艮8→震3→巽4→离9→坤2→兑7→乾6→坎1…
  - 阴局按宫数逆序：坎1→乾6→兑7→坤2→离9→巽4→震3→艮8→坎1…
- **填布**：找到值使门落宫后，**无论阴阳局均按顺时针（坎1→艮8→震3→巽4→离9→坤2→兑7→乾6）填写八门固定序列**：休→生→伤→杜→景→死→惊→开。
- **本案**：甲辰旬首壬地盘在坤2 → 甲辰时值使门在坤2。预测时庚戌时在艮8 → 值使门**死门落艮8**。顺时针布：
  - 艮8：死门
  - 震3：惊门
  - 巽4：开门
  - 离9：休门
  - 坤2：生门
  - 兑7：伤门
  - 乾6：杜门
  - 坎1：景门
- **注意**：中宫奇仪寄坤二宫（本例丙寄坤宫）。

### 第十步：排隐干
- **原则**：**时干加在值使门上**，随后按天盘三奇六仪顺序（或地盘顺序）排一圈。
- **本案天盘三奇六仪九宫顺序**：庚(离9) → 壬(坤2) → 戊(乾6) → 乙(离9?) → 辛(巽4) → 己(艮8) → 癸(坎1) → 丁(兑7) → （循环）。
- 时干庚加值使门死门(艮8)上，依序排布。

### 第十一步：查空亡与马星
- **空亡查法**（按旬首所在旬）：
  - 甲子旬：戌亥空(乾)
  - 甲寅旬：子丑空(坎艮)
  - 甲辰旬：寅卯空(艮震) **← 本案甲辰旬，艮震二宫空亡**
  - 甲午旬：辰巳空(巽)

## 疾病预测起局要点与断验实务

### 起局坐标定位原则
1. **当面问测**：以**日干**为求测者用神，看日干落宫。
2. **电话/远程问测**：以**月干**定坐标判断求测人身体。
3. **代问他人**：按六亲关系定用神——
   - 父母长辈病 → **年干**
   - 兄弟姐妹朋友病 → **月干**
   - 子女晚辈病 → **时干**
4. **时干落宫**：反映疾病**目前状态**，与用神落宫生克制化关系综合判断病性、部位、内外、程度、病因、病理、发展状况。
5. **空亡/伏吟**：原宫病灶转移，用**空亡转宫法**查新状态。

### 全息诊病思路
- **整体断法优于单宫断法**：九宫皆是病，亚健康即四柱外宫位问题，早防早治。
- **隐干为病因引子**：先从隐干分析导火索，再宫内综合神星门干宫属性多角度判读。
- **医药象意**：天心星乙奇为医药，天心=西医药，乙=中医药。临值符=名医名院高级药；临腾蛇=假医假药/巫婆神汉；临白虎=医术一流技术过硬；临太阴=医生心细；临开门丁辛=手术开刀。

### 关键格局病机判读
| 格局 | 病机含义 |
|------|----------|
| **击刑** | 灾病、别扭拧劲、不舒服。壬癸击刑巽四→肢体伤残疼痛；庚击刑艮八→车祸伤灾/肠胃病 |
| **门迫** | 破损。外主肢体伤残，内主脏腑组织坏损 |
| **反吟** | 急性病、病情反复 |
| **伏吟** | 久病慢性病、得病时间长、短期难愈 |
| **入墓** | 力量仅存20%，宝剑入鞘锋芒内敛 |
| **空亡** | 信息转移80%，仅留20% |

### 治疗择时择向指导
- **就医方位**：以克病神落宫之宫为首选，宜阳克阳阴克阴（同性相克力大）。
- **择时**：利用流月流日填实本宫、冲开病宫之时机。

## 实战案例精要（节录）

### 例一：前世炼丹童子，今世母子情深（2007.5.16 阳1局）
- **求测**：张小姐代问儿子健康、性格、学业、灾厄。
- **断验**：
  - 儿子脾气大固执（时干乙兑宫天英火+死门），内向不语（太阴），文化艺术擅长雕刻画画（兑宫乙丁太阴）。
  - 肠胃易炎（兑宫乙肠+丁炎）。
  - **自杀信息**：兑宫乙手+丁刀+太阴死门；**兔年凶险**（卯年填实震宫冲兑宫）。
  - 近两年惊悸大便不正（乾宫惊门+戌亥年填实乾宫+己壬癸）。
  - 今年易摔伤（流年乾宫六合癸足马星）。
  - **前世**：巽宫九天天宫+天任老人+丙火炉+辛颗粒=太上老君炼丹童子。
  - **童子煞未解**：喉咙易炎（巽引干乙喉+丙辛）、肺炎（乙气管+丙炎）、发烧（巽丙）。
- **调理**：移星换斗布局儿子房间，后身体好转。

### 例二：为爱妻求医无路（2007.6.8 阳9局）
- **求测**：陈先生代问妻子疑难病。
- **断验**：
  - 妻子内心抑郁狂燥急（日干癸合干戊兑宫地盘丙内心狂燥+伤门自狠）。
  - 潜伏8年（99卯年震宫冲兑宫），前年显苗头（05酉年填实兑宫），去年下半年加重（酉月填实兑宫）。
  - **阴宅问题**：西北角供神像（庚天芮乾宫），值符乾宫=阴宅七杀甲。
  - **处方**：晚上7-11点(乾宫时)移神像送西北寺庙，烧三柱香红布包走人后开。
  - **附体源头**：妻幼时庙台外小便、桥底小解带不洁附体。
  - **验证**：陈先生后车胎易扎（庚癸轮胎+丁坚硬+马星动）。
- **后续**：环境处理后病情明显好转。

### 例三：企业家健康策划（2007.8.24 阴3局）
- **求测**：孙先生自问健康、事业。
- **断验**：
  - 肝功能不好（日干庚艮宫=肝信息），肝火犯上头晕（玄武），早起口苦嗓子不适。
  - 右肾结石（乾宫癸肾+丁颗粒+庚硬），因第六颈椎（乾宫369数+九天=第六节）。
  - 血流不畅（乾宫癸血+庚阻碍）。
  - **环境应验**：右眼角痣（乾头九天高处丁眼癸痣）、大腿根生殖器上部痣（乾柱大腿九天上部丁男癸痣）。
  - 住房西北角高水龙头（乾柱管道九天高癸水开门开关）、西北灯不亮（丁灯被癸克九天高处）。
  - 东南窗堵/花草/小物（巽杜门乙辛窗+马星动）。
  - 腿部神经被堵（巽腿乙神经杜堵）。
  - 财运偏弱（日干庚入墓击刑），年底丑寅月填实恢复，明年丑寅年稳定发展。
- **调理**：25/26号上午9-11点(巽冲乾)去痣、清理东南窗、亮西北灯。

### 例四：都市丽人全方位预测（2007.9.17 阴7局）
- **求测**：周小姐自问健康。
- **断验**：
  - 右乳增生（日干甲坤宫戊乳癸壬奶马流庚硬杜堵，坤宫门迫不严重但值符难愈）。
  - 膀胱炎小腹痛（坤引干壬膀胱壬癸尿庚痛）。
  - **痣致病**：脊柱下痣（坤符柱癸）去痣后身心转化。
  - 心瓣膜开合不良（兑宫己戊心肌心景血辛瓣），引起血压不正常。
  - 现场环境处理后好转。

## 实操提示与避坑指南

1. **九宫格必须手绘**，井字格气场不聚，严重影响准确率。
2. **心法先于技法**：起局前心平气和、默念口诀，建立天人共振场。
3. **局数计算以农历月日为准**，年支序数按十二地支顺序（子1…亥12），时支同理。
4. **旬首仅由时柱决定**，与年月日无关；值符值使由旬首地盘落宫决定。
5. **天盘排布核心“旬首值符随时干”**，原宫九星随行，三奇六仪顺飞。
6. **八神排布看阴阳遁顺逆**，值符落时干宫，余神依序布。
7. **八门推运看旬首时辰起点**，按宫数顺/逆推至预测时辰，再顺时针布八门序列。
8. **隐干以时干加值使门为起点**，按天盘干序排布。
9. **空亡马星为关键补丁**：空亡宫信息转移80%，马星主动、驿马、交通、变动。
10. **“没吉没凶”贯穿始终**：断验时须结合具体人、事、时、空间，阴阳两面综合判读，切勿套用死格局。
11. **疾病预测重全息、轻单宫**：四柱天干遍布九宫，隐干为因，宫内组合为果，排除法圈定目标。
12. **医药择时择向**：天心乙奇为医药，克病神宫位为就医方位，同性相克力大，流月流日填实本宫冲开病宫为良机。

> “假传万卷书，真传一句话。” 掌握十一步流程与“没吉没凶”辩证思维，即得阴盘奇门精髓。
