# 道家秘传阴盘奇门遁甲十一步排盘实操流程与周纳羽实用阴盘体系交叉引用

> 本页面整合《凤麟奇门风水学》（王凤麟/凤麟易理体系）与周纳羽《实用阴盘奇门》两大道家阴盘奇门核心体系，系统梳理排盘实操流程、象意基础、宫害处理、意识起局、三合一修炼、护场反推等核心技法，建立两大家系的交叉引用知识网络。

## 一、 核心理论特色对照：两大阴盘体系的分水岭与共通性

| 维度 | 凤麟易理阴盘（王凤麟） | 周纳羽实用阴盘（周纳羽） | 共通核心 |
|------|------------------------|--------------------------|----------|
| **定局依据** | 月相（太阴运行） | 月相/意识时空定位 | **阴盘本质：依月相而非节气** |
| **转局频率** | 每时辰演一局 | 意识起局可超越时空限制 | **动态演局，信息量大** |
| **吉凶格局** | **没吉没凶**，象意阴阳双面 | **意识主导吉凶**，技法为辅 | **辩证观，扫除死格局** |
| **空亡用法** | 远空、近空、先天、后天多维断验 | 空亡为“镜子”、可躲藏、可填实、可冲动 | **空亡非凶，善用则灵** |
| **伏吟局** | 伏吟转宫有秘诀，可精准断事 | 伏吟动不起来，走罡步动磁场 | **伏吟主静，需动以化之** |
| **核心大法** | **风水移星换斗法** | **意识起局+三合一（技法/心法/神助）+护场反推** | **预测为调理服务，调理靠意识与行为风水** |
| **疾病预测** | 全息诊病，隐干为因，宫内组合为果 | 同，重“入局出局”、“封局心法” | **医易不分，象意即病机** |
| **符咒应用** | 烧符为主，贴符慎重（坤宫符墓禁贴） | 符咒配合意念、行为风水，心印手印即符 | **符随心动，意到符到** |

> **关键洞见**：两大体系均源于道家口传心授，**“没吉没凶”辩证观**与**“意识领先技法”**是共同核心。凤麟体系侧重排盘规范与移星换斗环境调理；周纳羽体系侧重意识修炼与实战心法（护场、反推、入局出局）。**学习建议：先掌握凤麟排盘规范与象意体系，再融入周纳羽意识起局与三合一修炼，方得阴盘精髓。**

## 三、 凤麟体系：十一步排盘标准实操流程

> 以下以 **2006年5月23日19时45分（农历四月二十六）** 为例，演示完整排盘过程。
> 四柱：**丙戌 癸巳 壬子 庚戌** → 阳七局，旬首甲辰壬。

### 步骤 1：排四柱
将起局阳历时间转换为干支（年柱、月柱、日柱、时柱）。
- **年柱**：以立春为界，万年历查得。
- **月柱**：地支固定，以节气“节”为界。天干由**年上起月法**推算。
- **日柱**：万年历查得，子时为日界（23点后属次日）。
- **时柱**：地支固定，天干由**日上起时法（五鼠遁）**推算。
- **简便记忆**：生合者定月（甲寅年寅月，甲己合土，生土者丙），克合者定时（丙辛日子时，丙辛合水，克水者戊）。基础命理可参考 [[bazi-mingli-xue-jichu-jiaocheng]]。

### 步骤 2：定阴阳遁局数
- **阳遁**：冬至后至夏至前。
- **阴遁**：夏至后至冬至前。
- **局数计算**：`(年支序数 + 月数 + 日数 + 时支序数) ÷ 9` 取余数（余0作9）。
  - 例：丙戌年(戌序数11) + 四月(4) + 二十六日(26) + 戌时(11) = 52，52÷9余7 → **阳七局**。

### 步骤 3：画九宫格
- **必须用九宫格（大方格分小方格）**，不可用井字格（四面透风、气场不聚、能量消耗、注意力分散）。
- **心法口诀**：默念“无极生太极，太极生两仪，两仪生四象，四象生八卦，八卦定乾坤”。
- **要求**：线与线交接紧密，格与格不相通，否则信息混乱判断不清。心平气和，产生共振场效应，达天人合一。

### 步骤 4：布地盘三奇六仪
- **原则**：阳局顺布、阴局逆布。序列：**戊己庚辛壬癸丁丙乙**（九宫数：戴9履1，左3右7，二4为肩，六8为足，五居中）。
- **操作**：几局戊落几宫，其余顺/逆飞布。
- **本案·阳七局地盘**：
  | 丁(4) | 庚(9) | 壬(2) |
  |------|------|------|
  | 癸(3) | 丙(5) | 戊(7) |
  | 己(8) | 辛(1) | 乙(6) |

### 步骤 5：找旬首
- **六旬首**：甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸。
- **查法**：以**时柱**查六十花甲子记数表。本案时柱**庚戌**，属甲辰旬 → **旬首为壬（甲辰壬）**。

### 步骤 6：定值符与值使门
- **值符** = 值班九星，**值使** = 值班门。
- **规则**：地盘旬首落在哪宫，该宫地盘星为值符、地盘门为值使门。
- **本案**：阳七局地盘壬落坤二宫 → 坤宫地盘星**天芮星为值符**，地盘门**死门为值使门**。

### 步骤 7：排天盘三奇六仪与九星
- **核心规律**：**旬首和值符随时干**。
- **操作**：看预测时辰时干在地盘落宫，将值符和旬首直接写入该宫，同时将旬首原宫地盘九星随之移入该宫；余下三奇六仪按地盘顺序依次填入各宫。
- **本案**：时干庚，地盘庚落离九宫 → 旬首壬加离九宫庚上，坤宫地盘星天芮移入离九宫。

### 步骤 8：排八神
- **八神序列固定**：值符 → 腾蛇 → 太阴 → 六合 → 白虎 → 玄武 → 九地 → 九天。
- **排布**：值符首先写入**时干所在宫（即天盘旬首落宫）**，余七神按阳遁顺时针/阴遁逆时针依次填入其他宫。
- **本案**：阳遁，值符落离九宫（时干庚宫），顺时针排布。

### 步骤 9：定八门
- **起点**：旬首地盘所在宫 = 值使门值班宫（旬首时辰内）。
- **推运**：按预测时辰在九宫顺序中推演值使门落宫。
  - 阳局按宫数顺序：坎1→艮8→震3→巽4→离9→坤2→兑7→乾6→坎1…
  - 阴局按宫数逆序：坎1→乾6→兑7→坤2→离9→巽4→震3→艮8→坎1…
- **填布**：找到值使门落宫后，**无论阴阳局均按顺时针（坎1→艮8→震3→巽4→离9→坤2→兑7→乾6）填写八门固定序列**：休→生→伤→杜→景→死→惊→开。
- **本案**：甲辰旬首壬地盘在坤2 → 甲辰时值使门在坤2。预测时庚戌时在艮8 → 值使门**死门落艮8**。顺时针布八门。

### 步骤 10：排隐干
- **原则**：**时干加在值使门上**，随后按天盘三奇六仪顺序（或地盘顺序）排一圈。
- **本案**：天盘三奇六仪九宫顺序：庚(离9)→壬(坤2)→戊(乾6)→乙(离9?)→辛(巽4)→己(艮8)→癸(坎1)→丁(兑7)→循环。时干庚加值使门死门(艮8)上，依序排布。

- 凤麟体系提供**标准排盘骨架**（十一步流程、象意标准），周纳羽体系提供**意识驾驭骨架的锋刃**。
