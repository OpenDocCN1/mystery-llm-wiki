### 阿弥陀佛心咒 —— 呼唤宇宙无限量光芒

#### 梵音与断字
```
namo amitabha / amitaha
na-mo  a-mi-ta-bha / a-mi-ta-ha
```

#### 中文注音
- **现代拼音**：南摩 阿弥陀佛 / 南摩 阿弥塔哈  
- **传统拼音**：南无 阿弥陀佛

#### 中译
> 虔诚皈依「宇宙无尽无量的光芒」  
> `amitaha`：梵文「无限量光芒」，指来自宇宙西方场域的智慧能量。

#### 能量特质
- **本质**：无量光芒、妙观察智
- **穿透力**：超越时空障碍，不受冤亲债主、邪魔外道干扰
- **智慧属性**：「妙观察智」——穿透表象见本质，超越逻辑思维的直观智慧

#### 核心功效
1. 阿弥陀佛日夜守护，心常喜乐、容光焕发、行事吉利
2. 光明护佑下远离灾难、冤亲债主、邪魔外道
3. 临终正念现前，往生极乐净土（自持或助念皆效）

#### 观想要点
- 想像咒音振动化为**无量金光**从西方普照，包裹全身
- 感受光芒**温暖、清明、安稳**渗透每个细胞
- 临终观想：阿弥陀佛与圣众现前，接引往生莲台

> **理论链接**：以 `E = hν` 计算，「无量光」即无限能量 [[buddhist-mantra-quantum-theory]]。净土宗「本愿他力」与吸引力法则同构：「心想事成」即振动共振。

| `padme` | 帕德美 | 莲花、智慧 | 阴性/智慧 |
| `hum` | 吽 | 成就、护持、密封 | 整合封印 |

#### 能量特质
- **本质**：爱、慈悲、同理心
- **连接力**：与万物建立美善连结，激活「集体潜意识」层面的慈悲共振 [[ESP通灵智慧体系#宇宙集体潜意识]]

#### 核心功效

2. 开放心扉：能接受爱、亦能给予爱
3. 持诵改善能量场、增强体质
4. 身心遭险时的「紧急护持网」

- 感受**慈悲光**从珠中流注全身，再向外扩散至一切众生
- 体会「自利利他、智悲双运」的融合感

### 心经咒 —— 到彼岸的自在船

#### 梵音与断字
```
tadyatha gate gate paragate parasamgate bodhi svaha
ta-dy-a-ta  ga-te  ga-te  pa-ra-ga-te  pa-ra-sam-ga-te  bo-dhi  s-va-ha
```

#### 中文注音
- **现代拼音**：达底亚塔 嘎碟 嘎碟 帕拉嘎碟 帕拉散嘎碟 伯地 斯瓦哈  
- **传统拼音**：怛姪他 揭諦 揭諦 波羅揭諦 波羅僧揭諦 菩提 薩婆訶

#### 中译
> 即说咒曰：去吧！去吧！向彼岸去吧！一起到彼岸取得智慧！吉祥成就！

#### 词义速查
| 咒字 | 含义 |
|------|------|
| `tadyatha` | 即说咒曰（启咒语） |
| `gate` | 去、前往 |
| `paragate` | 到彼岸 |
| `parasamgate` | 大众一起到彼岸 |
| `bodhi` | 圆满智慧、菩提 |
| `svaha` | 吉祥成就、圆满回向 |

#### 能量特质
- **双能量融合**：智慧（到彼岸）+ 慈悲（观自在菩萨摄受）
- **核心义理**：「空」——超越二元对立的究竟真理

#### 核心功效
1. 证得「心无挂碍、无有恐怖、远离颠倒梦想」
2. 通达宇宙智慧，心量广大
3. 超脱身心苦厄，获大自在

#### 观想要点
- 观想**观自在菩萨手持莲花**，引领自己与一切众生
- 一步步跨越「此岸」（烦恼生死）走向「彼岸」（涅槃智慧）
- 感受**慈悲护佑**与**智慧光明**同步灌注
- 安住于「自由自在、无挂无碍」的开阔境界

> **断字技巧**：梵文多为「两字一断」（如 `ga-te`、`pa-ra`），仅 `parasamgate` 含三字断 `sam`。详见 [[buddhist-mantra-quantum-theory#咒语断字法则]]。
