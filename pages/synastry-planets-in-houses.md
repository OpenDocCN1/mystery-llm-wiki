## 核心理论框架

### 天数、地数、人数三因互动模型

韩良露在《占星合盘的吸引力法则》前言中确立了合盘分析的三大基础因子：

- **天数**：本命星图中一出生就定下的这辈子所有命运（本命相位、星座、宫位配置）
- **地数**：身处的环境（宫位系统、地域经纬度、搬迁导致的宫位变化）
- **人数**：所有人对我们的影响（他人行星落入我宫位、我行星落入他人宫位）

> 所有命运的变化，都来自于天数、地数、人数三者的交互作用。

**宫位本质**：属于天地人三者中的**地数**，人际合盘中的宫位是「人数命运中的地数影响」。

### 行星与宫位的主被动互动模型

| 维度 | 行星方 | 宫位方 |
|------|--------|--------|
| **能量性质** | 拥有能量、主动发射 | 无能量、提供舞台/情境 |
| **典型角色** | 主动方、发起者 | 被动方、接纳者 |
| **心理体验** | 对宫位方有强烈认同感、吸引力 | 感受到被关注、受宠若惊，或压力 |
| **权利边界** | 可发起互动，但不可强迫 | **拥有拒绝/迴避权利**——「并不是每个月亮在你一宫的人说要来你家吃饭，你就非得做菜给他吃」 |
| **客观性要求** | 需尊重对方自主性，適可而止 | **必须保持客观**，才能决定顺水推舟还是婉拒 |

> **关键原则**：行星方带来恶缘时，宫位方可决定迴避或婉拒。君子之交淡如水——人际往来宜淡不宜浓，浓度越高，星图挑战越重。

### 三层分析框架：看合盘落宫必经三步

在关注「别人有什么行星进入我的宫位」时，**必须按序检查三层因素**：

1. **行星本身的本命相位好坏**（天数层面）
   - 例：某人本命太阳刑克火星/月亮，其太阳无论落入谁的何宫，都易在该宫位舞台产生冲突
   - 心理防御机制：当事人常归咎于「遇到坏人」，忽略自身本命相位吸引同频能量

2. **宫位本身的强弱与相位好坏**（地数层面）
   - 宫内有星 = 能量强，更易吸引他人行星落入
   - 宫内星有克相 → 落入行星即使无克相，也会因宫位本身克相而形成克相
   - 双重克相叠加 = 连锁负面效应放大

3. **行星落入宫位后，与宫主/其他宫位行星新形成的相位**（人数互动层面）
   - 空宫也可能因对宫/三方四正宫位行星形成相位
   - 例：对方太阳落入我一宫，与我七宫行星形成180°对冲
   - 「你的问题卡上别人的问题，别人的问题也卡上你」= 最困难的人际课程

> **实操口诀**：先看行星自带相位 → 再看宫位原有状态 → 最后看新形成相位。

## 逐宫核心解读精要（依书序摘录重点）

### 第1宫：自我形象舞台

- **太阳落入**：刺激1宫展现「单纯的个人本色」；太阳看重的是1宫的**个体本质**而非角色功能
  - 案例：作者1宫跨射手/摩羯，太阳射手友认同「吃喝玩乐」面，太阳摩羯编辑认同「工作责任」面
  - 若1宫有5/9宫星形成120° → 长期事业支柱但无私交
- **月亮落入**：**情绪依赖/喂养关系**；月亮方常找1宫吃饭、家庭式往来
  - 若月亮克相 → 1宫受情绪困扰；若1宫1/5/9宫星成吉相 → 1宫能安抚月亮
  - 亲子/拟亲子关系典型：子女月亮落父母1宫 = 剪不断情感脐带
- **水星落入**：中性沟通，**自由讨论无禁区**；水星方思考更明晰，1宫方点出隐藏动机
  - 水星克相 → 防卫性引发1宫不安
- **金星落入**：**情人眼里出西施**；金星方仰慕1宫外表/气质/生活型态，满足虚荣心
  - 金星克相 → 内在矛盾(自恋/欲望)或外在冲突(对方土星/海王星阻碍)
  - 时间久 → 1宫对奉承麻痺想脱离
- **火星落入**：刺激**生命活力欲望**；非单纯性欲，而是「在一起就有动力」
  - 火星克相 → 互相攻击能量；无克相 → 双方精力旺盛
  - 火星落7宫易冲突(要求扮演伴侣角色)，落1宫仅「做自己」契合
- **木星落入**：**鼓励1宫做自己**；区别于落7宫「视为伙伴互助」
  - 木星方发展程度决定激发1宫哲/文/教/灵层次
  - 木星非个人行星 → 私人互动少，多为社会文教合作；若木星合相对方月亮等个人星 → 兼有私交
- **土星落入**：**压制1宫自我表达空间**；1宫感存在感被打压
  - 职场/家庭常见；1宫本命有克相 → 压力倍增(土星同时触发多重克相)
  - 土星吉相 → 督促1宫聚焦责任目标；作者妹妹土星落作者1宫 = 教导照顾病人责任
  - **应对策略**：能躲则躲、避免一对一直冲、收敛锋芒、客观化「这是宇宙考验非针对个人」
- **天王星落入**：**「芝麻开门」咒语**；1宫卸下社会角色面具，展露原型面向
  - 作者天王星落父母1宫 → 非典型亲子、父母保持青春态、作者成父母照顾者
  - 天王星吉相 → 开拓新可能；克相 → 过度刺激让1宫不安
- **海王星落入**：**幻想投射/灵性共鸣**；海王星方希望1宫符合梦想
  - 吉相 → 灵性提升；克相 → 古怪行为让1宫困惑/觉得被欺骗
  - 落1宫+相位5宫 → 心灵共鸣式罗曼蒂克(区别金星肉体吸引)；海王星感受更强但不等于善待
  - **核心定理**：别人的不平衡→我的不平衡 → **躲得躲、不钻牛角尖、不随之起舞、制造团体场降低摩擦**
- **冥王星落入**：**深度影响/压力/改革**；力量过大不适合朝夕相处
  - 吉相 → 浴火重生/除旧布新；克相 → 操控/专制改革引发憎恨
  - 适合心理师/灵性上师角色(非同居)；作者冥王星落婆婆1宫 → 见面带玩、不干涉、保持距离

### 第2宫：财富资源舞台（自营商模式）

- **核心区别**：2宫=自己赚的钱(自营商)；8宫=他人钱/集资(股份公司)
- **太阳落入**：**互惠商业模式**——太阳=采矿人，2宫=矿藏
  - 太阳吉相 → 能干执行者+出资者佳配；不利私人亲密(2宫易感被物化)
  - 2宫高演化 → 影响太阳物质价值观(作者宝瓶2宫+太阳宝瓶董事长=公平原则经营)
- **月亮落入**：**家庭象征/实体给予安全感**；月亮方常在2宫家吃饭、住宿
  - 区别1宫：月亮2宫**必须在2宫家**，需要居家氛围；常涉及饮食分享
- **水星落入**：**商业沟通**；聊天全是生意、家族企业典型
  - 水星吉相 → 生意成；克相 → 2宫蒙损
- **金星落入**：**奢侈/享乐/服务业合作**；金星吉相 → 财富善用；克相 → 浪费/被包养
- **火星落入**：**金钱冲突高发区**；火星方衝動计划、慂恿炒股、对资源分配不满
  - 即使吉相 → 火星方看2宫存银行不顺眼、強勢督促投资 → 压力
  - **修为关键**：2宫心如止水不为所动；火星方察觉贪念能否熄灭
- **木星落入**：**受惠者是木星**；2宫提供资源，木星得幸運開採
  - 本命木星2宫≠木星赚钱，而是「物质领域享幸運」
  - 合盘：木星用2宫钱念书/旅行/社交 → 木星受益；木星极吉 → 反哺2宫
  - 2宫本不爱分享，但木星吉星 → 2宫给钱愉快、不心疼
- **土星落入**：**严肃沉重财务责任**；2宫基于责任给钱、给得不甘心→给完觉得变穷
  - 土星克相 → 2宫压力更大、阻止好机会、直接损害财务
  - 土星吉相 → 教导勤俭、保守理财；夫妻中2宫须防土星财务建议
- **天王星落入**：**非常规财务波动**；克相 → 突发暴富幻觉→暴雷(作者友中华电信认股倾家荡产)
  - 天王星股票=科技/泡沫型，跌无回；土星资产=房地/传产，给时间有利润
  - 吉相/高演化 → 激发2宫价值观反思(作者公公天王星落作者2宫=极致俭省+大额捐款，重塑金钱观)
- **海王星落入**：**迷惑/被骗/理想奉献**；2宫极难拒绝海王星(情感绑架)
  - 克相 → 海王星瞒着乱投资/骗钱；吉相 → 慈善/艺术/宗教奉献(非商业)
  - 父母海王星落子女2宫 → 支持学艺术
- **冥王星落入**：**掌控/代管/改造资源**；冥王星常成财务管理者
  - 案例：太太冥王星落先生2宫 → 管公司账/双薪分账/先生账付支出/太太账只进不出
  - 作者冥王星落父母2宫 → 强烈想改造父母挥霍 → 学占星后「给钱不干涉」关系改善
  - **核心**：冥王星把2宫钱当自己管的事；甚至想逼2宫去赚钱
  - 克相 → 大钱去无回；**客观评估是否该管钱、节制控制欲**=学占星目的

### 第3宫：日常沟通舞台（手足宫/有形法则）

- **3宫 vs 9宫**：3宫=有形世界法则(数理化通用)；9宫=无形世界法则(宗教/法律因文化异)
- **太阳落入**：**异姓手足/拜把兄弟感**；初期极易频繁见面、做无聊小事、轻松熟悉
  - 早婚者常选此类→后因缺乏月亮/土星/冥王星维系而离婚
  - 3宫缘分年轻时力大、易误判为终身伴侣
- **月亮落入**：情绪化日常交流、像兄妹相处、饮食起居分享
- **水星落入**：**沟通最顺畅**；思维同频、对话厘清彼此想法、媒体/写作合作
- **金星落入**：轻松愉快社交、分享美感/八卦/消费、非深度亲密
- **火星落入**：言语竞争/辩论/激烈讨论、一起跑腿办事、兄弟式打闹
- **木星落入**：扩展话题广度、鼓励学习/短途旅行/媒体传播
- **土星落入**：严肃沟通、规范表达、长辈教导晚辈、工作汇报压力
- **天王星落入**：离题万里/天马行空对话、打破思维定势、共同探索新知
- **海王星落入**：模糊/诗意/误解沟通、心灵感应式默契、或欺骗/自欺
- **冥王星落入**：深度心理剖析对话、掌握资讯主导权、改变思维范式

## 修为总结：从「自作孽」到「自作数」

> 「相較於『自作孽』的說法，作孽這個詞太過於批判，但我們可以說，每個人都活在天數、地數、人數的命運當中，我認為『自作數』才是其中的關鍵。」

1. **先檢視自己星图**：知道自己哪宫、哪星有克相 → 少跟人做该领域的事 → 纠纷率大降
2. **客观化人际能量**：把对方还原为「完整的人」而非单一行星投射 → 不窄化、不情绪化
3. **修行负面能量**：少一点执著/贪心/仇恨/愤怒 → 自己获益、周围人获益、世界少一点麻烦
4. **主动发展正面能量**：散发正向 → 吸引正向回馈 → 结善缘
5. **遵循正道行为标准**：合盘相位再好，不正道行为最终必生问题

> **最高理想**：如果世界上每个人的土天海冥都变好一点，落入别人任何宫位都能少造业、甚至积微德 → 整个世界变好一点。
