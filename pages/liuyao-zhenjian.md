## 概述

《六爻真鉴》由易学爱好者“愚”撰写，系统阐述了八卦六爻预测的**思维方式**、**一卦多断**操作体系与**飞宫伏神**、**象数组合**等核心技法。全书强调预测思维的“多维立体化”，主张以**转换太极点**实现同一卦对不同事项的多重断验，并通过表象（起卦六亲）与里象（伏神、变卦、六神）的交叉验证提升断准度。书中以大量实战卦例（如相亲卦、风水卦、婚姻卦）演示从外貌、性格、学历、职业、家境、姻缘成败到阴宅坐向的全息拆解，展现“象的组合学与翻译学”实战范式。

## 核心理论框架

### 预测思维方式：多维立体观

- **破除单一线性思维**：传统初学者多停留于“黑白、动静、生克”二元对立；本书主张思维应呈**放射状、球体状**展开，可在爻位、阴阳、六亲、卦宫、内外、主互变卦间自由穿梭。
- **太极点即观察基点**：同一卦中，每一爻皆可作“小太极”，预测师需依预测目的动态切换基点（如世爻为求测者、应爻为对方、父母爻为长辈/房产、子孙爻为子女/疾病/求财手段等）。
- **象具分裂性与包容性**：单一象（如妻财未土）在不同基点下呈现不同属性——既是对方本人，亦是对方父亲之财、对方母亲之子、对方兄弟之妻……实现**一象多解、多象定一象**。

### 一卦多断的转换太极点机制

| 转换步骤 | 操作要点 | 说明 |
|---|---|---|
| 1. 确立主太极 | 以卦宫五行为大太极，定出起卦六亲（表象六亲） | 世爻为求测者，应爻为首要对应对象 |
| 2. 按事项选用神 | 依预测主题（婚姻、疾病、财、职、风水……）在卦中锁定第一用神 | 如相亲卦以应爻妻财为第一用神 |
| 3. 转换太极点 | 以第一用神为新太极，重排六亲关系（里象六亲） | 妻财未土为太极时，子孙午火成其父母、兄弟卯木成其官鬼…… |
| 4. 多基点交叉验证 | 世爻、应爻、伏神、变卦、六神、月建日建时建等多基点同步建模 | 形成“六面体积木式”立体组合，提取全息信息 |
| 5. 象数归纳推演 | 将阴阳、五行、爻位、六神、納甲、三合六合、刑冲合害、进退伏反吟等要素编织成象数网络 | 最终以自然语言“翻译”出具体人事细节 |

> **关键口诀**：“起出卦的六亲不作用神时，是表面化六亲，也是表象；转换太极点后的六亲也是一种表面化的实质性六亲，也可以說是實質性的表象。”（《六爻真鉴》第三章）

### 飞宫伏神与表里象交媾

- **伏神非闲神**：每卦必排本宫伏神、对宫伏神（飞宫），伏神藏“潜在隐象、真实里象”，主后天变化、深层心态、隐性病灶、祖坟风水等。
- **飞伏生克吉凶**：
  - 飞克伏 → 伤身/事败
  - 伏生飞 → 泄气/耗散
  - 飞生伏 / 飞伏比和 → 相助/吉
- **表里象对照读心态**：表象（起卦六亲+年月日时）显露外在态度；表里组合揭示真实意图（如“表裡如一”还是“口是心非”）。

### 象数组合的“积木式”建模

1. **单一象**：阴爻=女性/柔/暗/弱；五爻=君位/领导/长辈；子孙=生发/青春/医药/快乐。
2. **双重组合**：爻位+六亲（五爻子孙=长辈喜乐/子女有出息）、阴阳+五行（阴火=双眼皮/隐疾）。
3. **多重组合**：爻位+六亲+六神+伏神+变爻+年月日时+卦宫……层层叠加成“六面体”。
4. **动静互换**：动爻是静的开始，静爻是动的开始；静爻亦可作用神、作太极点，不可弃之。

## 实战案例精要：相亲卦全息拆解

> **卦例要素**  
> - 癸未年壬戌月壬辰日丁亥时（旬空申酉）  
> - 本卦：巽宫风天小畜（初爻世、四爻应）  
> - 变卦：乾宫乾为天  
> - 关键动爻：四爻妻财未土(朱雀)动化子孙午火回头生合

| 预测项目 | 取用神/基点 | 核心象数逻辑 | 断验结果 |
|---|---|---|---|
| 对方年龄 | 应爻妻财未土 vs 世爻父母子水 | 应阴爻阴位+巽宫长女+子孙回头生 → 年幼活泼；世阳爻阳位+父母+乾宫老阳 → 年长成熟 | 女1980年生，男1973年生 |
| 身高体态 | 应爻妻财未土在巽宫 | 未土得月日帮扶→土厚/高大；巽木主长/苗条→木局限土 → 高挑结实 | 长得高、结实、健康 |
| 发质发色 | 六爻兄弟卯木(腾蛇) | 卯木受午戌泄气+合火库+腾蛇主细长 → 木衰黄、合长 | 头发偏黄、长发 |
| 脸型 | 五爻子孙巳火(勾陈)在巽宫 | 巽主面长额宽；巳火入月库+辰土泄气+化申金合圆 → 椭圆/申字脸 | 申字脸(鹅蛋脸) |
| 皮肤质地 | 妻财未土+巽宫弹性 | 土旺焦黑、巽木弹性制约 → 黝黑黄、有弹性 | 肤色黝黄、皮肤有弹性 |
| 眼皮 | 五爻巳火阴爻+化申金合 | 阴=双数、化合=双 → 双眼皮 | 双眼皮 |
| 面部瑕疵 | 五爻巳火化官鬼申金空+勾陈 | 官鬼=疤痕/青春痘、空=消失、勾陈=撑起/包 → 青春痘愈留疤 | 脸上有青春痘疤痕 |
| 胸部 | 四爻妻财未土 | 未土得月日旺+合围圆 → 土多肉多丰满 | 胸部丰满 |
| 腿部 | 二爻兄弟辰土(驿马木) | 月破值日不破+驿马木动 → 丰满修长 | 腿丰满且长 |
| 学历 | 妻财未土动化子孙午火冲父母子水 | 子孙冲父母=排斥读书；五爻父母静化空=家贫/师资弱 → 学历低 | 初中文化 |
| 职业 | 子孙巳火(妻财之父母)+伏神官鬼申金 | 子孙静化空=无固定长久财源；官鬼伏勾陈=非体制内/非官方庇护 → 靠手艺/打工 | 木竹制品厂打工 |
| 男方家境 | 乾内卦(世爻所在) | 乾金得岁月日生+四爻动生 → 环境优厚、善用资源 | 家境远好于女方 |
| 女方父母态度 | 子孙巳火(应之父母)真生世爻 | 真生=真心实意 → 喜欢男方 | 父母满意 |
| 女方本人态度 | 应爻动化子孙午火冲世 | 动=变、冲=排斥、子孙本吉反冲世 → 能说但话不投机、无好感 | 很能说但对男方无好感 |
| 最终分手 | 应世相害+应动冲世 | 子水未土相害+动冲 → 不和谐、别扭 → 土旺月(辰戌丑未)分手 | 土旺之月分手 |
| 阴宅风水 | 世爻父母子水为坐山 | 世爻重克冲+化子孙冲 → 坐北朝南变坐南朝北；西南丑土/巳火空 → 西南空缺有风 | 坐南朝北、西南空缺 |

## 关键技法索引

### 用神选取层级（一卦一断→一卦多断）

1. **持世** > **日月建** > **动爻** > **月破** > **旬空**（传统《天心正宗》《卜筮指要》口诀）  
2. **一卦多断首推“分真假六亲”**：同一六亲重现时，以**根源性、实质性**者为真用神，其余为附属象（详见第四章“文之真假”）。

## 学习路径与进阶建议

1. **夯实基础**：精通纳甲、六亲、世应、六神、刑冲合害、进退伏反、旬空月破等《增删卜易》核心理法 → 参考 [[liuyao-qimeng-jieyao]]、[[liuyao-jichu-rumen-qinglan]]、[[liuyao-lifa-jinjiie-qinglan]]。
2. **建立象库**：按“单一象→双重组合→多重积木”三级积累个人象义卡片，勿生搬硬套梅花象数。
3. **实战复盘**：以本书相亲卦、风水卦、地天泰卦、山天大畜卦为模板，自行起卦复盘“表象/里象/转换太极/飞伏生克”全流程。
4. **跨体系对照**：
   - 皇极六爻二元定位兼象定论 → [[huangji-liuyao-tixi]]、[[liuyao-hunyun-mifa]]、[[liuyao-zaihuo-yuce]]
   - 曲炜《六爻真传》爻位四层次/四建运用 → [[qu-wei-liuyao-tezhunban-jiangyi]]
   - 马志川《实战点窍》卦爻四层次制约/应期七大法 → [[liuyao-shizhan-dianqiao]]、[[liuyao-shizhan-da-quan]]
   - 王虎应因果观/姻缘专断 → [[liuyao-yinguo]]、[[liuyao-yinyuan-yuce]]、[[liuyao-yihui-zhimi]]
5. **心法修养**：预测师兼具心理咨询、医理常识、地理风水、行业知识（股票、法律等），以“预防为主、善意引导、客观告知”履行职业伦理（第二章“预测师预测常识”）。

## 版本与传承说明

- 作者自称“愚”，年近四十，1994年起跟莫先生学易，十余年实战心血结集。
- 全书分“预测思维方式”“预测师常识”“一卦多断概述”三章，后续章节（象义详解、更多卦例）因归档截断未全录入。
- 书中多次引用《易隐》飞伏神法、《天心正宗》用神取舍、《增删卜易》基础理法，属“新派实战”向传承。
