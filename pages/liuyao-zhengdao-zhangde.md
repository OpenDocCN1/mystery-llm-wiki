## 概述

张德《六爻正道》是以**卦意预测法**为核心的六爻预测体系，主张「轻六神、去格局、废用神、重爻义、析组合、顺卦意」，力图纠正传统六爻与新派六爻的偏差，确立六爻预测的客观规律。该体系将六爻预测准确率从 60% 左右提升至 95% 左右，强调**共性法**用以主动测来意，**消长法**用以推演发展趋势、断吉凶应期，实现「返璞归真、道法自然、大道至简」。

## 核心理念

### 卦意预测法
- **定义**：六爻模拟客观现实，卦爻结构组合、排列用意自有定则，卦师应「领会卦爻结构组合、排列用意，看看在该测项中卦要说什么、怎么说，然后无条件地绝对服从、紧扣卦的原意」。
- **原则**：不以主观意愿设定解卦思路，不游离曲解卦意，不被提问者牵着鼻子走，实现**人卦合一**。
- **特色**：纯粹采用逻辑联系断卦，简单、准确、细致、规律，快速看清测项来龙去脉。

### 共性法 与 消长法
| 方法 | 用途 | 特点 |
|------|------|------|
| **共性法** | 主动测来意 | 简洁实用，乃六爻固有规律，可将卦爻扫描的客观情形刻画淋漓尽致 |
| **消长法** | 推演发展趋势、断吉凶应期 | 结合「动静旺衰法」「穷则变，变则通」易理，提出整体或局部可行性方案，趋吉避凶 |

### 否定自我、服从真理
> 「不迷信权威，不迷信自我，只服从真理」是张德坚定准则。  
> 2005 年其著作《续六爻新大陆》《真命六爻》属新派体系，已主动淘汰并公开声明。  
> 主张学者需具备「否定自我」勇气，跳出一厢情愿的证明循环，以实践检验真理。

## 教学体系（2010 大纲）

《六爻正道》教材分两部分：**书面文字（三成含金量）** 与 **心传口授（七成含金量）**。

### 第一部分：书面文字精华理论

#### 第一讲：六爻预测机理方针
- 易者象也，比类取象即对应模拟。
- 卦爻反映主观心态与客观事态相互影响导致的事态走势。
- 每卦有既定切入角度与反映方式，卦师须绝对服从卦意。

#### 第二讲：传统六爻真正缺陷
1. 以主观意愿为中心，法无定法错觉  
2. 世爻与持世之爻不分  
3. 卦爻作用关系混乱  
4. 六亲分析与梅花易数、卦名、卦爻辞混用  
5. 偏重断语、神煞、六兽、外应  
6. 忽视世应，单凭「取用神」断卦  
7. 代测不识「卦站在他人立场」原则  
8. **核心缺陷：没有顺从卦意**

#### 第三讲：坚决淘汰新派六爻
- 研读赵奎杰、李涵辰、席学易、岳邦定、董元辰、袁炜明、饶宜献、召邑子、张代祥、陈春生、黄镜波、孙元希、刘树明等新派著作。
- 新派定格局法多达 11 种，均源于旺衰抽象化曲解，**格局非六爻固有，实为人为移植、节外生枝**。
- 新派可取处：严密推理逻辑、卦宫理论、爻作用关系借鉴。
- **核心缺陷：更加没有顺从卦意**。

#### 第四讲：六爻预测模型规范（28 节）
> 原则性归纳，非依经典权威或主观喜好，乃经验教训理性思考萃取。

| 节次 | 主题 | 关键结论 |
|------|------|----------|
| 1 | 月日 | 月令在先（70%）、日辰在后（30%），同功同权；原象月日为基础坐标，进行时月日不可相提并论 |
| 2 | 旬空 | 只依起卦日干支查；旺不为空、动不为空、冲实不空；进行时旬空无实用价值 |
| 3 | 入墓 | 伏入飞墓、静入月日墓、动入变墓；旺相入墓出墓有用 |
| 4 | 未戌土 | **未戌土照样生金**，非新派所谓「脆金」 |
| 5 | 刑害 | 刑=道不同相伤，害=妨害；作用按合冲生克处理，象义上刑表不协调、害表拆散 |
| 6 | 相并移位 | 卦中相同地支非「相并/移位/隔山化爻」；持世之爻=世爻态度方法，非世爻本身 |
| 7 | 爻划象义 | 爻划仅反映动静变化，强加树杈、孔洞等象义属践踏本质 |
| 8 | 综卦 | 原理简单：透明桌子底下看；原综卦义相同、互补；非技法范畴，理论不行综卦照样断错 |
| 9 | 过去将来 | 「阳动主过去、阴动主将来」无普适性；从月日、爻位、动变、应期距离综合考虑 |
| 10 | 卦宫世应 | 六亲以卦宫五行为中心（太极），持世之爻仅两仪之一仪；世应为社会公共立场重大标志 |
| 11 | 世与持世 | 八字日干≈卦宫，非持世之爻；持世=世持（持着、凭着） |
| 12 | 卦位爻位 | 卦位：上下(高低)、内外(本地外地)、先后、远近；爻位：反映国政/企业/家宅/人体等硬性一对一象义 |
| 13 | 梅爻混用 | 梅花易数断法随意性大，六爻具独立运算机制，**非但不靠梅易参断，更会产生干扰** |
| 14 | 游魂归魂 | 仅反映世爻升降，不能定吉凶，象义笼统常矛盾卦意，无实用价值 |
| 15 | 进退反伏 | 化进=力量增强，化退=力量削弱；伏吟=动如不动、变如不变；反吟=反复动荡；**六爻不论卦象反吟** |
| 16 | 装错了卦 | 六爻框架严格推演，装错卦不以「道法自然」为幌子 |
| 17 | 世应易位 | 世应位置经八宫卦序严格推演，非任意指定；姜文华「世应易位」属想当然发明 |
| 18 | 太极裂变 | 本质同随机起卦，硬性规定动爻数，不如重摇具针对性；王虎应受《铁板神数》启发，实为注射外来元素 |
| 19 | 纳支新说 | 纠正「震卦反装」等谬误；京房纳支依天文历法、音律、乾坤父母生六子法，乾震纳支相同故有伏吟现象 |
| 20 | 纳甲天干 | 六爻重支；天干仅用于查旬空、排六神 |
| 21 | 六亲转换 | 以卦宫五行为中心定六亲为唯一正确；世爻/持世之爻为太极坐标均属人为移植，日卦实证「卦宫定六亲」唯一性 |
| 22 | 动化虚化暗化 | 动化主流；虚化功能≈静爻；暗动非老阴老阳但表暗中行动，静卦可参照处理，有明动经卦中暗动不改变卦 |
| 23 | 卦气 | 卦宫系统已由六爻/地支/六亲具体化，**卦气非固有机制，不用** |
| 24 | 卦身 | 早见于《卜筮正宗》理论无例证；遇卦身不上卦不等于「事不出现」；算错卦勿赖卦身 |
| 25 | 六神 | 排布仅依日（二十八宿），三项原象中最轻；只能增感情色彩，**不参与吉凶判断**，前提符合六亲象义 |
| 26 | 神煞 | 唯桃花、驿马、墓库有运用价值，实为地支旺衰状态形象化比喻，具天文时空背景 |
| 27 | 依理取象 | 规律具必然性/可复制性/可操作性；六亲与地支密不可分；详列六亲象义、月破/空亡/六合/六冲/三合/半合/进退神/反伏吟/长生/墓/绝等核心象义 |
| 28 | 外应 | 兆象与所测事深层一致；卦直接反映、外应间接反映，两者相对独立；**外应可遇不可求**，严格须突如其来动态信息 |

#### 第五讲：六爻预测功能定位
- **地支信息**：主要体现六亲、时空、物质有无及相对大小、作用形式；方位、五行属性、具体数目、颜色、生肖微乎其微且缺乏规律性。
- **一卦多断**：六爻主动态信息，**一卦只能包含最关心/最强烈信息**；《卜筮正宗》云「莫若名利祸福寿夭逐件分占」；大小运限为人为曲解卦意、试图以六爻替八字的失败尝试。
- **测此应彼**：卦爻舍远报近、舍轻报重、舍静报动、舍喜报忧、舍他报己，乃主观关涉与客观情形共同作用，**明智做法：抛开先入为主，只顺卦意解读**。
- **测当天/测某事**：卦爻按客观现实排兵布阵达到最佳资源配置，原则上不用此卦断其它。

## 关键术语对照表

| 术语 | 本体系定义 | 传统/新派常见误区 |
|------|------------|-------------------|
| **持世之爻** | 世爻在这件事上所持态度/方法（世持），非世爻本身 | 误作「我」或「用神」核心 |
| **卦宫** | 太极、六亲定位中心、社会公共立场 | 常被忽视或误以持世之爻代替 |
| **旺衰** | 考察人事物「一直以来、当前、可能延续」的时空状态 | 抽象为格局、喜忌神 |
| **月破** | 悖时、残缺、被分裂、没兴趣、无能等 | 单论「破」字吉凶 |
| **空亡** | 没有、虚无、不确定、优柔寡断等 | 机械套用「旬空」「化空」 |
| **六神** | 仅增感情色彩，前提符合六亲象义，**不参与吉凶判断** | 常作断验主依据 |
| **格局** | **非六爻固有，人为移植，坚决淘汰** | 新派核心基石，分喜忌定吉凶 |

## 结语

《六爻正道》以**「顺卦意」为纲，「共性法」「消长法」为目**，在《增删卜易》《卜筮正宗》等经典与赵奎杰、岳邦定等新派著作之间开辟出一条**逻辑自洽、实战准确率 95%+**的客观规律之路。其教学大纲系统规范了月日、旬空、入墓、刑害、爻位、六亲、神煞、外应等 28 项模型细则，并通过「心传口授」解密六十四卦卦爻组合共性，使学者能在实战中做到「胸有成竹、底气坚实、游刃有余」。

> **张德语录**  
> 「理论学术的建立，是在简单、原始概念之上的；思想的产生和深入，也是来源于人们对朴素世界、简单问题的深入思考。如果真正懂得了简单，那么这个世界上就不存在复杂。」  
> 「否定自己，是走向成熟的必要条件，也是成熟的重要标志。在真理面前，没有谁有资格自负。」
