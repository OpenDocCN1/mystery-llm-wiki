## 紫微斗數安星法核心體系

本頁面依據勸學齋主《紫微高階之五·斗數人須知》系統整理，聚焦紫微斗數排盤實務中的關鍵疑點與作者定論，涵蓋派系源流、時空校正、星曜安置爭議、四化體系、大限起例、論命三要與實戰流程。

---

## 一、紫微斗數派系源流與分類

### 明澄派（透派）與南北派演變
- **明澄派**：明朝梅香開創「透派」，即明澄派。第十三代張耀文著《五術占卜全旨》，全家移民日本傳播（改姓川島），大弟子阿部泰山為日本頂尖斗數大師。早期台灣斗數書多源自日本翻譯，間接激發南派老師出現。
- **北派**：林真秘藏《北派道家紫微斗數》、陳岳鈴（英華）北派紫微斗數。宮位名稱、星曜體系與現代通行版本迥異（如官位十二宮、星曜含天虛天貴天印等）。
- **南派**：
  - **南派中的北派**：明澄派、觀雲主人王裁珊《紫微斗數宣微》（論節氣/月令排盤）。
  - **南派中的南派**（現代通行）：不論節氣，只論月份。依據《陳希夷紫微斗數起例歌訣總括》「何用經堂論五星」（一說「不用琴堂講五星」）為理據。
- **作者立場**：早期從北派轉南派，以自身命盤驗證（北派命宮卯、南派命宮辰），認同南派「不論節氣」更準。

### 陳希夷祖師與古籍淵源
- **道藏經載**：唐代呂純陽創，傳麻衣道者，至陳摶（希夷）多元化。
- **嘉靖版《紫微斗數全書》**：明朝進士羅洪先（王陽明弟子）序推薦，稱陳希夷十八代孫出示。約六百年傳承中歷經增刪改易。
- **其他古籍**：觀雲主人《紫微斗數宣微》（1935）、王亭之八卷樓鈔本、《遊藝錄》（俞樾）、《紫微斗數全集》《紫微斗數捷覽》（1581）。

## 二、排盤重點與疑點：時空校正篇

### 出生資料準確性：經緯度時差與真太陽時
- **核心原則**：命理運用天干地支蘊含陰陽五行，出生地經度不同，陽氣升降時刻不同，必須校正至**真太陽時**。
- **校正步驟**：
  1. 確定出生地屬哪個**理論時區**（以格林威治為零時區，每15度一區）。
  2. 查出生地經度偏離理論時區中心線（東加西減，**一度 = 4分鐘**，一分度 = 4秒）。
  3. **法定時區**（政治/經濟劃分）→ 還原理論時區 → 校正真太陽時。
- **夏令時間**：必須還原至標準時間（如美/加三月第2個週日開始，11月第1個週日結束；歐洲、俄羅斯、澳紐、巴西規則不同）。
- **實用工具書附表**：馬來西亞（謝翰仁撰）、新加坡（洪其蓮撰）、各國主要城市校正表（蘇筱晶製）。

### 子時早晚子爭議：作者定論「一律算新一天」
- **古代計時**：圭表、日晷、刻漏（西漢）、流沙（明初）、渾天儀（張衡）。官方五更報時（戌亥子丑寅）。
- **十二時辰細分**：北宋始分「初、正」（子初、子正），對應西洋24小時制（子時=23:00-01:00）。
- **爭議**：僅子時分早子(23:00-00:00)/晚子(00:00-01:00)屬不同兩日，他時辰不分。
- **作者定論**：**針對子時出生者（晚間23時起），一律算作新的一天**。理由：百思不得其解，且符合實務驗證。

### 閏月排盤與論命：十五日亥時分界
- **閏字源義**：《周禮》「閏月王居門中」，《說文解字》「閏，餘分之月，五歲再閏」。實為「十九年七閏」。
- **排盤分界**：
  - **閏月十五日亥時（含）之前** → 比照該月排盤（月系星、年干系星、年支系星、時系星均同該月）。
  - **閏月十六日子時（含）之後** → 比照次月排盤。
- **流年閏月論命**（採正月命宮在流年斗君）：
  - 閏月採「換宮不換干」（次月與閏月同宮，流月干不變）。
  - 次月採「換干不換宮」（同宮，自用其流月干）。

## 三、星曜安置爭議：四大派系與雙軌制

### 火星、鈴星：四大派系排法差異表

| 派系編號 | 核心口訣/規則 | 代表著作/作者 | 是否順數至生時 |
| :--- | :--- | :--- | :--- |
| **壹** | 年支三合定子時位，**不再順數** | 嘉靖版《紫微斗數全書》（伊力點校）、文誠堂刊本 | 否 |
| **貳** | 年支三合定子時位，**不順數**；巳酉丑：火戌鈴卯 | 謝繁治《周易與紫微斗數》、阿部泰山、吳情 | 否 |
| **參** | 年支三合定子時位，**順數至生時支**；巳酉丑：火卯鈴戌 | 梁湘潤、觀雲主人、陸在田、破空、天滴子、天乙上人、李達威、余雪鴻、張寶丹、顧祥弘、張耀文、廣照禪群 | **是** |
| **肆** | 年支三合定子時位，**順數至生時支**；巳酉丑：火戌鈴卯 | 南北山人、阿部泰山（另著）、吳情、清俞樾《游藝錄》 | **是** |

- **關鍵差異點**：巳酉丑年生人火鈴位置（參：火卯鈴戌 / 肆：火戌鈴卯）及是否順數生時。
- **作者實務採用**：**派系參**（順數至生時），論「火貪格」「鈴貪格」皆驗，但稱須更多角度參研。

### 天馬星：命馬、月馬雙軌制
- **發現**：不同書/軟體排盤，天馬星宮位不同。經長期驗證，**生年地支與生月地支排的天馬皆有作用**。
- **命名區分**：
  - **命馬**（原年馬）：以**生年地支**安星。避免與流年馬口語混淆而改名。
  - **月馬**：以**生月地支**安星。
  - **流年馬**：流年地支安星。
- **命馬安星表**（年支三合）：
  - 寅午戌 → 丑
  - 申子辰 → 未
  - 巳酉丑 → 寅
  - 亥卯未 → 申
- **月馬安星表**（月支三合）：同上，以月支論。
- **代表著作**：年馬派（梁湘潤、觀雲主人）；月馬派（張耀文、觀雲主人、南北山人、陸在田、破空、天滴子、天乙上人、李達威、余雪鴻、張寶丹、顧祥弘、阿部泰山、陸斌兆/王亭之、廣照禪群）。

### 空星：七顆精簡三顆，空宮可塑性理論
- **七顆空星來源**：
  1. **天空**：年支順前一宮（屬年支系星，非地劫組合）。
  2. **地空、地劫**：固定組合。
  3. **旬中空亡**（旬空）：六十甲子十干配十二支，每旬餘兩支（如甲子旬空戌亥），佔兩宮。
  4. **截路空亡**（截空）：陽宮逆行（甲申乙午丙辰…），陰宮逆行（甲酉乙未丙巳…），佔兩宮。
- **作者精簡策略**：**去除小空留大空**，只留**天空、地空、地劫**三顆。理由：七顆分散佔七宮，大限/流年命遷必逢一空，不分強弱寸步難行。
- **空宮可塑性理論**：
  - **空宮如空杯/空桶**：可裝補藥或毒藥、啤酒或烈酒，「近朱者赤，近墨者黑」。
  - **完整論述**：「容易學好，也容易學壞。因人性好習慣難『養』成，壞習慣易『形』成，故被誤解易學壞。」
  - **運用法則**：嚴選優良材料（知識/經驗）丟入桶中，加上特調 → 特殊產品。命坐空宮者**不要拒絕老天爺給的禮物，持續吸收學習**。
  - **空宮借對宮論命**：僅論**內性**（遷移宮為陰/內性，年紀大或常在外打拚才顯現）。大小星曜、生年四化可借，**宮干自化不可借**（自化只影響對宮星性）。

## 五、限運體系：小限不用、大限歸一命宮

### 小限：作者不採用，採太歲派論流年
- **小限起例**：四墓庫起歲（寅午戌起辰/水庫、申子辰起戌/火庫、巳酉丑起未/木庫、亥卯未起丑/金庫），男順女逆。
- **設立邏輯**：水火相剋、金木相剋「互發為用」。
- **作者棄用理由**：
  1. 太歲是宇宙流行之氣（如壬寅年寅宮流年命宮、壬干四化），人為小宇宙不可自外於大宇宙流年氣數。
  2. 小限採該歲干支發用較呆板，未考慮流年環境。
  3. 流年太歲論不出之事，應加強功力，**不可抓小限當事後諸葛**。

### 第一大限：統一從命宮起，不分父母/兄弟宮
- **古籍分歧**：
  - 嘉靖版《全書》卷二：陽男陰女從命前(父母宮)起，陰男陽女從命後(兄弟宮)起。
  - 南北山人《明版今注》載三種說法（命宮起、命前起、命後起）。
- **作者依據統一為「命宮起」**：
  - 觀雲主人《宣微》（1935）、俞樾《游藝錄》、顧祥弘《氣數命理寶鑑》皆從命宮起。
  - 陽男順、陰男逆、陽女逆、陰女順。
  - **實驗驗證：論斷皆準確無疑。**

## 六、星曜吉凶評價體系：擱置廟旺失陷，改論宮星五行生剋

### 廟旺失陷體系混亂無準據
- **等級不一**：三等(廟平陷)、四等(廟旺失陷/廟旺平陷)、五等(廟旺得地平陷)、七等(廟旺得地利益平和不得地陷)。
- **同星異論極大**：貪狼在卯（廟/平和/利益/地）、巨門在丑（旺/陷/不得地）、巨門在戌（多陷平/中州派獨旺）。
- **理論宣稱**：廟旺吉則大吉凶則不凶；失陷吉則無力凶則大凶。
- **作者實測**：**無論採哪本書曜度，無「廟旺逢忌不凶」剋應**，且分等無標準不一致。

### 作者替代框架：宮星五行生剋制化（三命支干說）
- **核心觀念**：星曜自有星性，入宮即落入環境，與宮位天干/地支/納音五行及藏干產生**生、旺、退、煞**作用。
- **三命支干（《陰陽元經》）**:
  - **一命**：干支納音同一五行（如癸亥：水水大海水） → 環境單純，非好即壞。
  - **二命**：干支納音兩種五行（如辛卯：金木松柏木） → 環境雙重。
  - **三命**：干支納音三種五行（如甲子：木水海中金） → 環境複雜，好中有壞壞中有好。
- **星曜藏干**：天機(乙木/一干)、貪狼(甲木癸水/二干)、巨門(己土辛金癸水/三干)。
- **結論**：宮星五行複雜度決定吉凶層次，**相剋削弱宮氣星氣，逢忌破壞宮氣星氣產生負面星性**。詳細論述見勸學齋斗數七書。

## 七、四化體系：庚干定「陽武陰同」，天同化忌為鐵律

### 庚干四化歷派見解眾多
陽武陰同、陽武同陰、陽武府同、陽武輔同、陽武輔相、陽武府相、陽武同相、陽武陰曲（俞樾《游藝錄》）。

### 作者堅持「陽武陰同」鐵律
| 年干 | 祿 | 權 | 科 | 忌 |
| :--- | :--- | :--- | :--- | :--- |
| **庚** | **太陽(武)** | **武曲** | **太陰** | **天同** |

- **反駁「陽武同陰」派**：彼稱「庚干若陽武陰同，太陰化科；癸干破巨陰貪，太陰又化科，太陰豈能兩次化科？」
- **作者反駁**：
  1. 「陽武同陰」會導致太陰**兩次化忌**，彼未解釋太陰可兩次化忌之理。
  2. **太陰主清明（清潔明亮），化科主清整，兩次化科合理無疑。**
  3. 觀察驗證：庚干整理家務窗明幾淨（太陽化祿主光明）；癸干東西落一落就好（破軍化祿）。
- **補充鐵律**：**庚干天同一定化忌**。
- **實務觀察法**：
  - **天相化忌** → 衣著不合身、邋遢、男生常掉衣襟；在大福/本福則破財。
  - **太陰化忌** → 住處整理狀況差（詢問當事人易失真，需提醒注重家裡整齊）。

## 八、斗君：由流命推算，雙重作用

### 斗君算法：流年太歲宮位起正月，逆數生月，順數生時
- **公式**：流年斗君 = 以**流年太歲宮位（流年命宮）起正月** → **逆數至生月宮** → **從該宮起子時順數至生時支**所得之宮。
- **例**：庚寅年，九月辰時生。寅宮起正月，逆數九月在午宮，午宮起子時順數辰時得**戌宮** → 此人每年流年斗君永在流年財帛宮。
- **固定規律**：命盤寅宮在何宮，流年斗君永在對應流年宮（命宮→流年命宮、兄弟宮→流年兄弟宮…）。

### 斗君雙重作用
1. **流年斗君即流年正月命宮**：流年逐月命宮論法以此為準。
2. **斗君盤命宮**：自成「斗君盤」，另具斷驗功能。

## 九、論命三要與實戰四部曲

### 斗數三要：宮性、星性、四化
#### 宮性
- **十二宮分天地人**、宮位干支五行局特性（木火土金水局特性表）。
- **結構原理**：四正（對沖）、三方（加會）、六合（合併）、六害（穿）。
- **宮位體用論**（河洛理數）：
  - 疾厄為命之體（一六共宗）、田宅為財庫（一十推庫）、官祿為命之用（一九推氣數）、交友為一氣生死位（一八推）。
  - 應用：論雙胞胎、六親、股東、桃花、財庫、三方四正。

#### 星性
- **核心原則**：**星無原罪、星無吉凶**；皆有正負面性。
- **十四正曜正負面剖析**：紫微/天機、太陽、武曲/天同/廉貞、天府/太陰、貪狼/巨門、天相、天梁/七殺/破軍。
- **輔佐煞化曜**：祿存/羊刃/陀羅、命馬/月馬/孤辰/寡宿/空星、左輔/右弼/文昌/文曲/化祿、化權/化科/化忌。

#### 四化之性
- **宮星四化關係比喻**、剛柔並濟、雙祿交流/明暗祿交流/祿馬交馳/祿忌交戰/祿科解忌/一忌抵三吉/忌多反吉辨偽/福星不忌辨偽/五福壽星全破祿存沖破。

### 論命四部曲實戰流程
1. **第一部**：先了解命造格局及個性 → **首重我宮（命宮）格局**（四化動態、命財官宮干四化）。
2. **第二部**：每個大限順著看一遍 → 他宮格局、**三方四正沖三方為反弓忌**、迅速看出一生功課（**忌星在哪宮重點關注**八大線：命遷、兄友、夫官、子田、財福、父疾）。
3. **第三部**：論大限 → 本生年四化在大限盤宮位、四化論大限（大限與本命好條件合看）、**每個大限化忌追論六親線**（600+頁詳細對照表：大限在十二宮 × 化忌飛入本命十二宮）。
4. **第四部**：論流年、流月 → 明白大限論法後再論流年，掌握本命/大限/流年三層比重。

### 常見問題

### 驗盤須知
- 必須有正確出生地、年月日時分。
- 以**三時斷法**驗證（午時報時 → 排午/巳/未三盤驗證）。
- 剖腹產擇日：規定**時辰進氣/氣純前20分鐘用刀**（如未時要求13:40用刀，台北加6分為13:46實際已進氣）。
