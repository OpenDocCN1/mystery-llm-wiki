## 格局详解

### 游子课

#### 定义与成因
- **核心条件**：三传皆土（辰、戌、丑、未），遇**旬丁**或**天马**为用神。
- **象义**：土为季神归墓，主巡游考绩；旬丁主动速，天马为驿递之神。身势摇动，使人好游，故名“游子”。统“观”之体，乃云萍聚散课。

#### 经典注解汇编
| 来源 | 核心要点 |
| :--- | :--- |
| **《订讹》** | ① 三传皆土，或见旬丁、二马。土为季神有巡游象。旬丁二马主动，使人好游。见天马又名“海角课”。主利出行、不利守静、病凶婚阻、逃难获、天阴不雨。支二课加干二课为用，或传送白虎为用，主动更甚。未戌丑阴传阳欲在家远出；戊未阳传阴欲在外思归。丑加辰破游、戌加未衰游、返吟四季复游。传值墓神煞害主冤家逼迫；传值合龙戏驿主万里奋飞。斩关并为绝迹（如范蠡、张良）。与淫泆并主私欲远行；与天寇并主盗贼远匿；与行年并身欲逃亡。五墓四杀并神将凶，主事迍邅、岁内官灾、三年破败（应观初六“童观”凶）。遇三奇六仪吉将、年命日辰有冲克救神可解祸为吉（应观六四“观国之光”吉）。 |
| **《大六壬通解》** | 补充：戊未为阳传阴欲在外思归；丑加辰破游、戌加未衰游、返吟四季复游。传值墓神煞害主冤家逼迫；合龙戏驿主万里奋飞。斩关并绝迹。淫泆并因阴私欲逃；天寇并因盗欲逃；行年并主身欲逃。五墓四煞并神将凶主迍邅破败。年命日用旺相乘吉将传得午卯子即华盖乘轩大吉。 |
| **《观月经》** | “何类名游子，五坟稼穑同。三传皆四季，恶事亦相攻。病者应难愈，逃走与西东。破财三年内，官灾在岁中。三传如有救，反祸却为通。” |
| **《心镜》** | “三传四季有六丁，不然天马又相并。占身欲出名游子，逃者天涯地角停。中见天魁为天马，末于大吉利斯成。若值墓神并杀害，恐有冤家来逼刑。” |
| **《袖中金》** | “三传俱季名曰游子。若旬中六丁与天马上卦者，主其人若不远行必欲逃亡，占捕盗难获。” |
| **《指窍》** | 四季相传分四时：春稼穑、夏游子、秋地角、冬五墓。逆传四季亦分四时占验。四季为稼穑，辰为五阳之促、戌为五阴之促，名老阳老阴，病者气短、物价高。辰戌无贵人凶。辰罡戌魁，经魁经罡，压宅宅凶、压人人困。 |

#### 实战案例
> **案例一**：同治癸亥年戊月癸丑日辰时，占何日动身/弟被掳回否。课名游子、闭口、赘婿、冲破。
> - **断验**：壬癸日鬼多无制，天网四张，行者难动、掳者难归。专看丁马乘太阴玉女可脱身。中末冲破天关不难高飞。自占卯日可动，掳者待卯月归。
> - **结果**：出旬卯日登舟回家，次年卯月李果归家。

### 三交课

#### 定义与成因
- **核心条件**：四仲日（子午卯酉）占，四仲加日辰，三传皆仲将，逢**阴合**（太阴、六合、天后）。
- **三重交加**：一交（四仲日时占遇四仲加支辰），二交（仲神发用三传皆四仲），三交（仲神乘太阴/六合/天后）。三者相遇交加，故名“三交”。统“姤”之体，风云不测课。

#### 经典注解汇编
| 来源 | 核心要点 |
| :--- | :--- |
| **《订讹》** | ① 四仲日时占为一交，课传皆仲为二交，将逢后雀阴合为三交。子午阴阳所起，卯酉日月所从，四败神为天地门户。主事体交加连累暗昧、进退两难、家隐私/人逃匿、谋事被阻、求望难、病讼凶。四仲纯全无父子相扶，四正四平互刑互破，前无孟可隐后无季可奔，遇兵贼欲逃不及。凶将：男犯重法、女犯奸淫。阴合门户不利阴小隐匿；空虚诈、武遗失、蛇火惊、雀口舌、勾战斗、虎杀伤丧孝。六阳日为交禄（以禄求私，乘玄武阴私失禄）；六阴日为交罗（阴私上门带凶将恶杀有杀伤祸）。午加酉死交、酉加午破交、返吟反目交，皆不能成合。无阴合则“三交不解”，过与不及祸更甚。年命日用旺相乘吉将传得午卯子名“轩盖”占官大贵（应姤九五“含章有陨自天”吉）。华盖亦四仲相加但有吉神。 |
| **《观月经》** | “四仲来加仲，发用谁为先，其中若有克，三交得此篇。男子逆其罪，女子外勾连。占人当六月，丁卯卯时看。仲秋加仲夏，被克是因缘。有救除华盖，非此罪迷天。” ①子午卯酉逆相加发用有克为三交卦。子加卯/酉加子发用玄武六合天乙主奸淫；勾陈白虎主杀伤逃亡。子午卯酉逆加曰破加凡事阻破。天后六合主奸邪事而人破。酉加午发用为媒。②男子逆罪女子私通。③仲秋加仲夏即酉加午。④华盖：午卯子为三传，见天马奇仪入卦更吉。 |
| **《心镜》** | “昴星房宿加日辰，太阴六合又并臻。今日复当逢子午，三传四仲类相因。三交家隐奸私容，不是自逃将避迍。螣蛇防火勾陈斗，玄武白虎因杀人。” |
| **《袖中金》** | 三传俱仲名三交。四仲日四仲相加人传发用为一交，得四仲正时为二交，上乘雀玄阴合为三交。主隐匿不明、失节阻碍、凡事被人阻破。三传务要俱备，不备则“三交不交”；仲年月日时则“三交不解”，二者灾祸甚于交。四仲纯全外无所寄，无父子相挟，四平四正互刑互破，前不能进后不能退，欲逃匿而不及。后合人传主阴私不明；勾虎人传主斗争杀伤丧孝。午加酉死交、酉加午破交、返吟反目交皆不吉。三交见午卯子乘天马龙常即华盖乘轩宜占官；空亡为乘轩落马；躔日月宿为天地烦。 |
| **《指窍》** | 四仲顺加/逆传分四时占验。三交有天马为华盖乘轩又为四正；有正禄为四正，无正禄为四散。三交主三四人交往。天马出行，四正得青龙朱雀吉神主士人赴试得解。四散五行无气主妇人败血小产。午酉自刑：午少阴酉纯阴老阴。酉为妻乘生旺为妻，无生旺为婢尼。酉加子见玄武生旺多婢生子。午酉血疾丑恶脓血。子午道路神，子午日得之言道路事。卯酉分气异则争，卯酉日得之言分争事。卯外门春分生气吉，酉内门秋分杀气凶。 |
| **《曾门》** | 三交因家匿罪人。从魁太冲六合太阴并加日辰为用曰三交；四仲复加四仲三传俱得四仲亦为三交。定章：太冲从魁六合太阴为门户蔽匿万物。太冲从魁太阳六合并加日辰为用为三交卦，占人家匿罪人。乙巳日酉加巳将得六合亦曰三交。丁酉午加酉上克下发用传见太冲终于神后为三传四仲，亦置罪人门户出入公私所由。太阴私蔽六合私门蔽匿罪人。卯酉日月出入子午阴阳起。三传四仲出入微密匿罪人。欲知何人以终传决：白虎杀人、玄武盗贼勾陈斗伤朱雀讼事天后淫泆太阴奸私。 |

#### 实战案例
> **案例一**：道光乙巳年卯月己酉日丑时，省垣书店王青云占回籍。课名三交、闭口、赘婿、冲破。
> - **断验**：轩盖逢空课名闭口，阻塞难行。交车相合人地相宜不能离析。日禄克支如人赘妻家难自由，宜合伙营生。天鬼发用伏殃，丧魄加巳未命健者亦衰弱者必死。
> - **结果**：次年身故。以婿入赘伙开书铺眷属留楚省，壬子年粤匪破城劫散财物（末传子水冲禄）。

### 乱首课

#### 定义与成因
- **核心条件**：日干加临日支（辰）而被日支克制（干临支受克），为**自取乱首**；日支加临日干而克日干（支临干克干），为**上门乱首**，兼发用更急。
- **象义**：干为尊上如首，支为卑下如足。卑下无礼作乱，故名“乱首”。上门乱首发用又名“反常课”。统“颐”之体（或云“大畜”）、悖逆紊乱绝上下之义。

#### 经典注解汇编
| 来源 | 核心要点 |
| :--- | :--- |
| **《订讹》** | 干临支被克为自取乱首；支临干克干为上门乱首兼发用更急。主少害长、下犯上、家门背逆、不可举事。自取乱首尊上自失礼为支所犯事体稍轻；上门乱首尊不惹卑卑下敢犯上事体重。自取乱首事发于内起于外，兵不利主贼来格战，总主来人迟营寨多刑伤。见卯酉后合主男女讹杂不分长幼。四课俱下贼上不免窝犯丑声祸自内出。或主祖宗别姓。将得青龙来意因幼小不知别籍异居；三传年命克制乱我之神名“患门救”。附：干临支生支曰偃蹇泄耗甚；受生曰俯就先难后乐；同类曰培本比和相助。**凌犯**：日克辰上凌下却得下贼上为用；辰克日下犯上却得上克下为用。互相凌犯主尊卑不分君骄臣逆或篡弑事。初传官鬼祸尤速。克下外事起克上内事起。 |
| **《观月经》** | “日为尊者父，辰作少年儿。尊者来加子，少者反克之。因名为乱首，老者必低蕤。家内应无礼，官司忌有仪。先祖是外姓，上宗别人儿。纵必家和顺，官司亦被欺。” ①乱首卦名白虹贯日。②凡乱首课主杂乱姓上祖必假名异姓。③若上祖是今姓老少和睦亦遭官司。④日为尊辰为卑尊就卑被卑克故曰乱首。⑤主家乱不利占上祖别人之嗣。更值魁罡勾陈至有不可形容之孽。列举特定干支组合（甲申乙酉、丙子丁亥、戊寅己卯、庚午辛巳等）。上门乱首辰来加日克日大无礼（戊寅己卯类）。 |
| **《心镜》** | “日往加辰辰克日，发用当为乱首名。臣叛君兮子杀父，妻背夫兮弟克兄。奴婢不从主委任，将军出塞愤其兵。日为尊长辰卑小，犯上之时忌此刑。正月酉时庚午日，传送初传午克庚。略举一端君须识，他占仿此理分明。” |
| **《毕法》** | 真乱首：干克支上神、支克干上神。或夫妇行年又值此尤急。占人必占乱首事。应小畜九三“舆说辐夫妻反目”凶象。列举大量干支组合对应上神克制关系。 |
| **《曾门》** | 夫妻行年在上相克在下相贼。夫以阳年为始阴年为终，妻以阴年为始阳年为终。终始相生和合，终始相克俱解。无阴天地解离各有他心。 |
| **《定章》** | 夫年立甲午妻年立壬子。登明临午上克下，太乙临子下贼上。妻之阳年神后克午。天地解离各有他心。无阴者无子孙。天地解离言阳年天上阴年地下。登明加午上克下太乙临子下贼上故上克下贼。夫阳年始天上胜光，妻阴年始地盘神后，神后制胜光始相克。夫阴年终地盘胜光，妻阳年终天上神后，神后制胜光终相克。故天地解离各有他心。附录正月午时占夫年酉妻年亥案例详解始终相生和合。 |

#### 实战案例
> **案例一**：同治丙寅年寅月壬戌日亥时占雇工。课名乱首、芜淫、回环。
> - **断验**：正时发用俱乘天空子丑值天空，主欺诈不实。占雇工以天空为类神乘日德日禄其人可用，非寻常欺诈。初遭夹克中末逢空必难成交。干加支受克仍传干上干上子丑合丑旧太岁仍归故主。论主仆干为我分也；论新旧干为先序也。类神属亥干为奴戌支克干我克奴奴不为我用。卦主既定乱首说不必泥。
> - **结果**：已议定刻日来家，旋因故主不舍仍归之。

### 赘婿课

#### 定义与成因
- **核心条件**：日干克日支（辰），又**日干加临日支**为用（干临支克支）；或**日支加临日干**被日干克（支临干被克）。
- **象义**：干为夫支为妻，干克者为妻财。干临支动就静如男子婿赘妻家（坐堂婿）；支临干静就动如妇人随男就嫁（随娘儿）。舍己从人以身入赘，故名“赘婿”。占者凡事不快寓居于人身不自由。统“旅”之体、为客求财课。

#### 经典注解汇编
| 来源 | 核心要点 |
| :--- | :--- |
| **《订讹》** | ①干临支克支、支临干被克兼发用更急。主凡事不快寄居身不自由乃为客求财课。屈意从人事多牵制孕迟病讼延行人滞。干临支克支利尊不利卑宜动不宜静兵利客；支临干被干克卑凌尊尊上不容兵亦利客。日用旺相乘吉将求望利名可就；将得六合必主招婚姻事。列举十二日干加支具体应验事类（甲戌女子衣服、甲辰斗讼、乙亥酒食言语、癸巳争衣惊恐、己亥女子惊逃、丁酉分离、壬午田宅相连、戊子女子疾病就人财物、丙申言他人事、辛卯木器伤财）。此课干临支克支惟乘囚死作合阴名赘婿；若乘旺相作勾虎又名“残下”甚不利卑小。皆主仗他人势事乃可成。支临干看支神原受艰难则不得已而出随他人受磨折；支上原有存处岂可轻易舍己从人，君子审其可否免失身咎。支乘脱气必无正屋可居终非自立象。中传见救神克日或年命得神将吉又名“赘婿当权”可任意所为。附：支临干生干日自在坐享；受生日求受反竭我力；同类曰壮基并国相济。 |
| **《观月经》** | “欲知赘婿卦，将身就妻家。辰往临其日，被克妾称邪。上下相勾引，行年作爪牙。假令正月占，甲戌卯时加。辰来临日上，被子克更无差。此名赘婿卦，仔细自呼嗟。妇人将子嫁，次后没荣华。” |
| **《心镜》** | “赘婿日干加克辰，辰来加日制其身。如男寄于妻家住，若女携男适就人。意欲所为全不肯，心怀不愿抑勒云。凶灾吉庆皆生内，故以天官决事因。” |
| **《袖中金》** | 乱首赘婿合述：日往加辰受辰克为乱首，辰来加日被日克为赘婿。上凌其下紊乱，下欺其上悖逆。①支临干被克是也。②假令甲戌日亥将卯时一课戌甲戌临甲被克发用是辰临日。乙丑日亥将寅时丑加乙下贼上亦赘婿。③此卦将嫁他人为男或随母之子。④今日干加克支辰辰来加日上被日干克。卑被尊制尊被卑制故不自由。⑤正月甲辰日酉时辰加甲是也。 |

#### 实战案例
> **案例一**：道光乙巳年申月甲戌日寅时杨姓占病。课名赘婿、盘珠。
> - **断验**：三合脱日病因肺伤气虚下陷。盘珠难脱体。女病：日临支克支赘婿，午加长生女嫁未归。天后火土所煎水亏火炎症，自生传墓非有寿征。
> - **结果**：初观病状符，别后不知究竟。
>
> **案例二**：咸丰甲寅年午月甲戌日卯时钱姓占店事。课名赘婿、盘珠。
> - **断验**：子必螟蛉妻必后娶。三合递生不离四课兼赘婿占事不脱，系众人借助开店退不能脱身进可取还魂债。三合逢后合家有结婚喜。三传会火逢岁月日建泄气太过不能任子，幸正时卯坐长生弟必有子可承。财乘死气中传建旺助之克妻复娶妻。
> - **结果**：妻重克以弟之子为子生意情形亦合。
>
> **案例三**：咸丰癸丑年卯月壬午日辰时族侄占母病。课名赘婿、回环。
> - **断验**：正时天后作鬼墓生遇旬空乘虎投墓病不可治。忌辰丑月。太岁乘朱克日丑午相害主诅咒。赘婿课当主婚姻口舌。
> - **结果**：三月母故夏终重见口舌并破财。

### 冲破课

#### 定义与成因
- **核心条件**：日辰之**冲神**加**破**为用。
- **冲**：动摇，初虽有德后必倾覆。子冲午主道路驰逐男女争谋变动；卯酉冲主门户改移逃亡失脱外人淫乱奸私；寅申冲主人鬼相伤夫妇异心；巳亥冲主事反复无实重求轻得；丑未冲兄弟兴衰相持谋心不同干事不遂；辰戌冲主仆离异贵贱不明不义之争。
- **破**：解散，主事更改多中辍。午破卯酉破子主门户破败阴小灾；辰破丑主丘墓寺观破损；戌破未先破后刑；亥破寅申破巳先破后合。
- **冲破凶为一类**。统“夬”之体、雪上加霜课。

#### 经典注解汇编
| 来源 | 核心要点 |
| :--- | :--- |
| **《订讹》** | ①冲者冲动意亦反复意；破者解散意亦破损意。如子年庚子日未时戌将三传午酉子：午岁冲日冲酉岁破日破；冲又加卯破为用；甲年忌见申冲亥破。冲破并而为课故名冲破。主情反复门户不宁婚难遂孕难成病凶散财平常谋望复倾。十二冲破细目同上。冲主人情暗中不顺出入难久。乘凶将无救凶甚。破加破碎煞尤凶。**宜忌**：旺不宜冲衰墓宜冲；吉不宜冲凶将宜冲；凶空不宜冲吉凶宜冲。类神空亡岁月冲则暗动日辰次之。破不宜望成事宜散凶事。 |
| **《大六壬通解》** | 例：子年庚子日午加卯占。子日以午为冲酉为破，午加卯为用。子岁子日午为岁冲日冲酉为岁破日破，卯为午破又加刑发用故曰冲破课。 |

#### 实战案例
> **案例一**：道光庚戌年辰月己酉日午时陈湘帆同年占会试。课名冲破、三交、励德、龙战。
> - **断验**：此课不中更有官讼盗贼。子支破卯支冲冲加破位逢玄武带天鬼贼神自支阴发用必有内破坏山林致口舌；朱雀乘月破加干上下相刑外讼。玄武临门断盗树：卯木逢春坐水方知为长生物非已成物；中传午破卯未传酉克卯伐木象；酉太阳贼必败露。外来讼：魁罡事干众人丑刑戌朱多属山林城郭。
> - **结果**：果不中。族议众山树茂拔攘窃值倍贺仪致家长执送；城内估客修公所因地基兴讼大众窃名具控致差扰祸起于人非自致。
>
> **案例二**：咸丰乙卯年未月丙午日酉时李茂盛雷氏占夫病。课名冲破、比用、蒿矢、三交。
> - **断验**：干阴亥贵为鬼带死气夫病不可救。不忧夫而忧妻：阳爻见生阴爻见克寅木虽空鬼反助其生夫病无妨；惟支科乘败气兼冲破为用妻将断矣。
> - **结果**：夫病愈后妻犯痢死。

### 淫泆课

#### 定义与成因
- **核心条件**：初传**卯酉**为用，将乘**天后、六合**。
- **象义**：卯酉阴私之门，后合淫欲之神，主淫奔泆欲。用起六合终于天后为**狡童格**（男诱女有逃亡事）；用起天后终于六合为**洪女格**（女随男通私奔走）。利私谋不利公谋。统“既济”之体、阴阳配合课。

| **《订讹》** | 与三交并为浊滥淫泆所私非一人一处。加天罗地网甚凶主恶声：子日丑天罗未地网，并天烦男遭杀伤、并地烦女遭杀伤、并二烦九丑男女皆遭杀伤（应既济上六“濡首厉”凶）。后合临日辰男女行年并者占婚不用媒先奸后娶。值空亡虚意。神将吉日用旺相应既济初九“濡尾无咎”吉。 |

### 芜淫课

#### 定义与成因
- **核心条件**：四课有克**缺一为不备**；及**日辰交互相克**。
- **不备判法**：刚日从日上起第一课，柔日从辰上起第一课。第一课干阳二干阴三支阳四支阴。阴课缺一为阴不周全（二女争男）；阳课缺一为阳不周全（二男争女）。日辰交互相克各自相生。夫妻皆有私通两情相背荒淫无度故名“芜淫”。占家门不正事多淫乱。统“小畜”之体、琴瑟不调课。

#### 经典注解汇编
| 来源 | 核心要点 |
| :--- | :--- |
| **《订讹》** | 不备①有克照常以克贼比涉论但四课必须那动。刚日从日上起一课柔日从辰上起第一课。四课之阴阳论非干支阴阳论。例乙卯日午时未将柔日从支起：辰卯巳辰巳乙午巳，巳辰作支阴神为二课不可复作干阳神为三课，此二阴一阳为阳不备。乙亥日巳时子将亦柔日从支起：午亥丑午亥乙午亥，午亥作支阳神为一课不可复作干阴神为四课，此二阳一阴为阴不备。主不周全物偏缺病难愈求望难成行人未至。阳不备兵讼利主贼不来；阴不备兵讼利客贼必来皆战不成。三传阳多事起男阴多事因女。阳多晴久阴多雨添。占多以不周全为断。附：干临支生支偃蹇泄耗甚；受生俯就先难后乐；同类培本比和相助。 |
| **《观月经》** | “四课如不备，其卦号芜淫。五月乙卯日未将午时占。辰阳见天罡，太乙作阴神。日上无阳类，二女竞男心。假令乙亥日子将巳时占。午为辰之阳，丑作午上兼。日阳还从亥，日阴无处添。此名为不备，双男竞妇兼。主有奸淫事，逢时心意嫌。有救应无事，凶神刑狱淹。戊午龙宫课，两辰丁酉占。金鸡皆一例，丑未二辛添。” 详注①-⑬解析日辰阴阳不全止三课备为芜淫卦、辰上见太乙被辰阴神占、亥乙日阳被辰阳神占、日阴神被辰阳神占、四课止三课二阳一阴二男争女、三奇六仪神为救、七日九课别责芜淫卦、日为夫辰为妇。 |
| **《心镜》** | “阴阳不备是芜淫，夫妇奸邪有外心。二女争男阳不足，两男一女共枕淫。上之克下缘夫过，反此诚为妇不仁。阳为阴将阴处合，阴来阳处为刑临。若知起例看正月，甲子时加卯课寻。甲上天魁子传送，甲夫阳也子妻阴。甲将就胜光为日之阴神天罡为辰之阳神是二阴一阳故曰二女竞男心。” |
| **《袖中金》** | （同上心镜要义） |

#### 实战案例
> **案例一**：咸丰丙辰年子月戊子日亥时占友处可离否。课名芜淫、狡童。
> - **断验**：上神互克干支芜淫，初合末后狡童，不必有奸邪事但人地不相宜。彼此相克中末逢空必难终局。支阴发用身遭夹克友虽待厚必因兄弟不能自由。
> - **结果**：年终往投次年正月即转情事亦符。

### 解离课

#### 定义与成因
- **核心条件**：**夫妻行年冲克**，及**上下神互相克贼**。
- **象义**：如夫年立午上见寅，妻年立子上见申。子上申怕午克，午上寅怕申克。上下互克天地解离各有异心。占者非断弦之凶必有反目之兆。

#### 经典注解汇编
| 来源 | 核心要点 |
| :--- | :--- |
| **《观月经》** | “夫妻天匹配，有难解离频。年命交相克，始终亦同陈。妻年行至午，夫年立于寅。六月申时占，妻逢配夫嗔。夫年上逢子，妻运仰观辰。辰逢克子水，的有解离迍。夫年反有克，与此一般伸。递相淫情起，暗地使媒人。” |
| **《心镜》** | “解离之卦看行年，先须察地后观天。夫妻始终互相克，二月寅时课请占。妻年立子夫年午，神后须知克胜光。午上功曹子传送，递相伤残更何安。子水本来先克午。子上申金怕胜光。午上功曹怕申克，此为始终互相残。金盆覆水皆斯类，玉轸音悲是断弦。解离夫妻行年上神将相克互相残。” 附注：①妻行年上神克夫夫行年上神克妻交相克。②夫运寅上见子妻运午上见辰。③夫行年上神克妻行年上神亦同。④不与四课三传同若两家行年相克夫有外妻妻有外夫心。⑤神后子妻天上行年胜光夫天上行年另一说。⑥夫年午上见功曹妻年子上见传送。⑦此课不干四课三传事但夫妻行年相克者；若无刑损或夫有外妻妻有外夫。 |
| **《毕法》** | “真解离卦者谓干克支上神支克干上神。或夫妇行年又值此尤急。此时占人必占解离事。已后例内唯详空亡而言则小畜九三‘舆说辐夫妻反目’不能正室也凶象。” 列举大量干支组合对应上神克制关系（甲子日干上午克支上辰子水克干上午等）。 |
| **《曾门》** | “夫妻行年在上相克在下相贼。夫以阳年为始阴年为终妻以阴年为始阳年为终。终始相生和合终始相克俱解。无阴天地解离各有他心。” |
| **《定章》** | 详解夫年甲午妻年壬子登明临午上克下太乙临子下贼上妻之阳年神后克午天地解离各有他心。无阴者无子孙。天地解离言阳年天上阴年地下登明加午上克下太乙临子下贼上故上克下贼。夫阳年始天上胜光妻阴年始地盘神后神后制胜光始相克。夫阴年终地盘胜光妻阳年终天上神后神后制胜光终相克。故天地解离各有他心。附录正月午时占夫年酉妻年亥案例详解始终相生和合。 |

#### 实战案例
> **案例一**：道光辛卯年巳月癸未日亥时自占月将酉。课名解离、弹射。
> - **断验**：干支上下对冲互克水日逢丁夫妇别离象。初传胎临月建末传天喜作吊必因产亡。纯阴之神当生男子。两贵相加逢岁月建此子应贵。
> - **结果**：本月妻孕冬月子生五月妻亡。后诗书未成一监终身以岁月冲破故。
>
> **案例二**：咸丰乙卯年戌月癸亥日申时人占妻病。课名孤寡（实为解离类）。
> - **断验**：未鬼为病卯木为医三传会子孙似无妨。初末前孤后寡又见天空真孤寡。水日逢丁占妻定克不必看子孙。即以子孙论酉破全局。
> - **结果**：亥月冲巳酉日破卯妻故。

### 度厄课

#### 定义与成因
- **核心条件**：四课内**三上克下**（幼度厄）或**三下贼上**（长度厄）。
- **象义**：上为尊下为卑。三上克下长欺幼势必遭厄；三下贼上长不正幼凌长。占家宅欠利老幼见灾。统“剥”之体、六亲冰炭课。

| **《观月经》** | **长幼卦**：“三上来临下根源长幼推。子孙先发用小者必低蕤。父母相临用凶神入墓悲。此看三传末诸卦总如斯。” **度厄卦**：“三下制其上六亲竟不虞。事还同长幼凶即暗嗟吁。生气逢欢乐休囚下泪珠。五行皆如此消息要工夫。” 详注①四课中三上克下为长幼卦；②甲乙日用起火神发动子孙低蕤；③甲乙日水神发动父母应；④诸卦人生人死人墓吉凶在重审卦注定；⑤今日何神发动亲情与长幼卦同；⑥三传人生欢乐人死墓忧愁务要精熟灾福自然见。 |
| **《袖中金》** | “三上克下为长幼三下贼上为度厄。长幼不利于小度厄不利于大。再详神将吉凶有救无救酌而用之。” |

> - **断验**：三上克下幼度厄三传递克殃咎兼日鬼发用不独考试不利且有病灾。正时午属离为目玄武克之；日干丙太阳被子水克制皆失明象。破碎克宅贵人乘之不免阴人口舌。
> - **结果**：果因眼病不能完卷口舌亦见。

### 无禄绝嗣课

#### 定义与成因
- **无禄课**：四上俱克下。日神阴阳俱相克不得其所不免投辰上两课辰上阴阳又相克无所投之路占者多主孤独。主庶人不禄有官罚职轻罚俸重削职。以上制下臣子受殃屈者难伸对敌利客讼宜先起者胜。惟火多克金有水可救。统“否”之体上下僭乱课。
- **绝嗣课**：四下俱贼上。主小人无礼暗算横灾殃祸病者死逃者转匿尊长见灾战斗利主讼宜后对中年多子息老后主孤独。

#### 经典注解汇编
| 来源 | 核心要点 |
| :--- | :--- |
| **《订讹》** | **绝嗣**：上不容下下难自存故名绝嗣。主在上无礼卑小不利孕伤胎病易死占子病死更验奴婢逃骨肉散。旬空发用来人必主独身。事起男子兵讼先者胜凡事动而必静。**无禄**：下犯上被上夺禄故名无禄。主孤独失业多刑伤病必死事起女人兵讼后者胜凡事静而必动。神将凶骨肉分离；吉来意主分财异居。 |
| **《观月经》** | **无禄卦**：“四课俱临下男鳏女寡孤三传如有救子必胜于吾。” **绝嗣卦**：“四下贼其上名为绝嗣凶中年多子息暮岁灭祖宗有救同前例无医断后宗专看发用类年月日时逢。” 详注③四课俱临下为无禄卦如发用水神未传得金神为救；发用金神三传见土神为救。吾者父也其五行并用此断。假令己未日亥将辰时占四上克下取比用酉金发用中传辰土生金为父未传亥水为子即有救虽无禄不言绝。④临年老也首尾初未传。若今日发用水神在土上终传复见土神此道尾相制。假令午将甲寅日未时占神后临丑下克上为用首制终传河魁土尾制其神子水欲前就功曹为子又下被大吉怒后欲亲从魁为母又被天魁戊土上降灾祸占人必灾。⑤四上克下即法令严加有屈不得伸雪。 |
| **《心镜》** | “首尾俱相制临年子失途切须看用数到老不如无。四课上神俱克下法式严时不可论臣子受殃从此起无禄如何独处尊。占人孤老谁扶侍空室穷炊岂得存官门竞小必当罪对者应知理不伸。” |
| **《袖中金》** | “无禄四上克下绝嗣四下贼上。上下之分贵于忠恕。四下贼上无其尊为不忠；四上克下不容其下为不恕。若得此体主奴婢散失子孙他之孤子空室。上不能保禄位下不能友妻子不友不亲不弟不义之耻。无禄主动而必静室家孤独病不久退官事不妒囚者脱逃者获凡事宜先举。绝嗣主静而必动小人犯上无礼暗横灾殃病者易死逃者转匿凡事宜后施。” |
| **《曾门》** | “四上克下名无禄室空无人老而孤独臣子受殃六亲死亡战斗客胜利以先举。” **《定章》**：“父以子为下君以臣为下夫以妇为下兄以弟为下四课皆上克下为孤独。法曰君欲害臣父欲杀子兄欲损弟夫欲伤妻主欲害奴是空室无人也。” **绝嗣**：《曾门》四下贼上名绝嗣亡其先人后有孤子战斗利主必不利客。《定章》臣忠君子孝亲为正今皆下贼上为灭绝。法曰臣害君子弑父妻害夫奴反主生男伤父生女伤母亡其先人为孤子占利居家不利为客访馆训教子弟。 |

#### 实战案例
> **案例一**：咸丰戊午年午月辛巳日丑时闻警占。课名无禄。
> - **断验**：正时白虎辛日逢丁巳受惊危；四上克下外胜内支来克干阴犯阳三传递克贼非一处贼符又克干支岂能安枕。寅木俯仰丘仇未传日禄旬空饷运维艰内战不和何能同仇敌忾。
> - **结果**：果如所占。
>
> **案例二**：亥月癸卯日占胎产。课名无禄（实四下贼上绝嗣格）。
> - **断验**：三传纯阴弄璋兆本月亥日冲胎必生。卯贵作子孙登天门子乃诗书中人。四下贼上恐子伤母？占产绝嗣无禄吉盖取上下分离义。
> - **结果**：未记录验证。

### 迤福课

#### 定义与成因
- **八迤（凶）**：时令死气发用(一)；下为旺气所胜(二)；上见丘墓(三)；下见仇克(四)；乘凶将(五)；带刑害子为坟墓星主死亡(六)；下贼上(七)；凶神临日辰相克(八)。
- **五福（吉）**：用起初死终旺子母相生(一)；子逢凶母带德解救(二)；始凶将终吉神(三)；初传鬼贼年命克制(四)；日神吉临旺相(五)。
- **迤福**：八凶者为迤五吉者为福。占事先凶后吉。统“屯”之体雷雨解灾课。

#### 经典注解汇编
| 来源 | 核心要点 |
| :--- | :--- |
| **《订讹》** | **五福**：占主一切吉。**迤福**：例癸酉日午时亥将春占课得午癸亥午寅酉未寅传未子巳将雀虎贵。用死一迤；未下寅春木太胜二迤；木墓未仰见丘土畏木俯见仇三迤；将雀四迤；雀与刑合五迤；子临未下贼上乘虎六迤；子得虚宿主坟墓哭泣七迤；干上蛇支上武俱凶将八迤。初未死末巳相一福；未生初子投母二福；初雀末贵三福；巳受子克得救人救四福；癸德附戊戊寄丙午临日五福。迤中有福故名迤福主化凶为吉先忧后喜。**八迤**：占主一切凶病危遭官坐死谋无成。小吉临寅为用八迤：春土死用神死气一迤；未土临寅寅旺木胜二迤；木墓未仰见丘丘土畏木俯见仇三迤；朱雀初传四迤；雀与刑并五迤；中传子临未下贼上六迤；子虚宿与白虎同位七迤；午加癸乘凶将螣蛇又下贼八迤。遇八迤须得旺相吉将相生为救福力均殃渐退疾病瘥官讼理得伸。 |
| **《心镜》** | “八迤五福详吉凶以意推之无定神欲别凶微吉有力不然八五是常文。冲破休囚刑墓杀恶将都看有几迤旺相相生吉神救又祝福之多少均福力均时殃渐退疾病瘥官讼理得伸。” |

#### 实战案例
> **案例一**：癸酉日午时亥将春占。课名迤福。
> - **断验**：财空忌妻？妻看天后乘神吉凶。巳为日胎胎空则子生何忌妻但初孕不宜空。全局逢冲合中犯煞？占产忌合正赖亥水破局期其生如达。水日逢丁有妻则克？此格参看天后天后无恙课传无凶煞不尽以克妻论。占妻产喜动喜空丁马乘天空乃胎动腹空何忌。
> - **结果**：本月丁亥日生男母无恙子大亦职俊戊午入泮。
> - **附录**：《玉田四难歌》 “胎孕生下行人逢无禄绝嗣亦堪容。”

### 侵害课

#### 定义与成因
- **核心条件**：日辰**六害相加**，并行年为用。
- **六害分类**：子未势家害；丑午卯辰少凌长害；寅巳申亥竞强争进害；酉戌鬼害。
- **象义**：害主损，似水壅滞血气未行事多阻隔。统“损”之体防人暗算象。

#### 经典注解汇编
| 来源 | 核心要点 |
| :--- | :--- |
| **《订讹》** | ①子未势家害丑午卯辰少凌长害寅巳申亥竞强争进害酉戌鬼害。六处都能肆其侵损故名侵害。①干支害神上下相加发用临行年更急。**象曰**：六亲失靠骨肉刑伤财利谮害疾病毁伤求婚人破出阵军殃胎孕防堕干谒不祥。六害神临日辰发用又乘凶将恶杀主侵害凶祸应损九二“征凶”；带合德善神吉将课体虽阻终成应损上九“利有攸往”。 |

#### 实战案例
> **案例一**：道光乙巳年戊月戊辰日巳时张姓占失牛。课名侵害、连珠、三奇。
> - **断验**：众鬼连茹盗必数人。丑加寅鬼死气牛已为砧上肉。魁度天门勾陈生武乘神追捕难获。玄被乘神克制玄阴酉戌相害日上辰冲戌关伙盗终必自供致生讼。
> - **结果**：盗已杀牛因分赃不均鸣团自供以致送官。
> - **附录**：《毕法》 “所筮不入仍凭类。” 丑为牛玄武为盗此类神也。丑入未传玄未入课传亦凭此断。

### 刑伤课

#### 定义与成因
- **核心条件**：课中**三刑发用**，并行年为刑伤课。
- **三刑类型**：
  - **寅巳申刑**（无恩刑）：父子在位相伤。寅刑巳举动险阻官事灾害彼刑我斗前事生发；巳刑申长幼不顺先犯后成彼刑我解仇将恩报；申刑寅人鬼残贼男女相制彼刑我动。
  - **丑戌未刑**（恃势刑）：三官皆土兄弟以力相伤。丑刑戌官鬼刑禁尊贵伤卑贱有挠不明；戌刑未少凌长举事妻财凶；未刑丑大小不和或见丧服。
  - **子卯刑**（无礼刑）：水木母子改节相伤。子刑卯门户淫乱死败尊卑不睦；卯刑子去明入暗水路不通子息不律。
  - **辰午酉亥自刑**，寅申巳亥四冲（无亥）、辰戌丑未四冲（无辰）、子午卯酉四冲（无酉午惟子卯互刑）为自刑。主自逞高大更改自害。受四冲缺一不全欹而不正三者各自相推不齐着力罚而相刑。
- **刑必有伤**故名刑伤。统“讼”之体大小不和课。
- **刑德格**：寻奴仆小人奔走去向详支之刑神所临方追之必获。德者甲己寅乙庚申丙辛戊癸巳丁壬亥阳德自处阴德从阳。德胜刑易获刑胜德难见德刑不相克见闭口课中推。

#### 实战案例
> **案例一**：道光己酉年午月辛丑日未时张姓占母病。课名刑伤、游子。
> - **断验**：刑伤课自宅发用病为参商所致。青龙纸钱煞加未传太常死气孝服煞加日干天后乘墓异棺入土象。辛日伏吟逢丁卯年课名游子出殡在迩。
> - **参议**：文书旺相或可无虞？印爻重叠专看天后一水七土克之能久乎？即以印爻论亦月盈则亏象。
> - **结果**：次日壬寅戌时故。寅应青龙戌死气。
> - **附议**：占病遇纯土课无论水日多鬼火日全脱不吉即庚辛甲乙日皆为所埋不能制受生。

### 二烦课

#### 定义与成因
- **核心条件**：**四仲月将**遇**四正及四平日**占，得**日月宿加四仲**，**斗罡系丑未**。
- **名词解释**：
  - 四仲：子午卯酉。
  - 日宿：太阳躔度宫神，正月初一起室二奎三胃四毕五参六鬼七张八角九氐十尾十一斗十二虚，每月初一移一宿逐日数二十八宿遇奎张井翼氐斗重算留一数尽月宿住处为太阴所在宫神。
  - 斗罡：辰。
  - 四正：朔(初一)望(十五)弦(初八二十三)晦(月终)。
  - 四平：即四仲子平卯卯平午午平酉酉平子。
- **成因**：日月经仲宿度数多有稽留及天罡凶神交系丑未贵人不得理事则三光不明德气在内刑气在外。天地相并故名二烦。占家有灾祸。统“明夷”之体荆棘满途课。

#### 经典注解汇编
| 来源 | 核心要点 |
| :--- | :--- |
| **《订讹》** | **象曰**：男遇天烦命遭刑戮女犯地烦身受虫毒征虎伤亡疾病号哭狱讼徒流胎孕不育。将乘螣蛇忧恐勾陈争斗后合阴暗白虎丧亡。天地烦并主男女俱患惟春夏可生秋冬必死。利居家不利出行及干求事凡百谋为决招凶祸应明夷上六“后人于地失则”凶。**天烦格**：日宿临四仲斗罡系丑未主男子犯法。男禁天烦无抵四正朔望弦晦。春夏男行年并日宿临卯午主犯县官刑囚见血徒配；秋冬临酉子犯刀兵刑戮污葬。**地烦格**：月宿临仲斗罡系丑未主女子受灾。女禁地烦无冲四平子午卯酉。春夏女行年并月宿临卯午主产难流血斗讼；秋冬临酉子刑丧犯法死亡。**案例**：三月十五己卯日子时酉将男命行年子日宿酉并临子加仲罡下系未天烦格；女命行年午月宿卯并临午加仲罡下系未地烦格。 |

#### 实战案例
> **案例**：九月初三丙午日午时卯将占寅命行年午。月将为日宿躔氐二度月宿躔氐五度太阳太阴俱值卯宫加午为仲辰为斗罡临未二并为天地烦曰二烦课。详细排盘见原文。
