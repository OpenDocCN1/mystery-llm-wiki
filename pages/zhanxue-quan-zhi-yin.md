# 占星学全指引

> 本页面系统梳理《占星学全指引》核心教学体系。本书以「日间/夜间」极性取代传统「男性/女性」二元标签，构建包容性占星语言，涵盖占星历史、天文基础（回归黄道）、四元素与三态、十二太阳星座、十二上升星座、三十六区间及主要行星意涵，定位为面向初学者至进阶者的包容性入门百科。

## 核心理念：包容性占星语言与日夜极性

### 移除二元性别标签
- **核心主张**：星盘不标示性别，每个人内在均具备所有行星与星座特质。传统占星将「阳性/男性」等同于主动、强有力、光明，「阴性/女性」等同于被动、虚弱、黑暗、破坏，带有父权制偏见。
- **替代方案**：全书采用古希腊占星技术中的 **日夜区分**，即 **日间行星/星座** 与 **夜间行星/星座**。
    - **日间**：对应吸气、外向、阳能量（太阳、木星、土星；牡羊、双子、狮子、天秤、射手、水瓶）。
    - **夜间**：对应呼气、内向、阴能量（金星、火星、月亮；金牛、巨蟹、处女、天蝎、摩羯、双鱼）。
    - **水星**：连接日夜两极的桥梁（双子/日间、处女/夜间）。
- **意义**：使占星语言更人性化、非二元化，能涵纳所有灵魂意识，回应时代变迁。详见 [[zhanxing-yu-zhen-wo#整宫制与行星状态]] 中关于行星状态（Sect）的应用。

### 占星定位
- **本命占星为主**：视星盘为潜力与可能性蓝图，非绝对吉凶，聚焦个人成长、疗愈阴影、有意识航行。
- **整合视角**：融合心理学、人本主义、萨满视角（医药轮），强调与宇宙自然循环和谐共振（量子纠缠隐喻）。

## 第一部：占星学积木

### 第一章：占星学基础

#### 什么是占星学
- **定义**：古老科学，观察行星长期周期移动，记录宇宙变化触发的模式与事件。
- **理论基石**：万物彼此链接（量子力学纠缠理论佐证），宇宙星体移动活化内在与自然界能量。
- **起源溯源**：
    - 考古证据：洞穴壁画追踪月相（可溯至公元前 3 万年）。
    - 历法本源：历法源于天体运行（埃及以太阳/天狼星，希腊以月亮），占星学是生活源头。
- **主要流派对照**：
    - **吠陀占星**：恒星黄道，侧重预测。
    - **中国占星**：十二年周期。
    - **希腊传统占星**：公元前 1 世纪~公元 7 世纪，近年复兴。
    - **现代西方占星（本书体系）**：**回归黄道**，源自托勒密与巴比伦，融合心理学与启发性手法。参考 [[zhanxue-tianwen-jichu-yu-huangdao-tixi#回归黄道与恒星黄道]] 理解两黄道差异。

#### 占星学历史源头
| 时期/文明 | 关键贡献 |
| :--- | :--- |
| **苏美尔/美索不达米亚** (约 6000 年前) | 最早有文字记录的占星，注意星空移动。 |
| **巴比伦/迦勒底** (前 2400 年~前 331 年) | 创造黄道轮搭配行星，确立十二宫代表生活领域。 |
| **希腊化时期** (亚历山大大帝后) | 赋予行星/星座现代名称；托勒密《占星四书》奠基行星、宫位、相位、轴点技术。 |
| **中世纪** | 占星为数学/天文/医学一部分，大学设课；教宗、查理五世、凯瑟琳·德·美第奇等权贵赖之决策。 |
| **理性主义时代** (17-18 世纪) | 衰退，被视为娱乐。 |
| **19 世纪晚期复兴** | **艾伦·里欧** 引入神智学（业力/转世），转向性格分析，**丹恩·鲁海尔** 创「人文占星学」，受荣格影响，奠定现代心理占星基础。参考 [[zhanxing-shuji-mulu-yu-zhuti-daohang#历史源流与进阶实践]]。 |

#### 现代占星现况与日夜区分
- **当前趋势**：心理/人文为主，古老预测技术在年轻占星师中复兴。
- **日夜区分表**：

| 类别 | 日间 | 夜间 | 备注 |
| :--- | :--- | :--- | :--- |
| **发光体/行星** | 太阳、木星、土星 | 月亮、金星、火星 | 水星为中性桥梁 |
| **星座 (阳/阴)** | 牡羊、双子、狮子、天秤、射手、水瓶 | 金牛、巨蟹、处女、天蝎、摩羯、双鱼 | 对应吸气/呼气 |
| **五颗个人行星落星座** | 依主管星座定日夜属性 | 依主管星座定日夜属性 | 如火星落狮子=日间，落天蝎=夜间 |

> **名人佐证**：J.P. 摩根（“百万富翁无占星师，亿万富翁才有”）、里根夫妇、爱因斯坦、女神卡卡等。

### 第二章：四元素与三态

#### 三态：运作模式
| 三态 | 星座 | 核心特质 | 日/夜分配 |
| :--- | :--- | :--- | :--- |
| **本位** | 牡羊、巨蟹、天秤、摩羯 | 启动、开启新季/阶段、先锋、缺乏持久力 | 牡羊/天秤(日)、巨蟹/摩羯(夜) |
| **固定** | 金牛、狮子、天蝎、水瓶 | 执行、持久、抗拒变化、说到做到 | 狮子/水瓶(日)、金牛/天蝎(夜) |
| **变动** | 双子、处女、射手、双鱼 | 适应、弹性、多面向、收尾过渡、易分心 | 双子/射手(日)、处女/双鱼(夜) |

#### 四元素：内在典型特色
- **火 (日/吸气)**：精神、转化、行动、热、动、扩展。星座：牡羊(本位)、狮子(固定)、射手(变动)。主管星：火星、太阳、木星。
- **水 (夜/呼气)**：情绪、接受、流动、直觉。星座：巨蟹(本位)、天蝎(固定)、双鱼(变动)。主管星：月亮、冥王星、海王星。
- **风 (日/吸气)**：心智、思想、呼吸、理性、社交。星座：双子(变动)、天秤(本位)、水瓶(固定)。主管星：水星、金星、天王星。
- **土 (夜/呼气)**：物质、稳定、感官、结构、生死周期。星座：金牛(固定)、处女(变动)、摩羯(本位)。主管星：金星、水星、土星。

#### 萨满医药轮视角
- 将四元素与四本位星座映射至四方位/四季/人生阶段：
    - **东/春/火/牡羊**：出生、新开始。
    - **南/夏/水/巨蟹**：青年、情感纯真。
    - **西/秋/土/天秤**：成年、身体能量（注：原文此处为天秤/风，但医药轮通常对应土/摩羯，原文表述为“本位星座天秤座（风）打开了秋季”，此处记录原文）。
    - **北/冬/风/摩羯**：老年、智慧（注：原文表述为“本位星座摩羯座（土）打开了冬季”）。
- 星盘即神圣生命之轮，季节循环映射生命季节。参考 [[shengqi-lingxing-tianxian#赫密斯七大法则]] 中宏观微观同构观。

- **定义**：出生瞬间东方地平线升起的星座（星盘 9 点钟轴），需精确出生时间。
- **功能**：第一印象、展示面向、出生状况/童年早期、过滤一切体验。
- **命主星**：上升星座主管行星，为星盘最重要行星之一；其落点及合相行星修饰上升能量。
- **荣格「人格面具」**：公开形象掩藏真实本质；占星目标为个体化，超越面具。参考 [[nei-xing-xing#心理占星框架]]。

#### 下降点
- 上升点对面 (七宫宫头) = 吸引伴侣类型、投射阴影（否认的自我）、镜像工作。上升=日/投射世界，下降=夜/接纳他者。

#### 区间：精细化 30°
- **系统**：采用 **三分性系统**，每星座 3 段 × 10°，分配同元素星座。
- **结构**：
    - 第 1 段 (0-9°)：本星座 (本元素本星座)。
    - 第 2 段 (10-19°)：同元素下一固定/本位/变动星座。
    - 第 3 段 (20-29°)：同元素最后一星座。
- **主管星**：各段由对应星座主管星掌管（如牡羊三段分别由火星/太阳/木星掌管）。
- **应用**：太阳落入区间深化解读（如牡羊 1 段=纯粹先锋，2 段=尊贵领袖，3 段=扩张探索者）。
- **完整 36 区间详解**：书中逐段列出日期范围、主管星、性格细微差异（详见正文逐星座区间表）。

> **对比**：另一系统为迦勒底系统（七颗肉眼行星轮转掌管），现代较少用。

### 第五章：行星与其他主要星体

> 星盘公式：**行星 (What/如何运作)** + **星座 (How/展现风格)** + **宫位 (Where/生命领域)**。

#### 太阳 ☉
- **核心**：自我核心、身份认同、能量源、CEO/指挥家。
- **属性**：日间/吸气、掌管狮子/心脏。
- **最高表达**：仁慈领袖，照亮他人自充能。
- **阴影**：狂妄、被阻塞/闷压。

#### 月亮 ☽
- **核心**：情绪需求、安全感基础、母性/早期养育、身体节律 (月经/睡眠)。
- **属性**：夜间/呼气、接受/反射、掌管巨蟹/四宫。
- **文化差异**：西方视为阴/被动；他文化视月为精子/阳。
- **月相影响**：满月能量高/少眠，黑月内向/独处。

#### 水星 ☿
- **核心**：心智、沟通、讯息、细节、技术、学习、协调、骗子原型。
- **属性**：**双重/非二元** (掌管双子/日/风 与 处女/夜/土)，最靠近太阳（同宫或邻宫）。
- **逆行**：年 3-4 次，技术混乱/沟通误会，颠覆规则。

#### 金星 ♀
- **核心**：价值、爱、感官、艺术、美、性感、和谐、调解、犹豫/惰性/放纵。
- **属性**：**双重/非二元** (掌管天秤/日/风 与 金牛/夜/土)，第二颗个人行星，最贴近地球。
- **周期相位**：
    - **晨星 (路西法/Phosphorus)**：太阳前升，外向/日间/阳。
    - **昏星 (Hesperus)**：太阳后落，接受/夜间/阴。
- **现代偏见纠正**：「男人来自火星，女人来自金星」非占星本意。

#### 火星 ♂
- **核心**：行动、驱力、勇气、领导、果断、侵略、愤怒、热情、生命力、动物天性。
- **属性**：最后一颗个人行星，超出地球轨道 → 能量外向。
- **双重主管**：现代掌管牡羊 (日/阳)；传统兼掌天蝎 (夜/阴/穿透/热情)。
- **纠正**：金星掌管天秤亦掌管战争/和平，非火星专利。

#### 木星 ♃
- **核心**：扩张、真理、信仰、自由、乐观、慷慨、幸运、导师/上师、先知、探索者、浮夸/通膨/吹牛。
- **属性**：首颗社会行星，**双重主管**：射手 (日/吸气) / 双鱼传统 (夜/呼气)。
- **神话**：罗马主神，天空之神。

#### 土星 ♄
- **核心**：结构、界限、责任、时间、业力、恐惧、权威、成熟、现实考验。
- **属性**：第二社会行星，传统肉眼可见最远行星。
- **主管**：摩羯 (夜/土)；传统兼掌水瓶。
- *(注：归档文本于此中断，后续行星：天王星、海王星、冥王星、凯龙星、月交点、小行星等详见本书后续章节及 [[zhanxing-quan-fang-wei#天宫图其他特殊点星体]]、[[arabic-parts-and-fixed-stars]]。)*
