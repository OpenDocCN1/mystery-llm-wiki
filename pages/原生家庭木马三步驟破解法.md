# 原生家庭木馬三步驟破解法

> **核心主張**：若不拔除木馬，只會不斷在原生家庭的負向印記中重複；透過「升維看問題」的三步驟破解流程，快速搜出核心負向印記，瞬間醒來並拋棄繼承，才能從家族命運劇本脫困，創造大無限的自由人生。

---

## 一、核心理論架構

### 人類木馬程式定義
- **隱喻來源**：特洛伊木馬 —— 特洛伊人自己打開城門迎入木馬，如同我們不自覺打開潛意識大門迎入原生家庭限制性信念
- **技術隱喻**：駭客遠端控制工具，在使用者不知情下竊取、修改、控制、破壞資料
- **心理機制**：心腦被卡住，只能依照既定程式反應當下，無法想到其他可能性
- **徵兆判斷**：覺得茫然、力不從心、充滿無力感、沒熱忱、窮忙、疲於奔命、不知為何而忙、時間不夠用、老是事與願違 → **鐵定中了人類木馬程式**

> **相關頁面**：[[人类木马程序]]、[[量子天命与AI时代新天赋]]

### 升維看問題：愛因斯坦原則
> 「我們不能在製造問題的同一個層次上解決問題。」

- **高斯算術隱喻**：1+2+...+100 不用逐個相加，退後幾十步全觀結構，頭尾相連（1+100=101），三步驟得出 5050
- **對應轉化**：將算式平移為「原生家庭負向木馬印記三步驟破解法」

## 二、三步驟破解核心流程

### 步驟一：頭尾相連
> **操作**：把目前當下發生的問題，與最初在原生家庭發生的同類型**初始事件**相比對

### 步驟二：頭尾第二數相連
> **操作**：把目前當下**之前發生過的同類型問題**，與在原生家庭發生初始事件**之後的同類事件**相比對

### 步驟三：找共同點
> **操作**：找到共同一致的 **情緒頻率／模組／慣性反應／行為**，寫出內建程式設定，並找出「抓著這個木馬程式不放」的**好處**

#### 好處範例（隱性動機）
- 被漠視 → 逼我們要自強
- 被拋棄 → 讓我們要自愛
- 挫折 → 教會我們更謙卑
- 失去 → 讓我們更加珍惜
- 我們能弱 → 就能更強大

## 三、實戰案例示範：學生 A 的職場協調困境

| 步驟 | 當下情境 | 原生家庭對應事件 |
|------|----------|------------------|
| **1. 頭尾相連** | 工作上主管與屬下同事不合，A 夾在中間協調 | 身為長女，小時候經常夾在父母與弟妹之間擔任協調衝突角色 |
| **2. 頭尾第二數相連** | 婚姻中夾在老公與孩子/公婆衝突間當緩頰者 | 求學時期身為班長，在老師與同學間擔任布達、維持秩序、協調的人 |
| **3. 找共同點** | **共同模組**：身為上下關係間的協調者 | **抓木馬好處**：能同時被兩邊重視與需要，透過協調得到「被需要」的感覺與價值感 |

### 破解方案：逆轉反應法
1. **覺察**：承認雖累但享受被感謝、讚美、成就感
2. **反向檢查**：若雙方和平不再需協調，會如何？ → 失落、覺得沒價值
3. **脫勾**：將價值感/成就感與「協調者」角色脫勾
4. **新反應**：遇同類情況 → **強迫自己放手**，讓雙方自己面對，絕不介入/傳話/給意見/協調
5. **堅持**：一次、兩次、三次……每次選擇與過去不同的反應，以新反應覆蓋舊模組

> **效果**：不再需從「協調者」找存在意義，省下時間專心做自己的事/夢想，建立扎實成就感

## 四、三代家族史破解源頭木馬法（深度掃描）

> **隱喻**：三步驟法如 X 光片；三代家族史法如超音波/核磁共振，能精密掃讀深處極小病灶  
> **量子糾纏觀**：搬到火星仍會與原生家庭產生精神糾纏，**必須在精神層面充分理解印記形成機制**

### 步驟一：完成三代家族史撰寫
- **角色設定**：記者、傳記作者、紀錄片導演、偵探
- **搜訪對象**：爸爸、媽媽、爺爺、奶奶、外公、外婆、姑伯姨舅、表堂兄弟姊妹
- **必記細節**：領養、墮胎、難產、自殺、意外、疾病、分居離婚、財務大事、離奇戲劇性故事
- **自我成長史**：出生至今每一件重要大事，特別是引發極大情緒部分；回溯至出生前（父母感情、墮胎念頭、誰帶大、獨生/兄弟姊妹、偏愛對象）

> **參考素材**：
> - 紀錄片《羅塞里尼家族絮語》—— 名人後代「羅塞里尼症候群」
> - 電影《Gucci：豪門謀殺案》/ 紀錄片《古馳夫人：黑寡婦派翠西亞》—— 兩組木馬基因族譜共演悲劇
> - 影集《魷魚遊戲》金句：「人不是因為別人值得相信才相信，是因為如果不相信，自己就會無依無靠。」
> - 紀錄片《天堂在405號公路塞車》—— 藝術家明迪·艾波蛻變教材
> - BBC 系列《7 Up》—— 跨三代時間軸追蹤 14 人人生軌跡

### 步驟二：跳出家族角色，升維成「靈魂程式維修工程師」
- **視角轉換**：從人造衛星俯瞰地球城市街道，一眼看到交通打結處
- **操作**：拿起三代家族史，**用紅筆以自己為主軸**，往上/下/旁圈勾三代共同點（行為模式、信念、情緒頻率、疾病、意外、重大事件）
- **基因剪輯**：把不想重複的負向模組剪掉

#### 案例：學生 B 的「月光族」金錢木馬
- **現象**：父母收入豐厚、會理財、無負債，B 卻入不敷出、衝動買玩偶、刷爆信用卡
- **源頭**：童年想買玩偶被父母拒絕（認為對學業無用），教育/補習卻捨得花錢
- **核心信念**：錢是有限的，自己想要的都得不到 → 長大後「報復式消費」填補「愛＝玩偶」的缺憾
- **延伸模組**：「愛＝物」木馬 → 寵孫爺奶/溺愛父母漏夜排隊買限量玩具，刷存在感，最終過勞、愧疚、低價值感

> **相關頁面**：[[天命辨识与天命木马清理]]、[[显化实操与情绪温度计]]

### 步驟三：歸納核心木馬方程式
> **方程式寫出來 → 準確預測「模組不變下」可能發生的事 → 及早趨吉避凶、變換車道**

#### 案例：好友 A（先生淋巴癌）
| 維度 | 內容 |
|------|------|
| **雙方原生家庭** | 女強男弱（個性強勢），A 夫妻同樣繼承 |
| **核心方程式** | 「女：強勢→神經衰弱」vs「男：隱忍→癌症」 |
| **機制** | A 幼時常被糾正 → 長大轉為「糾正」別人拿回權力 → 以老師「揪錯」模組管老公 → 老公長期接收負向批評能量 → 攻擊自己（淋巴癌） |
| **破解** | 中止「揪錯」模組，以愛的頻率交流，真心道歉，化抱怨為感恩/珍惜 |
| **延伸木馬** | 「揪錯/糾正」→「正義魔人」（堅信自己 100% 對，不容質疑，目的消除異己/爭贏）vs 真正義（為弱勢發聲，理性溝通，目的解決問題/達成平衡） |

## 五、側翼游擊補漏：九大問題單

完成三代家族史破解後，延伸補強次要木馬：

| 題號 | 內容 | 功能 |
|------|------|------|
| 1 | 寫出出生至今每一個重要轉折/抉擇點 | 以「已是過來人」高維角度修改過去反應模組 |
| 2 | 試想若當初做不同選擇，會有什麼不同路徑/結果 | 同上 |
| 3 | 列出此生最遺憾/懊悔的事，若改變哪個環節會不同 | 同上 |
| 4 | 重新經驗前半生大事記，會在哪些環節做什麼改變 | 同上 |
| 5 | 穿越回過去，想在哪些關鍵時間點給自己什麼建議 | 同上 |
| 6 | 若五年後的自己穿越來，會給什麼建議 | 同上 |
| 7 | 寫出目前最想完成的十個願望 | **檢查未來是否仍投射未清理木馬**（如買跑車/豪宅想證明成功、想讓原生家庭誰知道、期待誰的肯定） |
| 8 | 一句話總結前半生，並寫出常掛嘴邊/社群媒體的一句話 | **潛意識預設檢查**（如「人生充滿奇蹟」預設「充滿災難/挑戰」；「一定有辦法」預設「眼前必有困難」） |
| 9 | 置身每位家族成員角色，重新經驗重大事件，會在哪些環節改變 | 以高維角度幫三代修改反應模組，不再重演代代相傳劇本 |

> **執行標準**：「自我覺察」系統最少堅持 **21 天**，**3 個月以上更好**，方能徹底拋棄繼承負向印記

## 六、五大生命課題木馬破解示範

### 面對自我：自信、存在意義、價值感

#### 父母烙印負向印記機制
| 事件 | 母親反應 | 孩子反應 | 可能負向印記 | 建議破解 |
|------|----------|----------|--------------|----------|
| 想買玩具被拒 | 「再不聽話我就走了！」 | 害怕被遺棄，放下玩具哭著追媽 | 不再說真實需求，以權威期望為主，變成無聲音工具人 | 深談了解需求，將物欲轉為創作欲（積木/繪畫/黏土） |
| 玩具被鄰居搶 | 教訓「要跟朋友分享」 | 之後經常分享食物/玩具，甚至自己未吃飽/玩夠 | 習慣犧牲自己成全他人，直到被掏空失去自我 | 家長秉公處理，教孩子愛自己、勇敢表達、拒絕不合理 |
| 拿鄰居孩子比較 | 「你看看你，這個也不如他……」 | 兩極：越來越糟 / 拼命贏過對方 | 把「競技場思維」裝進腦袋，以贏過別人為成功標竿，忽略自身天賦/愛的需求 | 別拿孩子比較，協助孩子找到屬於自己的興趣/天賦 |
| 被同學欺負/弄傷 | 訓孩子：「是不是你做了什麼惹人家？」 | 之後遇類似狀況選擇不說 | 吸引施暴者，遇不合理待遇隱忍不說直到出大事 | 父母做最親密信任朋友，聯合學校關心霸凌孩子原生家庭 |

#### 兩大延伸木馬模組
1. **救世者木馬模組**
   - **核心**：給予帶著「交易目的」（等感謝/回報/崇拜），非真心無條件
   - **陷阱**：耗乾後沒人給關注 → 自我存在感受打擊；以「幫助別人」逃避自己課題
   - **破解**：先檢查自己是否最需要幫助的人；學會「願意相信別人自己也能做好」，從不信任控制轉為信任放手
   - **檢查題**：療程結束對方沒感謝/稱讚，你會不會失落？

2. **完美主義木馬模組**
   - **源頭**：母親說「做什麼事都要準備到完美才能去做」
   - **本質**：基於「看不到自己哪裡好，永遠覺得不完美」的焦慮（未來），否定當下自己
   - **破解關鍵語**：「不必想太多，現在就去做，先求有，再求好，邊做邊修正」
   - **曼德拉語錄**：「希望你的選擇，反映你的夢想，而非你的恐懼。」

> **核心原則**：不必鞭策出更好的自己，只有本初貌真的自己；最高維度一切已完美、已具足

### 人際/家庭/情感關係

#### 父母影響投射機制
- **四分之三個案**因未察覺父母影響，將負面模組投射到自己關係
- **父母不睦/離婚** → 對感情不信任木馬 → 高逃避/低焦慮（疏離型）或高逃避/高焦慮（恐懼型）
- **父母外遇** → 懷疑另一半 → 對方被疑心病搞煩 → 分手或真外遇
- **父母公開互揭瘡疤** → 孩子烙印「感情麻煩、充滿謊言背叛」+「自責/自我貶低」 → 自我價值感低落 → 變成金錢破口（花錢填補）

#### 三步驟破解個案

**個案一：被好友背叛/奪愛**
1. **揪錯**：被身邊親密的人背叛、奪愛
2. **方程式**：自己不夠好 → 總被親密的人背叛奪愛
3. **查訪**：妹妹把秘密告訴爸媽 → 被罵、討厭、感覺妹妹奪走爸媽愛
4. **破解**：置入妹妹視角重新體驗 → 理解妹妹感覺爸媽比較愛姊姊想奪愛 → 原諒當時還小的妹妹 → 不再用「受害方程式」創造更多事故
5. **反例**：同模組女性成為第三者/兩女爭一男（男方通常被媽媽/奶奶溺愛，外遇時選擇躲起來讓女人雙方競鬥）

**個案二：不斷逃獄卻逃不開情感依賴獄**
- **方程式**：夾在兩者之間，透過雙方爭奪自己來增加自我價值感
- **循環**：嚴格管控原生家庭 → 逃離找反對的女生結婚 → 發現女生變成另一管控者 → 出軌找「自由」女生 → 想保有錢又要更多愛 → 兩女水火不容逼選邊 → 放棄原配/錢/孩子重新打拚 → 事業興盛又想逃 → 再外遇……
- **破解**：以「面對」取代「逃避」，空出獨處空窗期面對孤單，不再找新對象填補空洞，直到能完全自處愉悅

**個案三：建築師 A，多次換女友/結婚/離婚/劈腿**
- **源頭**：幼時父母離異，交給奶媽帶，奶媽換好幾任，輪流由奶奶/外婆/姑姑/阿姨帶，晚斷奶
- **模組**：「習慣性」要有兩個以上女朋友，壓力時吸吮手指
- **破解**：同個案二，學會獨處/獨立面對自己

> **關鍵洞見**：自尊自信地基夠深穩 → 不需跟別人計較/攀比 → 省下討好/等待肯定/療傷精力 → 心胸寬闊真心欣賞別人 → 互為貴人 = 最高維度共好版本

### 個人天賦藍圖

#### 核心隱喻
- 電影《靈魂急轉彎》《魔法滿屋》：天賦不是別人眼中了不起的成就，而是以創造/創作點燃熱情活著的火花
- 參考：[[量子天命与AI时代新天赋]] 多維度雙錐雙向金字塔模型

#### 案例：會計師多興趣半途而廢
| 步驟 | 內容 |
|------|------|
| **1. 揪錯** | 很多興趣（畫畫/跳舞/寫作/花藝/茶道），大部分半途而廢 |
| **2. 方程式** | 自己喜歡的事都會被中斷 |
| **3. 查訪** | 幼時玩積木被媽媽打斷要先做功課 |
| **分析** | 媽媽內建「聽我的否則剝奪玩權利」模組 → 長大先選父母期望學校/工作，忽略喜好 → 剩餘時間學這學那，但「中途被打斷」模組仍運作 → 自己成為打斷自己的人（或投射到主管/同事/先生/孩子） → 耗費青春熱情 10-20 年 |
| **破解** | 列出真正想做的事 → 問「明天不在地球了，沒做哪件事最遺憾」（不遺憾清單取代夢想清單） → 列為最優先，每天盡可能多時間專心完成，**絕不半途而廢** → 只承諾做得到的，承諾後盡量不更動/反悔/拖延/取消 → 中途冒出新念頭寫在「完成首要事之後」待辦清單 |

> **心誠事享原理**：徹底清除/轉換負向印記（恐懼限制性信念） → 化恐懼為勇氣 → 恢復清明原廠設定 → 天賦之光無阻礙散發 → 機會資源自動聚流

### 金錢與財務

#### 核心原則
- 計較/掠奪/索求 = 貧窮開始
- 對自己信心決定財庫容量
- 覺得「不配得」 → 潛意識以離奇方式擋掉/推掉/花掉/被騙/被借不還/投資失利
- 「炫富」贏羨慕/崇拜 → 負向動機觸發「花更多錢/破財」
- 自我認同/情感關係木馬破洞 → 變成金錢破口（無信心買保養/名牌；焦慮健康買保健品/保險）

#### 十八題搜查金錢木馬「錢（潛）意識」

| 類別 | 題號 | 核心探查方向 |
|------|------|--------------|
| **原生家庭直接搜索** | 1 | 父母發生過什麼錢相關事印象最深？灌輸什麼金錢觀？ |
| | 2 | 家人金錢觀造成哪些正/負向影響？ |
| | 3 | 祖父母/親戚錢相關事印象深刻？ |
| **深度潛意識搜索** | 4 | 講到錢第一聯想是什麼？（負向詞→倒裝寫方程式；正向詞→寫「錢不能做什麼」） |
| | 5 | 瞬間有數十/百億，可能產生什麼問題？最害怕什麼壞事？ |
| | 6 | 瞬間有很多錢卻緊急事讓錢消失，可能是什麼事？ |
| | 7 | 瞬間沒錢，最害怕什麼情況？ |
| | 8 | 瞬間負債，最害怕什麼？覺得因何事導致？ |
| | 9 | 沒錢會向誰求助/借款？ |
| | 10 | 沒錢/負債，覺得自己是怎樣的人？ |
| | 11 | 最大/最奢華夢想是什麼？ |
| | 12 | 怎麼完成？預估花多少錢？順利完成可能途徑？失敗可能原因？ |
| | 13 | 瞬間變超級首富，覺得自己會怎樣？ |
| | 14 | 最想讓誰知道你是超級首富？ |
| | 15 | 有花不完的錢想做什麼/買什麼？最常買/囤積什麼？最常被哪三類廣告吸引？ |
| | 16 | 從超級首富變回原樣，感覺如何？會變成怎樣的人？ |
| | 17 | 從超級富豪變「負」豪，覺得自己怎樣？別人會認為你怎樣？ |
| | 18 | 從超級富豪變「負」豪，想盡快回超級有錢狀態嗎？ |

#### 關鍵解析範例
- **題 1 案例**：父親擔保被跑負債、母親借錢親戚不還 → 個案拋棄繼承債務但**未拋棄金錢負向印記頻率** → 十分鐘寫出「被父母影響木馬方程式」一步精準破解
- **題 4「錢=麻煩」** → 方程式：「怕麻煩 → 潛意識不讓自己太有錢免得找麻煩」
- **題 4「錢=萬能」企業家** → 花最多錢在保健品/醫藥費 → **金錢破口**：「賺錢是為買名貴保健品/找名醫/住 VIP 病房」→ 潛意識聚焦「生病」輕忽健康
- **題 5「怕被親友借錢」** → 核心木馬：「不敢拒絕」→ 怕失去親友/怕被說小氣（愛面子） → 只要身邊人發現弱點就借不還
- **題 5「怕被綁架」** → 「太有錢=很危險」→ 潛意識抗拒金錢能量 → 表面努力賺錢存錢但莫名「被漏財」
