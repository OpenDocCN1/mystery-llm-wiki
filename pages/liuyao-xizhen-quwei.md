# 曲炜《六爻详真》核心理论体系

> 本页面依据曲炜《六爻详真》归档全文编撰，提炼其核心理论创新与实战方法论，并建立与现有六爻知识库的交叉引用网络。

## 一、 理论渊源与定位

曲炜（道号“若水”居士）在六爻预测学上提出**“六爻的四个层次理论”“六亲通变原理”“卦象信息定向锁定原理”“六爻用神转换原理”“两象定一象原理”**等体系化成果。其理论建立在李洪成大师“爻的三个层次”基础上，经大量实践改进而成，旨在解决传统六爻理论中生克顺序混乱、用神取象单一、信息提取浅表等痼疾。

> **交叉引用**：李洪成“爻的三个层次”可参考 [[liuyao-shizhan-dianqiao]] 马志川《六爻实战点窍》第七章对“卦爻四层次制约核心论”的阐释；同属传统派创新体系的还有 [[huangji-liuyao-tixi]] 贾秉然《皇极六爻》的“二元定位兼象定论” 与 [[liuyao-bagua-quanxi-lun]] 马凤魁《六爻八卦全息论》的“全息论预测依据”。

## 二、 爻的四个层次理论 —— 断卦的“宪法级”规则

### 四层次定义与权力阶梯

| 层次 | 称谓 | 组成 | 核心权力 | 受制约来源 |
|------|------|------|----------|------------|
| **第一层次** | **日月建爻** | 日建、月建（年、时同例） | 对卦中**任何爻**拥有生、克、拱、合作用；生克权最大 | 仅受进行时之日月更替制约 |
| **第二层次** | **变爻** | 主卦动爻变出的同位爻 | 对本位动爻及主卦其它动静爻有生克拱合作用；主卦爻无权反制变爻 | 受日月建制约；若对本位动爻有生克冲合则专注本位，否则旁及他爻 |
| **第三层次** | **动爻/暗动爻** | 主卦发动之爻、暗动之爻 | 能生克同层次动爻及主卦静爻 | 受制于日月建、变爻（尤其本位变爻） |
| **第四层次** | **静爻/伏藏爻** | 主卦静止之爻、伏神 | 仅能生克同层次静爻，**无权生克动爻**；即使临日月建也不具备主动生克权 | 受制于上三层所有爻 |

> **核心原则**：**上层次爻有权生克下层次爻，下层次爻无权生克上层次爻**。同层次爻间可相互生克冲合，但一旦有上层次爻介入，全部让位。

### 层次转换的实战关键

- **日月入卦**：静爻、动爻、变爻值日月建时，暂具第一层次**力量**（非权力），不被同层或下层克伤；待日月更替，原主克爻上升为第一层次时可反制。
- **应期断验**：财爻临日建（第一层次），兄弟动爻（第二层次）虽旺动亦克不伤财；唯待兄弟入月建（午月）上升为第一层次，方能克财应破财 —— **层次转化是断应期的核心钥匙**。

> **对比参考**：[[liuyao-shizhan-da-quan]] 梁涵博《六爻实战大全》亦融入“卦爻四层次旺衰生克权”作为易理篇核心；[[liuyao-lifa-jinjiie-qinglan]] 青岚《六爻理法进阶》重点讲解“月建冲爻/日辰冲爻”的层次博弈。

## 三、 生克权判断四大标准 —— 冲、合、墓、空

> 书中反复强调：**“刑冲合害实质是生克的特殊表现，凡有特殊关系者，具优先生克权；同层次中首论合冲，次刑，次害，最后论普通生克。”**

### 冲（Chong）对生克权的影响

| 冲的形式 | 判断规则 | 关键口诀 |
|----------|----------|----------|
| **日月冲变爻** | 变爻被冲散/冲脱，**失去正常生克权** | “日月冲变，变爻无权” |
| **日月冲动爻** | 旺相称“冲脱”（可合解/值日解），休囚受制称“冲散”（永无生克权） | “旺相冲脱可解，休囚冲散永无” |
| **日月冲静爻** | 旺相→暗动（升三层）；休囚只冲不克→临界态（看动变向背定破/动）；休囚连冲带克→日破 | “静爻逢冲：旺动、休囚临界、受克日破” |
| **变爻冲动爻** | 变爻层次高，有主动权；若变爻被日月制住则无权 | “变冲动：变爻有权，除非被制” |
| **动爻冲静爻** | 旺相静爻→暗动；休囚静爻同月冲静爻规则 | “动冲静：旺变动、休论破” |

> **互解互破顺序**（必须背诵）：  
> 主卦合冲 → 变爻解 → 日月解 → 动变合冲 → 日月解 → 月建合冲 → 日建解 → 日建合冲 → 进行时日月解。

### 合（He）对生克权的影响

- **成化条件**：六合需两动或动+本位变爻 + 日月有化神且无克化神；三合需三动或日月动变参与 + 化神在日月且无克化神。
- **合而不化** → 论“绊住减力”，暂失生克权；低层次/衰弱一方暂失权，待上层次冲开（解合）恢复。
- **日月合动爻**：无论旺衰均论“绊住”暂失权，**唯用神动逢生合不论绊住，反增力**；原忌仇闲神无论生合克合均绊住。
- **静爻逢日月合**：旺相生合→“合起”相当动爻；克合→不论合起。测出行时，用神逢合多主“因事件住”（看合神五行属何六亲定性）。

> **实战金句**：“动爻逢日月合，如系用神逢生合不论绊住，为增力；原忌仇闲神无论生合克合都为绊住，暂时失去生克权，相当于静爻。”

### 墓（Mu）对生克权的影响

| 入墓形式 | 条件 | 效果 | 解墓方式 |
|----------|------|------|----------|
| **爻入日月墓** | 动变静均逢日月为墓 | 入墓期**暂失生克权**，亦不受他爻生克 | **冲墓爻**（非冲日月）；如静爻入动爻墓、动爻入变爻墓可加“合墓” |
| **静爻入动爻墓** | 静爻只入动爻墓，不入静爻墓；动爻若被上层次制住失权，则不收静爻 | 同上 | 合墓、冲墓、冲动爻均可解 |
| **动爻入变爻墓** | 仅入本位变爻墓；变爻失权则不收 | 同上 | **冲变爻、冲墓、合墓** 三解（唯动变墓可合解） |

**出墓三式**：冲墓、冲入墓之爻、合墓（仅限动变墓）。**书中明确否定“过月自出墓”**，强调入墓留下原象，必待冲合解除。

### 空（Kong）对生克权的影响

- **旬空期间**：无论旺衰，**无生克权，亦不受生克**；休囚逢空避克，出空受克。
- **真空/假空**：休囚逢空为真空（出空仍无权）；有气逢空为假空（出空复权）。
- **解空仅两法**：**出空**、**冲空**（冲空仅发挥半力）。
- **动爻空、变爻空、动变双空**：均须待出空复权；冲动爻/冲变爻均无效。
- **伏神逢空**：有气假空→出空逢值有用；无气真空→逢值也无用；**冲空、冲飞神均解不了伏神空**。

> **应期实战**：测月余事按日推出空；测年运按月推；测日内事按时辰推。**“空亡、入墓权力大于一般生克，同等条件下先论空亡入墓。”**

## 四、 六亲爻位取用对应关系 —— 构建预测网络

> 书中主张：**“狭义取用只找一爻，本书取用指取出所有相关爻，一一对应事物方方面面，形成预测网络。”** 社会阅历越丰富，对应点找得越准，断卦越细致。

### 世应双核对应

| 爻位 | 核心对应 | 扩展对应 |
|------|----------|----------|
| **世爻** | 求测者自己、我方、我单位、我国 | 主体人、主动方、内因 |
| **应爻** | 竞争/对立方（合伙、比赛、谈对象） | 无对立性事件中：目的地（出行）、求财环境/店面（求财）、审批部门（办证） |

### 六亲十类象对应速查

| 六亲 | 核心代表 | 衍生对应（择要） |
|------|----------|------------------|
| **父母** | 文书、合同、证件、房屋、车辆、长辈、保护者 | 手续、证明、合同、房产证、领导、上级、衣服、被动方 |
| **兄弟** | 同行、竞争者、朋友、兄弟姐妹、劫财、投资 | 合伙人、同事、对手、支出、损耗、分离 |
| **子孙** | 财源、顾客、下属、晚辈、医生、药、解厄、快乐 | 利润来源、客流、治疗手段、快乐事、化解忌神之神 |
| **妻财** | 金钱、利润、妻子/情人、物质享受、商品、房产交易价值 | 求财卦核心用神、卖房卦取财爻代表房子商品价值 |
| **官鬼** | 官方、税收、制裁、管理、疾病、工作、职位、压力、丈夫(女测) | 审批权、病灶、职位、法律、灾祸、忌神克用神之爻 |

> **用神转换例**：测卖房，**父母本代表房屋**，但“欲卖房子已不具居住保护功能，显现商品交换价值” → **转用妻财爻代表房子**；钱到手即房子卖出。详见 [[liuyao-q-and-a-quwei]] 曲炜《六爻答疑》中关于“用神转换”的多条问答。

### 爻位六亲组合信息锁定

- **世爻临官鬼动** → 自己为事行动、心有忧虑、主不安；
- **世爻化兄弟** → 有投资支出；
- **世爻临朱雀动** → 必有口舌官非；
- **财爻临玄武动** → 暧昧之财、灰色收入；
- **应爻临兄弟** → 求财环境竞争激烈、环境克财；
- **子孙伏藏/月破入墓** → 顾客少/无财源；
- **父母爻未上卦** → 寻店面中未定；
- **官鬼爻临月建合住** → 官方征收/罚款克财。

> **实战金句**：“先想象现实办成此事需具备哪些条件，再在卦中一一找对应点，看哪具备哪不具备，阻碍点即显。”

## 五、 信息象提取实战法 —— 从“断吉凶”到“断细节”

### 信息提取三步法

1. **定主用神**（世应、六亲核心用神）判断大吉凶、成败。
2. **扩对应点**（六亲、爻位、六神、伏神、变爻、纳音、卦宫）构建预测网络。
3. **组合推演**（结合社会常理、具体事件背景），从零碎象中**理出头绪，提取符合实际的那部分信息**。

### 六神加持的定向锁定

| 六神 | 核心意象 | 组合提取例 |
|------|----------|------------|
| **青龙** | 喜庆、文书、贵人、东方、青色 | 父母青龙动 → 文书喜事、合同顺利 |
| **朱雀** | 口舌、文书、南方、红色、电话 | 世爻朱雀动 → 自己口舌、打官司、电话联系 |
| **勾陈** | 旧、老相识、土特产、房地产、田地 | 应爻官鬼勾陈 → 老客户、房地产/土特产单位 |
| **腾蛇** | 惊恐、细长、虚幻、缠绕、多变 | 用神化墓临腾蛇 → 火车/飞机(细长腾飞) |
| **白虎** | 血光、凶险、西方、白色、车辆 | 子孙白虎动 → 血光灾、车辆损坏 |
| **玄武** | 暧昧、隐私、北方、黑色、偏财 | 财爻玄武动 → 灰色收入、偏门财、私密交易 |

### 经典卦例信息提取演示

#### 案 A：女测女儿未来电话原因（卯月癸酉日《天水讼》）

- **现象**：子孙戌土（女儿）月日休囚、临白虎、月建卯合克 → 众断“血光凶险”。
- **曲炜提取**：
  1. 子孙戌土旬空不受克 + 卦内无动爻克子孙 → **人安全**（内因无伤）。
  2. 原神兄弟旺相 → 生源不断 → **平安确证**。
  3. 月建卯(父母)合戌 + 日建酉(妻财)合辰(子孙) → **父母=通讯/电话，妻财=钱财/费用** → **因手机欠费(财)致通讯(父)中断**。
- **验证**：次日戌日出空冲动辰土，女儿来电确系欠费交款。

#### 案 B：测弟弟何日回家（申月丙午日《雷火丰》之《震为雷》）

- 用神兄弟亥水动化墓（辰土墓）。
- **酉日**酉辰合化金，月建申金引化成功 → **墓性质变化解墓** → 断酉日回。
- **进阶象**：化墓爻为官鬼(官方/国家)+腾蛇(细长) → **乘火车(官方墓库+腾蛇细长)返家**。

#### 案 C：测房子何时卖出（酉月辛未日《水天需》之《泽风大过》）

- 世爻申金(自己)暗动化亥水(财)旬空 → **暂无卖房目标/无联系**。
- 亥水出空(乙亥日)逢甲戌旬，世爻申金进神逢空 → **新毛病**，仍无联系。
- 唯待**甲申/乙酉日世爻申金出空**，世应财三方构成实质生克冲合联系 → **乙酉日成交**。

## 六、 起卦模式与思维方式的统一性原则

| 起卦法 | 核心机制 | 适用场景 | 思维匹配原则 |
|--------|----------|----------|--------------|
| **六爻摇卦** | 铜钱磁场传导求测者意念 → 阴阳组合成卦 | 重大决策、急事、求测者心静无干扰 | **必须用六爻纳甲推断体系**；动爻少、显象明、断得细致活灵 |
| **梅花易数** | 先天数/后天象起卦，不受求测者主观干扰 | 环境嘈杂、心不稳、随机事件、突发大事参断 | **必须用梅花易体用卦气断法**；直观快捷、不取用神 |

> **铁律**：“模式与推算机制必须相符合。摇卦用梅花断、梅花起卦用六爻断，准确率必降。”
> **融合条件**：两法起卦结果一致时可互参；不一致时，**各按其起卦模式对应的推断体系断**。

### 七大选模决策表（实战速查）

1. 首选**自己最擅长**模式。
2. 重大/突发事 → **时间卦(梅花)为主 + 六爻参**，矛盾以梅花为准。
3. 环境嘈杂/心不静 → **梅花易**。
4. 心静无干扰 → **摇卦**。
5. 非突发事(求财、婚姻、工作) → **不可随意用时间起卦**。
6. 随机事(随口一说) → **梅花易**；庄重事 → **摇卦**。
7. 以**第一意念**想用何法为准。

## 七、 断卦基本功修炼路线图

1. **背诵并内化“爻的四个层次”及层次转换规则** —— 这是断卦的“宪法”。
2. **精通“冲合墓空”对生克权的四大判断标准** —— 这是断卦的“刑法/民法”。
3. **建立“六亲+爻位+六神+伏神+变爻”多维对应网络** —— 这是断卦的“证据体系”。
4. **练就“联想思维+社会常理”信息组合能力** —— 这是断卦的“推理引擎”。
5. **积累实战卦例，验证“临界状态、层次转化、合冲互解顺序”** —— 这是断卦的“案例库”。

> **曲炜寄语**：“师傅领进门，修行在个人。教不教是师傅问题，学不学、能不能举一反三是徒弟自己的问题。学易不能单靠书本、单靠师傅一句句喂，剩下的全凭自己去悟！”
