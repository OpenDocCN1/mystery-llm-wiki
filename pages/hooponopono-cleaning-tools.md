## 工具一：蓝色太阳水 —— 液态清理剂

> **别称**：奇迹之水、生命之水。
> **核心作用**：协助清理讨厌的记忆；放置于工作桌可自动清理环境记忆、提升专注、清理电磁波影响记忆。

### 制作步骤（标准流程）

1.  **容器**：准备市售蓝色玻璃瓶（葡萄酒空瓶可复用）；无蓝瓶时，可用蓝色玻璃纸包裹透明玻璃瓶代替。
2.  **注水**：装入自来水或矿泉水，约四分之三满。
3.  **封盖**：**严禁金属盖**；使用塑料盖、玻璃盖、软木塞，或用保鲜膜+橡皮筋密封。
4.  **日晒**：置于阳光直射处 **30~60 分钟**。
    - 阴雨天：白炽灯（钨丝灯）下照射效果相同。
    - **日光灯/LED 灯无效**。
5.  **完成**：制作完成后倒入他容器效果不减。

### 使用规范

| 场景 | 操作要点 |
| :--- | :--- |
| **日常饮用** | 滴入几滴于普通水/饮品中；建议日饮 2 升；冷热不影响效果；属生水，尽早饮尽。 |
| **烹饪/洗澡/洗头/洗脸/洗衣** | 直接替代普通水使用。 |
| **桌面净化** | 工作桌放置 3/4 满一杯，自动清理空间与电磁波记忆。 |
| **外出/无水时** | **想象**自己正在饮用蓝色太阳水，效果同等。 |
| **情绪失控急救** | 水中加入 1~2 滴鲜柠檬汁饮用。 |

## 工具二：HA 呼吸法 —— 启动清理的「前置开关」

> **词源**：夏威夷语 "HA" = 神圣的灵感/生命之气。"Hawaii"、"Aloha" 皆含 HA，念诵即激活能量。
> **作用**：调整心灵环境，使意识接近零状态，为后续四句话清理铺垫。

### 七步骤 × 七循环 标准流程

| 步骤 | 动作与意念 | 时长/计数 |
| :--- | :--- | :--- |
| 1 | 坐定，脊背挺直，双脚踩地。 | — |
| 2 | 双手置大腿，拇指+食指+中指各自成圈，两圈套合（其余指放松）。 | — |
| 3 | **吸气**：想象神圣气息入体，心中默数 1~7。 | 7 秒 |
| 4 | **闭气**：保持能量内化。 | 7 秒 |
| 5 | **呼气**：想象吐出不良记忆，心中默数 1~7。 | 7 秒 |
| 6 | **闭气**：完成一次循环。 | 7 秒 |
| 7 | **重复**上述 ③~⑥ 共 **7 个循环**。 | 约 3.5 分钟 |

### 关键注意事项
- **环境**：安静、无背景音乐、不弯腰驼背。
- **专注**：全程消除杂念，专注呼吸与意念。
- **隐形版**：通勤、会议等公开场合，**在心里想象**做完整流程，效果同等。

## 工具四：删除键「X」 —— 一键格式化成瘾/创伤/关系破裂记忆

> **功能**：消除上瘾、虐待、关系破裂记忆；回溯心理阴影产生的时间轴，重置至正确位置；助保持冷静、专注清理。

### 两种操作模式

| 模式 | 操作方式 | 适用场景 |
| :--- | :--- | :--- |
| **心理意象法** | 问题发生时，**在心里想象一个大写「X」**，或对潜意识里的记忆说「X」。 | 随时随地、无工具环境。 |
| **实体书写法** | 对着**名片、贺年卡、圣诞卡**等实物，**用手指画「X」**（或笔划掉）。 | 清理对特定人物/往来关系的挂虑记忆（如担心对方健康）。 |

> **原理**：如同电脑删除键，机械式操作无需情绪卷入，直接切断记忆投射。

## 工具五：回家意象 & 马桶冲水意象 —— 即时情绪急救包

> **适用时机**：身处外地/学校/职场产生负面情绪、期待落空、被记忆牵着跑时。

### 回家意象（充电/归位）
**在心里构建专属「安全屋」全感官画面**：
- 视觉：玄关鲜花、车库爱车、窗户透出的暖光。
- 嗅觉：开门瞬间扑面而来的家的味道。
- 触觉/动觉：宠物在脚边嬉戏、脚下地毯的触感。
- **效果**：整个人放松下来，切断外部触发的记忆重播。

### 马桶冲水意象（排泄/释放）
**针对强烈烦躁、愤怒、执念**：
- 想象一台**脚踏式马桶**（非按钮式）。
- 将烦人的记忆/情绪 visualized 为污物。
- **反复用力踩踏冲水阀**，看/感受污物被水流卷走、彻底带离。
- **习惯化**：察觉内在记忆重播瞬间，立即启动此意象，抢在情绪发酵前清理。

## 根本清理语：四句话 / 第五真言

所有工具的底层驱动力均为 **「谢谢你、对不起、请原谅我、我爱你」**。
- **顺序不拘**，可仅念**「我爱你」**（涵盖前三句）。
- **对象**：始终对着 **尤尼希皮里（内在小孩/潜意识）** 说。
- **态度**：机械化、习惯化、无需情绪、无需分析原因。
- **进阶**：第五真言 **「我原谅我自己」** —— 神性原谅小我与记忆，可替代四句话 [[fifth-phrase-i-forgive-myself]]。
