# 六爻看鬼神

> **慕言秋水** 著 | 2014年11月完成 | 31个实战卦例 | 专攻鬼神灵异、凶死案例、坟墓风水、离婚官司等疑难断验

## 概述

《六爻看鬼神》是六爻预测师慕言秋水将十余年实战心得结集而成的案例专著。全书汇编31个实测卦例，聚焦于**鬼神灵异、凶死非命、坟墓风水、婚姻离婚、官司牢狱**等常规预测难以触及的“阴暗面”领域。作者以《增删卜易》为底本，融入**皇极六爻**二元定位、兼象定论等高阶技法，并大量运用**飞宫法、伏神拐角法、纳音类象、卦身卦世交叉定位**等实战技巧，展示了六爻在“阴阳两界、生死吉凶”精微处的断验能力。

书中每个卦例均包含：起卦信息（年月日时、空亡）、本卦变卦六神排布、断语要点、卦理深度分析、后续反馈验证。案例涵盖**保家仙、冤魂缠身、车祸横死、癌症凶亡、坟地风水煞气、离婚财产争夺、牢狱灾祸化解**等高难度实战场景，是六爻进阶者研究“疑难杂症”断法的珍贵资料。

## 作者与传承脉络

- **慕言秋水**：资深六爻预测师，师承**王天涧**大师，兼涉星相山法，主张“大道至简、道法自己、象大于一切”。
- 理论基石：《增删卜易》、[[huangji-liuyao-tixi|皇极六爻]]（贾秉然《黄金策》二元定位兼象定论体系）。
- 实战特色：重**理论与实践紧密结合**，擅长从**爻位生克、六神配合、伏飞拐角、纳音类象、卦象卦气**多维交叉验证，直指人心隐秘与阴阳机缘。

## 核心断验方法论

### 二元定位与兼象定论
- **世应双查**：世爻为己、应爻为人/事，再以飞宫法、伏神法多重定位同一对象（如丈夫、父亲、坟墓），多象印证，减少误判。
- **兼象取用**：一爻多用，如官鬼既主车祸、牢狱、丈夫、坟墓、又主鬼神、黑社会，结合六神、动静、生克、空亡综合判读。

### 飞宫法与伏神拐角法
- **飞宫法**：以世爻五行为本，顺飞九宫，查找六亲长辈、晚辈、宅院、坟墓、身体部位等空间对应，常用于定位“谁死、谁病、坟在何方”。
- **伏神拐角**：动爻化出伏神、伏神再化飞神，层层拐角，读取隐藏信息链（如：丈夫有外遇、坟地被挖、暗中行贿）。

### 纳音类象与卦气定性
- **纳音五行**定行业、疾病、器物、地形：如“炉中火”主砖窑、锅炉；“大驿土”主旅店、房地产；“霹雳火”主枪击、雷击、车祸。
- **卦气旺衰**定时间：月建日辰冲合刑害、进退神、空亡填实、出空入库，精准定应期。

### 卦身与卦世交叉定位
- **卦身**代表求测者居住环境、身体、事业主体；**卦世**代表求测者本人。
- 卦身被官父夹克主牢狱、车祸；卦世伏空逢冲主心神不宁、魂魄离散。

## 典型技法深度解析

### 案例一：多重象直读“两次流产”
- **初爻父母子水化子孙巳火**：巳长生在寅、在子为胎 → 怀胎象。
- **初爻伏父母子水**：两父母夹子孙巳火、临白虎、入戌库未到丑养地 → 流产。
- **六爻子孙巳火伏空入戌库** → 二次流产。
- **五爻子孙巳火被双官鬼申金夹合、临勾陈变鬼、与世爻同线** → 直读流产。
- **初爻子卯刑临白虎、二爻主打胎** → 佐证。
- **子孙有凶象为何定流产不定凶死？** 初爻子孙坐胎时临白虎被双子水克、卦中子卯刑在初二爻主打胎 → 定性流产。

### 案例九：旅店带小姐、公安罚款、女友妓头
- **子孙亥水动化申金长生、五爻酉金生、纳音屋上土大驿土** → 旅店。
- **子孙亥水临月建白虎空伏戌土、卯戌合、卯木妻财阴爻兑卦少女** → 黑社会合作带小姐。
- **三爻妻财卯木合父母戌未、亥卯未三合木局** → 以女友名义、父母出资。
- **子孙动化兄弟申金白虎玄武、亥申相害** → 公安朋友明查暗查罚款。
- **午亥暗合生戌、父母未土合动** → 五月兑店。
- **妻财卯木回头克、双父母夹克、木数三** → 兑价3万。
- **卯酉冲、申亥害、卯木申金属相** → 八月分手、女友属鼠、申金化出卯木主妓头。

### 案例十二：坟地风水煞气全景扫描
- **双父母夹卦、内卦艮山、父母动** → 问坟地风水。
- **六爻未土西南坟、酉金电线杆、寅木伏白虎电线杆、丁未天河水、丙寅炉中火砖窑、未土空风水被炼坏** → 高压线、砖窑煞。
- **六爻伏寅、初爻辰化卯** → 坟上有树、荫地主肝病骨折。
- **三爻巳亥平地木桥、丁未天河水** → 西南坟有桥主能人入狱。
- **初爻辰化卯空、东北坑正南高东北低** → 寿命不长。
- **二爻官父、坟地风水不好** → 牢狱车祸怪病。

## 实战启示与进阶建议

1. **疑难杂症必查伏飞**：常规六亲不上卦、世应不明显时，伏神飞宫是破解关键。
2. **六神定性不可少**：白虎腾蛇勾陈朱雀玄武青龙，各司其职，鬼神凶险更依赖六神意象。
3. **纳音类象穿透力强**：同一五行纳音不同，吉凶天壤之别（如大驿土旅店 vs 城墙土房产 vs 砂中土煤炭）。
4. **卦身卦世双核定位**：卦身代表环境/事业主体，卦世代表人本体，交叉验证极大提升准确率。
5. **化解建议落地化**：书中多给出“烧纸庙、拜旺贵人、调整佛堂朝向、迁坟、法术调理”等可操作化解方案，体现“知微知彰、趋吉避凶”易学本旨。
