# 商战与奇门

黄老师著有《奇门日课预测学》、《玄机风水密诀》、《商战与奇门》等系列专著。本书系统阐述奇门遁甲基础理论与商战实战应用，涵盖起局法、用神格局、趋吉避凶原则及新年开运、电话谈生意、洽谈座位等实战案例。

## 核心理论体系

### 奇门起源与发展脉络

奇门遁甲素称"中国方术之王"、"帝王之学"，与太乙、六壬合称"三式"。据考证：周秦称"阴符"，汉魏称"六甲"，晋隋唐宋称"遁甲"，明清始称"奇门遁甲"。

历史演变：
- **黄帝轩辕氏**：始创奇门四千三百二十局法
- **风后**：简化为一千零八十局（阴阳二遁各五百四十局）
- **太公吕望**：进一步简化为七十二活局
- **张良**：调整为十八活局（阳遁九局、阴遁九局），成现代时家奇门雏形

> 交叉引用：[[dong-bo-ju-shi-qi-men-miao-jue]] 东伯居士《奇门秒诀》对奇门源流、三才盘式、定局超神接气置闰的精简总览

### 三才盘式与核心符号

奇门遁甲造式三层，象天地人三才：

| 层级 | 对应 | 核心符号 | 数量 |
|------|------|----------|------|
| 天盘 | 象天 | 九星（天蓬、天芮、天冲、天辅、天禽、天心、天柱、天任、天英） | 9 |
| 人盘 | 象人 | 八门（休、生、伤、杜、景、死、惊、开） | 8 |
| 地盘 | 象地 | 九宫八卦、三奇六仪（乙丙丁三奇 + 戊己庚辛壬癸六仪） | 9宫/9干 |

**遁甲规律**：甲为元帅隐遁六仪之下（甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸），故称"遁甲"。

### 阴阳二遁与节气局数

- **阳遁**：冬至至夏至前，顺排六仪、逆布三奇，九局（一至九局）
- **阴遁**：夏至至冬至前，逆排六仪、顺布三奇，九局（一至九局）
- **上中下三元**：每节气十五天分三元（各五天），符头为甲或己
- **超神/接气/置闰**：交节与符头时差处理，芒种、大雪可置闰

## 起局七步法（快速起局）

1. **排四柱** 列出用事时间年月日时干支
2. **定局数** 根据节气与上中下三元确定阳遁/阴遁几局
3. **布地盘** 绘九宫格，按遁甲序数布三奇六仪（阳：戊己庚辛壬癸丁丙乙；阴：戊乙丙丁癸壬辛庚己）
4. **定值符** 依时辰旬首定地盘值符星（地盘六仪所落宫对应天盘九星）
5. **转天盘** 值符星带原宫三奇六仪顺/逆飞宫
6. **转人盘** 值使门（值符宫对应八门）按时宫顺序飞布八门
7. **排神盘** 直符落旬首六仪宫，阳遁顺时针、阴遁逆时针布八神

- **伏吟**：星门符归本宫（六甲时、癸亥时），不宜用事，主阻滞破财

- **三诈五假**：三诈（吉门+三奇+三阴神）百事吉；五假分天地人神鬼假，各有专用

## 趋吉避凶核心原则

### 总纲
> "急则从神，缓从门，动静先后分主客"

### 急则从神
事态危急无暇择吉门，从**值符**（天乙神）所在宫位行事，可免大险。

### 缓从门
1. **避凶时**：五不遇时（时干克日干，阳克阳/阴克阴）、时干入墓
2. **择吉方**：优先三奇+三吉门相会，兼直符/九天/九地/太阴/六合
   - 吉门 > 三奇（得门不得奇可用，得奇不得门不可用）
   - 专事专门：捕猎用伤门、吊丧用死门
3. **旺相休囚**：结合节令、宫位五行生克判断真吉真凶
   - 生门属土，临艮/坤/离宫得地，春季/四季月得时 → 旺相真吉
   - 凶门得时得地 → 真凶；休囚死废 → 凶门减凶

### 动静分主客
| 维度 | 客（动/先/主动） | 主（静/后/被动） |
|------|------------------|------------------|
| 动静 | 动 | 静 |
| 先后 | 先动 | 后动 |
| 态度 | 积极主动 | 消极被动 |
| 盘面 | 天盘（九星随时转） | 地盘（一局六十时不变） |

### 利主利客判断
1. **时辰**：五阳时（甲乙丙丁戊）利客，五阴时（己庚辛壬癸）利主
2. **格局**：白虎猖狂/腾蛇夭矫利客；青龙逃走/朱雀投江利主；伏吟利主（按兵不动），反吟利客（主动出击）
3. **天地盘生克**：
   - 天盘生地盘（星生宫）→ 利主
   - 天盘克地盘（星克宫）→ 利客
   - 地盘克天盘（宫克星）→ 利主
   - 主生客 → 耗散拖延；主克客 → 半实半虚；客克主 → 求吉反凶

> 结合旺相休囚综合判断，机动灵活：利主做主、利客做客

### 大事看星
重大行动除择时择方分主客，必看**九星吉凶旺衰**与宫位生克关系。

### 吉凶相对性
吉凶非绝对，可转化；需辩证看待，尽人事以转凶为吉。

## 应期断验方法

1. **原则**：用神旺衰/内外盘/伏吟反吟定远近快慢；先定地支后配天干；先值符后值使
2. **值符法**：刑冲以合应、旬空以填实应
3. **天盘六仪地支冲合**：逢合以冲应、逢冲以合应
4. **星门生克**：生逢生日、克逢克日
5. **用神长生旺相** → 应期快；**死墓绝** → 应期慢/不应
6. **庚格应期**：阴日看庚上干、阳日看庚下干（破案、寻人专用）

## 商战实战应用案例

### 新年开运（大年初一出行）

**操作要点**：
- 选吉时、吉方（有吉门/吉神/三奇/吉格、不落空亡）
- 吉方与年命宫相生比和
- 到达吉方停留30分钟以上吸纳旺气

**吉曜速查**：
| 类别 | 吉象 |
|------|------|
| 八门 | 开、休、生、景 |
| 天干 | 甲乙丙丁（甲为符首） |
| 九星 | 天辅、天心、天禽、天冲、天任 |
| 八神 | 直符、九天、九地、太阴、六合 |
| 吉格 | 天遁、地遁、人遁等 |

**实例1**：何经理（1969年八月生）2003年初一中午12:08往北方（坎宫）出行。坎宫有**开门+太阴**，年命落坎宫得助，不旬空。结果中标300万工程，全年顺利。

**实例2**：李总（1952年十月初三寅时生）2004年初一下午2:08往西北（乾宫）。乾宫**开门+九天**，年命坎宫**休门+直符**，乾坤相生。当年盈利增200万。

**实例3**：郑女士（1962年八月十六辰时生）2002年初一卯时(6:30)往西北跑步。乾宫**休门+太阴**，年命坎宫**天辅+六合+太岁同宫**。当年升正科长，得单位一把手夫人提携。

### 电话/传真谈生意

**操作流程**：
1. 准备以公司/住宅为太极点的八方位图
2. 客户方位落宫有吉门/吉神/三奇/吉格
3. 年命宫与客户方位宫相生比和更佳

**实例**：高厂长（1958年四月二十寅时生）塑料印刷机械厂业务下滑。按奇门择时十天内分方位打电话/传真：
- 6月16日申时(15:30-16:30)联系东南/南方客户 → 阳七局，**天盘休门+直符**落巽四宫（东南）、**生门+天蓬**落离九宫（南方）
- 6月17日未时联系西北客户
- 6月18日辰时联系东方客户
...
十天内谈成两单，原拒绝客户态度转变。

### 洽谈座位选择

**原则**：
- 作为主方：客到达前占据**利主方位**（值符/吉门/三奇/吉神所在宫位对应方位）
- 作为客方：选择**利客方位**入座
- 远行谈判：出发时、到达时、洽谈时三重择吉
- 签约时刻：另行择吉时刻签署
