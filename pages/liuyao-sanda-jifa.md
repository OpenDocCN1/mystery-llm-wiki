## 书籍概况

《六爻三大技法》为黎光先生2000年整理古例，将古代卦例中的基本卦理条分缕析整理成三类技法，每技法皆有固定公式。书中简化影响较小因素的讲解，尤其简化旺衰分析方法，强调学习时牢记「先抓主要矛盾」，明确主从关系。

全书以流程化思路重构清代六爻思想，意图使读者在一个月内打下基础。拙作《隐易千金断》所提供的技法均须在此基础上方能正确完善使用。

## 出版结构

### 上篇 登堂入室—六爻三大技法
根据多年预测经验吸收晚期六爻古籍精华与数千卦例规则而成。按日常生活咨询事体分为三类：吉凶占、得失占、应期占。每单元含学习要点、学习提示、课文、卦例、思考。卦例多引自《增删卜易》与《卜筮正宗》并以三大技法思路重析。

### 中篇 殿堂之术—三大技法现代应用
2000年后读者反馈古代卦例多、现代卦例少，黎光将2000年左右卦例重新整理并搜录近年新例，或以三大技法为分析步骤按部就班，或取卦交垂象申发延展，开拓形象思维，收理象结合定活两用之利。

### 下篇 筮法巅峰——《易隐》高层断法破解
中国内地冠玄先生在《中国当代预测家》中称《易隐》为研究周易与预测最上乘著作，京房遗法、筮法巅峰。黎光先生已将《易隐》重新编排评注，并专文讲解《易隐》占身命法，第九节为最大泄秘之处，含预测身命详细例子与门内秘传预测六亲属相方法。

### 附录
黎光先生易学文章小集，收录博客考证、心得、读者往来、生活日记。
《略窺門徑——六爻知識入門》原名「聽老澗講《增刪》」，为舒涵先生2008年创作，以最简明方式总结阴阳、五行、八卦、纳甲、起卦、基本卦理，被誉为六爻入门最佳教材。作者亦提出将占卜视作辅助决策手段与训练思维方式的现代占卜观。

## 核心框架

### 总论
- **要点总论**：吉凶观生克，即用爻所受生克；得失观组合，即世爻与用神组合；应期观病处，即卦之病处；细节观杂处，本书中篇论及。
- **各占法主要特点**：
  - 吉凶观生克，即用爻所受月日与变动爻的生克
  - 得失观组合，即世爻与用神的组合
  - 应期观病处，即卦象与用神的病处
  - 细节观多断，空合刑冲等意象应用

## 第一大技法 吉凶占

### 定义与适用范围
凡占事物吉凶者均称吉凶占。如占父母疾病、兄弟官非、子畜平安、妻子生产等。吉凶观生克，不必看世爻应爻及卦象。

### 学习步骤
1.  **取用爻**
2.  **辨旺衰**
3.  **查生克**
4.  **定吉凶**

### 一、取用神
- 占父母长辈吉凶 → 取 **父母爻**
- 占兄弟姐妹及朋友吉凶 → 取 **兄弟爻**
- 占子女晚辈牲畜吉凶 → 取 **子孙爻**
- 占妻子女人情人货物吉凶 → 取 **妻财爻**
- 占官员上级吉凶 → 取 **官鬼爻**

### 二、辨旺衰
按月令日建断土金水木火旺相休囚，月破规则略。

**月日同看法**：用神在月令休囚逢日建生扶，或在月令旺相逢日建克损者为**中和状态**。中和逢生为吉，逢克为凶。

#### 五行旺衰速查表
| 五行 | 旺相月份 | 休囚月份 | 月破月份 |
| :--- | :--- | :--- | :--- |
| **土** (辰戌丑未) | 辰戌丑未巳午 | 其它 | 辰破戌，戌破辰，丑破未，未破丑 |
| **金** (申酉) | 申酉辰戌丑未 | 其它 | 申破寅，酉破卯 |
| **水** (亥子) | 亥子申酉 | 其它 | 子破午，亥破巳 |
| **木** (寅卯) | 寅卯亥子 | 其它 | 寅破申，卯破酉 |
| **火** (巳午) | 巳午寅卯 | 其它 | 午破子，巳破亥 |

### 三、查生克
- **动爻**：可生克主卦中任何一个动爻或静爻。
- **变爻**：只生克主卦中与变爻同爻位的那个动爻（即动出变爻的那个动爻）。

**生克状态分类**：
1.  用旺逢生
2.  用旺逢克
3.  用衰逢生
4.  用衰逢克
5.  用爻旺极（变动爻均生扶，无克损）
6.  用爻弱极（变动爻均克泄，无生扶）

### 四、定吉凶

#### 吉象标准
1.  **用神有生**（有源）
2.  **用神无克**（无伤）

**细分四吉**：
1.  用旺有生
2.  用旺无克
3.  用衰逢生（危而有救）
4.  用衰无克（危而无凶，需用爻弱而有气）

#### 凶象标准
1.  **用神无生**（原神受伤，根蒂受损）
2.  **用神受克**（用神有损）
3.  **用神太旺**（物极必反）
4.  **用神太弱**（弱极不受原神之生）
5.  **用鬼互化**（均为凶）

**细分五凶**：
1.  **用爻旺极**：月日变动爻四处俱得生扶，无一处损害。主**物极必反**。注：占老人及重病时遇此旺极，以旺极反衰做凶论；占年轻人及轻近病时难做此论。
2.  **用爻弱极**：月日变动爻四处俱受损害，无一处生扶。逢生难救，逢克更伤。
3.  **用爻受变动爻之克**：
    - 用旺逢克：用爻旺相受克，只克不伤，危而无凶（小凶）。
    - 用衰逢克：用爻休囚受克，克神旺相，大凶。
4.  **原神受伤**：相生用爻之爻（用爻之生处）受月日变动爻克伤。
5.  **用鬼互化**：用爻自动化官鬼爻。若配用爻休囚或原神受伤，更定大凶。

## 吉凶占实战卦例精选（书中百余例核心验证）

> 书中收录《增删卜易》《卜筮正宗》古例及现代亲身卜例百余则，以下列举核心断验类型。

### 用旺逢生（吉）
- **例一**：辰月戊申日占父病，父母辰土临月建旺相，动爻官鬼午火相生 → **吉而无凶**。
- **例二**：申月戊辰日女占夫病，官鬼亥水得月生，动爻妻财申金相生 → **吉而无凶**。
- **例三**：卯月丙辰日占父病，伏神父母巳火得月生，飞神相生 → **吉而无凶**。
- **例四**：申月戊子日占坟地，世爻子孙子水得月生日比旺，旺而无克 → **吉**。

### 用旺无克（吉）
- **例一**：辰月乙巳日占寿命，世爻兄弟未土月比日生旺，无动爻克 → **吉**。
- **例二**：午月己卯日占妻病，妻财辰土月生日克不弱，无动爻克 → **吉**。
- **例三**：丑月庚子日占父病，父母丑土月比日耗旺，无动爻克 → **吉**。
- **例四**：寅月己卯日占母寿，父母巳火得月日相生旺，无动爻克 → **吉**。
- **例五**：申月己丑日自占病，世爻官鬼酉金得月日生扶旺，无动爻克 → **吉**。
- **例六**：辰月乙巳日占寿命，世爻兄弟未土月比日生旺，无动爻克 → **吉**。
- **例七**：申月癸巳日占父任职，动爻父母戌土受月泄日生不旺（中和），无克 → **平平无凶**。

### 用衰逢生（危而有救）
- **例一**：辰月丙申日占兄病危，兄弟亥水受月克日生不旺，动爻父母申金相生 → **本日得名医救活**。
- **例二**：午月戊辰日占妹产，兄弟酉金休囚日建逢生 → **次日生产母子平安**。
- **例三**：卯月己卯日占兄重罪，动爻兄弟丑土受月日克衰，变爻相生 → **最终凶而有救，蒙恩免死**。
- **例四**：寅月庚戌日占女病，动爻子孙未土受月克不旺，动爻相生 → **独静寅日起床**。
- **例五**：寅月庚戌日女占女病，动爻子孙亥水受月泄日克衰，动爻相生 → **出空寅日起床**。
- **例六**：午月癸丑日占妻病，妻财卯木受月泄日耗衰，动爻相生 → **填实寅日病愈**。
- **例七**：寅月戊午日占坟地，世爻妻财戌土受月克衰，日建动爻相生 → **葬后吉**。
- **例八**：寅月己未日占女病，子孙酉金休囚，日建及暗动爻相生 → **未申时得名医救治**。
- **例九**：卯月戊辰日占兄重罪，兄弟申金受月耗日生不旺，暗动父母辰土相生化解 → **危而有救，免死**。

### 用衰无克（危而无凶）
- **例一**：申月戊辰日占控告，父母爻逢月耗日泄衰，变爻克之（衰中逢克）→ **控告无效**；世爻逢月泄日比不弱，无克 → **自身无凶**。
- **例二**：酉月丙辰日占子病发展，子孙午火逢月耗日泄衰，月日及卦中无克 → **午日起床**。

### 用神旺极（物极必反·凶）
- **例一**：巳月戊午日老人自占病，世爻子孙辰土得月日帮扶旺极，老人体虚 → **旺极反衰，回光返照，入墓戌日亡**。
- **例二**：酉月壬申日老妇占夫病，官鬼亥水得月日相生旺极 → **世爻出空填实亥日亡**。（官爻临水主肾血，朱雀逢空主不能言语）

### 用神弱极（凶）
- **例一**：巳月乙未日自占病，世爻父母亥水得原神旺动相生（本吉），但世爻月破日克弱极，逢生不起，卯日冲伤原神 → **凶**。
- **例二**：丑月戊午日占婶病，父母卯木得月耗日泄衰，动爻相克 → **乙丑日病亡**。
- **例三**：酉月丁卯日占子病，子孙卯木逢月冲破衰，动爻相克 → **卯日病亡**。
- **例四**：戌月丁卯日占官司，世爻兄弟辰土逢月破日克（散） → **败诉**。

### 用旺逢克（小凶·危而有救）
- **例一**：五月戊子日占吉凶，世爻妻财辰土临月令旺相，动爻兄弟寅木相克 → **五月无事，寅月亥日寅木当旺克伤，遇劫受伤**。
- **例二/三**：申月癸卯日自占治病，世爻子孙申金旺相，动爻官鬼巳火相克 → **巳日病重，因旺相受克，危而有救**。

### 用衰逢克（大凶）
- **例一**：酉月庚辰日占岳父病，父母酉金临月令旺相但近病逢合凶，世爻动爻来克 → **凶**。
- **例二**：卯月壬申日占外任职，世爻兄弟戌土临月比日克中和，受变爻克 → **往后遇害**。
- **例三**：午月丁亥日女自占，世爻兄弟亥水临月因日比中和，受变爻动爻俱克 → **终亡于腊月**。
- **例四**：巳月戊申日占比赛，世爻子孙申金月令相克日建比扶中和，动爻相克 → **大输**。
- **例五**：寅月戊午日占子吉凶，子孙辰土月令相克日建生扶中和，变爻交相克 → **折伤手臂**。
- **例六**：巳月乙酉日占父寿，父母亥水逢月冲破衰，日建帮不起，动爻相克 → **冬季病亡**。
- **例七**：五月壬子日占官讼，世爻官鬼午火月令休囚衰，日建相克 → **败讼受罚**。
- **例八**：五月甲午日占父病，父母巳火月令休囚日建帮扶中和，近病逢合凶，暗动世爻子水克父母，原神官鬼被子孙酉金克 → **亥日父亡**。
- **例九**：申月戊午日自占病，世爻官鬼午火月耗日帮中和，变爻相克 → **亥月病亡**。
- **例十**：巳月丁亥日占仆人，妻财亥水月破日帮衰，两动爻来克 → **仆人已死**。
- **例十一**：未月戊辰日占年运，世爻妻财子水被月日相克衰，变爻动爻俱克 → **本年大病**。
- **例十二**：酉月甲辰日官员占控告，世爻官鬼丑土月耗日泄衰，变爻相克 → **次年二月入狱**。
- **例十三**：卯月癸亥日占一家吉凶，世爻子孙子水月耗日泄衰，变爻相克；妻财爻中和被变爻克 → **夏季午月火旺克泄，一家数口俱被烧死**。
- **例十四**：亥月丙寅日女占夫病，官鬼午水月克日生中和，动爻相克 → **本月乙亥日病亡**。
- **例十五**：寅月丁巳日自占运气，世爻子孙辰土月克日生中和，变爻相克 → **本月受伤见凶**。

## 第二大技法 得失占

### 定义与适用范围
凡占事情得失者均称得失占。如占求财得失、求官得失、求名得失、求学得失等。**得失观组合**。

### 学习步骤
1.  取用爻
2.  辨世用旺衰
3.  查世爻定位五神
4.  以世用组合定得失趋势

### 世爻定位五神
1.  **用神持世**：主得、主成、主我有。
2.  **泄神持世**（子孙持世）：主泄耗、主失、主不成（求财凶，求名利凶，逃亡吉）。
3.  **原神持世**（父母持世）：主有保护、主文书、主迟缓、主有证据。
4.  **仇神持世**（妻财持世）：主克用神、主破财、主阻碍。
5.  **忌神持世**（官鬼持世）：主压制、主官非、主病灾、主受制。

### 世用组合断验要领
- 结合世用旺衰、月日旬空月破。
- 卦体**六冲化六合**：先难后易、先散后成。
- 卦体**六合化六冲**：先易后难、先成后散。
- 世爻生用神、合用神 → 我有心求之，易成。
- 用神生世爻、合世爻 → 事来就我，易成。
- 世爻克用神 → 我有心克制，求财则得，求官则失。
- 用神克世爻 → 事来克我，凶。

> **注**：本书提供的归档文本在得失占章节处截断，详细卦例请参阅原书中篇及《隐易千金断》。

## 第三大技法 应期占

### 核心原则
**以卦之病处定应期**。书中总论提出「应期观病处」，与吉凶得失形成三大技法闭环。

### 病处类型与应期对应
1.  **用神休囚** → 待旺相之月日（出空、填实、冲开墓库）。
2.  **用神入墓** → 待冲开墓库之日（冲墓）。
3.  **用神旬空** → 待出空之日（填实、冲动）。
4.  **用神受克** → 待克神休囚、或用神旺相、或有解神（原神/子孙）发动之日。
5.  **卦逢六冲** → 事多变动，应期快，往往冲动之日应。
6.  **卦逢六合** → 事稳定缓慢，应期迟，往往合住之日或冲开合之日应。
7.  **变爻回头生克冲合** → 以变爻地支所临月日定期。

> **注**：应期占详细法则（七大应期定法等）见作者拙作《六爻实战大全》及《六爻实战点窍》第九章，本稿侧重确立「观病处」核心纲领。

## 自序与客序

### 自序 說卦
> 2015年12月21日述于羊城。黎光谈断卦需逻辑、意象、推演缺一不可。古人借术而悟道，乾卦自强不息、坤卦厚德载物，吉凶自找祸福自招。易道以易佐人伦，以道证情理。2003年香港出版《隐易千金断》讲意象与发挥，《六爻三大技法》讲逻辑与规则，二者结合为推演。

### 客序 良师 良医 良相
> 舒涵于2015年12月26日撰写。忆述从《易数精解》《周易与预测学》入手，经《听老澗讲增刪》建立基础，提出占卜三个难点：有水晶球、能切入得主要结论、能讲出故事。黎光《六爻三大技法》正是解决第二难点，即如何切入卦得主要结论。如中医有《伤寒论》体系化，六爻三大技法为卦眼与打蛇打七寸方法。新版披露高级教材与《易隐》高层断法讲解，集基础、核心技法、高层断法于一体。
