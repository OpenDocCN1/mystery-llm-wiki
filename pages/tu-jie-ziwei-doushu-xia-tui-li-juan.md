# 图解紫微斗数下推理卷

《图解紫微斗数下推理卷》是紫微斗数经典著作《图解紫微斗数》系列的下卷，专注于命理推断的实务操作与深度解析。全书以**天干地支合冲化刑害**为基础算法，以**十四主星动静紫府分类**为核心框架，系统详解**紫微星系**（紫微、天机、太阳、武曲、天同、廉贞）与**天机星系**诸星坐守十二宫位的亮度分布、星曜布局、基本命运及不同年干生人命运的完整参断体系，构建了从排盘基础到实战断验的完整知识链路。

## 核心知识体系

### 一、天干地支合冲化刑害——命理排盘的基石算法

作为古代代表时空体系的符号，天干与地支各自的相互组合代表着不同的含义，不同搭配**合则利，冲则斥，化则生，刑则伤，害则不吉**。[[tian-gan-di-zhi-he-chong-hua-xing-hai]]

#### 天干五合与相冲
| 合化类型 | 天干组合 | 化气 | 主宰 |
| :--- | :--- | :--- | :--- |
| 中正之合 | 甲己 | 化土 | 信 |
| 仁义之合 | 乙庚 | 化金 | 义 |
| 威势之合 | 丙辛 | 化水 | 智 |
| 仁寿之合 | 丁壬 | 化木 | 仁 |
| 多礼之合 | 戊癸 | 化火 | 礼 |

**天干相冲**：甲庚、乙辛、丙壬、丁癸。

#### 地支三合、半三合、六合
| 合局类型 | 地支组合 | 化气 | 力量层级 |
| :--- | :--- | :--- | :--- |
| **三合** | 申子辰、亥卯未、寅午戌、巳酉丑 | 阳水、阳木、阴火、阳金 | 最强（仅次于三会） |
| **前半三合** | 申子、亥卯、寅午、巳酉 | 水、木、火、金 | 次于三合 |
| **后半三合** | 子辰、卯未、午戌、酉丑 | 水、木、火、金 | 次于前半三合 |
| **六合** | 子丑、寅亥、卯戌、辰酉、巳申、午未 | 阴土、阳木、阴火、阳金、阴水、阴阳之合 | 再次于后半三合 |

#### 地支六冲、六害、三刑
- **六冲**：子午、丑未、寅申、卯酉、辰戌、巳亥（含五行克制关系：巳亥水克火、寅申金克木、丑未同类刑冲）
- **六害**：子未、丑午、寅巳、卯辰、申亥、酉戌（子未丑午象征不平衡/欲望失衡；寅巳申亥代表困逆受阻；卯辰酉戌象征转机）
- **三刑**：
  - 无礼之刑：子卯（刚直粗暴、怠惰姑息）
  - 无恩之刑：丑戌未（冷酷无情）
  - 恃势之刑：寅巳申（狡猾粗暴）
  - 自刑：辰辰、午午、酉酉、亥亥（愚痴）

> **时辰对照表**：子(23-1)、丑(1-3)、寅(3-5)、卯(5-7)、辰(7-9)、巳(9-11)、午(11-13)、未(13-15)、申(15-17)、酉(17-19)、戌(19-21)、亥(21-23)

### 二、十四主星分类体系——动静紫府双轨并行

十四主星可概分为两大星系，内部星曜常同宫、对宫或三合会照，互为因果；两星系最主要变化关键分别在**破军星**（动态星系）与**天机星**（静态星系）。[[ziwei-doushu]] [[ziwei-xingpan-liangda-jiegou]]

#### 动静之分
| 星系 | 星曜（8/6颗） | 核心特质 |
| :--- | :--- | :--- |
| **动态星系**（杀破狼） | 紫微、天府、武曲、天相、廉贞、七杀、破军、贪狼 | 开始、创新、变化、冲锋陷阵、大幅度波动 |
| **静态星系**（机月同梁） | 天机、太阴、天同、天梁、巨门、太阳 | 准备、酝酿、计划、智慧、小幅度变化、还原功能 |

#### 紫府之分（安星法依据）
| 星系 | 星曜 | 排列法则 |
| :--- | :--- | :--- |
| **紫微星系** | 紫微、天机、太阳、武曲、天同、廉贞 | 随紫微星而安 |
| **天府星系** | 天府、太阴、贪狼、巨门、天相、天梁、七杀、破军 | 随天府星而安 |

> **命盘结构**：十二宫位×十四主星=144种主结构组合，加六吉、六煞、四化、禄存、天马等18颗甲级助星及百余颗次级星，构成千变万化命盘。[[ziwei-doushu-an-xing-fa]] [[ziwei-doushu-paipan-zheng-shi-jiao-zheng]]
