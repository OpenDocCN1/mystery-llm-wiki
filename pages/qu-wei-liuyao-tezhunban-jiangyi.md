> 本页面系统整理曲炜《六爻真传》（2003年《桥路咨询》连载及讲义）的理论框架与实战方法，重点提炼其在爻位层次理论、四建运用、真假六亲取用、用神转换、从象与一气专旺、卦位卦象三才交位、六神信息象等方面的独到见解。该体系以《六爻详真》为纲，深化了断卦诀窍，兼融梅花易数与六爻纳甲体系，具有极强的实操指导意义。

## 核心口诀速查（六爻真传一句话精华）

### 基础断验铁则
- **兄弟持世求财**：世爻空易于求财（财旺相为前提），因兄弟空不劫财。
- **日月忌克用神**：若卦中无忌神发动克用神，用神代表的人事仅有小灾或不顺；若卦中有忌神发动克用神，待忌神值临日月旺相时必应凶。
- **原象定吉凶，进行时推应期**：具体一事一测之卦，关键看起卦时原象，不可按进行时推吉凶（流年长远之事除外）。
- **动爻被日月合住**：不能主动生变爻及静爻，但不等于不能盗泄、克他爻。静爻不能泄克生之。官鬼持世、财爻被合，世爻静则无财可求；世爻发动（含暗动）可盗泄财爻得财。
- **求财核心**：财爻现卦即有财，旺衰只论多少。能否得财取决于财爻五行之气能否流通到世爻。流通到世爻即得财，不到则无财。财爻衰弱不动或动而被合，唯世爻为官鬼发动（含暗动）时有财。
- **忌神被日月合住**：当时无事，应期待逢冲解合之时（冲爻或冲日月）。
- **流年卦世爻有用**：预示有好事；世爻无用则平淡。世爻受克但卦中无动爻克之则平安无作为。世爻旺相且有动爻克世，则有成有败。白虎或官鬼发动克世，或世临白虎受克，则平安有问题，喜忧同在。
- **螣蛇/勾陈临世或克世**：主签合同、违法、拘留审查之象。
- **男测婚兄弟持世**：心情迫切，或有竞争/阻隔（有人争女友或阻碍婚事）。兄弟克妻财，宜克破无气为成。兄弟持世女方嫁给认识的人（兄弟表密切朋友）。
- **女测婚子孙持世**：同理，女方想离。兄弟持世女测，主男方踢自己。
- **股票行情**：财爻伏藏，卦中兄弟发动（含暗动），逢财爻出现值日时，往往下跌。
- **父母临螣蛇发动或五爻发动**：必主车辆之事，多因车出事。官父同旺临月动，官伤兄弟、父伤子孙，主车祸压死人。
- **父母动、朱雀临兄弟动**：必有打官司或口舌争执。
- **测风水**：官鬼在二爻临青龙旺相主出高官；官鬼死绝临白虎主有惨死之人。
- **兄弟持世**：经商主破财、官非、婚姻不顺；文化、文教、交通、通信、信息等主大吉、官职有升。
- **离婚孩子归属**：子孙爻与哪方相合相生，跟哪方。
- **一方被父母合住**：因不能离或长辈不主张离。双方均被父母合住则不先提离婚，甚至离不离家同住。
- **未婚测婚世应均动**：均为阳爻相克相冲主一试即崩；均为阴爻主关系慢慢冷淡。
- **螣蛇临世应**：人手腕高明、人面玲珑、口才好。青龙临之又值金水木爻主长相漂亮。
- **官星临子午卯酉**：事业单位，测官职为正职。寅申巳亥为企业/自由业，测官职为副职。

## 思维突破：特殊格局——从象与一气专旺

### 从象判定条件（真从）

| 爻类型 | 必须同时具备条件 |
|--------|------------------|
| **动爻** | 1. 日月双方休囚无气，且至少一方受冲或克<br>2. 原神休囚无气，安静或发动化回头克/墓/绝/空/破<br>3. 卦中有动/变爻克制之 |
| **静爻** | 1. 日月双方休囚无气<br>2. 原神休囚无气不发动或无 |

> **核心原则**：某爻本身休囚无气，原神也休囚无气，同时无原神救助 → 确定为从象。

### 一气专旺判定条件（动静同规）
1. 此爻日月双方旺相
2. 卦中有动/变爻生扶
3. 卦中无动/变爻克泄耗
4. 克泄耗之爻静且休囚无力

### 从象/一气专旺吉凶论法
1. **主用神从象**：利于从世爻，不宜从他爻。从他爻 = 随从他人，与我无缘（测婚财从他爻 = 妻子/爱人跟随别人；求财 = 财随他人意）。
2. **世爻弱极从象**：宜从主用神爻，反得用神之益（类四柱日主从财官）。
3. **主用神一气专旺**：宜世爻从象，不宜世爻有气（世爻有气主事难成）。
4. **世爻一气专旺**：宜主用神从象，不宜主用神有气。
5. **用神持世**：无论从象或一气专旺均主吉。

### 比赛胜负判断
- 世爻一气专旺或弱极从象 = 实力强、能取胜。
- 世应五行相同、都从/都一气专旺 → 常主平局（足球、下棋、赛跑等允许平局项目）。
- 不允许平局项目（排球、乒乓球等）看哪方从得最真、一气专旺最真 → 哪方最真哪方胜。
- 同五行从象比日月破衰程度：日月破最衰者从得最真 → 该方胜。
- 同五行一气专旺比临日月建：临日月建者力量最大。
- 综合参考：原神距离从爻越远，从得越真。

## “四建”运用体系

### 四建分工原则
| 四建 | 管辖范围 | 适用预测期限 | 核心作用 |
|------|----------|--------------|----------|
| **太岁** | 永远荣枯 | 终身、长远、流年 | 帝君之星，占久远大事不可不用 |
| **月建** | 一年得失 | 流年、半年以上 | 万卦提纲，管往来祸福，用神临月内永远亨通 |
| **日建** | 一月祸福 | 月余左右、具体一事 | 君主之爻，数月间无不应验，六爻主宰 |
| **时辰** | 一日吉凶 | 当日之事 | 管一日吉凶，问当日事宜细辨 |

### 实战运用铁律
- **测流年**：以太岁、月令、日建为主，重年支、月支、日支，以日月支综合衡定旺衰。**一卦只管一年**，不可断往后几年。
- **测月余左右**：以月、日建为主，年与时可不考虑。
- **测本日内事**：以日、时为主，年、月不考虑。
- **测终身荣枯**：以年、月、日建为主。
- **信息同步原理**：求测者意念定向于何事/何时段，卦象信息有效期限同步。测一年卦象有效期一年，爻彻底月破指在所测事未完结前始终破，事完结后无意义。
- **四建入卦发动**：吉凶明显，往往代表时间量/应期。月建入卦应在本月或变爻月份；日建入卦应在日上；时辰入卦应在时辰上；太岁入卦应在流年上。

### 来意断验心法
- 绝大部分来意为近期急事或日内事，**紧抓日辰，兼看月与时**。
- 四建临何六亲，所发生事象多与该六亲代表事象有关。
- 看外因四建不可全看，要有重点，结合所测事长短期定取舍。

## 爻之四层次理论（核心创新）

> 在李洪成“爻三层次”基础上改进，确立生克权判断的绝对层级秩序，解决“谁克谁、克不克、克多少”模糊难题。

### 四层次架构与权力特征

| 层次 | 组成 | 权力特征 | 核心口诀 |
|------|------|----------|----------|
| **第一层次** | **日月建**（含年、时） | 对卦中每爻具有生克合冲绝对权力；动爻值日月升为一层次，暂时免克 | “日月为尊，生克合冲无不从” |
| **第二层次** | **变爻**（主卦动爻变出的同位爻） | 对本位动爻有生克合冲权；无本位关系时可作用主卦旁爻；变爻与变爻互不论 | “变爻重本位，有合冲克生，不再论旁爻” |
| **第三层次** | **动爻、暗动爻** | 能生克合冲同层动爻及静爻；受制于日月、本位变爻；无权生克日月及变爻 | “动爻有权克静爻，受制于日月变爻” |
| **第四层次** | **静爻、伏藏爻** | 仅同层次相生相克；无主动权生克动爻；动爻被克时静爻通关无力；受制于所有上层爻 | “静爻最卑，只论同层，动克静时通关无望” |

### 层次转换与特殊状态
- **日月入卦**：静爻值日月升为一层次（相当于日月建），但**无主动生克权**，不被动变爻克伤（暂时原象），待日月改变后可被新层次爻克伤。
- **暗动**：日冲静爻（仅冲不克且月不克）或月冲值日爻 → 静爻升为三层次（动爻层次）。
- **合住降级**：动爻逢日月合（非用神生合）降为静爻层次；变爻合住本位动爻，变爻不对旁爻作用。

### 生克原则铁律
1. **上层次克下层次 = 制**（使对方完全丧失生克权）
2. **同层次一对一 = 克**（有情制约，仅减小能力，未完全丧失；力量足时可达成制）
3. **同层次多克一 / 合局克一 = 制**
3. **下层次无权生克上层次**
4. **动爻在卦中不分远近**（有流动性，与所有爻贴近）；静爻与静爻有距离之分。

## 断卦基本规律：冲合刑害墓空交互规则

> 确立“合 > 冲 > 刑 > 害 > 常规生克”的动态博弈模型，在四层次架构下规定作用顺序、生克权增减、解救条件及应期判断。

### 合冲互解顺序（不可逆）
> **主卦合冲 → 变卦合冲解 → 月建解 → 日建解 → 流月流日解**
> - 问吉凶看原象
> - 问应期看进行时：衰待旺、动待合、合待冲、墓待出、空待出、静待冲

### 冲对生克权影响（核心判例）

| 形式 | 判断原则 | 关键案例 |
|------|----------|----------|
| **日月冲动爻** | 旺相动爻：冲脱有权减力，日合可解；休囚受制动爻：月破永无权，值日/逢合/出月有权。**值日月动爻不怕月冲**（同层次）。 | 测合同：世爻动化午冲应爻子，日建未合午，午不能冲子，合同不成。 |
| **日月冲静爻** | 旺相静爻：暗动（升三层次）；休囚静爻：连冲带克彻底无权，仅冲不克月内无权出月有权。**土爻相冲仅激本气，不伤，多为暗动**。 | 流年运气：辰戌相冲均静，只有冲象无冲力，世爻无大灾。 |
| **变爻冲动爻** | 变爻层次高，有主动权。**变爻被日月制住则无权冲**。变爻冲本位动爻时不对旁爻作用。本位动爻休囚冲散，旺相仅冲不克减力，连冲带克则无权（值日月除外）。 | 求财：世爻酉化卯冲，卯休囚世爻减力保权；卯只冲本位酉，不合戌土，财生世应验。 |
| **变爻冲静爻** | 旺相静爻暗动，休囚静爻破/临界（同日冲静爻逻辑）。 | — |
| **动爻冲静爻** | 动爻有生克权才能冲。旺相静爻暗动，休囚同日冲静爻。 | 被骗：世爻丑旺相被辰冲为暗动（心动上当）；子孙休囚公安无力，财休囚钱难追。 |

### 合对生克权判断

#### 合化成功条件（三合/六合同规）
1. **爻动齐备**：三爻全动/两爻全动，或一方为日月/本位变爻。
2. **日月有化神**：且日月**任何一方不得为化神克神**（出现克神则合而不化 = 绊住减力）。
3. **合化成功后**：以合出五行论生克，力量增大（如亥卯未合木局，木力增、土受克、亥被泄）。
4. **合而不化**：低层次/衰爻暂失生克权，待上层冲开方恢复。

#### 六合特殊规则
- **日月与动爻合**：绝大多数**合而不化 = 绊住**，层次降为静爻。
- **用神动爻逢生合**：**不为绊住，为增力**（保留生克权）。
- **原/忌/仇/闲神逢生合**：均为绊住（暂降权）。
- **静爻逢生合**：旺相时**合起 = 暗动**（日月为主生方），克合合不起。

#### 经典判例：母测女儿未来电
- 子孙戌土旬空避克，卦内无动爻克子孙 → **人平安**。
- 月建卯(父母)合戌，日建酉(财)合辰(子孙) → **父母合子孙 = 通讯受阻，财合子孙 = 欠费受阻** → 断手机欠费。次日戌日出空冲动辰土，果来电验证。

### 入墓对生克权影响

#### 入墓三形式与层次限制
| 形式 | 入墓对象 | 关键规则 |
|------|----------|----------|
| **入日月墓** | 动/变/静爻均入 | **只能冲爻解，不能冲墓/合墓**（日月为区域气场）。特例：日月墓入卦可冲墓解。 |
| **入动爻墓** | 静爻入动爻墓 | 动爻不入动爻墓（同层）。解墓：合墓/冲墓/冲爻均可。 |
| **入变爻墓** | 动爻入本位变爻墓 | 动爻不入旁爻变墓；静爻不入变爻墓。解墓：冲墓/合墓/冲爻均可。 |

#### 墓爻生克权核心
- **墓爻必须有生克权且层次高于入墓爻**，才能限制入墓爻。墓爻被合/冲/克失权 → 入墓爻出墓。
- **旺相爻入墓**：入墓期间无权，出墓恢复权。
- **休囚爻入墓**：出不出墓均无权（旺衰是根本）。

#### 经典判例
1. **测明日危险**：世爻动化寅回头克，寅入月墓未 → 无权克世 → 明日平安（只断所问之日）。
2. **测卖房**：财爻寅旺相入月墓未，世爻辰逢空 → 财世双无权构不成联系 → 卖不成（问吉凶看原象，不可勉强推应期）。
3. **测弟回家**：兄弟亥动入变爻辰墓 → 解墓三法（巳冲亥、戌冲辰墓、酉合辰墓）→ 进行时推酉日先遇合墓 → 酉日果回。

### 空亡对生克权影响

#### 空亡核心规则
- **旬空之爻**：无论旺衰，空期间**无生克权，不受生克**；只有出空、填实、冲空时有权。
- **休囚逢空**：避空，出不出空均无权。
- **空之象**：不实、落空、虚假、不踏实（测钱财空 = 假，测合伙应空 = 对方不实）。

#### 解空方式与力量发挥
| 空爻形态 | 解空方式 | 力量发挥 |
|------------|----------|----------|
| 静爻旬空 | 冲空/出空 | 旺相冲空发挥**半力**，出空全力；休囚出空仍无力。 |
| 动爻旬空 | 冲空/出空 | **冲空即可全力发挥**。 |
| 变爻旬空 (变空) | 仅出空 | 冲动爻/冲变爻**均无用**，须待变爻出空。 |
| 动变双空 | 仅出空 | 冲动/冲变均无用。 |
| 伏神逢空 | 有气 = 假空，须出空逢**值**(非临) | 冲空伏神/冲飞神**均不能解空**；飞神空伏神易引拨。 |

#### 推出空原则（按时间跨度）
- 月内事 → 按日推；当日事 → 按时辰推；流年运气 → 按月推；终身运气 → 按年推。

#### 经典判例
- **测官运**：世爻巳休囚，官爻亥旺逢空 → 亥出空克世 → 戌月隔离，亥月免职。
- **测妹妹来日**：兄弟申动化空入墓 → 变爻出空+冲墓同期 → 壬寅日果到。
- **测房子卖出**：世爻连续逢空（甲戌旬空→乙亥出空→甲申旬再空）→ 必待**再出空**甲申日 → 果卖出。
- **测要账**：应爻动生世但入墓(口头应允)，财爻逢空(无钱) → 年前要不来。

## 实战判断：卦爻旺衰与生克权综合判定

### 静爻生克权判定九则
1. 双休囚 = 临界状态（有无之间）
2. 一休囚一受克 = 无权
3. 双受克 = 更无权
4. 一受生一受克 = 临界上线（有权）
5. 一受克一值临 = 有权
6. 入墓/逢空/被合 = 暂无权，解除后看临界上下线
7. 逢日生合(主生方) = **合起 = 暗动有权**；克合合不起
8. 被日月合住 = 暂无权，解合后看临界线

### 动爻生克权判定六则
1. 日月双休囚不受克 = 临界，**看动变爻向背**（生扶有权，克泄耗无权；变爻回头生/进神有权，退/绝/墓/回头克无权）
2. 被日月/变爻合住 = 降权同静爻
3. 日月一克一休囚 = 无权
4. 日月一克一生 = 有权
5. 被日月/变爻冲破 = 无权
6. 入墓/旬空 = 暂无权，出墓出空看临界线

### 变爻生克权判定四则
1. 一克一休囚 = 临界，**仍有点权**（比动爻强）
2. 双休囚 = **仍有权**
3. 双受克 = 无权
4. 旬空/入墓/逢日月合 = 同动爻逻辑

### 制与克的本质区别
- **制**：使对方**完全丧失生克权**（上层次冲克、同层次多克一、合局力量克一）
- **克**：有情制约，**仅减小生克能力**，未完全丧失；力量足时可达成制
- **同层次一对一**：克不伤，双方均减力（主克减力小，被克减力大），仍有生克权，**最终看日月状态**

## 核心口诀总速查卡

> **层次定生克**：日月为尊变爻次，动爻第三静最卑。上克下兮制无敌，同层相克双减威。值日升官免克伤，暗动升权似动爻。合住降级同静论，用神生合反增辉。

> **冲合刑害序**：合重冲轻刑害微，同层高层各有规。合化需齐化神助，克神出头合不成。冲散冲脱看旺衰，值日同层冲不倒。变爻冲动重本位，无合冲克旁爻游。

> **墓空定生死**：入墓暂失生克权，墓爻有权层次高。旺相出墓权力恢，休囚出墓也枉然。旬空避克亦避生，休囚逢空永无权。动爻冲空全力发，变空唯待出空日。连续逢空勿轻断，再出空期方为真。

> **制克分明辨**：制者全失生克能，克者减力犹存诚。多克一兮合局克，上层冲下皆为制。一对一兮克不伤，日月状态定输赢。

> **断卦两重天**：问吉凶兮看原象，问应期兮看进行。衰待旺兮动待合，合待冲兮墓待出。空待出兮静待冲，病解之时应期呈。

> **用神转换灵**：同一事物角度异，用神随之换新衣。雨伞牛猪工作官，求测角度定乾坤。真假六亲分肉象，假爻事物真爻身。两现不妄取一弃，条件常理定主宾。

> **卦位三才用**：上卦天爻外来高，下卦地爻本地劳。人爻中间主人事，六神六亲配卦爻。交位交象联想活，射覆寻物神妙高。

> **六神象类分**：青龙喜庆朱雀文，勾陈土地腾蛇惊。白虎凶险玄武隐，结合六亲断因缘。

## 结语

曲炜《六爻真传》以**爻位四层次理论**为纲，以**四建运用**、**冲合刑害墓空交互规则**为目，以**真假六亲取用**、**用神转换原理**为用，以**卦位卦象三才交位**、**六神信息象**为象，建立了一套逻辑自洽、操作性极强的六爻断验完整体系。其最大贡献在于：

1. **确立了生克权判断的绝对层级秩序**，彻底解决了“谁克谁、克不克、克多少”的模糊难题；
2. **将梅花易数体用卦气法与六爻纳甲动爻法深度融合**，形成“以六爻层次为骨架、以梅花卦气为气血”的混合预测模型；
3. **提出用神转换原理与真假六亲取用法**，从本质上解决了“同一事物因角度不同用神不同”及“六亲爻受克究竟主灾何人何事”的困惑；
4. **提供了海量实战案例的完整推演过程**，展示了从起卦、定层次、理生克、查墓空、推应期、下断语的标准化作业流程。

建议学习者：**先熟记四层次架构与合冲互解顺序，再结合《六爻详真》《六爻实战大全》《六爻理法进阶》等著作，通过复盘书中案例内化判断逻辑，方能得其精髓。**
