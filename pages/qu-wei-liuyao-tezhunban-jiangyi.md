# 曲炜《六爻特训班讲义》核心体系

> 本页面系统整理曲炜《六爻特训班讲义》（2003年）的理论框架与实战方法，重点提炼其在爻位层次理论、生克权判断、冲合刑害墓空交互规则方面的独到见解，并结合书中大量实战案例建立知识索引。该讲义以《六爻详真》为纲，深化了断卦诀窍，兼融梅花易数与六爻纳甲体系，具有极强的实操指导意义。

## 理论基础篇

### 梅花易数核心体系

#### 八卦类象与阴阳本性
- **阴阳生克本性**：阳爻发动主克（好斗、求刺激），阴爻发动主生（生育功能），但此特性在合冲之后论。如午火动克申金，若有未土动则先论午未合，午火不克申金。
- **八卦万物类象**：乾天兑泽离火震雷巽风坎水艮山坤地，各卦对应人物、器物、方位、身体、姓氏等详细类象，是取象断验的基础。详见 [[liuyao-qimeng-jieyao]]、[[liuyao-shizhan-dianqiao]]。

#### 起卦与断卦两大法门
| 维度 | 先天起卦法 | 后天起卦法 |
|------|------------|------------|
| 核心逻辑 | 先得数后起卦，只以卦象推论，不用爻辞，用后天卦方位先天数，不加时辰数，以卦气定克应 | 先有象后起数，据卦象爻辞卦辞定吉凶，必加时辰数，以动静状态结合成卦之数定克应 |
| 适用场景 | 快速断验，重体用动静应期 | 详细推演，重爻辞卦辞参断 |

#### 卦气旺衰与应期定法
- **四季卦气**：春巽震旺离相，夏离旺坤艮相，秋乾兑旺坎相，冬坎旺震巽相；辰戌丑未月坤艮旺。
- **应期三大诀窍**：
  1. **卦数定应期**：测生意用主卦上下卦数相加，测走失用主卦加动爻数，测病用主互变总数；姿势修正系数（站×1，跑÷2，坐×1.5，卧×2）。
  2. **克应定应期**：用卦生体卦以生体之卦五行日月定期；克体卦以克体之卦五行日月定凶期。
  3. **变卦指方向**：测失人失物行人，变卦往往示所去方向及地理环境。

#### 分类预测铁则（梅花易体用生克法）
- **核心公式**：体为我，用为事/人。用克体凶，体克用吉，用生体利，体生用耗，体用比和顺。
- **覆盖十六大类**：天气、人事得分、家宅、婚姻（重阴阳配合）、生育、饮食、求谋、求名、求财、交易、出行、行踪、拜见、失物（变卦定方位物象）、疾病（用神旺衰、原神通关、太岁护佑）、官司（体旺用衰体克用胜）。
> 💡 实战心法：断卦必重**内因组合**（卦中动爻生克合冲），外因（日月）靠内因起作用；善用**联想思维**将零碎信息按社会常理组合。

#### 外应取象五原则
1. 必须突发突然之征兆（非常态现象）。
2. 必与所测事物有关联。
3. 取近取明，远微不论。
4. **外应辅助卦理，不可弃卦取应**；卦吉应吉大吉，卦凶应凶大凶，吉凶交互则吉凶参半。
5. 顺其自然，不刻意寻找。

### 六爻占断基本规律：爻位四层次理论

> 这是曲炜体系的**核心创新**，确立了生克权判断的绝对层级秩序，解决了传统六爻“生克混乱、旺衰难定”的顽疾。

#### 爻位四层次架构
| 层次 | 组成 | 权力特征 | 核心口诀 |
|------|------|----------|----------|
| **第一层次** | **日月建** | 对卦中每爻具有生克合冲绝对权力；动爻值日月升为一层次，暂时免克 | “日月为尊，生克合冲无不从” |
| **第二层次** | **变爻** | 对本位动爻有生克合冲权；无本位关系时可作用主卦旁爻；变爻与变爻互不论 | “变爻重本位，有合冲克生，不再论旁爻” |
| **第三层次** | **动爻** | 能生克合冲同层动爻及静爻；受制于日月、本位变爻；无权生克日月及变爻 | “动爻有权克静爻，受制于日月变爻” |
| **第四层次** | **静爻、伏藏爻** | 仅同层次相生相克；无主动权生克动爻；动爻被克时静爻通关无力；受制于所有上层爻 | “静爻最卑，只论同层，动克静时通关无望” |

#### 层次转换与特殊状态
- **日月入卦**：静爻值日月升为一层次（相当于日月建），但**无主动生克权**，不被动变爻克伤（暂时原象），待日月改变后可被新一层次爻克伤。
- **暗动**：日冲静爻（仅冲不克且月不克）或月冲值日爻，静爻升为三层次（动爻层次）。
- **合住降级**：动爻逢日月合（非用神生合）降为静爻层次；变爻合住本位动爻，变爻不对旁爻作用。

## 核心技法篇：冲合刑害墓空交互规则

> 本章详细规定了五种特殊关系在四层次架构下的作用顺序、生克权增减、解救条件及应期判断，构建了**“合>冲>刑>害>常规生克”**的动态博弈模型。

### 冲对生克权的影响
#### 同层次相冲（四种）
- **动爻冲动爻**：必须考虑，双方均减力，旺相者减力小仍有权，休囚者冲散无权。
- **静爻冲静爻**：仅六静卦或有暗动时论，有动爻时只有冲象无冲力。

#### 高层次冲低层次（六种形式·核心判例）
| 形式 | 判断原则 | 典型案例 |
|--------|----------|----------|
| **日月冲动爻** | 旺相动爻：冲脱有权减力，日合可解；休囚受制动爻：月破永无权，值日/逢合/出月有权。**值日月动爻不怕月冲**（同层次）。 | 测合同案：世爻动化午冲应爻子，日建未合午，午不能冲子，合同不成。 |
| **日月冲静爻** | 旺相静爻：暗动（升三层次）；休囚静爻：连冲带克彻底无权，仅冲不克月内无权出月有权。**土爻相冲仅激本气，不伤，多为暗动**。 | 流年运气案：辰戌相冲均静，只有冲象无冲力，世爻无大灾。 |
| **变爻冲动爻** | 变爻层次高，有主动权。**变爻被日月制住则无权冲**。变爻冲本位动爻时不对旁爻作用。本位动爻休囚冲散，旺相仅冲不克减力，连冲带克则无权（值日月除外）。 | 测求财案：世爻酉化卯冲，卯休囚世爻减力保权；卯只冲本位酉，不合戌土，财生世应验。 |
| **变爻冲静爻** | 旺相静爻暗动，休囚静爻破/临界（同日冲静爻逻辑）。 | — |
| **动爻冲静爻** | 动爻有生克权才能冲。旺相静爻暗动，休囚同日冲静爻。 | 测被骗案：世爻丑旺相被辰冲为暗动，心动上当；子孙休囚公安无力，财休囚钱难追。 |

#### 合冲互解顺序铁律
> **主卦合冲 → 变卦合冲解 → 月建解 → 日建解 → 流月流日解**  
> **顺序不可逆**！问吉凶看原象，问应期看进行时（衰待旺、动待合、合待冲、墓待出、空待出、静待冲）。

### 合对生克权的判断
#### 合化成功条件（三合/六合同规）
1. **爻动齐备**：三爻全动/两爻全动，或一方为日月/本位变爻。
2. **日月有化神**：且日月**任何一方不得为化神克神**（出现克神则合而不化=绊住减力）。
3. **合化成功后**：以合出五行论生克，力量增大（如亥卯未合木局，木力增、土受克、亥被泄）。
4. **合而不化**：低层次/衰爻暂失生克权，待上层冲开方恢复。

#### 六合特殊规则
- **日月与动爻合**：绝大多数**合而不化=绊住**，层次降为静爻。
- **用神动爻逢生合**：**不为绊住，为增力**（保留生克权）。
- **原/忌/仇/闲神逢生合**：均为绊住（暂降权）。
- **静爻逢生合**：旺相时**合起=暗动**（日月为主生方），克合合不起。

#### 案例：母测女儿未来电
- 子孙戌土旬空避克，卦内无动爻克子孙 → **人平安**。
- 月建卯(父母)合戌，日建酉(财)合辰(子孙) → **父母合子孙=通讯受阻，财合子孙=欠费受阻** → 断手机欠费。次日戌日出空冲动辰土，果来电验证。

### 入墓对生克权的影响
#### 入墓三形式与层次限制
| 形式 | 入墓对象 | 关键规则 |
|--------|----------|----------|
| **入日月墓** | 动/变/静爻均入 | **只能冲爻解，不能冲墓/合墓**（日月为区域气场）。特例：日月墓入卦可冲墓解。 |
| **入动爻墓** | 静爻入动爻墓 | 动爻不入动爻墓（同层）。解墓：合墓/冲墓/冲爻均可。 |
| **入变爻墓** | 动爻入本位变爻墓 | 动爻不入旁爻变墓；静爻不入变爻墓。解墓：冲墓/合墓/冲爻均可。 |

#### 墓爻生克权判断核心
- **墓爻必须有生克权且层次高于入墓爻**，才能限制入墓爻。墓爻被合/冲/克失权 → 入墓爻出墓。
- **旺相爻入墓**：入墓期间无权，出墓恢复权。
- **休囚爻入墓**：出不出墓均无权（旺衰是根本）。

#### 经典判例
1. **测明日危险**：世爻动化寅回头克，寅入月墓未 → 无权克世 → 明日平安（只断所问之日）。
2. **测卖房**：财爻寅旺相入月墓未，世爻辰逢空 → 财世双无权构不成联系 → 卖不成（问吉凶看原象，不可勉强推应期）。
3. **测弟回家**：兄弟亥动入变爻辰墓 → 解墓三法（巳冲亥、戌冲辰墓、酉合辰墓）→ 进行时推酉日先遇合墓 → 酉日果回。

### 空亡对生克权的影响
#### 空亡核心规则
- **旬空之爻**：无论旺衰，空期间**无生克权，不受生克**；只有出空、填实、冲空时有权。
- **休囚逢空**：避空，出不出空均无权。
- **空之象**：不实、落空、虚假、不踏实（测钱币财空=假，测合伙应空=对方不实）。

#### 解空方式与力量发挥
| 空爻形态 | 解空方式 | 力量发挥 |
|------------|----------|----------|
| 静爻旬空 | 冲空/出空 | 旺相冲空发挥**半力**，出空全力；休囚出空仍无力。 |
| 动爻旬空 | 冲空/出空 | **冲空即可全力发挥**。 |
| 变爻旬空 (变空) | 仅出空 | 冲动爻/冲变爻**均无用**，须待变爻出空。 |
| 动变双空 | 仅出空 | 冲动/冲变均无用。 |
| 伏神逢空 | 有气=假空，须出空逢**值**(非临) | 冲空伏神/冲飞神**均不能解空**；飞神空伏神易引拨。 |

#### 推出空原则（按所测事物时间跨度）
- 月内事 → 按日推；当日事 → 按时辰推；流年运气 → 按月推；终身运气 → 按年推。

#### 经典判例
- **测官运**：世爻巳休囚，官爻亥旺逢空 → 亥出空克世 → 戌月隔离，亥月免职。
- **测妹妹来日**：兄弟申动化空入墓 → 变爻出空+冲墓同期 → 壬寅日果到。
- **测房子卖出**：世爻连续逢空（甲戌旬空→乙亥出空→甲申旬再空）→ 必待**再出空**甲申日 → 果卖出。
- **测要账**：应爻动生世但入墓(口头应允)，财爻逢空(无钱) → 年前要不来。

## 实战判断篇：卦爻旺衰与生克权综合判定

### 静爻生克权判定九则
1. **双休囚** = 临界状态（有无之间）。
2. **一休囚一受克** = 无权。
3. **双受克** = 更无权。
4. **一受生一受克** = 临界上线（有权）。
5. **一受克一值临** = 有权。
6. **入墓/逢空/被合** = 暂无权，解除后看临界上下线。
7. **逢日生合(主生方)** = **合起=暗动有权**；克合合不起。
8. **被日月合住** = 暂无权，解合后看临界线。

### 动爻生克权判定六则
1. **日月双休囚不受克** = 临界，**看动变爻向背**（生扶有权，克泄耗无权；变爻回头生/进神有权，退/绝/墓/回头克无权）。
2. **被日月/变爻合住** = 降权同静爻。
3. **日月一克一休囚** = 无权。
4. **日月一克一生** = 有权。
5. **被日月/变爻冲破** = 无权。
6. **入墓/旬空** = 暂无权，出墓出空看临界线。

### 变爻生克权判定四则
1. **一克一休囚** = 临界，**仍有点权**（比动爻强）。
2. **双休囚** = **仍有权**。
3. **双受克** = 无权。
4. **旬空/入墓/逢日月合** = 同动爻逻辑。

### 制与克的本质区别
- **制**：使对方**完全丧失生克权**（如上层次冲克、同层次多克一、合局力量克一）。
- **克**：有情制约，**仅减小生克能力**，未完全丧失；力量足时可达成制。
- **同层次一对一**：克不伤，双方均减力（主克减力小，被克减力大），仍有生克权，**最终看日月状态**。

## 核心口诀速查卡

> **层次定生克**：日月为尊变爻次，动爻第三静最卑。上克下兮制无敌，同层相克双减威。值日升官免克伤，暗动升权似动爻。合住降级同静论，用神生合反增辉。

> **冲合刑害序**：合重冲轻刑害微，同层高层各有规。合化需齐化神助，克神出头合不成。冲散冲脱看旺衰，值日同层冲不倒。变爻冲动重本位，无合冲克旁爻游。

> **墓空定生死**：入墓暂失生克权，墓爻有权层次高。旺相出墓权力恢，休囚出墓也枉然。旬空避克亦避生，休囚逢空永无权。动爻冲空全力发，变空唯待出空日。连续逢空勿轻断，再出空期方为真。

> **制克分明辨**：制者全失生克能，克者减力犹存诚。多克一兮合局克，上层冲下皆为制。一对一兮克不伤，日月状态定输赢。

> **断卦两重天**：问吉凶兮看原象，问应期兮看进行。衰待旺兮动待合，合待冲兮墓待出。空待出兮静待冲，病解之时应期呈。

## 结语

曲炜《六爻特训班讲义》以**爻位四层次理论**为纲，以**冲合刑害墓空交互规则**为目，建立了一套逻辑自洽、操作性极强的六爻断验体系。其最大贡献在于：
1. **确立了生克权判断的绝对层级秩序**，彻底解决了“谁克谁、克不克、克多少”的模糊难题；
2. **将梅花易数体用卦气法与六爻纳甲动爻法深度融合**，形成“以六爻层次为骨架、以梅花卦气为气血”的混合预测模型；
3. **提供了海量实战案例的完整推演过程**，展示了从起卦、定层次、理生克、查墓空、推应期、下断语的标准化作业流程。

建议学习者：**先熟记四层次架构与合冲互解顺序，再结合《六爻详真》《六爻实战大全》等著作，通过复盘书中案例内化判断逻辑，方能得其精髓。**
