# 紫微斗数安星法实务标准参考

> 本页面依据《紫微階梯① 紫微初階》（勸學齋主編著）系統整理，提煉出完整的二十步排盤操作流程、速查表與核心口訣，構建安星法實務的標準化參考框架。所有表格、口訣、排序邏輯均忠實還原原書，並以結構化方式呈現，便於實務查閱與教學傳承。

## 核心排盘流程总览（二十步法）

| 步骤 | 环节 | 核心依据 | 关键产出 |
|------|------|----------|----------|
| 1 | **定宮干** | 生年干 → 五虎遁月起寅宮順排 | 十二宮各得一干（宮干） |
| 2 | **定命身宮** | 生月（不論節氣）+ 生時支 → 速查表/歌訣 | 命宮、身宮落宮位置 |
| 3 | **安十二宮名** | 以命宮為起點，逆時針依序排布 | 命、兄弟、夫妻、子女、財帛、疾厄、遷移、奴僕、官祿、田宅、福德、父母 |
| 4 | **定五行局** | 命宮干支交叉查表（或生年干對命宮支） | 金四/木三/水二/火六/土五局及納音 |
| 5 | **定紫微星** | 五行局 + 出生日 → 速查表 | 紫微星落宮 |
| 6 | **安紫微星系** | 以紫微星為樞紐，逆排天機、太陽、武曲、天同、廉貞 | 紫微系六主星定位完成 |
| 7 | **安天府星** | 紫微星對沖巳亥線，平行對宮即天府 | 天府星落宮 |
| 8 | **安天府星系** | 以天府星為首，順時針排太陰、貪狼、巨門、天相、天梁、七殺、破軍 | 天府系八主星定位完成 |
| 9 | **安時系星** | 生年支分四組（亥卯未/巳酉丑/申子辰/寅午戌）+ 生時支 | 文昌、文曲、火星、鈴星、地空、地劫、台輔、封誥 |
| 10 | **安月系星** | 生月查表 | 左輔、右弼、天刑、天姚、天馬、解神、天巫、天月、陰煞 |
| 11 | **安日系星** | 以左輔、右弼、文昌、文曲為起點，順/逆數至生日數 | 三台、八座、恩光、天貴 |
| 12 | **安年干系星** | 生年干查表 | 祿存、擎羊、陀羅、天魁、天鉞、四化（祿權科忌） |
| 13 | **安年支系星** | 生年支查表（天壽另以身宮起子順數） | 天才、天壽、破碎、蜚廉、鳳閣、龍池、咸池、寡宿、孤辰、天喜、紅鸞、天哭、天虛、華蓋、命馬 |
| 14 | **安截路空亡** | 生年干查表 | 截路、空亡（或合稱截空） |
| 15 | **安旬空星** | 生年干支組合查表（六十甲子旬空） | 旬空（兩宮） |
| 16 | **定命主星** | 命宮地支查表 | 命主星（不入盤，註明於命盤空白處） |
| 17 | **定身主星** | 生年支查表 | 身主星（同上） |
| 18 | **安天殤、天使** | 固定宮位 | 天殤守奴僕宮、天使守疾厄宮 |
| 19 | **起大限** | 五行局 + 陰陽男女 + 命宮為起點 | 十二大限區段（每限十年） |
| 20 | **起小限/流年** | 另行章節（流年斗君、流年干支系、歲前將前等） | 流年、小限排布 |

| 甲、己 | 丙 | 甲己之年丙作首 |
| 乙、庚 | 戊 | 乙庚之歲戊為頭 |
| 丙、辛 | 庚 | 丙辛便從庚起首 |
| 丁、壬 | 壬 | 丁壬壬寅順行流 |
| 戊、癸 | 甲 | 戊癸何方發，甲寅好追求 |

**操作**：寅宮得干後，順時針依十天干循環填入十二宮。

**口訣**：
```
天府南斗令，常對紫微君；
丑卯相更迭，未酉互為根；
往來午與戌，蹑践子和辰；
巳亥交馳騁，同位在寅申。
```

## 关键概念交叉引用

- **派系差異**：透派（梅素香創立）以節氣定月，其餘派別（含本書）以農曆月定月，不論節氣。參見 [[ziwei-doushu-xiang-xing-lilun]] 關於方法論的批判性反思。
- **中州派體系**：王亭之《中州派紫微斗數初級/深造講義》以十八飛星、統計實證為特色，安星法與本書有異同。參見 [[zhongzhou-pai-ziywei-doushu-shenzhao-jiangyi]]、[[中州派紫微斗数初级讲义]]。
- **紫微階梯系列進階**：本書為「紫微初階」，續有「紫微進階」涵蓋掌上排盤、完整論斷法則與研究方向。參見 [[ziwei-jie-ti-chu-jie]]。
- **實務案例**：依婷講課記錄提供真太陽時換算、格局案例（日月並明、反背、照壁等）與命理故事。參見 [[yiting-ziwei-jiangke-jilu]]、[[ni-buzhidao-de-doushu]]。
- **相性與共性理論**：關於「共性」與「特性」在論命中的邊界，參見 [[ziwei-doushu-xiang-xing-lilun]]。

## 使用指南

1. **教學/自學**：按二十步流程逐項操作，配合速查表與口訣，可獨立完成標準命盤。
2. **實務查核**：排盤軟體/人工排盤後，以本頁各步驟表格為核對清單，確保無遺漏、無錯位。
3. **研究延伸**：各星系口訣與速查表為進階研究（如飛星四化、宮干化祿、大限流年動態分析）的基礎數據層。
4. **跨派對照**：遇異派排法（如透派節氣月、中州派飛星），可回溯本頁「核心依據」欄位，釐清差異源頭。
