# 占星占心

## 書本基本資訊

- **書名**：《占星占心》
- **作者**：Cecily（希斯莉）
- **推薦序**：秦瑞生（天人之際占星研究學會學術顧問）、李榮宗（前 HP/飛利浦醫學事業部總經理）、孫龍翔（中華民國道家學術研究會理事）
- **核心定位**：古典占星技法與現代心理占星諮商態度的融合實戰著作
- **特色**：以八大真實諮商案例，展示古典占星「十星三位」分析框架在婚姻、事業、健康、感情等領域的具體應用邏輯

## 作者脈絡與學術淵源

### Cecily（希斯莉）簡介
- **師承**：秦瑞生老師，研習西洋古典占星、印度占星、大六壬、三元玄空陽宅學
- **研讀經典**：Benjamin N. Dykes 英譯本《The Book of Astronomy》（Guido Bonatti）、《Christian Astrology》（William Lilly）等古典原典
- **教學經驗**：文化大學推廣部古典占星基礎班講師，主持讀書會與研討會
- **網路平台**：部落格「迷占星 108 室」，與同門衛恣共同經營天人之際研究學會部落格
- **命盤特徵**：上升雙魚座，本命月亮落第十二宮 1 度合相皇冠恆星北落師門（Fomalhaut），直覺力強、具靈性深度

### 學習歷程三階段
1. **心理占星入門**：初接觸占星以心理探索為主，發現無法滿足大眾對具體預測的需求
2. **古典占星復興**：拜師秦瑞生，系統學習中世紀至文藝復興時期完整實用命理架構（本命、流年、卜卦、擇日、合盤、換置、A*C*G 等）
3. **中西融合實證**：延伸研習紫微斗數、八字、人相、姓名學等中國命理，建立跨體系驗證機制

### Cecily 的整合立場
> 「古典占星提供具體預測骨架，心理占星賦予諮商溫度與轉化空間。兩者交會，更具不凡意義。」

- **實務取向**：以古典技法（命主星、宮主星、飛星、衍生宮、相位網絡、大運流年）回答「何時、何事、吉凶」
- **諮商態度**：以心理占星同理心、自由意志、業力轉化觀點陪伴當事人面對命運
- **哲學基石**：佛法因果觀——星盤呈現累世因緣和合，預測非宿命論，而是「健康檢查」式覺察，配合「面對、接受、處理、放下」四步驟超越定數

## 核心分析框架：古典占星簡易三步驟

書中前言詳細闡述，所有案例均遵循此標準流程：

### 步驟一：命宮代表因子
1. 找出**上升星座**（ASC）
2. 確定**命主星**（上升星座守護星）
3. 檢視命主星**落座星座、宮位**、**第一宮內行星**
4. 判斷命主星強弱（廟旺陷弱）、相位狀況

### 步驟二：事項代表因子
1. 依詢問主題鎖定**相關宮位**（如婚姻看第七宮、感情看第五宮、事業看第十宮、健康看第六/八宮）
2. 找出該宮**宮主星**（宮頭星座守護星）、**宮內行星**
3. 檢視宮主星**落座星座、宮位**（即「飛星」）、其掌管之其他宮位

### 步驟三：交互關聯分析
1. **命主星與事項宮主星**的相位、接納、互容關係
2. **事項宮內行星**對命宮（ASC/命主星）的相位衝擊
3. **衍生宮法則**：以事項宮為新一宮重新起算，觀察配偶/對方的事業、財富、健康等
4. **時機觸發**：流年行運、大運、進度、日月食、太陽弧等引動本命相位

## 案例深度解析：核心星象邏輯與諮商轉化

### 案例一：B小姐——上帝之手介入的愛情
**關鍵配置**：
- 上升獅子，命主太陽入十一宮雙子
- 第五宮射手，宮主木星入十宮雙子，**互容**水星
- 第五宮內月亮射手，**大十字**：對沖太陽/水星(十一宮)、刑土星/凱龍星(八宮)、對沖火星(二宮)
- 第七宮水瓶，宮主土星入八宮雙魚、天王星入二宮處女，**同參與大十字**
- 第四宮天蠍，宮主火星/冥王星皆陷入大十字網絡

**分析邏輯**：
1. **命主太陽十一宮雙子** → 外型亮麗、領導才華、資訊敏銳（驗證雜誌主管身分）
2. **五宮主木星飛十宮** → 戀人易為同事；金星巨蟹 + 五宮月亮 → 渴望溫馨家庭
3. **雙大十字鎖死二/五/八/十/十一宮** → 家庭強力反對、感情歷程極度坎坷、對象罹癌離世
4. **相位調合**：大十字頂點多與 ASC/MC 形成六合/三合 → 仍能憑智慧事業重站穩腳步

**諮商轉化**：
> 「上天送妳一個獨特禮物——永恆的愛情，這是一般人求之不得的古物。」  
> 將「命中註定無婚」重構為「擁有超越生死的愛」，釋放當事人對婚姻形式的執著。

### 案例二：Q先生——華麗地圖之繽紛
**關鍵配置**：
- 上升射手，命主木星入十宮天秤，**互容**金星(十一宮主入三宮雙魚)
- 木星合天王星(十宮)，六合 ASC
- 水星(七宮主)入三宮水瓶，六合幸運點(一宮)
- 太陽(九宮主)摩羯 **互容** 土星，三合冥王星(MC 附近)
- 金星雙魚三合火星(十一宮主入十一宮天蠍)

**分析邏輯**：
1. **命主木星十宮天秤互容金星** → 樂觀自信、藝術才華、公關交際強（合唱團長、建築博士）
2. **金星為十一宮主入三宮** + 木星合天王星 → 人際網絡集中於同學/朋友，涉藝術/靈性領域
3. **五宮主火星天蠍入十一宮** + 金星三合 → 熱烈追求藝術氣質異性，但五宮土星牡羊陷宮刑月亮 → 感情受阻財虧
4. **七宮主水星水瓶入三宮** 六合幸運點 → 配偶來自手足/鄰里/同學/地緣（西北方/水瓶方位）
5. **九宮主太陽摩羯互容土星** 無刑剋 → 高等教育延長（十年博士班）

**諮商轉化**：
- 指示「出生地西南方」→ 金門教職 → 透過親戚介紹遇現任妻（女檢察官）
- 解盤時誤說西南方實為西北方（水瓶），卻意中成真，展現衍生宮與方位學交叉驗證

### 案例三：Z小姐——乘著愛情來攪局的金星
**關鍵配置**：
- 上升巨蟹，命主月亮處女入三宮 **合冥王星**
- 五宮天蠍，宮主火星入十一宮雙子、冥王星入三宮處女，**火冥雙主星雙飛**

- 五宮海王星三合 ASC，對沖太陽(二宮主)

**分析邏輯**：
1. **命主月亮處女三宮合冥王星** → 母性照顧者、細節控制、疑心病重、情緒化
2. **五宮海王星三合 ASC** → 感情浪漫幻想、易被蒙蔽
3. **金火合相十一宮六合 MC** → 緣份來自工作場合，對象為共事同事
4. **冥王星(五宮主)合月亮** 被 **金火刑剋** → 追求者異性緣多、神秘、引發職場糾紛，當事人暗中偵查（諜對諜）

**諮商轉化**：
- 多次卜卦/星盤預警「感情破壞事業」，當事人仍衝動投入
- 最終主廚離職、餐廳經營空窗，驗證「感情燃點太低、環境加味釀製」之判斷

### 案例四：E小姐——暴力相向的婚姻與無形高塔
**關鍵配置**：
- 上升雙魚，命主木星十宮射手 **廟宮** 三合太陽，海王星九宮射手 **旺宮**
- 五宮金星巨蟹 **三合 ASC**
- 七宮處女，**火星合 DSC 沖 ASC**，刑命主海王星
- 七宮冥王星刑木星(命主)
- 十宮木星被冥王星刑，但三合太陽

**分析邏輯**：
1. **雙魚上升 + 金星三合 ASC + 命主雙重廟旺三合** → 極具魅力、藝術才華、樂觀自信、「發電機女王」
2. **火星合 DSC 沖 ASC 刑命主** → 配偶脾氣爆烈、肢體暴力、猜疑控制、不願放手
3. **七宮冥王星刑命主木星** → 婚姻關係成隱形枷鎖，配偶占有欲極強
4. **十宮木星被冥王星刑** + 四宮土星 → 配偶家庭地位良好但遭其暴戾所苦，原生家庭傳統保守

**諮商轉化**：
- 大量吉相位（大三角、小三角）調和除火星外所有凶星 → 人生其他領域福分深厚
- 「時間讓枷鎖自然風化」——以行運時間視角陪伴當事人等待解脫契機

### 案例五：F小姐——堅韌生命能量與重獲新生
**關鍵配置**：
- 上升摩羯，命主土星一宮摩羯 **廟宮** 合木星

- 火星為四宮/十一宮主 → 衍生宮：七之十宮（配偶事業）主星火星弱宮沖 ASC
- 十一宮(七之五宮)雙主星：火星飛七宮、冥王星八宮刑月亮 → 配偶外遇對象直接衝突破壞

**分析邏輯**：
1. **命主土星一宮摩羯合木星** → 憂慮說教、踏實耐操、教師性格、常為丈夫收拾爛攤子
2. **火星七宮弱宮沖 ASC 互容木星** → 丈夫情緒不穩、酒色財氣、暴力相向
3. **十一宮火冥雙主星雙飛七/八宮** 刑剋命宮/七宮主 → 外遇對象(屬羊巨蟹)直接衝突、謀財
4. **五宮金星雙魚旺宮** 六合命宮土木 → 三女兒溫順藝術天分、母女互動佳、與父疏離

**諮商轉化**：
- 自殺未遂後見三女兒哭泣 → 「為女兒活下去」成為錨點
- 法律訴訟討回財產，星盤顯示未來生命重心為栽培三女兒

### 案例六：J小姐——貴婦蛻變與金星大運新一章

### 案例七：O先生——中年金星大運與情騙局
**關鍵配置**：
- 上升巨蟹，命主月亮獅子二宮，**大三角**：月亮/太陽/MC（同火象）
- 月亮受太陽容納 → 受人敬重高階主管、家庭經濟棟樑
- 五宮天蠍，宮主火星四宮天蠍 **廟宮** 合海王星，六合金星
- 一宮天王星獅子，**三刑會沖**：刑火海(四宮)、凱龍星(七宮)
- 金星摩羯 → 易受悲苦動人女性吸引
- 七宮主土星飛五宮，冥王星(五宮主)飛二宮，**土冥刑剋** → 兩女人戰爭實為利益爭奪

**分析邏輯**：
1. **月亮大三角太陽/MC + 容納** → 事業成就、家庭棟樑
2. **火海合四宮 + 天王星一宮三刑會沖** → 情慾強、異鄉易受性誘惑欺騙、海王星幻象
3. **金星摩羯 + 海王星九宮主飛四宮** → 異鄉渴望家庭溫暖、吸引喬裝悲苦女性
4. **七宮凱龍星參與三刑會沖** → 婚姻岌岌可危、雙方難癒傷痛
5. **夜間出生 49 歲進金星大運** → 引動潛伏浪漫基因與生理反應，引爆婚姻風暴

**諮商轉化**：
- 大老婆及時發現、設停損點、給回頭機會
- 「一次破壞性事件反讓死寂婚姻重生」——危機轉化為關係重構契機
