# 六壬核心神煞体系：十二天将与十二支神/月将

> **来源依据**：本页面主要依据《四库全书白话图解·图解六壬大全》（第一部《占法及神煞》、第二部《吉凶占断》、第三部《毕法赋》）中的“导读一 认识大六壬”、“导读二 大六壬的基本方法”、卷三《六壬歌诀》第一章“神将与神煞”、卷四《六壬赋辞》之《括囊赋》《三才赋》、卷五至八《课经》相关论述，以及《轩辕肘后经》《大六壬玉成歌》《心印赋》等经典歌赋内容整理而成。

## 概述

大六壬作为“三式之首”（太乙、奇门、六壬），其神煞体系极为繁复且核心。其中**十二天将（十二贵神）**与**十二支神（十二月将/十二神将）**构成了六壬占断的“肉身”与“灵魂”。

- **十二天将**：将阴阳五行、天干地支具象化为具有特定性格、职司的神祇形象（如天乙为贵人、白虎为廷尉），主管**天时、气候、人物性情、动态变化**，随月将加时顺逆排布于天盘。
- **十二支神/月将**：依太阳运行位置（节气）确定，管辖**地理、时令、万物生克、静态类象**，固定排布于地盘（或随月将轮转）。

两者结合“干支加神将，再加六亲”，形成信息交汇点，为占断提供依据。

### 昼夜贵人与顺逆排布规则

天将排布的**起点**由**天乙贵人（值符）**决定，**方向**由贵人所落地支的阴阳属性决定。

#### A. 昼夜贵人定位（值符起例）
> **口诀**：“甲戊庚牛羊，乙己鼠猴乡；丙丁猪鸡位，壬癸蛇兔藏；六辛逢马虎，此是贵人方。”

| 日干 | 昼贵 (阳贵) | 夜贵 (阴贵) | 备注 |
| :--- | :--- | :--- | :--- |
| **甲、戊、庚** | **丑** (牛) | **未** (羊) | 阳干，禄在寅/巳/申，贵在丑/未 |
| **乙、己** | **子** (鼠) | **申** (猴) | 阴干 |
| **丙、丁** | **亥** (猪) | **酉** (鸡) | 阳/阴火 |
| **壬、癸** | **巳** (蛇) | **卯** (兔) | 阳/阴水 |
| **辛** | **午** (马) | **寅** (虎) | 阴金，独行 |

- **昼时**：占时为卯、辰、巳、午、未、申（日出至日入）。
- **夜时**：占时为酉、戌、亥、子、丑、寅（日入至日出）。

#### B. 顺布与逆布
> **诀曰**：“贵蛇朱六勾青，空白常玄阴后。从戌至巳逆行，以辰到亥顺就。”

- **贵人临亥、子、丑、寅、卯、辰（北方、东方，属阳）**：**顺布**（顺时针/数字增大方向）。
- **贵人临巳、午、未、申、酉、戌（南方、西方，属阴）**：**逆布**（逆时针/数字减小方向）。

**排布示例（昼贵丑，顺布）**：
丑(贵) → 寅(蛇) → 卯(朱) → 辰(合) → 巳(勾) → 午(青) → 未(空) → 申(虎) → 酉(常) → 戌(武) → 亥(阴) → 子(后)

## 三、天地盘与四课三传核心流程

### 定地盘（体）
以子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥十二地支按方位固定排列（子北、午南、卯东、酉西），**永不动**。

### 定天盘（用）
**月将加时**：以占时地支为起点，将当月月将加于其上，顺时针排布十二地支。天盘随月将、时辰变动。

### 取四课（象）
以**日干支**与天地盘互参照出四组上下关系：
- **第一课（日阳）**：日干 → 十干寄宫 → 查天盘上神。
- **第二课（日阴）**：第一课上神 → 查地盘位置 → 查天盘上神。
- **第三课（辰阳）**：日支 → 查地盘位置 → 查天盘上神。
- **第四课（辰阴）**：第三课上神 → 查地盘位置 → 查天盘上神。

### 起三传（应）——九宗门
以四课**上下相克（贼克/比用/涉害/遥克/昴星/别责/八专/伏吟/返吟）**决定初传（发用），再由初传上神作中传，中传上神作末传。

| 宗门 | 触发条件 | 取用核心 |
| :--- | :--- | :--- |
| **贼克法** | 有下贼上（优先）或上克下 | 取克者上神 |
| **比用法** | 多贼克或多上克 | 取与日干阴阳比和者 |
| **涉害法** | 多克且俱比/俱不比 | 取归本家受克最深者 |
| **遥克法** | 四课无克 | 取上神遥克日干(蒿矢)或日干遥克上神(弹射) |
| **昴星法** | 无克、无遥克、四课全 | 刚日取地盘酉上神(虎视)，柔日取天盘酉下神(冬蛇) |
| **别责法** | 四课不全(三课)、有合 | 阳日取干合上神，阴日取支前三合神 |
| **八专法** | 干支同位(伏吟类) | 刚日顺数三神，柔日逆数三神 |
| **伏吟法** | 天地盘重叠 | 有克用克，无克刚日自任(干上神)，柔日自信(支上神) |
| **返吟法** | 天地盘相冲 | 有克用克，无克取驿马/井栏射 |

## 四、神煞克应断验体系

### 六亲（五行生克代名词）
以**日干**为“我”：
- **生我（父母）**：资助、文书、长辈、屋舍、根基。
- **我生（子孙）**：泄气、耗财、晚辈、医药、出路、解厄神。
- **克我（官鬼）**：压力、官职、疾病、灾祸、丈夫(女占)、克制我者。
- **我克（妻财）**：财物、妻妾、利益、谋求之物、父母之仇。
- **同类（兄弟）**：竞争、分财、朋友、同辈、劫财、比肩。

> **断验**：三传生日为福，克日为祸；子孙克官鬼为救神；妻财克父母为忌神。

## 六、与天干地支、五行的深度映照关系

1.  **天将即干支具象化**：
    - 甲→青龙(木)，乙→六合(木)，丙→朱雀(火)，丁→腾蛇(火)，戊→天乙/勾陈/天空(土)，己→天乙/太常(土)，庚→白虎(金)，辛→太阴(金)，壬→天后(水)，癸→玄武(水)。
    - **寄宫定位**：天将落宫必依十干寄宫（甲寄寅、乙寄辰等），这是“干神将位，当立贵贱尊卑”的基础。

2.  **支神即地支本气显化**：
    - 子→神后(水)，丑→大吉(土)，寅→功曹(木)，卯→太冲(木)，辰→天罡(土)，巳→太乙(火)，午→胜光(火)，未→小吉(土)，申→传送(金)，酉→从魁(金)，戌→河魁(土)，亥→登明(水)。
    - 支神固定于地盘，代表**地理方位、时令气候、万物本体类象**。

3.  **五行生克贯穿始终**：
    - **起课**：月将(支神)加时 → 天地盘上下相乘 → 产生生克制化。
    - **四课**：日干支(五行)与天盘上神(五行)生克 → 定贼克比用。
    - **三传**：初传(五行)生克日干 → 定六亲吉凶 → 中末传递生克 → 定事成败进退。
    - **神将**：天将(五行)乘地支(五行) → 如青龙(木)临酉(金)为金克木(受克)，临亥(水)为水生木(得生) → **“将是神兮神是将，若得青龙便是寅”**，神将五行与地支五行互动，是断验精微处。

4.  **阴阳昼夜双轨制**：
    - **昼贵(阳贵)顺布**：阳气主进、主动、主外、主显，利男子、利先动、利远谋。
    - **夜贵(阴贵)逆布**：阴气主退、主静、主内、主隐，利女子、利后动、利近谋、利隐避。
    - 《括囊赋》云：“贵人顺治德扶，忠臣孝子；天乙逆行杀动，便佞交朋。”

## 七、学习与实践路径建议

1.  **夯实基础符号系统**：熟练掌握**十干寄宫**、**六十甲子**、**年上起月/日上起时**、**二十四节气与月将对应**、**六甲旬遁与旬空表**。
2.  **精通天地盘构建**：熟练手盘/脑盘排布天地盘，理解“体用、动静、阴阳、内外”关系。
3.  **熟背九宗门起传法**：这是六壬“算法”核心，需通过大量实例练习（如《课经》案例）达到肌肉记忆。
4.  **内化六亲生克与旺衰**：将“生我/我生/克我/我克/比我”转化为具体人事物象（父母/子孙/官鬼/妻财/兄弟），结合**旺相休囚**、**长生十二宫**判断气数强弱。
5.  **神煞作辅助验证**：核心靠“课体+三传+六亲+旺衰”，神煞（贵人、驿马、三奇、凶煞等）作**锦上添花或雪中送炭**，不可本末倒置。
6.  **研读经典歌赋**：**《括囊赋》**(总纲)、**《毕法赋》**(百法实战)、**《玉成歌》**(推断要诀)、**《轩辕肘后经》**(三传综合)、**《心印赋》**(神煞日辰)——此五赋为六壬断验“五大法典”。
