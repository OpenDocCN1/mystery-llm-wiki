# 凤麟奇门风水学·符号象意系统

> 本页面依据《凤麟奇门风水学》（王凤麟著）第一章至第四章内容整理，聚焦其核心区别于市面阳盘奇门的“阴盘遁甲”理论体系与“符号象意编码表”。该系统主张**“没吉没凶”**、以**月相定局**、引入**隐干**、**星座反编译**等独有操作法则，构建了用于阴盘断验的核心知识库。

## 核心理念：阴盘遁甲与“没吉没凶”

《凤麟奇门风水学》开篇确立道家秘传阴盘遁甲的三大基石，与流行于世的阳盘奇门（拆补法、置闰法）形成鲜明分水岭：

1.  **起局法别：月相定局**  
    依太阴星（月亮）盈亏变化排布九宫，**每时辰演一局**，信息量较阳盘“五日一局”更丰富、精准。
2.  **空亡法别：四维空亡体系**  
    包含远空、近空、先天空、后天空，**“一切玄机尽在空亡中”**。
3.  **断验法别：没吉没凶（核心分水岭）**  
    - 符号、格局**只有阴阳、正反、特定时空针对特定人事的信息差别**，无绝对吉凶。  
    - 例：天辅星既主文曲大吉，亦主监狱、被看管；丁+癸（朱雀投江）既主凶格，亦主生意火红、热恋婚姻。  
    - **实战启示**：摒弃繁复吉凶格局鸟笼，以“类象直读、一支枪一个准星”定成败。

> **交叉引用**：阴盘排盘十一步实操详见 [[yin-pan-qimen-paipan-shi-yi-bu]]；阳盘与阴盘基础理论对比见 [[bu-chui-niu-qimen-jiangyi-yi]]、[[dong-bo-ju-shi-qi-men-miao-jue]]、[[qi-men-dun-jia-ji-chu-yu-pai-pan]]。

## 排盘基石：阴盘十一步定局流程

第三章规定了从公历时间到完整盘面的标准化作业程序（此为象意落宫的前提）：

| 步骤 | 核心动作 | 关键规则 |
|---|---|---|
| **第一步** | **排四柱** | 公历转干支，以立春分年、节气分月、子时分日、五鼠遁分时 |
| **第二步** | **定阴阳局数** | 冬至后→夏至前为**阳遁**；夏至后→冬至前为**阴遁**。局数 = (年支序数+月数+日数+时支序数) ÷ 9 余数 |
| **第三步** | **画九宫格** | 古法九宫格（非井字格），默念“无极生太极…八卦定乾坤”，线交接紧密不相通 |
| **第四步** | **布地盘三奇六仪** | 阳局顺布、阴局逆布，**戊落几宫即几局**；九宫数口诀：“戴九履一，左三右七，二四为肩六八为足” |
| **第五步** | **找旬首** | 六甲旬首：甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸；按**时柱**查对 |
| **第六步** | **定值符值使** | 旬首落宫之地盘星 = **值符**，地盘门 = **值使门** |
| **第七步** | **排天盘三奇六仪九星** | “旬首值符随时干”：时干落宫接旬首值符，地盘九星随之转动 |
| **第八步** | **排八神** | 值符落时干宫，阳遁顺时针（1-8-3-4-9-2-7-6）、阴遁逆时针（1-6-7-2-9-4-3-8）布腾蛇、太阴、六合、白虎、玄武、九地、九天 |
| **第九步** | **定八门** | 值使门随时辰顺飞（阳局按宫数123456789，阴局987654321），其余门顺时针排休生伤杜景死惊开 |
| **第十步** | **排隐干** | **道家秘传增九符号**：时干加值使门，按天盘或地盘三奇六仪顺序布一圈，**信息量大增** |
| **第十一步** | **查空亡马星** | 空亡按六旬（甲子旬戌亥空=乾宫空等）；马星按四正四维（亥卯未马在巳/巽宫等） |
