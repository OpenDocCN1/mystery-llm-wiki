# 内经呼吸养生法

## 概述

《内经呼吸养生法》由湛若水撰写，以《黄帝内经》气论为核心，系统阐述丹田呼吸、阴阳平衡、排浊纳清的养生理论与三招实操功法。全书分为「壹·养生的智慧」与「贰·呼吸的奥秘」两大部分，融合古典医学理论与现代科学视角，提供简易、安全、弹性的居家养生功法。

> **核心主张**：呼吸是生命力之源，丹田为练气养气枢纽，透过「纳清」促「排浊」，重建呼吸功能，达成性命双修、身心并进。

## 壹 养生的智慧

### 《黄帝内经》是养生宝典

- **三大基本元素**：气、阴阳、五行 —— 实为气的衍生物，上中下游关系。
- **核心立论**：「天地大宇宙，人身小宇宙」，以「易理阴阳、天人相应」为基础，全篇以气贯穿，藉「呼吸吐纳」成养生根本。
- **脉学奇迹**：《内经》在无仪器时代全盤洞悉人体经络穴道，成为后世针灸把脉依据。

### 天地大宇宙，人身小宇宙

- **阴阳定义**：「阳化气，阴成形」。阴主静、固化；阳主动、气化。两者结合创生万物。
- **人体阴阳分布**：「阳中之阳心也，阳中之阴肺也，阴中之阴肾也，阴中之阳肝也，阴中之至阴脾也」。
- **稳态理论呼应**：坎农「稳态」理论与《内经》「阴平阳秘，精神乃治」殊途同归，皆指陰陽平衡为健康关键。
- **多重次元观**：肉体（高密度/阴）与能量体、意念体、自性本体（低密度/阳）共存，振动频率决定次元分野。[[fei-wei-zong-qi-li-lun]]、[[yi-fei-wei-zong]] 均探讨肺为宗气之源，与此「阳化气、阴成形」观相通。

### 人体能量的阴阳变化

- **张景岳论**：「医道虽繁，一言蔽之曰阴阳」；「生命为阳气之作用」，阳气难得易失，补阳为主。
- **孙思邈、李可佐证**：人老体衰、百病多因阳气耗失；「阳虚者十占八九」。
- **增补阳气之道**：摄取阳气必须靠呼吸，故练气功、学呼吸为首要养生之道。
- **道家修炼公式**：炼气化精 → 炼精化气 → 炼气化神 → 炼神还虚（从有到无、高密度向低密度），与天地创生序（神→炁→精→气，无到有）逆向操作。[[25形人养生攻略]] 亦以《内经》阴阳二十五人为核心，辨识体质调理养生，同宗同源。

### 能量支配健康

- **呼吸功能曲线**：人一生呼吸效率由高而低，对应「成、住、坏、空」。四十岁为转折点（平盛不摇），此后血气下坡。
- **电池喻义**：丹田似电池，白天耗电、夜晚充电；练功达「行住坐卧心息相依」如汽车边跑边充。
- **《灵枢·天年》十岁至百岁气血衰旺表**：十岁气在下好走 → 四十岁平盛不摇好坐 → 六十岁心气衰好卧 → 百岁五脏皆虚神气去。
- **血气与体能二而一**：练气旺盛血气可活化细胞、提高再生力。[[jingluo-fangliao]]、[[ren-shen-shu-an-quan-neng-liang-suo]] 亦强调能量通路疏通对细胞新陈代谢的决定性作用。

### 百病皆因气逆

- **阴阳流向定律**：外阳内阴、背阳腹阴、左阳右阴、上阳下阴 —— 阳必向阴流动，呼吸为阳气入身管道。
- **顺行与逆行**：气血循一定轨道，阻塞则滞，打通即通。高血压、高血脂、高血糖「三高」多为气血循环不畅、代谢不良所致。
- **气逆两况**：五行相克、行气方向阻逆。中年后下半身摄能退化，轻浮之气上飄成逆行；上火致浊气不降。
- **情志致病**：忧虑恐惧郁结肝火、心气不舒，阻碍气血循环，「痛则不通，通则不痛」。

### 排浊纳清为养生第一要务

- **三态废物**：固、液、气三态废物积聚阻滞气血、生毒害健康。气体最易滞留胸腹脏腑。
- **二氧化碳与毒素**：CO₂ 堆积 → 碳酸盐 → 内脏纤维化；肠道毒素（肽类、胺类、氨、硫化氢）蓄积 → 自身中毒 → 脑细胞受损、记忆力下降、肝功能下降。
- **三焦主气**：华佗《中藏经》云「三焦通则内外左右上下皆通」。练气打通三焦，气循环代谢顺畅，此即「排浊纳清」。
- **三消路径**：打嗝、放屁、排汗 —— 三路通畅则气逆血瘀减少。
- **三尸九虫**：道家视为先天藏于脏腑深处之浊邪之气，练气首务在排出深层浊气。
- **现代环境阻碍**：久坐、冷气密闭空间、忍屁习惯、寒气收敛毛孔，致适应节气调节功能紊乱。
- **发热流汗排毒**：运动发热促免疫细胞增生、抑制病原体；马拉松选手大汗排重金属零癌症案例佐证。深呼吸排毒速度为平常十五倍。
- **正气御邪**：身虚招阴邪，「正压百邪」，乐观心境与练气提升正气可御侵袭。
- **腰围与健康**：中年后摄能上移，下半身静脉血回流难，滞留腹臀 → 腰围大小反映健康状况。[[zhongyi-zhengti-fangliao]]、[[wuxing-fangxiang-liaofa-quanshu]] 均以阴阳五行、经络气血调和为整体疗愈框架，与此「排浊纳清」观一致。

## 贰 呼吸的奥秘

### 养生由呼吸开始

- **孙思邈**：「善养摄者，须知调气焉。」呼吸为改变体质、增强免疫、健康长寿的关键钥匙。
- **Breath = 生命力**。人生面对灾难疾病，端赖生命力强弱。
- **《内经》**：「人始生，先成精」「呼吸精气」。气血旺衰系于呼吸供能。
- **庄子**：「吹嘘呼吸，吐故纳新，熊经鸟伸，为寿而已。」呼吸+运动=长寿。
- **石原结实**：「过四十岁下半身开始缩水」，下半身肌肉占全身 70%+，衰退招百病。[[25形人养生攻略]] 亦重视体质辨识与日常调理，互为表里。
- **腹围祸害**：腹部、大腿为「第二心脏」，中老年静脉回流不畅 → 脂肪水分堆积 → 循环代谢差、增心肺负担 → 文明病、代谢症候群元凶。法研腹部脂肪涉及炎症反馈回路、伤肺功能。
- **简单练腹法**：站姿收腹挺胸（如见比基尼美女），两三周腰围消失。劳动阶级因常收腹用力，腹围少超标。
- **足部保养**：老人行动迟缓因下半身气血退化、双足无力如树根腐。搓脚心、热水泡脚、赤足行走、金鸡独立（郑少秋案例）皆疏通足部经络。
- **足背部功法**：L 型伸腿、脚板竖直九十度、双手交叉翻掌平举、吸气闭气全身用劲七秒、放松吐气，重复十分钟。助背气通畅、强健肌力、强化膝关节、助下肢静脉回流。
- **提阴窍接地气**：提肛带火气上行，应改提阴窍（如忍小便），常提阴窍守涌泉，气下降。人以天阳为魂、地阴为魄，丹田与地心相通得陰气滋养肉体。[[ren-shen-shu-san-yi-neng-liang-liu]] 中「正中能量流、监督者能量流、协调者能量流」亦强调接地与能量循环。
- **α 波与动态静修**：脑波呈 α 波即「气功态」。一般人闭眼睡眠 Pmax[α(f)] ≤ 44±3%，禅修高人清醒可达 100%。「行住坐卧不离这个」即时时保持气功态，「长生须伏气」。
- **心乱气散**：动态静修需修心功夫，随时随地保持清静。

### 以婴儿为师

- **婴儿呼吸**：三四岁前仍用腹式呼吸，印证《内经》「人生十岁，其气在下」。
- **婴儿脑波**：五岁以下幼童固定 α 模态，非成人 β 模态，即「赤子之心」。儿童接纳宇宙能量场信息能力远超成人，甚至留有前世记忆、见元神。
- **胎息**：胎儿未启动肺呼吸，经全身穴道细胞与宇宙沟通得能量。「天人同一气，彼此感而通；阳自空中来，抱我主人翁」。
- **老子**：「专气致柔，能婴儿乎？」婴儿无思无虑，脑波与自然谐波共振，全身聚气柔顺。
- **练气入气功态/入定态**：慢波现象似胎息，肺呼吸降至最低，能量由精转炁（电能转磁场），电能靠呼吸、磁场靠感应攝取。
- **《道枢》**：「凡人以有息为常，圣人以无息为常。」息住脉停为悟道验证。
- **成人 β 波主导**：生活紧张压力表现。放松专注时转 α 波。年龄越小 α 越强，新生儿几乎全慢波，胎息功能未退化。
- **施肩吾**：「行气之法，但泯思虑，微微元气，自然遍体。」凝神静心，任鼻息悠长，全身感应充能。
- **气功态体感**：全身麻麻、身轻，被能量包围，随呼吸一胀一缩如「全身皮肤呼吸」。
- **婴儿「其气在全身」**：襁褓动则四肢全动，推知全身细胞处气场包围中。「人在气中，如鱼在水中」。
- **《囟顖经》**：「三岁以下呼为纯阳，元气未散。」幼儿纯阳之体，呼吸通天地能量。
- **指纹发旋为能量漩涡痕迹**：旋转产生吸力，显示胎息期全身处「摄能」状态，神经末梢为能量入口。
- **意念开关仪器**：阳明脑科学研发，α 波状态下意念可控制远端电器。
- **后天意识成熟 → β 波化 → 全身呼吸能力消失**。
- **静坐与丹田功差异**：静坐身心一动气即散（α→β），丹田气练好则清醒兼具 α β（混元气），行住坐卧全身被宽频谱能量包围，为武术气功基础。
- **黄元吉**：「行住坐卧总要将神光下照丹田，日积月累真气冲冲，包固一身内外。」以婴儿为师，重启儿童摄能模式。

### 呼吸是生命力之源

- **唯一可意识干预的生理运作**。呼吸有好坏，效率优劣大影响健康寿命。常人呼吸粗短急浅，非良呼吸。
- **呼吸调节自律神经**：呼气→副交感神经兴奋；吸气→交感神经兴奋。良好呼吸协调平衡两者。
- **真气与谷气**：「真气者，所受于天，与谷气并而充身者也。」谷气=食物生物能量；真气=天地能量。两者同类相近始能合流。动植物吸天地真气转化为谷气，人食之间接摄真气。辟谷者靠真气维生。
- **人体摄能两管道**：饮食、呼吸。真气=精气，呼吸为摄取精气途径之一。道家辟谷闭关靠呼吸摄能。
- **饮食健康资讯多，呼吸研究少**。善用呼吸强化气血，治标治本。
- **两大作用**：
  1. **摄氧**：肺泡毛细血管气体交换。浅呼吸→死腔→轻度缺氧→代谢差→易病。
  2. **摄能**：「后天之气足」即呼吸所吸空气中「氤氳内蕴」之气（能量渗透弥漫感）。孟子「善养吾浩然之气」。呼吸摄能之气类瑜伽 Prana（万物原始能量），主要为电能=阳气。
- **阳气入身路径**：口鼻→心脏→丹轮→穴道→细胞，推动气血、营运全身。心轮旋转生吸力，吸收呼吸带入能量成心电，供心跳血液循环。「血行脉内，气行脉外」，气脉与心电谐波共振，血管有压力输送血液。
- **心肺复苏术**：呼吸停心跳停。《灵枢·五十营》：「一呼脉再动，气行三寸；一吸脉亦再动，气行三寸；呼吸定息，脉行六寸。」气为血帅，呼吸吸氧入肺、吸电入心，与血管谐波共振运血。
- **心轮功能低下→心病**。《痹论》：「心痹者，脉不通。」气血阻塞致心功能低下，严重猝死可能因气脉不通心脏麻痹。
- **气血之「气」非仅氧气**，含多种能量，左右体形容貌体能疾病寿命。现代医学未掌握「气」影响，致多病因不明。
- **生命维持两条件**：营养摄取、垃圾清运，皆需电能热能。《内经》：「人之血气精神者，所以奉生而周于性命者也。」万病皆因能量循环受阻。

### 丹田主司练气养气

- **《内经》「其气在下」界限**：上半身阳、下半身阴，以脐为界。十岁少年呼吸能量直达脐下。
- **丹田条件最佳**：袋状、柔软无骨、可伸缩、经脉以此为根据地。**丹田=人体电池=气的工厂和仓库**。
- **背部对应位置**：仙骨（发力中心），传输能量供活动。丹田存、仙骨出，一切修炼以丹田为大本营。
- **《达摩秘功》**：意领气，气血随意聚丹田，身强体健益寿延年。丹田「呼吸出入系乎此，阴阳开合存乎此……关系全身性命，此中一线不绝，则生气一线不亡」。
- **《难经》**：「丹田者，人之根本也」「脐下动气者，人之生命也。」学气功第一步：呼吸吐纳吸气到丹田、存丹田、转化供身。
- **水火既济**：丹田称「阴海」。吸入带火气的阳气送达丹田与阴气会合＝「火入水鄉」＝「水火既济」。《灵宝天尊说救苦妙经》：「行水不行火，则气难上腾；行火不行水，则不能薰蒸。」丹田功能即媾和阴阳、启动生化。
- **道家口诀反序**：「坎中之水引之上升；离宫之火导之下降」实不可行。须先导心火（离火）入丹田（坎水），水遇火发热生动力，水气始上升。
- **孟子**：「气者，体之充也。」身如皮球，丹田脐为进气口，球足气则弹得高跳得远。体弱气衰必往丹田脐充气。
- **武术气功**：丹田气壮后须「布气」运筋骨皮肉，配合拍打、攻击技术力道练习，「打」出来。静坐气为电磁场作用神经，无法用于肌肉发力。
- **作者练丹田历程**：龟鹤揉腹半年 → 黄豆砂包撞击三月 → 小木槌 → 中木槌 → 大木槌 → 师兄弟互「修」 → 丹田坚如充气轮胎，重拳不痛、大铁锤击、汽车从腹上开过。再布气四肢头背，皮沙袋拍打年积月累 → 筋骨皮肉坚韧，过招不易伤。此为「武术/硬气功」「铜筋铁骨」「铁布衫」，含脱肛胀气头晕血压升高风险，须专人指导。
- **养生级丹田功**：膝微屈，丹田吸足气，闭气横膈膜压紧，双掌举高轮流拍打小腹十分钟。初轻后重，久练保腹力不松、全身血气畅通。

### 如何脱胎换骨？

- **丹田气囊**：儿时张开充气好，随年龄消扁失纳气力。腹式呼吸起降小腹引能入丹田，守窍聚气，久之气囊重新开窍，坚硬富弹性，密度升高腹压增高，推动腹腔静脉血回流、脑脊髓液循环加快、优化内分泌、增强免疫、提升全身脏器机能。
- **长期丹田呼吸＝「养气」**：气渗透力推进力丰强，打开丹田网膜囊下部已粘连两层网膜腔，丹田能存更多气，越壮，并经温养程序练化提升气层次。
- **守窍拍打捶练**：提高丹田及邻近细胞对能量敏感度，吸收更多能量，经奇经八脉输往全身灌溉筋骨皮肉五脏六腑。此即《内经》「其气在下」生化作用，练气养生基本原理。
- **三焦通＝胸腹囊膜全开**：清朝唐宗海：「胸腹之内，通身之膜皆是三焦。」三焦主持诸气，总司气化运行。练气灌注全身打通三焦，气顺利新陈代谢，为练气者重要里程碑。
- **全身「满」感**：练功感全身吸满如丹田吸气，气场渗透全身进入气功能，体内外建立能量通道，细胞时时充电活化，道家养生境界分水岭。
- **龙吟虎啸、毕剥声**：三焦气通，气体上下左右顺流，胸腹发行气通脉声；网膜囊开，出必剥声。浊气排净，身轻体健，修道「脱胎换骨」近矣。
- **黄元吉**：「炼精炼气，阳火一临，阴霾尽消，陈年老病，悉化为疮肿瘍血，从大小便而出。」先扫净身污，为炼气修道大务。
- **《灵枢·本藏》**：「经脉者，所以行气而营阴阳，濡筋骨，利关节者也。」经脉为阴阳流动行气管道，气至筋骨濡劲关节滑利。经脉=人体运输网络系统。[[ren-shen-shu-an-quan-neng-liang-suo]]、[[ren-shen-shu-san-yi-neng-liang-liu]] 亦以安全能量锁、三一能量流对应经络能量通路，互为参照。
