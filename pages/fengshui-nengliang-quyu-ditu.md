## 概述

本页面系统梳理日下由纪惠《召唤宇宙能量的幸运整理术》第4章核心体系：**以玄关为底边、住宅中心为太极点**的风水能量区域划分方法。该体系不依赖传统方位（八卦九宫），而是采用**相对几何定位法**，将居家空间划分为六大功能性能量区域与一圈召唤福神区域，提供公寓与独栋住宅的实测套用图示、太极位重叠判断标准、中央区清爽维护与早晚通风换气等完整实操指南。

> **核心原则**："和方位、方向没有关系，请以玄关为底边，家的中央为『太极』，与能量区域地图对照参考。" —— 日下由纪惠

## 理论基础：住宅即能量身体

### 住宅直接反映住户频率
- 家与住户频率契合，如同志同道合的朋友，**物以类聚，人以群分**
- 环境完全承继住户能量，是**最亲密的能量镜像**
- 整理提升环境能量品质 → 住户频率跟随上升 → 形成正向循环

### 顺应风水循环，引入优质气流
- **风** = 空气流动（呼吸） | **水** = 血液循环/水流
- 宇宙能量（天）+ 大地能量（地）→ 每日循环注入万物
- 能量从**入口（大门/玄关）进入 → 流向各房间 → 汇聚中央（太极）**
- 遇能量不佳处，优质气流"一溜烟跑掉" → 需打造良好气流环境

### 有意识关注呼唤能量丰富生活
- 意识界限划分场域 → 场域内能量落地生根
- 感知场所/物品能量 → 呼唤宇宙之"风" → 打造最佳运气能量通道

## 六大能量区域 + 一圈福神区域 详解

以**玄关为底边**，**住宅几何中心为太极点**，纵横三等分内框，四连线连接太极四顶点至四角，形成以下区域：

| 区域名称 | 核心关键词 | 对应人生面向 | 整理重点 |
|----------|------------|--------------|----------|
| **人际好转区域** | 人际关系、人气、亲子、婆媳、沟通能力 | 社交、家庭和谐 | 擦拭发光物体（镜子、屏幕、门把），保持反射面清澈 |
| **工作发运区域** | 工作、人脉、读书、合格、专注力、灵感 | 事业、学业、创作 | 整理书桌、文件、学习资料，维持专注环境 |
| **运气提升区域（太极）** | **出人头地、身心健康、良缘、求子** | **核心综合运势** | **严禁放物品，设为聚集地，保持绝对清爽** |
| **梦想实现区域** | 恋爱、美丽、目标达成、自我肯定、自我确立 | 爱情、自我实现 | 布置愿景板、美化装饰，强化目标可视化 |
| **创造安定人生区域** | 安全、安心、小孩成长、不动产 | 家庭根基、资产稳固 | 收纳重要文件、印章、存折，营造安稳感 |
| **金钱运提升区域** | 财产、存款、收入提升、名声 | 财富、社会评价 | **每个角落约50cm范围**，彻底清理死角杂物 |
| **召唤福神区域（宅周）** | 所有运气提升 | 环境边界保护 | **公寓：玄关周围+阳台；独栋：房屋占地周边**，清理户外堆放物 |

> **太极是优质能量汇集处**。若中央是厕所/厨房/浴室/走廊/楼梯/储藏间，虽不能视为标准太极，但**用心打扫保持整洁，同能环绕优质能量**。

## 区域划分实操步骤

### 确定内外框
- **内框**：取居家**纵向与横向最长处**圈出矩形
- **外框**：
  - **公寓** = 玄关周围区域 + 阳台
  - **独栋** = 房屋占地范围全周边

### 定太极点
- 内框纵横**各三等分**，正中心即**太极点**
- **重叠判断**：只要某房间与太极区**有任何重叠**，该房间即拥有优质气流汇聚

### 划分六区
- 以太极四顶点向四角连线，形成六大功能区
- **形状复杂户型**：外框补成方形，虚设角落连线，再回内框找对应区

### 金钱运区域特例
- **户型过于复杂** → **所有角落**均视为金钱运提升区
- 范围：**边长约50cm**，不拘面积大小，重点清理死角

## 太极位特殊情况处理表

| 太极落在何处 | 判断 | 对策 |
|-------------|------|------|
| 客厅/餐厅/卧室/书房/起居室 | **标准太极** | 严禁堆物，设为家人聚集核心区 |
| 厕所/厨房/浴室 | **非标准太极**（水气重） | **极致清洁**，保持干燥通风，可置小型绿植化解 |
| 走廊/楼梯/玄关 | **非标准太极**（气流通道） | **保持畅通无物**，日常擦拭扶手/地面 |
| 储藏间/杂物间 | **非标准太极**（停滞区） | **彻底断舍离**，转为功能性收纳，保持三成空位 |
| 无法确定/户型极不规则 | **虚设太极** | 按几何中心点定位，以该点周围1m半径为核心维护 |

## 中央区（太极）保持清爽实操规范

### 绝对禁忌
- ❌ 堆放杂物、储物箱、季节性用品
- ❌ 设置猫砂盆、宠物窝、垃圾桶
- ❌ 摆放大型家具阻断气流
- ❌ 作为临时"待处理区"

### 必须执行
- ✅ **每日早晚各开窗1-3分钟**（晨间空气经夜间净化，能量最高）
- ✅ 维持**地面可见度100%**，无遮挡物
- ✅ 设为**家人自然聚集区**（茶几+地毯/榻榻米+坐垫）
- ✅ 定期**除尘杆清理天花板四角**（不良气流囤积代表性场所）
- ✅ 放置**一盆圆叶绿植**（如发财树、绿萝）象征生生不息

### 能量检测自测
> 站在太极点闭目深呼吸3次 → 感受：
> - ☐ 气流顺畅无滞重感
> - ☐ 身体自然放松、思绪清明
> - ☐ 想要久留、不想离开
> → 全中 = 太极能量良好；否则立即执行清理

## 早晚通风换气标准作业程序 (SOP)

### 早晨（推荐 6:00-8:00）
1. 起床即开**全屋所有窗户**（含厕所/浴室/厨房）
2. 打开**室内所有门**（促成贯穿风）
3. 计时 **1-3分钟**（冬季可缩短至1分钟）
4. 关窗前在太极点**深呼吸3次**，吸纳晨间高频能量

### 晚上（推荐 18:00-20:00）
1. 下班/晚餐后开**对角线窗户**形成对流
2. 重点排出**白天积累的浊气/电磁场残留**
3. 计时 **1-3分钟**
4. 关窗前在玄关**拍手3下**（声波驱散残留滞气）

### 特殊天气调整
- 雨天/雾霾：开窗时间减半，配合**空气净化器/循环扇**
- 极寒/酷热：改用**对角线微缝通风**（各窗预留5cm）+ 晨昏各5分钟全开

## 六大区域针对性整理行动清单

### 人际好转区域 → "光亮法则"
- [ ] 每周擦拭**所有镜面**（穿衣镜/化妆镜/玄关镜/浴室镜）
- [ ] 每日擦拭**手机/平板/电脑屏幕**（酒精棉片/专用布）
- [ ] 每周擦拭**门把手/拉手/开关面板**（金属光泽度=人缘光泽度）
- [ ] 移除区域内**破损/起雾/划痕**反射物
- [ ] 摆放**一件圆形/椭圆形金属/玻璃装饰**（象征圆融人际）

### 工作发运区域 → "专注法则"
- [ ] 书桌**仅保留当前项目文件/笔记本/一支笔**
- [ ] 书架按"现用/参考/存档"三区分类，**非现用上锁/收箱**
- [ ] 电脑桌面**零图标**，文件归类至云端对应文件夹
- [ ] 墙面贴**单一年度目标/关键词卡**（A5纸手写，每季更换）
- [ ] 椅子后方**留白1米**（后背有靠山，前方有展开空间）

### 运气提升区域（太极） → "空白法则"
- [ ] **地面零物品**，仅保留地毯/坐垫等软性铺设
- [ ] **天花板四角**每月除尘杆清扫1次
- [ ] **早晚通风**严格执行SOP
- [ ] 摆放**圆叶绿植1盆 + 无香白蜡烛1支**（每周点燃15分钟）
- [ ] 家人**每日在此停留≥15分钟**（聊天/阅读/冥想/发呆均可）

### 梦想实现区域 → "可视化法则"
- [ ] 制作**愿景板**（A3软木板/相框，贴目标图片/关键词/截止日期）
- [ ] 摆放**代表目标的实物微缩模型**（如微缩房屋/护照/证书复印件）
- [ ] 照明改为**暖色调可调光灯**（营造"已实现"的温暖感）
- [ ] 每日睡前**站在区域中央朗读目标清单3遍**
- [ ] 移除**一切"未完成/失败/负面"关联物品**

### 创造安定人生区域 → "收纳法则"
- [ ] 重要证件（房契/身份证/印章/存折/保单）→ **防火防水保险箱**
- [ ] 家庭医疗/教育/维修档案 → **标签分类文件盒**，按年份归档
- [ ] 孩子成长纪念品 → **每年1个纪念盒**，超量拍照数字化后精简
- [ ] 应急物资（现金/药品/手电筒/水/食品） → **专用背包放入口处**
- [ ] 定期检查**保险箱/文件盒/应急包**有效性（每半年1次）

### 金钱运提升区域 → "死角清零法则"
- [ ] **全屋角落（含虚设角落）50cm半径内**彻底清空
- [ ] 角落**禁止放置**扫把/簸箕/垃圾桶/脏衣篮/宠物用品
- [ ] 角落**仅允许**放置：落地灯/大型绿植/装饰性落地花瓶（三选一）
- [ ] 每月**角落巡检**：手电筒照射无灰尘/蜘蛛网/积水/霉点
- [ ] 发现**霉味/异味/潮湿**立即处理（除湿机/漂白水/专业防水）

### 召唤福神区域（宅周） → "边界净化法则"
| 住宅类型 | 范围 | 重点行动 |
|----------|------|----------|
| **公寓** | 玄关外侧3米内 + 阳台全域 | 玄关地垫每日拍打/阳台地面每周水洗/排水口每月疏通/移除阳台所有非园艺堆放物 |
| **独栋** | 房屋外墙周围1米 + 院落/车道/入口道 | 外墙基部每季高压水枪冲洗/落叶/杂草/垃圾日清/大门/门柱/门牌每周擦拭/门口灯每日亮灯30分钟 |

## 常见户型套用快速参考

### 一室户/开放式套房
- **太极** = 唯一主空间几何中心
- **六区重叠度极高** → 以**时间分区**替代空间分区：
  - 早6-9点 = 人际区（整理仪容/早餐社交）
  - 早9-晚6点 = 工作区（办公/学习）
  - 晚6-9点 = 梦想区（规划/技能/社交）
  - 晚9-睡前 = 太极区（冥想/阅读/复盘）
  - 睡眠时段 = 安定区（卧具整理/次日准备）
  - **全天候** = 金钱区（角落清零/钱包定位）

### 两室一厅/三室两厅标准户型
- 按标准几何法划分，**以卧室门为界**微调区域边界
- **主卧**常落入"安定/梦想"区 → 强化收纳与愿景
- **次卧/书房**常落入"工作/人际"区 → 强化专注与光亮
- **客厅/餐厅**常含**太极** → 严守空白法则

### 复式/跃层/阁楼
- **每层独立划分**内外框与太极
- **楼梯间** = 垂直能量通道 → **严禁堆物、每日扫拖、装感应灯**
- **阁楼/地下室**若高度<2.1m → 纳入"金钱区/福神区"按角落法则维护
