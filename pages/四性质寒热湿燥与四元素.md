# 四性质寒热湿燥与四元素

寇佩珀的《400年占星药草医典》与《400年占星药草千方》把药草、人体部位与疾病都编入同一个占星体系，而「寒、热、湿、燥」四种性质正是这个体系里最细的一层刻度：它既是药草条目中被逐项标明的属性，也是把四元素与三方宫重新接回身体经验的接口。本页整理这套性质语言的分级方式、它在药典中如何被用来罗列药草，以及如何据以「以对立性质恢复平衡」来选药。

## 寒热湿燥：四性质与分级

在《400年占星药草千方》第二单元〈单方药剂〉的体例中，药草按〈根部〉〈树皮〉〈花朵〉〈果实〉〈种子〉〈动物〉〈矿物〉等章节归类之后，会以「寒热属性」项目列出其性质。该项目的写法正是「以『寒』、『热』、『湿』、『燥』四种属性加上等级」，把归属的植物药草罗列其中。

到了第四单元〈盖伦的医疗法要点〉，〈关于药物的属性〉一章进一步理论化地阐述「平性」与「寒性」、「热性」、「湿性」、「燥性」各级药物的不同用途与效果。可见这套性质语言至少包含两个层面：

- **四种基本性质**：寒、热、湿、燥；
- **等级刻度**：每一性质依强度分等，并另设不偏的「平性」作为基准。

在药草条目里可以看到等级的实际标法。例如蝮蛇之舌「就其热度而言算是温和的，但干燥程度达到第二级」；大天使草则被描述为「比有臭味的荨麻稍微干热些」。也有同一药名之下并存相反性质的例子，如蓼草分「性热的蓼草」与「温的蓼草」，并强调「两种蓼草具有相反的性质」，读者可借舌感分辨——性热者使舌头刺痛，温和者不会。

## 四元素是四性质的再组合

书中最关键的提示是：占星的四元素（星座的四象属性或三方宫），在古典时代就是四种属性的再组合。也就是说，火、土、水、风并非独立于寒热湿燥之外的另一套语言，而是把寒、热、湿、燥两两搭配后得到的二阶分类。

据古典四元素说的通行内容，这一再组合一般对应为：

| 四元素（三方宫） | 寒热湿燥组合 |
|---|---|
| 火 | 热 + 燥 |
| 土 | 寒 + 燥 |
| 水 | 寒 + 湿 |
| 风 | 热 + 湿 |

因此，当一个星座被归入火象或水象，它同时也携带了一组性质倾向；而药草被标为「热而燥」或「寒而湿」时，实际上就已经落在某一元素的组合逻辑里。书中指出这套观念「早就深入许多领域，并形成连贯」，正是要说明占星、药草与医学共享同一套性质语法。

这也解释了为什么药草条目常同时给出「行星归属」与「寒热属性」：行星提供的是交感／反感的对应关系，寒热湿燥提供的是可以直接作用于身体冷热干湿的物理刻度，两者互为经纬。相关体系背景可参见 [[占星医疗与行星药草配伍]] 与 [[寇佩珀占星药草医典]]，三方宫与四正的区分见 [[星座三原型与四正]]，星座二分三分四分法见 [[黄道十二宫体系]]。

## 性质如何用于罗列与选用药草

### 罗列：以性质为检索轴

〈单方药剂〉把「寒热属性」作为独立项目，等于在药草的行星归属之外再开一条检索轴。读者可以跳过行星，直接按「寒」「热」「湿」「燥」加上等级来查找药草：需要暖性的、需要润性的、需要燥性的，都可以由此入手。这与书末药草速查表按笔画排列的索引方式互补——速查表解决「找哪一味」，寒热属性解决「这一味属于哪一类」。

### 选用：性质、部位与行星三线并看

〈关于药物的适用症状与身体部位〉则说明怎么根据行星配置和药草属性选取药物。推荐序把这一操作概括为三个层次：

1. 理解个案的出生命盘，容易生什么病；
2. 理解症状的行星属性——病灶在什么器官、由哪颗行星主宰、该行星落在个案哪个宫位；
3. 依症状的寒热燥湿与行星归属，选取相应性质的药草。

换言之，星盘给出体质蓝图，性质给出配方的用力方向。

## 以对立性质恢复平衡：反感医学的操作依据

书中最直接的操作原则是「反感作用」（anti-pathetic medicine）：疾病由某一行星或某一性质造成时，选用对其有反感、即性质相反的药草来抗衡。寇佩珀在致读者的信中把它写得很具体：

- 知道了引起疾病的行星，就可以用与之对立相冲的行星所主司的药草来对抗疾病；
- 水星药草可治木星造成的疾病，反之亦然；
- 发光星体（太阳、月亮）所致疾病可由土星药草医治，反之亦然；
- 金星药草可治火星引起的疾病，反之亦然；
- 有时也可以透过交感作用来治，即每颗星体用自己相关的药草治自己相关的疾病——太阳与月亮治眼疾、土星治脾脏、木星治肝脏、火星治胆囊与黄胆汁疾病、金星治生殖器官疾病。

推荐序给出的两个例子，正是把行星层面的对立翻译成性质层面的对立：

- 个案主诉「发炎热如火星」，就用冷静的月亮或金星药草予以降温消炎；
- 病灶在消化道、因命盘月亮在六宫而易因情绪紧张胃痛，若属「紧张胃寒」，就用热性的太阳、火星药草（香料类）暖肠胃，以反向操作恢复平衡。

药草条目中也处处可见这种对偶：紫朱草属金星，「藉由对火星的反感作用」治疗长期溃疡、发炎与烧烫伤；蓼草两种相反性质并存，提醒使用者必须先辨明寒热再决定用途；万灵丹（毛茛一类）由火星支配、「辛辣且燥热」，用于各种寒性头部不适与胀气腹绞痛。这些例子都指向同一件事：性质不是标签，而是处方方向。

## 与中医「调体质」的对观

推荐序指出，这套操作与中医「调体质」概念相近：十七世纪之前理性主义与实证医学尚未兴起时，西洋医学哲学与中医非常近似；寇佩珀主张采收、用药乃至治病择时都应参考星辰相位，与中医衡量经络运行、子午流注有异曲同工之妙。其精神最终回到全人医学观——「As above, so below.」天象与人体有所对应，药草师治疗的不是病，而是人，目标是帮助个案恢复平衡。这一层对观在 [[占星医疗与行星药草配伍]] 中有更完整的展开。
