## 核心神话基础：欧西里斯神话

埃及魔法与宗教密不可分，核心叙事围绕 **欧西里斯** 的死而复生展开。根据归档文献，该神话确立了埃及人对来世复活的信仰范式，直接塑造了木乃伊制作、护符使用及葬礼仪式的逻辑。

### 神话梗概
- **欧西里斯**：教导埃及人艺术、法律、建筑与农业的仁君，深受爱戴。
- **伊西斯**：欧西里斯之妻兼妹，精通魔法，为寻回丈夫遗体不惜远渡腓尼基、施展咒语拼接肢体。
- **塞特**：嫉妒欧西里斯的邪恶兄弟，设计将其杀害、肢解为 14 块抛撒全国。
- **托特**：鹭头神，魔法与文字之神，著《托特之书》，以咒语协助欧西里斯复活。
- **荷鲁斯**：欧西里斯与伊西斯之子，复仇继位，欧西里斯遂成为冥界审判官。

## 灵魂三部分论

埃及人认为人死后灵魂分为三部分，每部分对应特定象形符号，常制成护符佩戴或随葬：

| 灵魂部分 | 含义 | 象形符号 | 护符功能 |
|----------|------|----------|----------|
| **Ka（卡）** | 与肉体关联的生命力，死后仍依附遗体 | 举起的双臂 | 供养 Ka 需木乃伊完好及供品图像 |
| **Ba（巴）** | 可游走世界的个性灵魂，需每晚返回肉体 | 人头鸟身 | 护符引导 Ba 识别归途 |
| **Akh（阿赫）** | 不依肉体的高等灵魂，可入永恒精神世界 | 朱鹭 | 标志完成转化的终极护佑目标 |

> **交叉引用**：[[ancient-egyptian-book-of-the-dead]] 对“巴与卡”二元论有更详细的经文翻译与题解。

## 魔法仪式体系

### 开嘴仪式
- **目的**：象征性让死者重获语言与感官能力，使《亡灵书》咒语生效。
- **操作**：祭司用特制工具（如小斧、燧石刀）触碰木乃伊或雕像的口、眼、耳、鼻，同时诵念咒语。
- **地位**：被视为最古老的仪式魔法范式之一。

### 四方位金字塔与神圣空间
- **结构原理**：金字塔四面精准对准东西南北，象征世界中心、天地连接轴线。
- **仪式空间**：魔法仪式须建立以四方位为骨架的神圣空间，呼应日出日落的太阳神圣方位。
- **荷鲁斯四子**：分守四方位，各护一内脏器官，对应四女神：
  - 爱姆塞特（人头）— 肝 — 伊西斯 — 南
  - 哈比（狒狒头）— 肺 — 奈芙蒂斯 — 北
  - 杜阿穆特夫（豺头）— 胃 — 奈特 — 东
  - 克贝赫塞努夫（隼头）— 肠 — 塞尔凯特 — 西
- **实操**：内脏罐按四方排列，构成微型宇宙秩序。

## 感应魔法原理

埃及日常魔法的核心技术是 **感应魔法**，即“以象似象、以接触传影响”，与 [[frazer-sympathetic-magic]] 中詹姆斯·弗雷泽归纳的 **模仿律** 与 **感染律** 完全对应：

| 原理 | 埃及实践 | 弗雷泽术语 |
|------|----------|------------|
| 制作恶魔/敌人形象 → 刺破、焚烧、砍首 | 蜡像、陶俑、纸草人等替身破坏仪式 | **模仿律** |
| 获取目标发甲、衣物、名字 → 施咒 | 收集指甲屑、头发、书写真名于护符 | **感染律** |

> **核心洞见**：“防卫重于治愈”，埃及人倾向佩戴护符预防恶魔侵害，而非事后驱除。

## 五大常见护符详解

所有护符须经 **“开光”仪式**（诵咒、涂油、熏香、日月光照等）方具魔力。埃及象形文字“既是文字又是图像”，使护符兼具文字咒语与视觉符号双重效能。

### 乌查特——荷鲁斯之眼
| 维度 | 详情 |
|------|------|
| **象征** | 荷鲁斯左眼（月亮）与右眼（太阳），代表完整视觉、王权护佑、数学分数单位（分数之和=63/64，缺 1/64 象征托特补全的智慧） |
| **材质** | 天青石、玛瑙、花岗石、黄金、白银、木材 |
| **用法** | 佩戴求力量、守护、安全、健康；绘于棺椁、船首、门楣；医疗处方开头常绘此符求验方有效 |
| **咒语示例** | “我是荷鲁斯，我的眼睛完好无损，邪恶远离我” |

### 斯卡拉布——圣甲虫
| 维度 | 详情 |
|------|------|
| **象征** | 凯普利（晨阳神）推滚太阳如甲虫推粪球，寓意自生自灭、永恒循环、重生 |
| **材质** | 蓝/绿釉陶、青金石、绿松石、红玉髓、象牙、陶瓷 |
| **变体** | **心脏圣甲虫**：平底刻《亡灵书》第 30B 章“心脏不证我罪”咒语，置于木乃伊心口，防心脏称量时作证不利 |
| **用法** | 生前佩戴求活力、朝气；死后随葬保障来世重生；印章戒指兼作行政印信 |

### 泰特——伊西斯之结
| 维度 | 详情 |
|------|------|
| **象征** | 伊西斯腰带结/搭扣，代表月经血与生育力，延伸为伊西斯魔法束缚与解脱的双重力量 |
| **材质** | 红玉髓、红玉、石榴石、红玻璃、黄金 |
| **用法** | 女性佩戴护佑分娩、生育；死者佩戴得“在冥界自由通行”；常与安卡、杰德柱组成“三件套”悬挂颈部 |

### 安卡——生命之钥
| 维度 | 详情 |
|------|------|
| **象征** | “生命”词语本身；上环=永恒精神，下十字=物质显化，合为“精神降入物质”之钥 |
| **材质** | 青金石、绿松石、红玉髓、黄金、青铜、陶瓷、木材 |
| **用法** | 神像手持安卡向法老鼻孔吹气 = 授予永生；佩戴提升生命力、延年益寿；葬礼仪式中祭司以安卡触碰木乃伊五官配合开嘴仪式 |
| **现代延伸** | 科普特十字演变；新时代能量疗愈中作“生命能量开关”手势 |

### 杰德柱——稳定柱
| 维度 | 详情 |
|------|------|
| **象征** | 欧西里斯脊柱/装尸柱，四横档=四方位/四子/四元素，核心轴=世界轴；寓意“稳定、复活、永续” |
| **材质** | 木材（最传统）、黄金、青金石、绿釉陶、红玉髓 |
| **仪式** | **竖立杰德柱节**：法老亲手竖立巨型柱子，象征国家秩序重建、欧西里斯复活 |
| **用法** | 死者颈部悬挂微型杰德柱，保证脊椎完整、来世复活；建筑基石埋藏镇宅；护身符求事业稳固、根基不摇 |

## 实操框架：自制埃及护符基本流程

1. **选材与造型**  
   - 依上表选取对应矿物/木材/陶土，雕刻或模制标准图像。
   - 尺寸以佩戴舒适为宜，心脏圣甲虫需预留平底刻字空间。

2. **净化**  
   - 流水冲洗 → 熏香（乳香/没药/桃金娘） → 月光/日光浴各一昼夜。

3. **开光仪式**  
   - 面向对应方位（如安卡面东、杰德柱面四方依次旋转）  
   - 诵念神名与咒语 3/7/9 遍，以指尖涂少量乳香油触碰护符关键部位（眼、结、环、柱顶）。  
   - 吹气三口（象征托特吹入生命之气）。

4. **佩戴/安放**  
   - 生前：红绳/金链佩戴颈部，或缝入衣物内袋。  
   - 身后：按《亡灵书》规定位置置于木乃伊绷带层间（心脏圣甲虫贴心口、安卡置胸口、杰德柱置颈椎、伊西斯之结置下腹、荷鲁斯之眼置额头/双手）。

5. **定期维护**  
   - 每逢朔望日以尼罗河水/清水轻拭，复诵咒语 3 遍，充月光 1 小时。
