## 页面定位

本页为占星书目主题导航的核心枢纽，旨在将零散的占星著作沉淀为结构化、可交叉引用的知识网络。页面按“学习路径与主题领域”双重维度组织书目，重点收录**《占星全方位》**、**《实力占星系列》第一册**、**《内行星》**、**《占星十二宫位研究》**、**《你的身体就是12星座》**、**《十二宮位》**、**《十二星座首席爱情大师》**、**《占星、業力與轉化》**、**《占星占心》**、**《占星合盘的吸引力法则`**、**《占星、心理學與四元素》**等核心条目，确立其在综合体系构建、心理占星、宫位心理深度解析、医学占星、宫位专题实务、职场实用星座指南、演化占星业力转化体系、古典占星实战案例教学、关系合盘吸引力法则、人本占星理论基石中的基石地位，并关联錠堅、秦瑞生、萨司波塔斯、韩良露、鄭工智、Stephen Arroyo、胡因夢、希斯莉（Cecily）等作者著作脉络及各专题深度解析页面。

所有条目均链接至对应的结构化知识页面，形成“书目索引 → 核心框架 → 专题深度 → 实践应用”的四层导航结构。

##### 哲学三基石：波姆·混沌·荣格
| 维度 | 核心观点 | 占星学启示 |
| :--- | :--- | :--- |
| **大卫·波姆** | 全息宇宙（隐秩序綻放显秩序）、身义合一（物质/意义两面）、不可分割整体性、含义为桥梁 | 占星非引力机制，**全息共振**；天宫图为隐秩序显化图；行星原型为隐秩序先驱显现；**整体论替代还原论**。 |
| **混沌/复杂科学** | 非线性动力、碎形几何（自我相似/局部含整体）、奇异引子、循环回馈/自我组织、亂中有序 | **天人感应=碎形同构**；星座/宫位/行星/相位/流年/主限/測定圖/泛音盤皆为**黄道碎形分形展开**；双生子微小初始差异导致巨大人生分歧（蝴蝶效应）。 |
| **荣格** | 集体无意识（心灵场）、原型（先天心灵模式/人格面具/阴影/阿尼玛/智慧老人/本我）、同步性（非因果有意义巧合/量子非定域性印证） | **天宫图=心灵地图/奇异引子**；行星/星座/宫位=原型载体；同步性解释“为何天上星象对应地上事件”；时事占星基于**集体无意识**激活。 |

##### 历史五阶段记忆锚点
1.  **萌芽→黄金→死亡**：巴比伦征兆 → 希腊化托勒密奠基 → 圣奥古斯丁神学扼杀/西罗马亡。
2.  **阿拉伯保存→西欧回流→文艺复兴黄金**：阿尔布马萨/比鲁尼 → 波纳提/培根/阿奎那斯(自由意志) → 王公/星历/医疗/普拉西德/诺查丹玛斯。
3.  **科学分离→第二次死亡**：哥白尼/开普勒/牛顿/天文剥离占星 → 理性主义衰退。
4.  **通神会→里欧→心理占星王国**：布拉瓦茨基 → 里欧“个性即命运”避法律/建事业 → 卡特实证 → 亚当斯法庭认证。
5.  **现代分流与复古**：心理占星（格林/亚若优/萨司波塔斯）主流化 → 1990s古典复古（巴克利/汉德/莉利手稿） → 印度占星（吠陀）崛起 → **整合趋势**（秦瑞生/希斯莉实践）。
