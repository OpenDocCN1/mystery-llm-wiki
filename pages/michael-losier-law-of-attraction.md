# 迈克尔·劳塞尔《吸引力法则》核心体系

> **核心定位**：迈克尔·劳塞尔将吸引力法则从理论转化为**可操作的三步骤训练体系**，强调**语言重塑振动**、**差异明晰愿望**、**心灵感应罩管理**、**允许（愿望实现）即去除怀疑**，并提供标准化工具表单与实战案例。

---

## 一、吸引力法则基础原理

### 核心定义
> **吸引力法则界定**：不论你的注意力、能量集中于哪个方面，也不论这种注意力和能量是消极的还是积极的，你都在吸引着你自己的生活。

### 心灵感应（振动）双极模型
- **积极心灵感应（+）**：快乐、爱、兴奋、富裕、自豪、舒服、信心、友爱
- **消极心灵感应（-）**：失望、孤独、缺乏、难过、混乱、压力、愤怒、受伤
- **关键机制**：吸引力法则**只对当前瞬间发出的心灵感应反应**，反馈更多相同性质的体验。

### 无意中的吸引——观察与思考环形圈
```mermaid
graph LR
A[观察当前现实] --> B[产生对应心灵感应]
B --> C[吸引力法则反馈同频体验]
C --> A
```
- **破解点**：有意识地从“不想要”转向“想要”，改变语言与焦点。

### 语言即振动生成器
- **禁用词**：“不要、不是、不” —— 大脑自动过滤否定词，聚焦于被否定的对象。
- **转化公式**：听到自己用否定词 → 立即问**“那么，我想要什么？”** → 说出积极陈述 → 振动转正。

> **交叉引用**：[[law-of-attraction-comprehensive-guide]] 中的“四步显化法则”与本体系“三步骤公式”互补；[[xianhua-shijian-yu-zhuanzhu-lianci]] 详细对比了坎菲尔德、詹姆斯·雷等流派的语言重构技术。

| 步骤 | 核心动作 | 关键工具 | 产出 |
|------|----------|----------|------|
| **步骤1：辨清愿望** | 列出差异（不想要） → 翻转为明晰（想要） | **差异明晰进程表** | 精确的愿望清单（B面） |

## 三、步骤1：辨清愿望——差异明晰进程表

### 核心概念
- **差异**：让你感到不好、不喜欢、心情不佳的体验。
- **作用**：差异是**识别真实愿望的罗盘**——通过“不想要”精准锁定“想要”。

### 操作流程
1. 选定生活领域（金钱、关系、职业、健康……）。
2. **A面**：罗列 50–100 条差异（越多越清晰）。
3. 逐条读 A 面 → 自问**“那么，我想要什么？”** → 写入 **B面（明晰）**。
4. 划掉 A 面，仅保留 B 面作为愿望清单。

### 实战案例：贾妮丝（理想朋友关系）

| 差异 A面 | 明晰 B面 |
|----------|----------|
| 1. 不主动 | 1. 灵活、善于平衡 |
| 2. 不善于听人讲话 | 2. 善于倾听、沟通 |
| 3. 缺少温柔 | 3. 感情丰富、敏感 |
| 4. 不在乎我的想法/感受 | 4. 询问我的想法与感受 |
| 5. 不喜欢外出 | 5. 喜欢与朋友共同开心 |
| 6. 不喜欢旅游 | 6. 喜欢短途/长途/探险旅行 |
| 7. 总催促我 | 7. 耐心，允许按时完成 |
| 8. 未征求同意就决断 | 8. 决断前征求我意见 |
| 9. 不喜欢跳舞/看电影 | 9. 喜欢戏剧、电影、跳舞、娱乐 |

### 实战案例：格雷格（理想经济状况）

| 差异 A面 | 明晰 B面 |
|----------|----------|
| 1. 没有足够的钱 | 1. 拥有大量金钱 |
| 2. 总欠账单 | 2. 轻松付清账单 |

## 四、步骤2：高度重视愿望——心灵感应罩与愿望陈述

### 心灵感应罩模型
- **隐喻**：身边一个巨大玻璃罩，**只装当前正在发出的振动**。
- **法则只对罩内振动反应**。
- **目标**：把新愿望的振动**主动装入罩内**。

| 装入罩内的行为 | 驱逐出罩的行为 |
|----------------|----------------|
| 谈论/注意/白日梦/设想愿望 | 担心、抱怨、说“不”、回忆消极事 |
| 认为已实现、对愿望说“是” | 反复思考缺失、为愿望祈祷（带匮乏感） |
| 为喜好事物兴高采烈 | 察觉消极事物 |

### 两大振动提升工具

#### 工具1：重述确认——“我正处于……的过程之中”
| 普通确认（易生怀疑） | 过程确认（真实感强，振动正） |
|------------------------|--------------------------------|
| 我有一个苗条身材 | **我正处于越来越喜欢自己身材的过程之中** |
| 我是百万富翁 | **我正处于变得非常富有的过程之中** |
| 我有完美伴侣 | **我正处于吸引完美伴侣的过程之中** |

> **原理**：陈述属实 → 感觉良好 → 发出积极振动 → 吸引同频。

#### 工具2：愿望陈述（三段式标准结构）

**结构**：
1. **开头句**  
   `我正处于吸引我所有需要做、需要知道以及吸引我理想的[领域]的过程之中。`
2. **陈述主体**（从 B 面明晰条目转化，用句式库）  
   - 我非常高兴因为我知道 ________  
   - 我非常高兴当我 ________  
   - 我已决定 ________  
   - 越来越多的 ________  
   - 我一想到 ________ 就兴奋  
   - 我认为 ________ 是个好主意  
   - 看到自己 ________ 我很自豪
3. **结尾句**  
   `吸引力法则正在组织安排并展现出能够给我带来愿望的所有可能性。`

**贾妮丝愿望陈述节选（理想朋友关系）**：
> 我正处于吸引我理想人际关系的过程之中。  
> 我非常高兴因为我知道我理想的伴侣就住在这个城市。  
> 我一想到能与理想伴侣一起旅行就兴奋不已。  
> 我认为创建完整的客户数据库是好主意。  
> 看到自己恰当选择健康食品，我非常自豪。  
> 吸引力法则正在组织安排并展现出能够给我带来愿望的所有可能性。

**格雷格愿望陈述节选（理想经济状况）**：
> 我正处于吸引我理想经济状况的过程之中。  
> 我向往的理想经济状况是：需要什么就能自由拥有享用，生活自由舒适。  
> 我非常希望能轻松自如地付清各种账单。  
> 我一想到源源不断的经济收入就兴奋不已。  
> 我还非常希望能有盈余进行收益颇丰的投资。  
> 吸引力法则正在组织安排并展现出能够给我带来愿望的所有可能性。

### 自检标准
- 读完愿望陈述 → **感觉良好、振奋、放松** → 振动已纳入罩内。
- 若有不适/怀疑声 → 修改措辞直到感觉转好。

## 五、步骤3：愿望实现（允许）——去除怀疑的九大工具

### 核心公式
> **愿望实现 = 消极振动（怀疑）的缺失**  
> **显化速度 ∝ 允许程度（怀疑去除速度）**

| 状态 | 显化速度 |
|------|----------|
| 强烈愿望 + 强烈怀疑 | 极慢/不显化 |
| 强烈愿望 + 少量怀疑 | 慢 |
| 强烈愿望 + **零怀疑** | **极快** |

### 怀疑来源：限制性信念
- **识别法**：听到自己说 **“因为……”** 后面的理由。  
  例：“我想写书，**因为**没学位所以不行。” → 限制性信念：“没学位写不出书。”

### 核心工具：愿望实现陈述（三步制作法）

**制作公式**：
1. 问：**“当下是否已有人在做/拥有我想要的？”** → 是。
2. 追问：**“多少人？今天/昨天/上周/上月/去年？”** → 大量存在。
3. 用 **第三人称、概括性、合情合理** 语句写下证据（避免用“我”触发怀疑）。

**贾妮丝愿望实现陈述（理想朋友关系）**：
- 上月有许多女性与理想伴侣约会。
- 今天有更多女性首次约会就选中终身伴侣。
- 今天有数千万对伴侣相扶相伴。
- 每天都有更多女性吸引到理想伴侣。
- 数百万对伴侣一起参加社交、旅行、跳舞。
- 本周有数十万对伴侣去跳舞。

**格雷格愿望实现陈述（理想经济状况）**：
- 今天有数百万人收到支票。
- 每天有数十亿美元在账户间转移。
- 刚才一分钟就有人收到支票。
- 每天有数十万人赢得奖金/金钱。
- 昨天就有人成为百万富翁。
- 今天就有人找到赚钱捷径。
- 越来越多人吸引赚钱方法增加额外收入。

**自测**：读完 → **感到轻松、说“啊，这感觉真好”** → 怀疑消解，进入允许态。

### 九大辅助允许工具

| 编号 | 工具 | 核心动作 | 作用 |
|------|------|----------|------|
| 1 | **明示例证（证据）** | 主动寻找并确认“愿望已部分显化”的迹象 | 证据消除怀疑，提升振动 |
| 2 | **记录吸引力法则例证** | 日记/笔记记录每一个同步/巧合/小显化 | 积累信心，训练大脑关注已得 |
| 3 | **欣赏与感恩** | 有意识地欣赏当下拥有的一切 | 瞬间提振频率，扩大罩内正能量 |
| 4 | **“我正处于……过程之中”** | 将所有愿望陈述改为过程式 | 保持陈述真实感，持续输出正振动 |
| 5 | **“我肯定能……”** | 替代“我想要……” | 从匮缺感转向确信感 |
| 6 | **“很多情况可能发生……”** | 面对不确定时保持开放 | 降低控制欲，允许更多路径显化 |
| 7 | **寻求信息** | 主动学习相关知识/技能 | 行动配合振动，减少“我不知道怎么做”的怀疑 |
| 8 | **制作愿景箱** | 收集代表愿望的实物/图片/文字放入盒子 | 具象化锚定愿望，每日触发正振动 |
| 9 | **创造一个空间** | 物理/时间/心理上为愿望腾出位置 | 向宇宙发信号“我已准备好接收” |
| 10 | **让吸引力法则自行运作** | 停止监控进度、放下执着 | 彻底释放“缺失感”，回归允许态 |

> **贾妮丝用“明示例证”化解挫折**：遇到心仪但住在别国的男子 → 初感失望 → 教练引导列出该男子符合愿望清单的所有特质 → 振动秒转正 → 后续吸引到本地理想伴侣。

## 六、进阶应用模块

### 变得更富有、吸引更多金钱
- **核心**：建立**充裕振动**而非匮乏振动。
- **工具**：列出“充裕的证据”（氧气、阳光、免费资源……）→ 每日阅读 → 重塑金钱蓝图。
- **整合表单**：`充裕生活与吸引更多金钱整合表`。

### 人际关系与心灵感应
- **吸引理想关系秘诀**：
  1. 做自己的理想伴侣（振动同频）。
  2. 列出理想关系特质清单（B面）。
  3. 每日阅读愿望陈述 + 愿望实现陈述。
  4. 对现有关系中的“差异”即时翻转，不纠缠负面。
- **保持积极振动三法**：欣赏日记、过程式确认、愿景箱。

### 教导儿童使用吸引力法则
| 秘诀 | 实操 |
|------|------|
| 1. 用简单语言 | “心情好=磁铁吸好东西” |
| 2. 让孩子从自身经历回答问题 | “你什么时候感到开心？那时发生了什么？” |
| 3. 孩子爱“秘密” | 把法则包装成“超级秘密魔法” |
| 工具包 | 愿望贴纸、感恩罐、愿望实现故事绘本 |

```
【辨清】差异明晰表 A→B  (50-100条)  → 精准愿望清单

    └─ 愿望陈述三段式：开头 + B面主体 + 结尾
    ↓
【允许】愿望实现 = 零怀疑
    ├─ 核心：愿望实现陈述（第三人称证据法）
    └─ 九大辅助：证据/日记/感恩/过程语/我肯定能/多种可能/求知/愿景箱/腾空间
    ↓
显化加速 → 生活成真
```

> 宇宙不在意你‘怎么做’，只回应你‘是什么振动’。”
