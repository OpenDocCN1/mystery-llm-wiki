## 二、第一章：紫微高階排盤核心技法

### 宮干冠蓋兩招新法（速算核心）

#### 新招之一：生年干定寅宮干
> **公式**：生年干序數 × 2 + 1 = 寅宮干序數（取個位數）
> - 天干序數：甲1 乙2 丙3 丁4 戊5 己6 庚7 辛8 壬9 癸10
> - 例：壬寅年（壬=9）→ 9×2+1=19→個位9→壬干入寅宮

#### 新招之二：生年干定位圖（兼作五虎遁月、五鼠遁時）
| 生年干 | 定位宮 | 記憶口訣 |
|--------|--------|----------|
| 甲 | 戌 | 甲己通用 |
| 乙 | 酉 | 乙庚通用 |
| 丙 | 申 | 丙辛通用 |
| 丁 | 未 | 丁壬通用 |
| 戊 | 午 | 戊癸通用 |
| 己 | 己 | 甲己通用 |
| 庚 | 辰 | 乙庚通用 |
| 辛 | 卯 | 丙辛通用 |
| 壬 | 寅 | 丁壬通用 |
| 癸 | 亥 | 戊癸通用 |

> **原理**：宮干即五虎遁月，子月干=寅月干、丑月干=卯月干。  
> **應用**：同圖可求流月干支、流時干支（日干序數×2-1=子時干）。

#### 紫微安星捷法（生日÷局數）
1. **整除**：商數即為步數，寅宮起1順數
2. **不整除**：加<局數的數字使整除
   - 加**奇數** → 商數**減**該奇數
   - 加**偶數** → 商數**加**該偶數
3. **商數>12** → 減12
4. **商數≤0** → 0=丑、-1=子、-2=亥、-3=戌、-4=酉

## 三、第二章：星盤與宮盤雙盤論——解開命盤密碼

### 核心定義

| 概念 | 定義 | 功能 |
|------|------|------|
| **宮盤** | 十二宮位（命兄夫子財疾遷友官田福父）逆佈十二地支，有本命/大限/流年/流月/流日/流時盤 | 規律固定，管轄人生領域 |
| **星盤** | 紫微/天府雙星系排入十二宮形成的星曜分佈圖，有固定軌跡與間隔 | 星曜自然環境與彼此關係，含論斷哲理機密 |
| **命盤** | = 宮盤 + 星盤 | 雙盤同步運用飛宮飛星，視野不再片面 |

> **關鍵洞見**：太陰代表女人，其福德宮必為巨門（主口）→修飾言辭即成好命女人；欺負女人的天干是丁（使太陰化祿卻巨門化忌）；欺負男人的天干是庚（使太陽化祿卻天同化忌）。

### 兩種命宮：明命宮與暗命宮

| 命宮類型 | 定位 | 影響 |
|----------|------|------|
| **明命宮** | 排盤地盤命宮（本命/大限/流年/流月/流日/流時六宮） | 表層人格、顯性運勢 |
| **暗命宮·年干宮** | 生年干所在宮位（即宮干冠蓋定位宮） | 一生祿權科由此化出，**逢生年忌謂「源頭不淨」**，行好運隱禍心、環境阻礙多 |
| **暗命宮·年支宮** | 生年支所在宮位（生肖宮），辛壬年有雙暗命宮（重輕之分） | 第一流年即此宮，**流年逢生年忌→身體不健或多囉唆** |

> **實務啟示**：暗命宮讓原本純粹的殺破狼/機巨同梁摻合異質特性，如血型A含AO、星座含上升星座，使論命更精微。

## 八、核心觀念速查卡

| 觀念 | 一句話精華 | 實務關鍵 |
|------|------------|----------|
| **雙盤論** | 命盤=宮盤+星盤，宮管事星管性 | 同步飛宮飛星，不再片面 |
| **兩大結構** | 殺破狼=陽武主帥，機巨同梁=陰文師爺 | 陰陽互為體用，強化本體才是根本改運 |
| **明暗命宮** | 明命宮顯性，暗命宮（年干/年支）隱性 | 源頭不淨=年干宮自化忌，年支宮流年逢忌 |
| **星曜鐵關刀** | 結構→性→斷→活→化，五步到位 | 不懂星性談四化=緣木求魚 |
| **四化啟示** | 祿因忌果，權為過程，科為果，忌為因中因 | 忌入=欠債，忌衝=傷害，化忌在福德=賺錢不快樂 |
| **得運失運表** | 身體部位=宮位預警儀表板 | 部位有恙即查三盤對應宮位，按得運良方操作轉運 |
| **大限轉換** | 每限必陰陽互換，前三年適應期 | 主動配合陰陽律動，不適感非運好壞而是頻率不同步 |
