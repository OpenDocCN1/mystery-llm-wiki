# 占星全方位

鍾堅《占星全方位》為作者十五年占星研習筆記之系統化結晶，定位為「工具書」與「人格分類學」，以「自我了解」為核心主題，融合傳統命理與現代心理占星，建構「理論—技術—實戰」完整知識體系。

## 寫作緣起與三大原則

### 邁入玄祕學的緣起
作者三十歲前為傳統哲學信徒，對命理採「三不政策」。約三十六歲「太陽時期」尾聲，逢天王星、海王星進入寶瓶座，啟動靈修學習（占星、斗數、占卜、氣功、禪坐），發現「小傳統」奧義與「大傳統」哲學同體太極，莎比恩寓言詩「印度瑜珈師顯示自己的治癒力」恰應驗人生轉折。

### 寫作三大原則
1. **簡要化**：拒絕商業拖長、故弄玄虛，囊括大量原理技法於一冊，行文精簡扼要。
2. **學術化**：採學術論文態度，堅持占星為完備成熟學問系統，不矮化為流行文化。
3. **深刻化**：緊扣「自我了解、分析人性、靈性進化」核心主題，避免博而不精。

## 核心主題：自我了解

> 「認識你自己！」——希臘德爾菲阿波羅神殿銘文

占星學主題為「自我了解」而非「預測吉凶」。生命無高低順逆吉凶之分，僅型態不同的人生脈絡。出生星圖揭示天生特質，後天管束傷害致內在小孩受困，占星協助尋找、喚醒、治療內在受傷小孩。採「雙管齊下」途徑：**知識經驗** + **直觀想像** = 領悟占星隱喻的基本配備。

## 五術定位與占星學

中國文化分「大傳統」（經史子集）與「小傳統」（**山、醫、命、卜、相** 五術）。五術共同主題為「氣化論/磁場論」，占星屬「命」術。

| 術別 | 定位與功能 | 核心意涵 |
|------|------------|----------|
| **山** | 深山練氣養生修道 | 身法（動氣功/導引）、心法（禪坐/覺知）、身心合修 |
| **醫** | 對治身心疾病，護持修行 | 天（順天道養生）、地（護色身物質基礎）、人（由病入道靈性成長） |
| **命** | **預知人生吉凶順逆時機，趨吉避凶，穩健生涯規劃** | 外：星辰磁場影響人體磁場（天命之謂性）；內：生命系統對上呼應星辰、對下生行為種子 |
| **卜** | 針對特定時空一事一占，研判氣場生滅變化 | 變：問進退不問吉凶；不變：從變化中領悟實踐智慧 |
| **相** | 氣場具象化現象研究（面相/掌相/宅相/墓相） | 先天：氣場性格具象化；後天：相由心生，先天命定+後天氣質轉變 |

## 命理三大原理

### 磁場論/氣化論
- **受胎階段**：不同磁場尋波頻相合母體受胎（因果輪迴律）。
- **出世時刻**：嬰兒出生剎那，成熟中樞神經（接收器）接收宇宙整體能場，注入不重複能量模式 → 大宇宙影響小宇宙。早產兒接收器未就緒故算命不準。
- **公式**：受胎階段 + 出世時刻氣場變化 = 命運（展現於命盤/出生星圖）。

### 統計學
先民觀察積存「出生時地與性格表現關連性」龐大數據，建構統計科學。愈後代著作愈優（資料愈充分），屬集體創作，具濃厚科學性格。

### 德行論
《尚書·洪範》標準：卜者推命者擇三賢士，少數服從多數，先謀心、謀卿士、謀庶人、最後謀卜筮。德業皆備的諮商師具備更高段精準分析力。

## 心氣境業圖與人性三元論

### 心氣境業四層結構
- **心**（根源/良知/佛性）↓ 隱顯問題 ↓ 超越因果
- **氣**（工具/性情性格）↓ 順逆問題 ↓ 前世果 + 今世因 = **命**（主體性）
- **境**（後天環境/別業）+ **業**（共業）↓ 善惡分別 ↓ 果/因 = **運**（客觀化）

> **命** = 心 + 氣（先天，占星分析準確率 95%+）  
> **運** = 境 + 業（後天，命因運果，占星分析準確率 75%+，算至共業始模糊）

### 人性三元論
| 層面 | 性質 | 代表說法 | 走向 |
|------|------|----------|------|
| **心（性）** | 先天/善 | 孟子性善論 | 心性為主、氣質為用、氣為心役 → 順成善業/德（得） |
| **氣** | 先天/中性可善可惡 | 宋明理學變化氣質 | 心性陷落、氣質僵化、氣掩心性 → 逆向惡業/失（落） |
| **境、業** | 後天/順善逆惡 | 荀子性惡論 |  |

## 生命三機制與行星對應

每張出生星圖隱含三層機制，構成生命曼陀羅：

| 機制 | 內涵 | 對應行星 | 對應星座宮位傾向 |
|------|------|----------|------------------|
| **靈性機制** | 頓法，直接回歸靈性良知透現 | 天王星、海王星、冥王星 | 後段星座宮位（雙魚/十二宮）傾向 |
| **群性機制** | 漸教，面對了解轉化超越集體潛意識/輪迴/民族性/家風 | 木星、土星 | 中段星座宮位過渡 |
| **個性機制** | 本能、個性、內在心理 | 太陽、月亮、水星、金星、火星 | 前段星座宮位（白羊/一宮）傾向 |

學習占星不僅了解個性，更要融入群性互動，**喚醒終極靈性**。

## 陰陽中道觀與三類占星學

### 陰陽中道結構
- **陽路（自力）**：禪坐/靜心/冥想/煉氣 → 心性覺醒（心性論），過陽生專制/自我膨脹。
- **陰路（他力）**：適度借助外力 → 天人感應（天道論），過陰生迷信/宿命論。
- **中道**：平衡點。健康占星屬**陰路平衡工具**。

### 三類占星學定位
| 類別 | 尺碼 | 成熟度 | 說明 |
|------|------|--------|------|
| **個人占星學** | 太陽系 | **最成熟豐富** | 為一個人算命，本書介紹核心技法 |
| **軍國占星學** | 太陽系 | 歷史最久 | 為群體/國家算命（如天王入寶瓶座引發時代變局、大十字星象對應九二一地震） |
| **宇宙占星學** | 恆星 | 尚未成熟 | 為地球算命（如 1987A 超新星微中子穿透地球、霍皮族藍星預言） |

## 改命轉運觀

- **運能否轉？** 視命能否改。命可改但非朝夕之功，**基礎在修養**。
- **知命（自我了解） → 復命（修心養性）**：占星最大功能在自我了解，愈了解愈掌握自己，吸收力拋擲力愈強，靈性成長可能性愈大。
- **深層機制**：命理為能量層次語言，能量運轉源於心神（「相由心生、萬法心造」，苦難皆自我懲罰）。深層知命 = 連接 **知識語言 + 能量語言 + 心靈語言**。
- **終極目的**：靈性全然解放與自由，基礎即自我了解礎石。

## 出生星圖製作四大注意事項

1. **準確出生時間**：精確至「分」，誤差 ≤15 分佳，>30 分宮位月亮相位模糊，影響推運精準度。僅知日期只能看行星星座。
2. **日光節約/夏令時間**：台灣歷年實施時程表需查核，輸入軟體時勾選 Daylight 或出生時間減一小時。
3. **準確經緯度**：台灣為東經 E、北緯 N，誤輸 W（西經）星圖顛倒。參考書附重要城市經緯度表。
4. **正確時區**：全球以格林威治零時區為準，台灣/大陸/港/星/菲屬東八區，**輸入 -8.0**（負號不可少）。

## 第七章 天宮圖中的其他特殊點和星體

本章介紹除星座、後天宮、行星外的補充要素，包含月交點、小行星、假設行星、中點/映點/反映點、阿拉伯點（希臘樂透）、恆星，以充分掌握天宮圖每一要素。

### 月亮交點、小行星、假設行星

#### 月亮交點
月亮交點指北交點（上升交點，近北極）與南交點（下降交點，近南極），非實際星體，而是月球白道面（傾角約 5.9°）與黃道面之兩交點，永相對 180°。因日蝕、月蝕發生時太陽、地球、月交點連成一直線，自古形成「集體無意識」深刻記憶，故具神秘意涵。

- **北交點**：白道面由黃道下向上交叉。代表過去靈魂旅程進入新意識領域，**需開發的心理意識**（星座）與**生活領域**（宮位）。
- **南交點**：白道面由黃道上向下交叉。代表前世/業力/無意識習性，**應揚棄的心理意識**（星座）與**需調整的生活領域**（宮位）。
- **論斷重心**：星座較宮位為重。
- **平均交點 vs 真交點**：差距不超 1°45'。
- **運行**：逆黃道順時針，週期約 18.6 年，財務金融占星中佔重要地位。

#### 小行星
位於火木軌道帶，1801-1807 年發現前四顆：穀神星、維斯塔、帕拉斯、朱諾。早期被忽視（星體太小），1970 年代 Zipporah Dobyns 博士等編纂星曆表始受重視。現已超過 4000 顆。

- **凱龍星**：1977 年發現，軌道介土星天王星間。對應人類尋求治療精神創傷之主題，象徵「隱藏傷痕/心理創傷/受傷療癒者」。準驗性高，建議使用。重點觀察落宮位及與其成相位之行星（主相位為主）。

#### 假設行星
天文學未發現，占星家假設使用。始於德國阿爾弗雷德·威特創立漢堡學派。包含 Cupido, Hades, Zeus, Kronos, Apollon, Admetos, Vulcanus, Poseidon 等，以及後繼者提出的 Transpluto, Lilith 等。作者認為「已發現的小行星大多不被使用，更何況假設行星」，僅供知悉，不鼓勵使用。

### 點的應用：中點、映點、反映點

#### 行星圖形與中點
漢堡學派核心公式 **A + B - C = D**（行星圖形）。簡化為 **A + B - C = C** 即 **1/2 (A + B) = C**，形成**中點**理論（宇宙生物學派艾伯特家族發揚）。
- 中點代表兩星體能量對稱匯聚之敏感點。
- 若中點會合其他行星、敏感點（ASC、MC、月交點等），訊息更強烈。
- 計算以白羊 0° 為 0° 黃道經度換算（金牛 0°=30°，雙子 0°=60°...雙魚 0°=330°）。

#### 映點與反映點
源於夏至（巨蟹 0°）冬至（摩羯 0°）轉捩點，符合中國易經「夏至一陰生、冬至一陽生」陰陽消長理念。

- **映點**：某行星距至點（夏至/冬至）若干度，另一邊同距離之對應點。
  - 星座對應固定：摩羯↔射手、水瓶↔天蠍、雙魚↔天秤、白羊↔處女、金牛↔獅子、雙子↔巨蟹。
  - 度數對照表：1°=29°、2°=28°...15°=15°...30°=30°；分數：1'=59'...30'=30'。
  - 性質：類 **60° 次吉調和相位**。吉星會合帶來吉象轉捩；凶星會合增強凶象轉捩。原理：赤緯平行。
- **反映點**：映點之對沖點（+180°）。
  - 性質：類 **90° 刑或 180° 沖凶相**。吉星減吉；凶星增凶。原理：赤緯反平行。

**案例：希特勒** 土星獅子 13°27' 升中天，火星/金星金牛 16° 互為映點，加深火土凶惡。金星為命主星入廟卻捲入映點，火土皆入陷宮。  
**案例：1999/08/11 日蝕盤** 天王星水瓶 14°40'、火星天蠍 14°40' 互為映點，土星金牛 16°52' 為天王星反映點，三大凶星形成大十字，對應全球連續大地震（含台灣 921）。集集鎮盤冥王星合中天。  
**案例：李遠哲** 木星射手 27°13'、金星摩羯 3°29' 互為映點（兩吉星），木星入廟三合命度，金星三合天王星，對應諾貝爾獎榮譽。

### 阿拉伯點 / 希臘樂透

源於希臘托勒密《四書》及瓦倫斯，阿拉伯人繼承發展，故誤稱阿拉伯點。公式結構 **ASC + 行星 - 行星 = 敏感點**，屬漢堡學派公式特例。安東尼·路易士整理達 130 種。核心理念：行星象徵出生時世界環境，ASC 代表命主意識平面，兩者結合成命盤敏感點。

#### 核心四點與瓦倫斯尊貴判斷法

| 點位 | 白天盤公式 | 夜間盤公式 | 核心意涵 |
|------|------------|------------|----------|
| **幸運點 ⊗** | ASC + ☽ - ☉ | ASC + ☉ - ☽ | 實體身體、物質、金錢財富。Paul of Alexandria：象徵身體一切事、貫穿人生、變為財富聲望恩典。 |
| **精神點 Ψ** | ASC + ☉ - ☽ | ASC + ☽ - ☉ | 精神、心靈、宗教、信心、聲望、行為模仿。又稱太陽點。 |
| **基礎點 β** | ASC + ⊗ - Ψ (取 ☉-☽ 最短距) | 同 | 落地平線下，如基礎支撐。 |

**瓦倫斯五大尊貴指示**（採整星座宮位制 Whole Sign Houses，參酌傳統主星與現代行星）：

### 恆星 / 固定星

古今中西皆重恆星。中國星官系統（三垣二十八宿）早於先秦，漢司馬遷《史記·天官書》有載。西方 1923 年國際天文聯會統一命名，1930 年劍橋《科學的星座區劃整理》，民國 26 年中西星名對照表出版。

**應用原則**：
- 重點觀察 **ASC、MC、太陽、月亮** 與重要恆星 **0° 會合**（恆星無射線，不論 60/90/120/180 相）。
- 可進而查水金火木土天海冥、幸運點等。
- **歲差校正**：表列黃道經度以 **公元 2000 年** 為準，歲差每年約 50.2893 秒，須換算至事發年度黃經。
- **判斷原則**：容許度 1° 內會合為主。
  1. 恆星在 ASC/MC → 極大影響。
  2. 凶星恆星會合吉星（木/金） → 不竊取吉意，但有修飾效果。
  3. 吉星恆星會合凶星（土/火） → 不改變凶意，但調整凶象。
  4. 吉會吉 → 加乘正面；凶會凶 → 加乘負面。
- **恆星性質**：類比行星（如織女星 Vega 具金/水/海性質：藝術、敏感、想像、科學自我表現）。

#### 三大恆星缺點度數 / 星雲盲點
古占星家指出三度數易導致目盲，源自 1880 年左右恆星黃經：**金牛 29°（昴宿星團）、獅子 6°（鬼宿三）、射手 8°（心宿二）**。因歲差已移位，**現代必須以歲差較正後之恆星位置為準**，不可死守固定度數。

## 第八章 行星在黃道十二星座意義

了解四種純質料（寒熱乾濕）、四大元素、先天黃道十二宮、後天十二宮及行星原理後，可討論基本要素互動現象：行星落星座、行星落宮、行星相位。本章著重 **行星落星座** 詮釋。

### 詮釋方法論：五大邏輯推演

本書融合古典與現代技巧，批評現代心理占星僅著墨心理行為、忽略純質料邏輯、吉凶象單以調和/不調和相位論、無視晝夜盤差異。讀者應掌握以下五點邏輯：

1. **心理機制層面**：黃道十二宮提供心理機制。行星受星座制約，能量呈現星座特質，構成人格一部分。  
   *例：火星（貫注精力、直接）落金牛（穩定、緩慢、韌性）→ 行動緩慢、不激進。*

2. **純質料協調性**：行星本身純質料與星座純質料協調與否。吉星（金/木）難調和星座 → 吉象銳減、現負面。  
   *例：金星（濕冷）落白羊（熱乾）對抵 → 和諧愛情難持久、易現色慾性慾。*  
   （四大元素由純質料構成，故隱含行星落四元素關係。）

3. **四正特性（三方/四分）**：細分同元素內差異。  
   *例：木星（成長擴展）落水象三宮：*  
   - 巨蟹（基本）：強化主動照顧、溫情籠絡。  
   - 天蠍（固定）：強化集中執著、信仰堅持。  
   - 雙魚（變動）：強化廣泛變動、憐憫感受。

4. **定位星制約**：現代易混淆星座=主星=宮位同族關係，且三王星主星有爭議，以定位星詮釋須小心。

5. **晝夜盤區分（教派/區分內外）**：白天盤行星適於白天盤，夜間盤行星適於夜間盤。涉及區分內/外時，吉凶象顯現差異。  
   *本書採傳統七顆行星詮釋；三王星參考 Project Hindsight 及 Curtis Manwaring 著作，不在此詳述。羅睺/計都涉前世業力，僅供參酌。*

**吉凶象綜合判斷**：按行星**必然尊貴/無力**（入廟/旺/陷/落）+ **來自其他行星之刑剋**（合/刑/沖）+ **晝夜盤區分內外** 綜合說明。無法全面加入偶然尊貴/無力。行星落星座是基本元素進一步互動，詮釋天宮圖的基石。
