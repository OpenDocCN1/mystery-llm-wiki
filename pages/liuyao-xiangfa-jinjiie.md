## 书籍概况

- **书名**：《六爻象法进阶》（上册）
- **作者**：青岚（蒋岚）
- **机构**：知微易学会
- **定位**：六爻预测象法进阶教材，承接《[[liuyao-jichu-rumen-qinglan|六爻基础入门]]》与《[[liuyao-lifa-jinjiie-qinglan|六爻理法进阶]]》
- **核心体系**：
  1. **六神象法**——青龙、朱雀、勾陈、螣蛇、白虎、玄武六神在卦象中的具体取象规则与案例验证
  2. **组合象法**——爻位、六亲、六神、卦宫、神煞等多维信息的组合拆解与综合判读
  3. **长生十二宫象法**——以长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养十二状态为坐标的旺衰趋势与象意推演
- **特色**：以大量实战卦例（书稿约 21 万字）为主线，重点论述日常预测高频用象，难点专题（客观取用法、六亲转换原理、一爻多象法、六害用法等）另置《六爻实战技法》展开。

## 序言要旨：象法怎么学

作者在序言中提出四点学习建议，形成本书的方法论底色：

1. **找准方向**——区分江湖派、传统派（理象结合，本书主攻）、象数派、新派四大取象流派，按自身条件择一深入。
2. **围绕核心推理**——以卦主所测之事为唯一核心，先解主题再补细节，避免“眉毛胡子一把抓”。
3. **勤于实践总结**——书本理论必经实战验证、归纳吸收，方成己用；以“客观取用法”为例，作者曾专门收集近百代占卦例自证总结。
4. **提升阅历、长久坚持**——象法非速成，需多年积累与社会阅历支撑；如断姻缘先成“情感高手”，方能精准读象。

> “功夫在卦外，不要死钻理论，其他方面都要一并学习提高。” —— 青岚课堂语录

## 第一章 六神象法：青龙详解

本书第一章系统梳理六神中出现频率最高、应用最广的 **青龙** 象意，按八大类场景展开，配以 30 余枚实战卦例验证。

### 吉庆喜庆之象（卦象吉时）
- **关键词**：结婚、生子、升官、发财、得工作、得奖、失物寻获、心愿遂意
- **判例精选**：
  - 测进保健院工作：官鬼持世临青龙，旺相吉利 → 录取（《[[liuyao-jichu-rumen-qinglan|六爻基础入门]]》同类取用法对照）
  - 测能否结婚：妻财持世临青龙，世应相合 → 结婚并因怀孕
  - 测儿子比赛：用神父母亥水特殊旺相临青龙 → 获二等奖，家长满意
  - 测钱包失而复得：子孙持世临青龙，日冲动爻生世 → 一个多月后在保卫科寻回
  - 测作品入选：应爻子孙临青龙发动克世爻官鬼 → 忧虑消除，作品入选
  - 测涨工资：子孙独发化财临青龙 → 涨 500 元
  - 测借款归还：妻财独发克世临青龙 → 分两次还清

### 乐极生悲、贪图享乐之象（卦象凶时）
- **关键词**：酗酒、暴饮暴食、沉迷游戏、淋雨、落水、溺水、一夜情染病
- **判例精选**：
  - 测一夜情怀疑性病：兄弟寅木克世临青龙 → 乐极生悲，实为传染性软疣非性病
  - 测母亲健康：父母辰土临青龙发动化回头克 → 胃口不佳、喝喜酒摔伤（乐极生悲）
  - 测前程行业：应爻子孙临青龙化妻财申金临驿马 → 旅游行业（娱乐、在路跑）
  - 测儿子学业：子孙酉金过旺临青龙 → 贪玩沉迷手机被劝退
  - 测母亲走失/亲叔打鱼未归：父母伏藏青龙之下，月建冲破、子孙冲伏神 → 均验证溺亡（青龙指水域）

### 外形判断：漂亮、高大、气质佳
- **组合规则**：
  - 青龙 + 寅卯木 → 高挑苗条
  - 青龙 + 亥子水 → 水灵聪明
  - 青龙 + 巳午火 → 热情青春
  - 青龙 + 土爻 → 沉稳御姐/帅哥型
  - 旺相 + 桃花 + 青龙 → 吸引力极强
- **判例精选**：
  - 相亲女：妻财卯木旺相临桃花、应爻临青龙、白虎主白净 → 高挑大美女，但应爻旬空不诚心
  - 女同复合：妻财卯木临青龙发动化退神 → 复合，女友长相漂亮身材好
  - 抢男友：初爻兄弟卯木临青龙冲伏藏官鬼 → 长相极好的女性插足

### “高大上”、理想化、空想之象
- **正面**：体面工作、外形精巧、目标远大
- **负面**：内外不一、浮于表面、眼高手低、人浮于事
- **判例精选**：
  - 换工作：世爻官鬼临青龙入墓、妻财被合 → 现工作体面，仅因待遇一般一时迷茫
  - 测新公司：元神官鬼旺相临青龙旬空化退 → 表面文艺高大上，内部混乱不去
  - 进高价货：应爻妻财临青龙、世爻元神动化回头克 → 期望高大上，利润一般放弃
  - 投资财运：应爻临青龙入日墓 → 传销项目假象，破财
  - 找人拿货：世爻临青龙化父母回头生 → 自信满满看好货，长期必亏
  - 去南京工作：应爻父母旺相、元神过旺临青龙 → 过于理想化，半年一事无成
  - 测财运：世爻上爻临青龙休囚 → 心有大目标但能力行动力不足，短期难变
  - 开咖啡店：世爻临青龙衰败化退神 → 空想而已，未开店
  - 进修康复科：应爻临青龙发动生世过旺反衰 → 想当然，院长不同意
  - 买房：世爻过旺临青龙 → 眼光过高未看上，最终买别处
  - 换工作回内地：元神午火临青龙旬空化进神 → 期待高、短期不如意、长期有前途

### 性格：正直、清高、自强不息、不屑求人
- **正面**：有骨气、作风正派、不合群、全靠自己打拼
- **负面**：清高看不起人、嗤之以鼻、阴阳怪气
- **判例精选**：
  - 相亲对象：应爻官鬼临青龙旺相 → 人品正直、无父母自力更生，但卦主婚后辛苦
  - 单身测姻缘：世爻上爻临青龙 → 男孩眼光高清高，缘分差
  - 女同分手：世爻上爻临青龙冲应爻化退神 → 眼光高瞧不起对方，分手在即
  - 何时有姻缘：世爻上爻临青龙化官爻反吟 → 眼光高、接触多但反复不成

### 物品：新、正规、质量好、保养好、正式缘分/原配
- **判例精选**：
  - 相机丢失：妻财持世临青龙、伏神玄武官鬼酉金西方 → 新相机保养好，西方被拿走，报警无用
  - 二手房：应爻父母临青龙月破 → 房子新但质量装修一般，中介谈不成
  - 投资新店：应爻父母临青龙、子孙伏藏三刑 → 新店有股权纠纷/官非，建议不投（青龙兼取酒水饮食）

### 官方、权势、贵人、稳定正式工作
- **适用对象**：公务员、事业单位、国企、银行、教师、大型知名企业、世界 500 强
- **判例精选**：
  - 感情坚持/放弃：应爻官鬼临青龙月建冲世 → 有钱有势之人抢走女友（非必为官员）
  - 人身安全：世爻动化官鬼回头克临青龙、三合局成群 → 官方处罚/聚众斗殴，经劝说化解
  - 承兑丢失：五爻官鬼临青龙临日辰发动生应爻 → 承兑在老板处，被罚款（五爻君位=领导）
  - 经济官司：月建官鬼临青龙冲世、伏神父母解破 → 官方表面不利实则助世，操作得当全赢
  - 租写字楼开卦馆：应爻官鬼临青龙三合局冲世 → 官方找麻烦，按卦象规避两年圆满撤离
  - 老公出走：用神寅木旬空入墓临腾蛇、日冲青龙申金五爻道路 → 抑郁欲自杀，遇贵人带回

### 卦象不吉时：好色、花心、私生活混乱
- **判例精选**：
  - 英国帅哥：应爻官鬼临青龙旺相、日月妻财相合、动爻合兄弟 → 私生活极度混乱、情场老手
  - 前男友复合：官鬼临青龙旬空发动合妻财亥水、伏神父母巳火 → 花心、隐婚、假结婚欺骗他人
  - 抢前女友：兄弟戌土临青龙月建克合官鬼 → 前女友插足不成退出，卦主强势缘分仍难久
  - 年底分手：官鬼临青龙发动化妻财回头生父母 → 花心与他女在一起，丑月分手
  - 暖男渣男：应爻官鬼临青龙旺相、妻财发动生官化父母 → 与已婚女性有染，后遇更好对象
  - 多女性并存：官鬼临青龙动合日月妻财、动合上爻兄弟 → 同时与多女性交往，卦主仅其一

## 学习路径建议

1. **先读基础** → 《[[liuyao-jichu-rumen-qinglan|六爻基础入门]]》建立八卦纳甲、六亲世应、起卦装卦基本功
2. **练理法** → 《[[liuyao-lifa-jinjiie-qinglan|六爻理法进阶]]》掌握月建日辰冲爻、暗动飞伏、旬空月破等动静判断铁律
3. **进象法** → 本书《六爻象法进阶》三大体系（六神、组合、长生十二宫）配合 30+ 实战卦例内化取象思维
4. **攻专题** → 《六爻实战技法》（未出）解决客观取用、六亲转换、一爻多象、六害等疑难
5. **横向对照** → 结合上表九大体系页面，对比不同派别取用神、断吉凶、定应期差异，形成自洽体系

> “实践是检验真理的唯一标准，只有经过诸多实战卦例验证的卦理才是自己的卦理，才能形成自己的理论体系。” —— 青岚
