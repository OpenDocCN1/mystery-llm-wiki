## 理论框架总览

### 占星学的本质：灵魂与高层自我的「密码系统」

> 「占星学系统是人类最高创造者直接给予的礼物，它允许人在所有层面同时发展——不仅仅是显现个性的物质身体层面，也在更高的精神层面和星芒体层面，及更在那之上的层面。」（希拉里翁语录）

- **指导灵与守护者**根据灵魂选定的课题，安排最匹配的出生时间 → **行星配置即密码**。
- **太阳、月亮、行星落星座**不是静态性格标签，而是**跨世业力的动态投射**。
- **三大层面同步运作**：物质/人格层面 → 精神/心智层面 → 灵魂/高层自我层面。

### 核心区别：礼物 vs. 课题 vs. 过滤机制

| 概念 | 说明 |
|------|------|
| **礼物** | 前世通过特定行为（英勇、牺牲、服务、学习等）赢得的能量连接，自动接入高层能量源。 |
| **课题** | 每份礼物附带的责任：学会建设性地运用能量，避免消极极端（攻击、压抑、逃避、理想化等）。 |
| **人格过滤** | 环境、情结、早年经历会「模糊化」太阳礼物；月亮反映早年家庭环境直接塑造的特质；水金火以「叠加作用」在基础性格上增添课题。 |

### 相位的业力含义

| 相位 | 角度 | 业力含义 |
|------|------|----------|
| **合相** | 0° | 能量融合，和谐与否视行星本质（如土金合相=爱受限，木金合相=爱扩张）。 |
| **六合** | 60° | 积极机会，两行星特质易整合。 |
| **刑相** | 90° | 困难课题，特质冲突阻碍和谐呈现，需有意识整合。 |
| **三合** | 120° | 最有利，特质互增、协同呈现。 |
| **对冲** | 180° | 两极拉扯，需牺牲一方或有意识平衡。 |

> **实操提示**：本书仅详述上述五大相位；实际排盘请结合 `[[zhanxing-tuxing-xiangwei-quanshu]]` 图形相位全书九步优先分析法。
