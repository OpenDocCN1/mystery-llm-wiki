# 马志川《六爻实战点窍》全书架构总览

## 书籍定位与作者心路
作者马志川研易三十余年，主张学易如作战，“十个碉堡要有所选择，各个击破”，集中兵力专攻《六爻》配合《玄空风水》《姓名学》。全书分两大部分：第1-9章为**应知启蒙教程**，供初学者入门；第10章起为**分类预测实战**，由初级进阶至高深层次，均为作者多年实践真实记载。

> **交叉引用**：同类六爻体系综述可参阅 [[liuyao-bagua-quanxi-lun]]、[[liuyao-shizhan-da-quan]]、[[liuyao-sanda-jifa]]、[[liuyao-yinyuan-yuce]]、[[liuyao-yinguo]] 等页面。

## 第一章 应知启蒙：八卦与河洛基础

### 八卦类象与先后天体系
- **先天八卦**（伏羲）：乾南、坤北、坎西、离东、震东北、巽西南、艮西北、兑东南。序数：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。
- **后天八卦**（文王）：坎一、坤二、震三、巽四、中五、乾六、兑七、艮八、离九。乾坤为父母，震坎艮巽离兑为六子。
- **八卦口诀**：乾三连、坤六断、震仰盂、艮覆碗、离中虚、坎中满、兑上缺、巽下断。

### 河图洛书与五行生数
- **河图**：天一地二至天九地十，五十五数生成五行（一六水、二七火、三八木、四九金、五十土）。
- **洛书**：戴九履一、左三右七、二四为肩、六八为足，与后天八卦方位严丝合缝。

### 核心术语体系（装卦必备）
| 术语 | 定义 |
|------|------|
| **主卦/变卦/互卦** | 现时之象 / 最终变化之象 / 中间过程之象 |
| **六亲** | 父母、兄弟、子孙、妻财、官鬼——以五行生克拟人法提取用神 |
| **纳干/纳支** | 卦配十天干、爻配十二地支 |
| **六神** | 青龙、朱雀、勾陈、腾蛇、白虎、玄武——附合断验 |
| **用神/原神/忌神/仇神** | 所测事代表 / 生用神者 / 克用神者 / 生忌神者 |
| **进神/退神/飞神/伏神** | 动爻化出之十二长生状态与隐伏取用法则 |
| **空亡/月破/日破/反吟/伏吟** | 特殊吉凶判断节点 |

## 第二章 基础知识：干支与六十甲子

### 十天干
- **五行属性**：甲乙木、丙丁火、戊己土、庚辛金、壬癸水（各分阴阳）。
- **人体/脏腑对应**：甲头乙项丙肩丁胸戊肚己脐腹，庚腰辛肋壬股癸四肢；甲胆乙肝丙小肠丁心戊胃己脾，庚大肠辛肺壬膀胱癸肾心包。
- **生克规律**：木生火、火生土、土生金、金生水、水生木；木克土、土克水、水克火、火克金、金克木。

### 十二地支
- **阴阳五行**：子午寅申辰戌为阳，丑未卯酉巳亥为阴。
- **六合/三合/六冲/三刑/六害/四废** 全表速查。
- **人体/脏腑/方位/时辰/月份/旺相休囚** 完整对照。

### 六十甲子与纪年月日时法
- **年上起月法**、**日上起时法** 歌诀与速查表。
- **节气划分**：以“节”为界定月支，非农历初一。

## 第四章 起卦方法：多元取象同源
1. **摇卦法**（三枚铜钱，六遍记爻，老阴×、老阳○、少阴--、少阳—）
2. **年月日时法**（年支数+月建+日数÷8取上卦；+时辰数÷8取下卦；总和÷6取动爻）
3. **报数法**（一数/两数/三数/四数，依先天/后天序数组卦定动爻）
4. **手机号码法**（前五位定上卦、后六位定下卦、全号和定动爻）
5. 其它：字数、声色、方位、生肖、姓名、太玄数等。

> **核心原则**：无论何法，**心诚则灵，信息同步**。

## 第五章 如何装卦：从卦象到信息模型

### 纳支规律
- **阳卦**(乾坎艮震)纳阳支(子寅辰午申戌)；**阴卦**(坤兑离巽)纳阴支(未巳卯丑亥酉)。
- 皆从**初爻向上**顺排，六十四卦一律遵循八宫首卦规律。

### 定世应位（两大速算法）
1. **阴阳互变法**：首卦上六世、三应；初变初世四应、二变二世五应……至五变五世二应；游魂四世初应、归魂三世上六应。
2. **天人地同异法**：
   - 天(三、上)同→二世；异→五世
   - 地(初、四)同→四世；异→初世
   - 人(二、五)同→游魂四世；异→归魂三世
   - 本宫首卦六世三应；归魂内卦定宫；一二三六世外卦定宫；四世游魂内变更。

### 确定六亲
- 以**主卦宫五行**为“我”，生我=父母、比和=兄弟、我生=子孙、我克=妻财、克我=官鬼。
- **主、互、变卦六亲皆依主卦宫属定**，不随变卦改换。

### 爻配六神
- 以**日干**起初爻顺排：甲乙日青龙起、丙丁日朱雀起、戊日勾陈起、己日腾蛇起、庚辛日白虎起、壬癸日玄武起。
- 六神性情：青龙吉/朱雀诈/勾陈阴/腾蛇惊/白虎血/玄武盗淫。

### 标明空亡
- 六甲旬空口诀：甲子旬戌亥、甲戌旬申酉、甲申旬午未、甲午旬辰巳、甲辰旬寅卯、甲寅旬子丑。
- **旺不空、动不空、有生扶不空、月破真空**。

## 第七章 断卦程序：内外条件与层次制约

### 标准断卦流程
1. **排全盘**：主/互/变卦、纳干支、六亲、世应、六神、空亡、标明月日年时干支。
2. **提用神**：依测事类选定用神、原神、忌神、仇神所在爻位。
3. **内部生克**：观察用原忌仇在卦中之动静、变化、合冲刑害、进退吟、飞伏藏。
4. **外部制约**：引入**月建、日辰、太岁、时辰**为第一层次爻，决断旺衰生克权力。
5. **层次制约**（核心模型）：
   - **第一层次**：年月日时——旺衰来源，代表上级、大环境、时机。
   - **第二层次**：变爻——能生克制化动爻。
   - **第三层次**：动爻——能生克合制静爻、同层爻、伏藏爻。
   - **第四层次**：静爻、伏藏爻——受制于上三层。
6. **现在时与进行时**：以起卦月日为“现在”，顺推后续月日为“进行时”，动态追踪吉凶应期。

### 经典案例逻辑
- **王某谈生意**：《火山旅》六合静卦，世爻辰土受月日卯木克制衰极，原神午火虽旺临兄弟劫财，忌神卯木当令旺极，应爻酉金虽两现得生但原神受克且日破月破 → **双方心有余力不足，不成**。
- **苏父病重**：《风雷益》初爻父母子水用神临月破日合休囚，忌神未土动化午火回头生、得月日生扶、联合辰戌勾陈土克用神 → **脾胃之疾，辰日冲墓并扶忌神制用神，果应辰日辰时病故**。
- **科长升职**：《水风井》父母亥水用神得月建申金生、日辰亥水帮、动爻酉金生，忌神丑土动化退入三合金局反生原神 → **内外条件皆利用神，酉月原神上升第一层次应期升职**。

## 第八章 确定应期：预测师水平的试金石

### 生用神/世爻应期（吉事）
1. 用神/世爻临月日旺相、六神吉 → **值月值日应**。
2. 用神/世爻静不临月日、不受克 → **待用神/世爻临值或原神临值应**。
3. 原神变爻回头生但被月日制 → **待原神受生或当值应**。
4. 原神入月/日墓 → **待冲墓之日月应**。
5. 用神旺相入墓 → **待出月出日不受克应**。
6. 原神旺相不发动 → **待后临月日应**。

### 克用神/世爻应期（凶事/特例）
- 忌神临月日旺动 → **当月当日应**；忌神静同层 → **待仇神生忌神月日应**；忌神化进 → **以变爻定应期**；忌神化退逢冲 → **以冲变爻之神定应期**；测凶危忌神宜入库化退死绝。

### 旬空应期
- 测吉事用神/世爻逢空 → **出旬填实之年月日时应**；动空不空看原神；空逢合待冲合；空逢克待出空或制煞；空入库待冲库。

### 逢合/冲/刑/伏神应期
- **三合/六合**：动爻/用神与月日成局 → **当月当日应**；局中被冲/有静爻/逢空/入库/化绝 → **待静爻临值/出空/冲库/生旺应**。
- **六合**：用神发动后逢合支神日 → **该日应**。
- **冲**：吉事被冲凶、凶事被冲吉；用神逢冲后逢合日应；用神逢空被冲填实日应。
- **刑**：用神逢刑临值日应；三刑有空待出空、有墓待冲墓、有休囚待生旺。
- **伏神**：有用伏神临月日生扶、得飞神生扶、制克忌神飞神时应；被飞神克待飞神月破日破合空墓绝回头克时应。

### 外应
- 现场人事物象征信息，凭灵感捕捉悟性断卦，因人而异，不作详述。

## 第九章 五行生克：动态推演的底层算法

### 生克表现形式
| 类别 | 形式 | 吉凶导向 |
|------|------|----------|
| **相生** | 月建生、日辰生、动爻生、动化回头生 | 用神原神宜逢生；忌神仇神不宜逢生 |
| **相克** | 月建克、日辰克、动爻克、动化回头克 | 用神原神不宜受克；忌神仇神受克反吉 |
| **克处逢生** | 用神受克处得他处生扶（如月克日生、动爻生） | **转危为安、走出绝境** 关键模型 |

### 明动与暗动
- **明动**：卦中显见发动爻（阳○、阴×）。
- **暗动**：爻旺相静止，被日辰冲动（日冲休囚为日破）。
- **静卦**：无明动、无暗动。

### 补救月破
- **不可救**：静爻月破；动爻月破再逢日辰/变爻/动爻伤克。
- **可救**：动爻月破，**无他爻制克**，且动化回头生或进神 → **出月填实旺相时应**（如周先生巳火用神亥月破，动化寅木回头生，待巳月升职验）。

### 用神原神忌神仇神通关模型
| 角色 | 旺相有力条件 | 无力/失效条件 |
|------|--------------|---------------|
| **原神** | 旺相临月日/得动爻生/动化回头进/长生帝旺/与忌神同动/旺动临空化空 | 休囚不动被克/休囚逢空破/动化退/衰绝/入墓/化绝克破散 |
| **忌神** | 旺相临月日生/动化回头进/旺动临空化空/长生帝旺/忌仇同动 | 休囚不动被克/静临空破/入墓/衰动化退/衰绝/与原神同动/化绝空克破散 |
| **通关** | 用神衰、忌神旺动克用，卦中另一五行旺动**化泄忌神且生用神** | 水克火用木、火克金用土、金克木用水、木克土用火、土克水用金 |

### 月日同权原理
- 农历360天，12月各30天，12地支轮值月建各30天；日辰地支全年轮值亦各30天 → **日月同功同权**。
- 月建掌一月之权：能扶衰抑旺、制服动变、冲飞扶伏、合则有用破则无力。
