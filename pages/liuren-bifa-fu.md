# 六壬毕法赋

《六壬毕法赋》（简称《毕法赋》）是大六壬术数体系中流传最广、实用性最强、内容最全面的传世佳作，被历代壬学界奉为圭臬。其正文仅百句七言赋文，却字字珠玑，将六壬各种课象变化尽纳其中。明代郭载騄校刊《六壬大全》第三部即为此赋，收入《四库全书》子部术数类。

> **核心定位**：六壬断验核心法则总汇，百法赋文配以白话提要、变格类格、实占课例，构建完整实战知识体系。

---

## 版本源流与著作权

- **作者**：宋代 **凌福之**（字福之，履贯未详），约生活于宋理宗宝庆年间。
- **成书缘起**：凌福之本邵彦和《大六壬口鉴》断案方法，参以心得创作百句七言赋文，融贯旧说，遂成《毕法赋》。
- **历代评价**：
  - 清代程树勋《壬学琐记》称其“因用邵彦和断案而作，而复参以心得，故其书从考验中来”，起了拨乱反正作用。
  - 《四库全书总目提要》云：“决断之幽微，可为定论。”
  - 《图解六壬大全》编者誉为“壬学史上流传最为广泛、实用性最强、内容最为全面、最受壬学界推崇的传世佳作”。

## 体系架构与内容构成

《毕法赋》全书可分为 **正文、小注、正格、变格、类格、课例** 六大组成部分：

| 组成部分 | 说明 |
|----------|------|
| **正文** | 百句七言赋文，阐述百种壬课形象格局（如“前后引从升迁吉”代表初末传夹拱干支） |
| **小注** | 紧随赋文之后，含课局结构说明、占断原则、历史典故、易卦爻辞印证 |
| **正格** | 对赋文主体演示的课体特征及实占象意的直接解释说明 |
| **变格** | 正格下分出的几种不同情况（如第二十一法“交车合”下十种变格） |
| **类格** | 与正格类似但实则不同的课格（如第二十九法“人旺弃宅格”属“眷属丰盈”类格） |
| **课例** | 每格后列举符合该课格局的实占课例并加以分析说明 |

> **卷帙结构**：
> - **卷九**《毕法赋》上：第一法至第五十法
> - **卷十**《毕法赋》下：第五十一法至第一百法
> - **卷十一**《十二宫分野》上
> - **卷十二**《十二宫分野》下

### 关键判断要素（八大基本要素）
1. **先锋（正时）**：事物发生的先兆
2. **值事（月将）**：管辖当月之事，如值月之神
3. **外事（日干）**：当事者与外界关系
4. **内事（日支）**：家宅、妻子、至亲之事
5. **发端（初传）**：事物发展的起始，用神吉凶直接影响成败
6. **移易（中传）**：事物变动的中间状态
7. **归计（末传）**：事物发展的归宿终结
8. **变体（年命）**：行年与本命，最终吉凶还看年命生克

## 学习路径建议

1. **入门基础**：先读《导读一·认识大六壬》《导读二·大六壬的基本方法》，掌握天地盘、月将、四课三传、十二天将/支神、六甲旬遁、六亲、行年年命等核心操作。
2. **百法精读**：按上述十大类主题研读《毕法赋》百法，重点掌握**正格课体特征**、**变格适用条件**、**类格区别**、**实占课例推断逻辑**。
3. **实战演练**：结合《六壬神课大全》卷三至卷八《课经》六十四课、卷九十《毕法赋》百法，进行历史名课复盘与现代案例实测。
4. **兵占专攻**：研习附录三大兵占专篇，对照《三元奇门遁甲讲义》《商战与奇门》等军事预测典籍，构建三式军事决策交叉验证体系。
5. **分野地理**：熟悉十二宫分野天文地理对应，结合《晋书·天文志》李淳风体系，用于年运、地理、风水等宏观预测。

## 版本与校勘说明

- **底本**：《四库全书》文渊阁足本十二卷《六壬大全》（明代郭载騄校、郭御青刊）。
- **点校版**：许颐平主编、程子和点校《四库全书白话图解·图解六壬大全》第三部·毕法赋（2009年）。
- **主要校勘点**：
  1. 天乙贵人昼夜顺逆取法，书中仅载先天贵人图而未用，乾隆御批指出“未免失之舛漏”。
  2. 十二宫分野多拘牵旧说，未能订正（如福建划入吴越分野系宋明后事）。
  3. 兵占赋辞中“六辛日以寅为游都”实为举例讹误（寅为木，辛金游都应在申酉方）。
  4. 部分课例天将排布与干支不符，需结合《心镜》《观月》《括囊赋》等并行校勘。

## 结语

《六壬毕法赋》以百法赋文为纲，变格类格为目，实占课例为证，构建了大六壬断验最完备的**格局识别—类神取象—旺衰生克—应期定断**四维实战体系。其核心价值在于：
1. **格局分类穷尽**——覆盖仕途、财物、婚姻、胎孕、疾病、讼狱、人宅、合作、军事等全谱系
2. **变格类格严密**——同一赋文下区分正格/变格/类格，避免一例套用
3. **类神象意具体**——十二天将/支神、六亲、胎财生死气、德禄刑害等象意系统细致
4. **实战导向明确**——每法附课例，白话提要直指断语，便于学习者对号入座

> **研习箴言**：“六壬变化多端，课式近三千万，其断法十分凌乱。要理解毕法要义，难度非常大，要将其实际运用到占课推断之中难度更大。唯有循序渐进，真正弄懂九个基本推算形式及每个式子的具体要求规则，方能得其门而入。”—— 《图解六壬大全》编者谨识
