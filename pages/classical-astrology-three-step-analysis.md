## 概述

本頁面系統化整理希斯莉（Cecily）著作《占星占心》「前言」章節所提出的**古典占星簡易分析三步驟**，並結合書中多個實戰案例（F小姐、B小姐、Q先生、Z小姐、E小姐、J小姐、O先生等），詳細闡釋**命宮代表因子**、**事項代表因子**、**交互關聯分析**的操作流程，以及**飛星**、**互容**、**衍生宮**、**大十字/大三角**等關鍵技法的具體應用。此三步驟旨在提供一套結構化、可操作的古典占星盤面分析框架，彌補現代心理占星側重心理分析而缺乏事件預測實務的不足。

> 參考來源：《占星占心》前言〈古典占星與現代占星的相會〉及後續案例章節。相關書評與脈絡可見 [[zhanxing-zhan-xin]]。

## 三步驟核心架構

### 第一步：命宮的代表因子

**目的**：建立命主本質與生命劇本的基準錨點。

**操作項目**：
1. 找出**上升星座**（ASC，第一宮起點）。
2. 確定**命主星**（上升星座的定位星/守護星）。
3. 記錄**命主星落入的星座與宮位**（即「飛星」至何宮）。
4. 記錄**第一宮內的行星**（含敏感點）。

**關鍵概念**：
- **上升星座/ASC**：東方地平線與黃道交點，代表肉體容貌、性格面具、生命啟動點。
- **命主星**：掌管上升星座的行星，象徵命主核心動力與生命導向。
- **飛星**：命主星離開本宮落入他宮，將命宮意涵「帶往」該宮位事務。

**案例速查（F小姐）**：
| 項目 | 內容 |
|------|------|
| 上升星座 | 摩羯座 |
| 命主星 | 土星 |
| 命主星星座 | 摩羯座（入廟） |
| 命主星宮位 | 第一宮（飛回本宮） |
| 第一宮內行星 | 木星、土星 |

> 圖示來源：書中 F小姐星盤與「占星寶盒」命主星說明。

---

### 第二步：事項的代表因子

**目的**：依詢問者關心議題，鎖定對應宮位及其掌管行星。

**操作項目**：
1. 依主題確定**代表宮位**（如婚姻→第七宮、感情→第五宮、事業→第十宮、健康→第六/八宮、財務→第二/八宮、子女→第五宮、兄弟→第三宮、父母/家庭→第四/十宮、交友/願望→第十一宮、隱疾/靈性→第十二宮）。
2. 找出該宮位的**宮主星**（宮頭星座的定位星）。
3. 記錄**宮主星落入的星座與宮位**（宮主星飛星）。
4. 記錄**該宮內的行星或敏感點**，並註明這些行星**掌管哪些宮位**（即它們也是其他宮位的宮主星）。

**關鍵概念**：
- **宮主星**：特定宮位起點星座的守護星，代表該領域的「執行者」。
- **宮內行星**：駐留該宮的行星，直接染指該領域事務。
- **掌管宮位/轉宮**：行星同時掌管兩個宮位（傳統雙主星），其落宮會串連兩宮事務。

**案例速查（F小姐・婚姻/第七宮）**：
| 項目 | 內容 |
|------|------|
| 代表宮位 | 第七宮（夫妻宮） |
| 第七宮星座 | 巨蟹座 |
| 第七宮主星 | 月亮 |
| 月亮星座 | 雙子座 |
| 月亮宮位 | 第六宮（飛至疾厄/工作宮） |
| 第七宮內行星 | 火星 |
| 火星掌管宮位 | 第四宮（家庭）、第十一宮（社交/財帛） |

> 同理可套用於 B小姐（第五宮愛情）、Q先生（第三/十一宮兄弟社交）、Z小姐（第五宮桃花）、E小姐（第七宮婚姻）、J小姐（第一/七宮自我與伴侶）、O先生（第五/七宮桃花婚姻）等案例。

### 第三步：交互關聯分析

**目的**：將「命宮因子」與「事項因子」置於同一盤面，透過相位、飛星串聯、宮位轉換、相位型態，判斷事項對命主的**來龍去脈、吉凶程度、時間觸發點**。

**分析維度**：
1. **相位關係**：命主星與事項宮主星/宮內行星的相位（合/刑/沖/拱/六合）。
2. **飛星串聯**：命主星飛入事項宮、或事項宮主星飛入命宮、或雙雙飛入第三宮位（形成「雙飛」或「交換」）。
3. **衍生宮/轉宮法**：以事項宮為新第一宮重新起算，觀察原本其他宮位在衍生體系中的新意涵（如以第七宮為一宮，原第十宮變衍生第四宮＝配偶家庭/事業）。
4. **相位型態**：大十字、大三角、T型、小三角、星簇等整體幾何結構。
5. **行星狀態**：入廟/旺/弱/落陷、受刑剋/受容納/互容、光燄/燃燒/逆行等。
6. **時間觸發**：流年行運、推進、大運、過運行星引動本命相位。

**判斷邏輯**：
- **吉論依據**：命主星與事項因子形成拱/六合、互容、受吉星（木金）拱照、落入吉宮（一/五/九/十一）、大三角調和。
- **凶論依據**：刑沖剋害、落入凶宮（六/八/十二）、大十字鎖死、宮主星入弱/落陷、受惡星（土火冥天凱）嚴重刑剋、無調和相位救應。
- **混合論**：吉凶參半，視調和相位強度、時間觸發節點、當事人自由意志運作而定。

**案例速查（F小姐・第七宮火星沖ASC）**：
- 第七宮火星（宮內行星）對沖 ASC（命宮起點）→ 伴侶直接衝擊命主身心。
- 火星掌第四/十一宮 → 婚姻衝突牽動家庭根基與社交財務。
- 命主星土星在一宮摩羯入廟，但與木星同宮、木星落陷（摩羯為木星落陷宮）→ 雖有主見耐操，仍難免為伴侶收拾爛攤子。
- 大十字結構（見下文）進一步鎖死婚姻變數。

## 關鍵技法深度解析

### 飛星

**定義**：行星（尤其是命主星、宮主星）離開其本宮/掌管宮位，落入其他宮位的現象。

**操作規則**：
- 命主星飛宮：將「自我核心」帶往該宮事務（如命主星飛十宮＝生命重心在事業/名聲）。
- 宮主星飛宮：將該宮事務「延伸」至落宮領域（如七主飛八宮＝婚姻牽涉對方財務/生死/性/隱秘）。
- **雙飛/交換**：A宮主飛B宮、B宮主飛A宮，形成強烈雙向綁定。

**案例應用**：
- **B小姐**：五宮主木星飛十宮（事業）→ 戀人易為同事；七主月亮飛六宮（工作/疾厄）→ 婚姻受工作健康影響。
- **Q先生**：命主木星飛十宮天秤（與金星互容）→ 事業順遂且具藝術公關才華；十一主金星飛三宮（兄弟/同儒）→ 朋友多為同學藝術圈。
- **Z小姐**：五主火星飛十一宮、冥王星飛三宮 → 桃花來自社交圈/同事，且易引發職場糾紛。
- **E小姐**：十宮主木星在十宮（不飛）、海王星在九宮 → 事業與高等教育/靈性/外國緣結合。
- **J小姐**：命主水星飛十二宮 → 隱匿自我、靈性內省；十主土星飛七宮 → 事業與伴侶合作。

> 相關理論可參考 [[zhanxing-quan-fang-wei]] 中的「十星三位說」飛星邏輯，以及 [[planetary-condition-traditional-astrology]] 的行星狀態評估。

### 互容

**定義**：行星A落入行星B的廟旺宮，**同時**行星B落入行星A的廟旺宮。雙向接納，能量自由流通，極為吉利。

**廟宮/旺宮/弱宮/落陷宮速查**：
| 行星 | 廟宮 | 旺宮 | 弱宮 | 落陷宮 |
|------|------|------|------|--------|
| 太陽 | 獅子 | 牡羊 | 水瓶 | 天秤 |
| 月亮 | 巨蟹 | 金牛 | 摩羯 | 天蠍 |
| 水星 | 雙子/處女 | 處女/寶瓶 | 射手/雙魚 | 射手/雙魚 |
| 金星 | 金牛/天秤 | 雙魚 | 牡羊/天蠍 | 牡羊/處女 |
| 火星 | 牡羊/天蠍 | 摩羯 | 金牛/天秤 | 巨蟹 |
| 木星 | 射手/雙魚 | 巨蟹 | 雙子/處女 | 摩羯 |
| 土星 | 摩羯/寶瓶 | 天秤 | 巨蟹/獅子 | 牡羊 |
| 天王星 | 寶瓶 | 射手 | 獅子 | 金牛 |
| 海王星 | 雙魚 | 射手/雙魚 | 處女/雙子 | 獅子/處女 |
| 冥王星 | 天蠍 | 獅子 | 金牛 | 水瓶 |

**案例應用**：
- **Q先生**：命主木星（十宮天秤）⇄ 十一主金星（三宮雙魚）→ **木金互容**，事業/名聲與社交/藝術雙向加持，形成大三角一角。
- **F小姐**：命主土星（一宮摩羯）⇄ 七宮火星（七宮巨蟹）→ **土火互容**，但雙雙落陷/弱宮（木星摩羯落陷、火星巨蟹弱宮），互容反成凶論基礎，婚姻糾纏難解。
- **J小姐**：二主月亮（二宮巨蟹入廟）受太陽容納（太陽在一宮雙子）→ 月亮強旺掌財，但八主土星飛七宮剋月亮，配偶理財不當損財。
- **O先生**：月亮（二宮獅子）受太陽容納（太陽在五宮天蠍）→ 命主得容納，財帛/自我資源受事業/權威支持。

> 互容與容納是古典占星評估行星「能否落實意圖」的核心指標，詳見 [[planetary-condition-traditional-astrology]]「獎賞與虐治」維度。

### 衍生宮 / 轉宮法

**定義**：以特定宮位為新「第一宮」（衍生ASC），按順序重新編號其餘宮位，從而讀取該宮位視角下的衍生事務。

**公式**：衍生第 N 宮 = 本命第 (N + 目標宮位 - 1) 宮（模 12）。

**常用衍生對照表（以第七宮為例）**：
| 衍生宮位 | 對應本命宮位 | 意涵 |
|----------|--------------|------|
| 衍生一宮 | 本命七宮 | 配偶本人 |
| 衍生二宮 | 本命八宮 | 配偶錢財/資源 |
| 衍生三宮 | 本命九宮 | 配偶兄弟/短途旅行/信仰 |
| 衍生四宮 | 本命十宮 | **配偶家庭/父母/事業** |
| 衍生五宮 | 本命十一宮 | **配偶桃花/情人/願望** |
| 衍生六宮 | 本命十二宮 | 配偶隱疾/秘密/靈性 |
| 衍生七宮 | 本命一宮 | **配偶眼中的命主（命主為配偶的伴侶）** |
| 衍生八宮 | 本命二宮 | 配偶共同財產/命主錢財 |
| 衍生九宮 | 本命三宮 | 配偶高等教育/長途/法律 |
| 衍生十宮 | 本命四宮 | 配偶事業聲望/命主家庭 |
| 衍生十一宮 | 本命五宮 | 配偶社交圈/命主子女/桃花 |
| 衍生十二宮 | 本命六宮 | 配偶工作健康/命主疾厄 |

**案例應用**：
- **F小姐**：七宮火星掌本命四宮（家庭）與十一宮（社交）→ 衍生十宮（配偶事業）由火星主管，印證配偶從事金屬機械創業；衍生五宮（配偶桃花）為本命十一宮，雙主火星/冥王星分落七宮/八宮且刑剋 → 配偶外遇破壞婚姻。
- **E小姐**：七宮水星飛本命六宮 → 衍生十二宮（配偶隱秘/外遇）由水星主管，水星在獅子座（異性緣強）且對沖五主月亮（本命十二宮）→ 配偶婚外情隱匿發生。
- **J小姐**：十主土星飛七宮 → 衍生四宮（配偶家庭/事業）由土星主管，土星在射手座（好大喜功膽怯）→ 配偶事業決策搖擺不定。

> 衍生宮法則源自希臘化時期，現代古典占星復興後重見天日，參考 [[zheng-gong-zhi-yu-shier-gong-wei]] 整宮制與宮位轉換邏輯。

### 大十字與大三角相位型態

#### 大十字
- **構成**：四顆行星兩兩相距 90°（刑）與 180°（沖），形成兩組對沖、四組刑相位，四星座屬同一**特質**（基本/固定/變動）。
- **意涵**：極大張力、鎖死、持續衝突、必須在四宮位事務間不斷取捨、內化壓力轉化為動力。
- **判斷要點**：
  1. 屬何特質：基本十字＝行動衝突；固定十字＝僵持拉鋸；變動十字＝資訊混亂/適應壓力。
  2. 落宮位：鎖死哪四大生活領域。
  3. 是否有吉星參與/調和相位救應。

**案例應用**：
- **B小姐**：**兩組大十字**同時鎖死二/五/八/十/十一宮：
  - 第一組：二宮火星、五宮月亮、八宮土星/凱龍、十一宮太陽/水星 → **基本十字**（牡羊/巨蟹/天秤/摩羯）→ 行動層面衝突：錢財/桃花/生死/事業/社交五方拉鋸。
  - 第二組：二宮天王/冥王、五宮南交、八宮土星、十宮木星/北交 → **固定十字**（金牛/獅子/天蠍/水瓶）→ 僵持層面：變數/權力/業力/責任/命運軸鎖死。
  - 結果：愛情宮（五宮）成為核心受害區，男友辭世、父母反對、事業波動同步爆發。
- **F小姐**：七宮火星、一宮木土、四宮/十一宮（火星掌管）形成潛在大十字結構，婚姻/自我/家庭/社交四方受困。

#### 大三角
- **構成**：三顆行星兩兩相距 120°（拱），通常落同一**元素**（火/土/風/水）。
- **意涵**：天賦才華、順暢流動、機會自來、保護機制。
- **判斷要點**：三星落宮、掌管宮位、元素屬性（火＝行動/土＝物質/風＝智社/水＝情靈）。

**案例應用**：
- **O先生**：二宮月亮（獅子/火）、五宮太陽（天蠍/水？實際書中寫「月亮與太陽及 MC 形成大三角」）→ **火/水/土混合大三角**，月亮受太陽容納，命主自信、事業順遂、家庭經濟棟樑。
- **E小姐**：擁有**兩個大三角**及多小三角，幾乎每顆凶星都有拱照救應（除火星），使命主在婚姻災難外仍享福澤、才華、事業順遂。
- **Q先生**：木星（十宮天秤/風）、金星（三宮雙魚/水）、天王星（十宮天秤/風）→ 風/水大三角邊緣，公關/藝術/創新才華自然流露。

> 相位型態分析可配合 [[zhanxing-xingxing-tianwen-yu-yiyi]] 行星屬性與 [[zodiac-sign-correspondences]] 星座元素特質研判。

## 綜合案例研判流程示範

以下以 **F小姐（婚姻案）** 為例，演示完整三步驟＋技法整合：

| 階段 | 操作 | 關鍵發現 |
|------|------|----------|
| **步驟一** | 命宮因子 | 摩羯上升、命主土星在一宮摩羯入廟、合木星（落陷）→ 刻苦耐勞、教師性格、易說教、自我要求高。 |
| **步驟二** | 事項因子（婚姻/七宮） | 七宮巨蟹、七主月亮飛六宮雙子、七宮內火星（掌四/十一宮）→ 配偶情緒不穩、暴力、外遇牽涉家庭財務。 |
| **步驟三** | 交互關聯 | 1. 火星沖 ASC → 伴侶直接攻擊命主身心。<br>2. 土火互容但雙弱 → 婚姻糾纏難斷。<br>3. 衍生宮：七宮為一宮，本命十一宮成衍生五宮（配偶桃花），火星/冥王星分落七/八宮刑剋 → 外遇破壞。<br>4. 六宮月亮刑八宮冥王星 → 工作壓力/健康與配偶資源/生死糾結。<br>5. 一宮木土合相拱三宮金星 → 自我資源與兄弟/溝通有調和，子女緣佳（五主金星旺宮拱一宮）。 |
| **時間觸發** | 流年/大運 | 走入金星大運（五主金星旺宮拱命宮）→ 子女長大成人支持、決心離婚、重獲新生。 |

## 實務操作清單

1. **排盤與校正**：確認出生時間精確至分鐘，必要時以重大事件（婚喪生子、手術、遷徙）校正上升星座。
2. **列出三步驟表單**：
   - 表 A：命宮因子（上升、命主星、命主星落宮、一宮內行星）。
   - 表 B：事項因子（目標宮位、宮頭星座、宮主星、宮主星落宮、目標宮內行星、該行星掌管宮位）。
   - 表 C：交互關聯矩陣（相位、飛星串聯、衍生宮對照、相位型態、行星狀態、時間觸發）。
3. **標註行星狀態**：廟/旺/弱/陷、順/逆/留/光燄/燃燒、受容納/互容/刑剋/拱照。
4. **識別關鍵型態**：大十字、大三角、T型、星簇、雙飛/互容/容納鏈。
5. **撰寫判斷草稿**：先寫「吉論依據」、再寫「凶論依據」、最後綜合「時機與建議」。
6. **諮商話術轉化**：將專業術語轉為當事人可理解的生命敘事，保留同理心空間，避免宿命論絕對化。
