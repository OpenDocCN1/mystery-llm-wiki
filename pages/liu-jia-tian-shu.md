# 秘传六甲天书三卷全貌

> 本页依据《化解大法全书下》第三章“秘传六甲天书”及相关章节整理，构建六甲天书三卷的完整知识体系，涵盖源流传承、神将体系、坛场仪轨、秘法实操等核心内容，并建立与祝由十三科、茅山术、六甲法术奇门等体系的交叉引用。

## 一、 源流传承与经典定位

### 东华大帝君授书始末
- **授书场域**：元始天尊、道德老君、玉帝紫微大帝会于三十三天丙胃宿形宫，丁卯昴宿同在。
- **授书缘由**：东华大帝君奏请将六甲天书流传南阎浮提，救度刀兵凶年、黎民失业、父子相离之苦。
- **三清许可**：元始极尊允准“此书流传在世，令传世安邦，定乱救度众生”。
- **托生传递**：老君下世托生赵相公家，寄于白杨梅树李子，为十五岁女子吞服，腹怀八十一年，卯时左胁剖生，身长九尺五寸，头白如丝。
- **传承脉络**：老君将书三卷传关尹喜先生，至今传于凡世。

### 六甲神总咒
> 上清上帝，东华大帝君，令吾印天书，并使六甲六丁之神，天游十二溪女，那延天女，五人统摄神兵，三员大将，火光大将，浮海大将，吼风大将。此等众圣，各领神兵百万垓，助吾法力，神通，千变万化，永得遵吾六甲神印，立在坛前。令吾七政九宫，保佑尔身，使之从吾上朝元君，与道合真，和形炼魂，策空泛浮升天摄云。急急如律令。

**实战要诀**：现出师人阵地、他兵围困时，守持六甲神印念咒三遍，六甲六丁立现，三员大将各领鬼兵百万垓，空中雷声、降石冰雹击溃敌军。

> **关联体系**：六甲六丁神将体系亦见于[[liu-jia-fa-shu-qi-men-fa-shu-pian]]《六甲法术奇门法术篇》之“护法神将”与“神将祭炼”章节。

### 飞身印与吞服诀
- **造印料**：五月初五取梨木十二块（面阔二寸八分、厚五寸），匠人雕刻，朱砂印十二颗。
- **吞服法**：每日午时炼二十四气满吞之；早晨服真气七日，新水吞十二颗，百日飞身去地三五尺，五年容貌更变，九年飞升乘彩云上朝玉帝。
- **脱壳前提**：须服五言丹药、吞十二溪女印、持六甲天女二印，功满九年仍未脱凡壳，需行“脱壳朝真法”。

## 五、 坛式斋醮仪轨（标准化流程）

### 前期净化四咒
1. **净口咒**：丹朱口神，哇秽除氛，舌神正伦，通命养神，维千齿神，祛邪卫真。急急律令。
2. **净身咒**：灵宝天尊，安慰安形。弟子魂魄，五肠玄冥。青龙、白虎、朱雀、玄武、侍卫我身。急急律令。
3. **净土地神咒**：坛场土地，神晚抵灵。通天达地，出入幽冥。为吾传奏，不得留停。有功之日，各书上请。急急律令。
4. **净光咒**：天地玄宗，万气本根……金光速现，覆护坛庭。急急律令。

### 器物咒纸笔墨
- **咒水咒**：天一生水，地六之一……白乾元，亨利贞（书符于水中）。
- **咒纸文**：褚王之英，于地生成。龙章凤篆，资之以陈，符习迅速，遍历灵天。
- **咒笔文**：神笔扬扬，万古传芳。吾今书篆，飞召千方。云与风飕驭，速降灵场。
- **咒墨文**：神灵墨灵，通函达冥。松君效职，兰友凝馨。仙宾降格，速驾云乘。
- **咒符文**：太乙灵场，紫气煌煌……书毕以符置箕上，打虎头诀、箕诀，烧五鬼符。

### 请仙/发牒/送仙完整链路
| 环节 | 关键动作 | 核心咒文/文书 |
|------|----------|---------------|
| **请仙** | 焚香三盘果、茶酒三盏、虔诚拜请 | “道由心合，心假香传……今臣关告，圣达九天” |
| **书符** | 净身净口后，嘘气布纸笔，念咒书符 | “玄女元君，痰化十方……急急如律令摄” |
| **发牒** | 青光纸二张、朱砂新笔书牒文，粘封压四角 | “雷霆火急，建都司下……右仰直符使赵弓马温准比” |
| **请箕/降仙** | 箕头书二十八宿基、留轸字、贴箕头烧 | “青龙朱雀，白虎玄武，经天四七二十八宿” |
| **送仙** | 事毕必送，托箕于水盂 | “已蒙仙真降……后有所求，再当奉请” |

**请仙礼仪物料**：果酒花烛、香灯、锦褥放六甲印/天女印、二十八宿符、通仙符、催符、斩邪符、定仙符、粘柱符、粘桌下符。

> **仪轨对照**：上述流程与[[liu-jia-fa-shu-qi-men-ji-chu-pian]]《六甲法术奇门基础篇》中“开坛仪轨、启灵符、请神诀、捏诀手势”高度同构，均遵“净身净口→咒器→请神→书符→发牒→送神”标准范式。

## 八、 东华大帝君脱壳朝真法

1. **前提**：持六甲天女二印，服五言丹药，吞十二溪女印，九年功满未脱凡壳。
2. **环境**：一室如法对待，勿透风，留二窗纳月光。
3. **操作**：焚香礼拜东华大帝君 → 盘膝正坐、握固存神、披衣冥心、闭目微轻、取火炼气 → 想三魂上飞扬、凛然自现。
4. **升天盛相**：朱雀前引、玄武后随、青龙白虎分列、金童玉女狮子白鹤两行、六甲六丁十三溪女那延天女随后、三员大将伏剑前导、魔军奔逃 → 车歌乐轻、盖绮罗人妇女队、身登五色龙云 → 见楼台耸翠、院宇金玉、花草满庭、异香女乐 → 升天宫朝玉帝受符命回 → 洞府紫气红光罩顶、祥鸾瑞凤 → 登仙上品。
5. **结语**：须奏东华大帝君，得享洞天长春之乐。

## 九、 煮黑豆隐身法（北斗遁法）

### 采豆时咒（正月初一三更、甲子日五更、每遇六甲日）
> 天则灵，地则灵，左手指七星，右手指北斗，天上二十八宿，是吾所管。头戴北斗七星，脚踏九曲黄河，吾奉上界血子，吾是下界避难人，吾等吞豆人不见，吾等收豆便是人。急急如律令敕。（**四十九遍**）

### 煮豆咒（煮熟晒干时）
> 天玄地黄，六甲九章，出行不见，永保长生。人来追我，掩其两目。马来追我，断其四足。吾等隐身，谨请北上元真君，变吾家在须弥山安身。急急如律令敕。（**七遍**）

### 遁藏实操
- 急难时含豆于口，手执六甲总牌二道（桃木刻符），众人不见其牌。
- 欲遁藏房舍及多人：先人不见房屋，见职万丈高山、清渠一尺或视为江河。
- 解遁：将豆并符收起即复常。

> **关联**：隐身遁法亦见于[[zhu-you-shisan-ke]]“隐身遁法”章节，及[[liu-jia-fa-shu-qi-men-fa-shu-pian]]“净宅术”中。

## 十、 冷启敬先生引鼠招欢和合秘诀

### 总纲
- **法名**：引鼠招欢和合法。
- **分三件**：引鼠法、招合法、和合法（原文第三件“和合法”因截断未全录）。
- **戒律**：得术人为利行隐遁法，为争行妙袅法，为王行服法魔利知天术。隐人之妻须洁净为正。五鬼法、搬运法、使鬼之便，后人学者心中聪明、手快眼清。

### 引鼠法
1. **材料**：鼠肺和辰砂咀书符。
2. **前操**：先念和合咒、捻和合诀、烧六神符七道、结北斗印、步罡。
3. **书符**：又书和合符于手宫、左脚，口念催神咒。
4. **效验**：鼠自然出来，走桌上如穴中；书符焚之，鼠即宁静。
5. **放生**：引来不可打死，少放几个于野外，**切不可乱用**。
