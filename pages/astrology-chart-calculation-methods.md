## 核心定位与前提

《占星玩家手册》（The Astrological Player's Handbook）第二章确立了 **阿圭亚制（Aquid）即普拉西德斯分宫法（Placidian House System）** 为全书排盘基准。作者强调：“使用太粗略的星宫命盘，足以摧毁任何优秀的占星学家”，因此必须掌握从出生数据到精确命盘的完整数学天文操作链路。

> **前置知识**：理解黄道坐标与赤道坐标转换、恒星时与平太阳时关系、岁差对星历表的影响，可参考 [[zhanxing-tianwen-jichu-yu-huangdao-tixi]]。

## 一、制作命盘必须具备的基础数据

| 数据项 | 精度要求 | 说明 |
|--------|----------|------|
| **出生时刻** | 精确到分（秒更佳） | 年、月、日、时、分；需注明是否为夏令时/战时/标准时间 |
| **出生地点** | 经纬度精确到分 | 国家、省/州、县、市；经度（东/西）、纬度（北/南） |

> **工具书推荐**：瑞士版《苏黎世星历表》（Zurich Ephemeris）、《专科用星历表》（College's Ephemeris）、达顿《宫位表》（Dalton's Table of Houses）、全美占星图书馆出版的《美国国内各地之经纬度》《美国以外地方之经纬度》、多萝西·唐《美国国内各地之时差转换》。

## 二、时间系统转换链路（步骤 1–3）

### 出生时间 → 标准时间（ST）
- 查《时差转换表》确认出生当地是否实施夏令时（DST）或战时（War Time）。
- **规则**：夏令时通常 4 月最后一个周日拨快 1 小时，10 月最后一个周日拨回；战时全年拨快 1 小时。
- **示例**：1942-07-07 09:30 AM（波士顿，战时） → 减 1 小时 → **08:30 AM 东部标准时间（EST）**。

### 标准时间 → 地方平太阳时（LMT）
- 查《经纬度表》得出生地经度（λ）与所属时区中央经度（λ₀）。
- **公式**：LMT = ST + 4 × (λ₀ - λ) 分钟（东经为正，西经为负）。
- **示例**：波士顿 λ = 71°04′W，东部时区中央经度 λ₀ = 75°W → 差 3°56′ → 4×3.93≈15′44″ → **LMT = 08:30:00 + 00:15:44 = 08:45:44 AM**。

### 地方平太阳时 → 格林威治平太阳时（GMT）
- **公式**：GMT = LMT + 4 × λ（λ 为西经，单位度；转换为时分秒）。
- **示例**：λ = 71°04′ = 71.0667° → 4×71.0667 = 284.267 分钟 = 4 小时 44 分 16 秒 → **GMT = 08:45:44 + 04:44:16 = 01:30:00 PM**（即 13:30）。

> **交叉引用**：时间系统转换是 [[zhanxing-yu-ce-ji-fa-ti-xi]] 中行运、推运、回归图起算的基础。

## 三、恒星时计算（步骤 4–5）

### 取前一日中午恒星时（ST₀）
- 翻《苏黎世星历表》SS（Sidereal Time）栏，找 **出生当日前一日 12:00 GMT** 的恒星时。
- **示例**：出生 GMT 为 7 月 7 日 13:30 → 取 7 月 6 日 12:00 ST = **06h 55m 21s**。

### 计算从前一日中午到出生 LMT 的时间间隔（ΔT）
- 前一日 12:00 到当日 00:00 = 12 小时。
- 当日 00:00 到出生 LMT（08:45:44）= 8h 45m 44s。
- **ΔT = 20h 45m 44s**。

## 四、恒星时修正值累加（步骤 5c–5d）

| 修正项 | 查表依据 | 示例数值 |
|--------|----------|----------|
| **时间间隔修正**（ΔT → 恒星时增量） | 达顿宫位表第 5 页「恒星时修正值之平均时间表」 | 20h→3′00″, 45m→17″, 44s→07″ → **3′24″** |
| **经度修正**（GMT-LMT 差 → 恒星时增量） | 同表 | 4h→39″, 44m→07″, 16s→00″ → **46″** |

**累加公式**：  
**精确恒星时 = ST₀ + ΔT + 时间修正 + 经度修正**  
= 06:55:21 + 20:45:44 + 00:03:24 + 00:00:46 = 27:45:15 → 减 24h → **03:45:15**。

## 五、纬度修正与宫位插值（步骤 6–7）

### 纬度修正（达顿表 B）
- 地球扁率导致同恒星时下不同纬度宫位不同。
- **示例**：纬度 42°22′N → 查表 B 修正值 ≈ **-12′** → 修正纬度 = **42°10′N**。

### 双重线性插值得精确宫位
达顿宫位表以 **恒星时（行）** 与 **纬度（列）** 为双入口参数。目标参数落在四格交叉点内，需两次插值：

#### 时间插值（固定纬度 42°）
```
目标恒星时 03:45:15 介于表列 03:42:57 与 03:47:06 之间
差值 = 249 秒；目标与下限差 = 138 秒 → 权重 = 138/249
各宫位 = 下限值 + (上限值 - 下限值) × 138/249
```

#### 纬度插值（固定插值后时间）
```
目标纬度 42°10′ 介于 42° 与 43° 之间 → 权重 = 10/60 = 1/6
最终宫位 = 42°值 + (43°值 - 42°值) × 1/6
```

#### 示例结果（摘录）
| 宫位 | 最终黄道经度 |
|------|--------------|
| 第10宫 (MC) | 28♉ 33′ |
| 第11宫 | 3♊ 42′ |
| 第12宫 | 5♊ 59′ |
| 第1宫 (ASC) | 3♋ 43′ |
| 第2宫 | 26♋ 47′ |
| 第3宫 | 24♌ 58′ |
| 其余宫位 | 对冲宫位 +180° |

## 六、行星位置修正至出生时刻（星历表插值）

星历表给出 **每日 12:00 GMT** 行星黄道经度。需插值至 **出生 GMT (13:30)**。

### 插值公式（线性近似）
```
行星出生位置 = 日中位置 + (次日中位置 - 当日中位置) × (出生GMT - 12:00) / 24h
```
- 时间差：13:30 - 12:00 = 1.5 小时 = 90 分钟
- 权重 = 90 / 1440 = 1/16

## 八、操作要点与常见误区

| 环节 | 关键提示 |
|------|----------|
| **时间修正** | 必须核对历史时区变更、夏令时起止规则、战时令；参考《世界时区变迁表》或 tz database。 |
| **经纬度精度** | 城市中心与医院可能相差数分，对 ASC/MC 影响可达 1°；建议用 GPS 坐标。 |
| **恒星时累加** | 秒→分→时进位务必逐级核对；可用十进制小时制辅助验算。 |
| **宫位插值** | 双线性插值假设局部平面近似；高纬度（>60°）宫位扭曲大，需更高阶插值或直接球面三角解算。 |
| **行星插值** | 月亮日行 13°，线性插值误差可达 1′；专业级需用三次插值或数值积分。 |
| **相位容许度** | 本书采用日月 10°、其余 6°；现代流派常按相位类型分级（合/冲 8°、三/六分 6°、四分 5°）。 |

## 九、从手工计算到现代工具链的映射

| 手工步骤 | 现代算法/库 | 说明 |
|----------|-------------|------|
| 时间系统转换 | `pytz` / `zoneinfo` / IANA tzdb | 自动处理历史夏令时/战时 |
| 经纬度查询 | GeoNames / Google Maps API | 精确到秒 |
| 恒星时计算 | `ERFA` / `SOFA` / `Astronomy Engine` | 含章动、岁差、△T 修正 |
| 宫位计算 | `Swiss Ephemeris` `swe_houses()` | 支持 Placidus、Koch、Regiomontanus、Whole Sign 等 20+ 制 |
| 行星位置 | `Swiss Ephemeris` `swe_calc_ut()` | DE431/DE440 行星历，精度 < 0.1″ |
| 相位搜索 | 自定义角度模运算 + 容许度表 | 可生成相位网格、相位弧图 |

> **实践建议**：教学/考试仍建议完整手算一次，建立“天文几何直觉”；实务咨询直接调用成熟库，专注于解读层面。
