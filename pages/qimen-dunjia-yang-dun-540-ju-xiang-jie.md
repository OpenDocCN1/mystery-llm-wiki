## 核心定位与体系概述

### 奇门遁甲：中国古代最高决策学
奇门遁甲融《周易》、天文、律历、阴阳五行于一体，形成完整的数理模型。它将天时、地利、人和与能量场在时空中组合，提供模拟宇宙统一信息场的立体动态象数模型，用于自然、社会、人生决策及趋吉避凶的时空选择。属“三式”之首（太乙、奇门、六壬），历称“帝王之学”。[[qimen-dunjia-fundamentals]]

### 本部结构：1080式盘中的前540局
全书第二、三部详解**时家奇门1080个式盘**（阳遁540 + 阴遁540）。
- **阳遁540局** = 9局 × 5日 × 12时辰
- **九局对应节气三元**：
  - **一局/七局/四局**：冬至、小寒、大寒（上/中/下元）
  - **八局/九局/二局**：立春、雨水、惊蛰
  - **三局/九局/六局**：春分、清明、谷雨
  - **四局/一局/七局**：立夏、小满、芒种
  - *（注：具体节气排局规则见“置闰与三元”章节）*
- **五日干组**：甲己日、乙庚日、丙辛日、丁壬日、戊癸日（对应符头甲/己）
- **十二时辰**：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥

### 盘面数据结构（每时一局）
每个时辰局（小局）包含四大核心信息板块：
1.  **符使宫位**：值符（天盘九星）、值使（人盘八门）所落宫位。
2.  **三奇方位**：乙、丙、丁三奇在天盘/地盘的落宫及与门、星的组合关系（得使、入墓、相生克）。
3.  **四吉方位**：九天、九地、太阴、六合（神盘四吉神）所落宫位及利用方向（出击、驻防、潜伏、撤退）。
4.  **诸局格象**：吉格（二吉神九遁、三奇得使、玉女守门、天三门、地四户等）、凶格（伏吟、反吟、击刑、时墓、奇墓、五不遇、天网地网、孤虚、宫迫、青龙逃走、白虎猖狂、荧入太白等）及综合吉凶判断。
5.  **吉方判断**：综合三奇、吉门、吉神落宫，指明趋吉方向。

## 核心理论基石（卷六：排盘总述与诸格）

### 排盘四大步骤（口诀法）
1.  **定阴阳二遁**：冬至后阳遁（顺布六仪、逆布三奇），夏至后阴遁（逆布六仪、顺布三奇）。
2.  **定三元局数**：以甲、己为符头，符头所临地支定上中下元（子午卯酉=上/一、七、四；寅申巳亥=中/八、九、二；辰戌丑未=下/三、九、六）。
3.  **寻值符值使**：按旬首（六甲）所在宫位，该宫星为值符（直符），该宫门为值使（直使）。
4.  **三盘转动**：
    - **天盘**：值符星转至时干所在宫。
    - **人盘**：值使门转至时支所在宫。
    - **神盘**：小直符（六合）对准大值符所在宫，阳顺阴逆。

> **工具**：奇门圆盘（四层同心圆：地盘/天盘/人盘/神盘）与奇门方盘（九宫定盘），配合“新制奇子”（三奇六仪合体筹码）操作。[[qimen-dunjia-fundamentals]]

### 置闰与接气法（闰奇超神接气直指）
- **正授**：符头与节气同日。
- **超神**：符头逐日逾越节气。
- **置闰**：超神至9天以上，**仅在芒种（阳遁尽）与大雪（阴遁尽）之后**置闰，补齐历法差额（奇门历360天 vs 回归年365.24天）。
- **接气**：置闰后节气超前符头，直至下一正授。
- **循环**：正授 → 超神 → 置闰 → 接气 → 正授……
- **关键**：置闰错误“差之毫厘，谬以千里”。[[qimen-dunjia-yin-dun-540-ju-xiang-jie]]

#### 吉格
| 类别 | 核心格局 | 判断标准 |
| :--- | :--- | :--- |
| **二吉神** | **青龙返首**（天盘戊加地盘丙）、**飞鸟跌穴**（天盘丙加地盘戊） | 最吉利格局 |
| **九遁** | 天遁、地遁、人遁、神遁、鬼遁、风遁、云遁、龙遁、虎遁 | 吉门、三奇、吉神、地盘特定组合 |

| **玉女守门** | 值使门加地盘丁奇 | 利阴私和合 |
| **天三门** | 月将加时支，得从魁、小吉、太冲方位 | 避祸天门 |
| **地四户** | 时支加月建，得除、定、危、开方位 | 地户宜用 |
| **地私门** | 阴/阳贵人加日贵支，得六合、太阴、太常 | 隐秘吉方 |
| **太冲天马** | 月将加时支，太冲所临地支 | 出行避难 |
| **急则从神** | 直符、天乙（值符）、值使所在宫 | 紧急趋向 |

#### 凶格（避忌核心）
| 格局名称 | 形成条件 | 主凶义 |
| :--- | :--- | :--- |
| **伏吟** | 九星/八门/值符停留原宫不动 | 主大凶，损人口、孝服哀丧 |
| **反吟** | 九星/八门/值符冲至对宫（子午卯酉辰戌丑未寅申巳亥） | 动荡不安，事难成 |
| **六仪击刑** | 值符六甲与地支相刑（甲子/午刑卯/酉，甲申/辰刑寅/戌，甲戌/寅刑巳/亥） | 刑伤克害 |
| **时墓** | 时支为时干墓库（戊戌、壬辰、丙戌、癸未、丁丑、己丑） | 时干入墓，气绝 |
| **奇墓** | 三奇入墓库（乙墓未/戌坤二/乾六、丙墓戌乾六、丁墓丑艮八） | 三奇无力 |
| **五不遇** | 时干克日干（如甲日遇庚辛时） | 自克不利 |

| **地网遮** | 天盘六壬加临时干 | 不宜出行 |
| **孤虚** | 旬中缺支为孤，冲支为虚（如甲子旬孤戌亥、虚辰巳） | 空亡对冲 |
| **宫迫** | 门克其所在宫（如开门/惊门临三四木宫，金克木） | 门制其宫 |
| **青龙逃走** | 天盘乙奇加地盘辛 | 木克金，主谋泄 |
| **白虎猖狂** | 天盘辛加地盘乙 | 金克木，主惊恐 |
| **荧入太白/太白入荧** | 丙奇加庚 / 庚加丙 | 火金相战 |
| **符勃/飞勃/天乙伏飞宫** | 丙奇、值符、庚仪与值符互加 | 符使受困 |

#### 推断辅助法（第三章）
1.  **八节三奇图例**：八节（二至二分四立）落宫定三奇方位，辰戌丑未为煞。
2.  **起神杀例/月例**：太岁、独火、丧门、勾陈、官符等飞九宫，月建寻三奇。
3.  **日家寻时家伏断时**：七星值日忌时（如太阳直日忌子寅酉）。
4.  **三奇取时克应**：三奇到八卦宫的具体物象应验（如乙奇到乾见黄衣人/缠钱，丙奇到坎见执杖/黄白禽，丁奇到离见青衣人/进财等，共8宫×3奇=24组应验规则）。

## 使用指南

1.  **查阅特定时辰盘面**：定年份节气 → 定阴阳遁/局数(一至九) → 定日干组(甲己等) → 定时辰(子至亥) → 对应本页或各局详解表格 → 读取「符使/三奇/四吉/格象/吉方」。
2.  **决策判断流程**：
    - 看**伏吟/反吟/击刑/时墓/奇墓/五不遇/天网地网**等大凶格 → 有则避用此时。
    - 看**青龙返首/飞鸟跌穴/三奇得使/九遁/玉女守门/天三门/地四户/太冲天马**等大吉格 → 有则优先用此时。
    - 综合**三奇方位**（得使/入墓/相生克）、**四吉神方位**（九天出击/九地驻防/太阴潜伏/六合撤退）、**吉门方位**（开休生旺相方向） → 确定**趋吉方位**。
    - 参考**三奇克应**（物象验证）及**八节三奇/月建神煞**辅助断时。
3.  **置闰校验**：凡涉及芒种、大雪前后节气交接，必须核对《闰奇超神接气直指》规则，防止超神误用导致“谬以千里”。
