## 概述

《六爻答疑》由曲炜信息咨询中心编撰，收录163个实战核心疑难问答，系统解决六爻预测中的理论认知、操作规范、断卦技法、应期验证等关键问题。全书分为“对易学的认识”“基础知识问答”“六爻问答”三大板块，兼具理论深度与实操指导，是六爻进阶必读参考。

> **相关知识页面**：[[qu-wei-liuyao-tezhunban-jiangyi]]（曲炜《六爻真传》体系）、[[liuyao-shizhan-dianqiao]]（马志川《六爻实战点窍》）、[[liuyao-jichu-rumen-qinglan]]（青岚《六爻基础入门》）、[[liuyao-yihui-zhimi]]（王虎应《六爻疑惑指迷》）

## 一、 对易学的认知定位

### 预测准确度的科学界限
- 六爻预测平均准确度 **80%左右**，高手可达 **85%-90%**，**不可能达到100%**。
- 影响准确度的四大因素：理论体系未臻完善、预测者水平、预测者心态状态、求测者意念集中度。
- **辩证看待“大师失准”**：科学无极限，人智有极限；出错是常态，不出错才反常。

### 四柱与六爻的互补关系
| 维度 | 四柱（八字） | 六爻 |
|------|-------------|------|
| **比喻** | 一个“面”，有广度 | 一个“点”，可聚焦放大 |
| **长处** | 定一生大象、行运吉凶、六亲、性情 | 测具体单事、随机事件、比赛、他人他事 |
| **局限** | 难测具体某日某事、他人之事 | 测终身不如四柱精准全面 |
| **建议** | **双修优势互补**，两法有相通之处可互相促进 |

### 新法与老法（传统法）的态度
- **不相互否定**，以长期实践检验使用价值。
- 曲炜体系**基本继承古法**，在传统基础上提高发展；古法经几千年验证，实践准确率高。
- 新法为新生事物，需长期验证，不可凭几卦论成败。

### 辨别歪理邪说的三条经验
1. **自吹成“神”者多欺诈**；真学者谦逊谨慎，成熟谷穗头压得低。
2. **贬低他人、唯我独尊**者心术不正、心虚表现；认可他人优点才显实力。
3. **理论是否符合社会自然规律**；不一致必为歪理。

### 关于“大师高低”与宣传理念
- 术有专攻，如医分内外科，**难分绝对高低**；取长补短，“三人行必有我师”。
- 宣传**实事求是，不包装成“神”**；踏实做人、真诚做事、善待读者，承诺“不满意全额退款”。

### 一卦多断的边界
- 仅能提取**与求测事相关**信息；无关信息（如断学业卦看搬家、祖辈生死）体现不出，说准属巧合。
- 可多断：学业成绩、临场发挥、科目优劣、录取校层次、方位远近等关联信息。

## 二、 基础知识与操作规范

### 摇卦操作细节
- **铜钱选择**：**现代五角硬币最佳**（大小分量适宜，磁场感应现代气息强）；乾隆钱为封建产物，不适应现代社会。
- **正反面定义**：有国徽面为“背”（阴），标“五角”字面为“字”（阳）。
- **意念集中**：心中只想求测之事，无杂念即可；无需等待一分钟、无需数摇动次数、无需分正反面放置。
- **时间限制**：**亥时、子时均可摇卦**；一天中任何时间意念集中皆准。
- **无钱币应对**：特殊情况特殊对待，用**时间卦、报数、来人方位/年龄/衣色**起卦，**宜用梅花易断**，六爻准确率较低。

### 起卦方法的适用性
| 起卦法 | 适用断法 | 说明 |
|--------|----------|------|
| 摇钱卦 | 六爻纳甲法 | 标准流程，信息最全 |
| 时间卦/报数/字划/颜色 | 梅花易数 | 器具不全、环境受限时避繁就简 |
| 字划起卦 | 以对方书写字体笔画为准 | 繁简体不拘 |
| 终生卦闰月 | 按实际归属月数加数 |  |

### 卦象分类与判读原则
- **八纯卦（首卦）**：摇卦得之为**六冲卦**；时间起卦得之为**比和卦**。
- **比和卦**：上下卦五行相同（如乾兑、坤艮），主吉祥，看动爻变卦定吉凶。
- **六冲卦/六合卦/反吟/伏吟/游魂/归魂**：各有特定含义，**吉凶仍以五行生克结果论**，合冲只揭示事成速度或缠绵程度。
- **卦身定法**：以《卜筮正宗》法为准（阴世从午月起，阳世从子月起，数至世爻位）。

### 世应与六亲核心规则
- **世爻**：求测者自己，一卦核心。
- **应爻**：求测之事/对象/他人，一卦中心点。
- **代测卦**：测子女升学/仕途、子女测父母工作、测友人婚姻工作等，**世爻代表被测人**；但测六亲疾病、出行安全属直接测六亲，非代测。
- **真假六亲**：
  - **内六亲** = 本姓直系（父母、兄弟、子女、祖父母、叔伯、未嫁姑姑、兄嫂）。
  - **外六亲** = 外祖、姨/姨父、妹夫/姐夫、姑父、外甥等。
  - **一般不用分真假**；仅在预测**亲属病伤灾、生死大关**时区分。
  - **真六亲** = 本宫内卦六亲；**假六亲** = 本宫外卦六亲（外卦同宫亦为假）。
  - **假变真条件**：真六亲出差在外、外地工作/治病时，以外卦为真。

## 三、 爻位四层次与生克权力体系

> **核心理论来源**：[[qu-wei-liuyao-tezhunban-jiangyi]]、[[liuyao-shizhan-da-quan]]、[[liuyao-lifa-jinjiie-qinglan]]

### 四层次层级与权力
| 层次 | 爻类 | 权力 | 力量来源 |
|------|------|------|----------|
| **第一层次** | **月建、日辰** | **生克权** | 时令之气，月建限当月，日辰贯全年及事未了前 |
| **第二层次** | **变爻**（动爻本位变出） | 生克权 | 前提：对本位动爻**无生克合冲**关系时，方可克主卦他爻 |
| **第三层次** | **动爻**（含暗动） | 生克权 | 旺相有气方有权；休囚、空亡、入墓、被合、被制则失权 |
| **第四层次** | **静爻** | 无生克权 | 值日月仅得第一层次**力量**，无**权力**；不入动爻/变爻之墓 |

> **关键区分**：**权力 ≠ 力量**。值日月静爻有力量无权力，不能冲克动变爻；动变爻亦克不伤值日月静爻。

### 同层次生克顺序
**合冲并列第一 → 刑 → 害 → 无特殊关系生克**（六爻中无特殊关系生克仍须论，四柱一般不论）。

### 跨层次生克铁律
- **上层次绝对制约下层次**；下层次刑冲合害**让位**于上层次。
- 变爻对本位动爻无作用时，始得克主卦他爻。
- 日月合爻为“绊住”，暂失生克权，**不能合化**（日月五行不可改变），须冲日月或冲被合爻解合。
- **争合**（两爻同合日月）只表信息，合力不牢，**仍存生克权**。

### 特殊状态判断
| 状态 | 判断标准 | 生克权 |
|------|----------|--------|
| **临界状态** | 日月一生一克/双休囚（静爻）；双休囚不受克（动爻）；一休一克/连冲带克（变爻） | 看同层动变爻向背生扶定夺 |
| **暗动** | 旺相静爻逢日冲 | 属第三层次，**变爻不作第二层次论** |
| **日破** | 休囚静爻逢日冲 | 无生克权 |
| **动散** | 休囚动爻逢日冲 | 散，失权 |
| **动不散** | 旺相动爻逢日冲 | 不散，保留权 |
| **实空** | 爻逢空亡又逢日冲 | 实，出空有权 |
| **月破** | 动爻月破：当月无用，出月看旺衰；静爻月破：无法补救 |  |

## 四、 刑冲合害深度解析

### 六合成化内幕
- **生合**（寅亥木、辰酉金、午未土）：藏干相生，**极易成化**。
- **克合**（子丑土、卯戌火、巳申水）：藏干相克，**先天不足**，需外力（日月动爻）催化。
- **成化双条件**：
  1. 合爻全动，或日月作第一/二层次合。
  2. **化神真**（日月无克化神五行）。

### 三合局与半合
- **三合成化**：中神（旺神）力量增强，长生/墓库之支性质转化为中神特性，力量被抑制。
- **墓地半合**（午戌火、卯未木、子辰水、酉丑金）：缺长生之支，**难成化**；中神旺则论合局，弱则论入墓。
- **半三合只论生克**，半三会一般不论。

### 六冲胜负逻辑
- **本质 = 生克 + 斥力**；冲力 > 克力。
- **胜负双因素**：
  1. **五行特性**（先天）：水克火(刚胜柔)、火克金(精胜坚)、金克木(刚胜柔)、木克土(专胜散)、土克水(实胜虚) → 子胜午、酉胜卯、申胜寅、亥胜巳。
  2. **时令旺衰**（后天关键）：**当令得气者胜，旺可胜衰**；“金多火熄、水多土流”乃乘旺反侮象。

### 三刑与自刑
- **寅巳申三刑**：含冲(寅申)、合(巳申)、害(寅巳)；**核心看用神有无生克权**，有权不论刑。
- **丑戌未三刑**：全土，**激起土气旺**；丑未先论冲，丑戌论刑。
- **自刑**（辰午酉亥）：**同字叠加力量旺**之象，非四字齐全、非异字相刑。

### 六害谁害谁
| 害组 | 实质 | 受害方 | 吉凶 |
|------|------|--------|------|
| 子未 | 未土克子水 | 子 | 未害子 |
| 丑午 | 午火生丑土 | 午 | 丑害午 |
| 寅巳 | 寅木生巳火 | 寅 | 巳害寅 |
| 卯辰 | 卯木克辰土 | 辰 | 卯害辰 |
| 申亥 | 申金生亥水 | 申 | 亥害申 |
| 酉戌 | 戌土生酉金 | 戌 | 酉害戌 |
> 相生三组：被生方受益、主生方受损；相克三组：受克方受损。

### 入墓与解墓
- **入墓对象**：动爻墓、月墓、日墓；静爻**不入变爻之墓**（同层次）。
- **伏神**亦论月破、日破、入墓。
- **解墓**：**必须冲墓/合墓/值日月**引拔；过月/过日**不自动解**（特例除外）。
- **受克墓爻失权**：墓爻被上层次冲克合伤，静爻不入其墓。

## 五、 用神取象与六神应用

### 用神选取核心原则
- **测吉凶成败** → **以卦内因组合定吉凶**（现在时）。
- **测应期** → **以进行时断**（动爻逢值/合/冲/空/墓等时间节点）。
- **同一事项长短不一**：如测行人，当天回/数月回均有，依预测者意图与卦象定。

### 常用用神对照
| 求测事项 | 主用神 | 参考用神/观察点 |
|----------|--------|-----------------|
| 求财/生意 | **妻财爻** | 子孙爻(源头)、世爻关系、发动爻生克 |
| 官职/求职 | **官鬼爻** | 兄弟爻(竞争)、父母爻(文书)、世爻旺衰 |
| 婚姻(男) | **妻财爻** | 官鬼爻(婚姻证/阻碍)、世应关系 |
| 婚姻(女) | **官鬼爻** | 妻财爻(竞争)、世应关系 |
| 学业/考试 | **父母爻**(文凭)、**官鬼爻**(名次) | 子孙爻(克官鬼)、世爻 |
| 疾病/灾祸 | **官鬼爻**(病灾)、**子孙爻**(药医) | 世爻(自身)、发动爻克世 |
| 失物 | **兄弟爻** | 世爻、应爻、方位 |
| 出行 | **世爻**(自身)、**应爻**(目的地) | 六冲/六合、动爻生克世 |
| 阳宅/风水 | **世爻**(宅/穴) | 父母(房)、妻财(财)、官鬼(灾)、兄弟(损)、子孙(丁) |

### 特殊用神规则
- **父母测子女**升学/工作/婚姻：**世爻代子女**，非不取用神。
- **子孙持世不为福神**之情况：测求官(子孙为忌)、官鬼持世子孙动克世。
- **官鬼持世/生世**不为灾，反为**原神**。
- **鬼伏财下** → **女测婚**有妻在家象。

### 六神生克职能
- 六神依五行对别爻生克，**力量极小，几乎忽略不计**。
- 实战**主看临六神之爻**对其他爻的生克冲合。

### 八卦万物类象提取法
- **依具体求测事提取最贴切信息**，结合社会常理。
- 例：自知违法求得乾卦克世 → 取“公安机关/政府制裁”象，不取“马/老父”象。

## 六、 应期断验实战法则

### 核心应期口诀
| 动爻状态 | 应期触发条件 |
|----------|--------------|
| **动待合** | 用神发动逢合之时 |
| **动逢值** | 用神发动逢值日/月之时 |
| **动逢冲** | 用神发动逢冲之时(如入墓逢冲出) |
| **空待出** | 用神逢空，待出空之日/月 |
| **墓待冲** | 用神入墓，待冲墓/合墓之日/月 |
| **静待动** | 用神静止，待发动之日/月 |
| **衰待旺** | 用神休囚，待旺相之月/日 |
| **合待开** | 用神被合，待冲开之日/月 |
| **退神/进神** | 变爻退/进逢值日/月 |

> **两原则并存时，进行时靠前者为准**。

### 流年卦应期
- **世爻真空** → 全年愿违难益；**非真空** → 可成事，但钱财未到手/进不敷出。
- **起卦月建断吉凶**，**进行时月建看应期**。
- 测短期事(一日内)参**时辰**；测长期事参**流年太岁**。

### 方向与距离
- **中心点**：**求测者所在地址**。
- **求财方向**：以**妻财爻或子孙爻方位**为主，兼顾世爻旺衰。
- **距离单位**：视事物大小远近灵活定夺(米/里/公里)，无固定标准。

## 七、 实战疑难专题精选

### 卦爻旺衰精微差异（地支藏干视角）
> **详见**《六爻答疑》原文第24问详细藏干推演，此处摘要核心结论：
- **生力**：亥水生木 > 子水生木；寅木生火 > 卯木生火。
- **克力**：未土克水 > 戌土 > 辰土 > 丑土(依藏干生克链定)。
- **冲克胜负**：申金冲克寅木 > 酉金克寅木(连冲带克)；酉金冲克卯木 > 申金克卯木。

### 伏神飞神断法
- **飞生伏** = 飞神泄气助伏神(用神) → **吉**。
- **伏生飞** = 用神泄气助飞神 → **凶**。
- **伏空下易出**仍需**冲飞神/冲伏神/值日月**引拔，非自动出。

### 回头克与合并存
- 子水动变丑土：**回头克 + 子丑合**共存。
- 断病逢合凶、出行难动、**合中有克**；吉凶须综合全卦条件。

### 原神日月合住当日应期
- 测当日事，原神与日月合，**当日冲开合之时辰**原神可生用神。

### 天气预测起卦时辰
- 心念动时起卦；测当日天气**依子时起卦为佳**。

### 损卦不主无财
- 细审世爻、财爻旺衰、原忌神生克而定。

### 主互变三阶段
- **主卦** = 现在时(发生)；**互卦** = 中间阶段(发展)；**变卦** = 结局/进行时(结果)。

### 摇卦多卦取准与心情影响
- 同事多卦：**意念最集中那卦为准**。
- 心情不好不影响，**摇卦瞬间意念集中**即准。

### 六爻测风水局限
- **只能在已选目标基础上判吉凶**；**不能无中生有找宝地**。
- 选定目标后摇卦：世爻为穴场，看人/财/官利弊，**属风水学高深知识，慎重断验**。

### 年运/宅运调整物品摆放
- 年运物放卧室，宅运物放屋外；但**山形地貌信息同步**，调理需结合生辰八字、排行全面衡量，**非易事**。

### 寅木克五土月令力度
| 月令 | 寅木克丑土力度 |
|------|----------------|
| 木月、水月 | 力大 |
| 火月 | 土旺相，不克 |
| 土月 | 木休囚，力小不克或微克 |
| 金月 | 木受克，不克五土 |

### 再次摇卦间隔
- 首卦信息**基本定位**；想再测**随时可摇**，信息大致一致。

### 代测范围界定
- **属代测**：测子女升学/仕途/工作、子女测父母工作、测友人婚姻/工作。
- **不属代测**：测六亲疾病(直接测六亲)、测六亲出行安全(看人身能否归)。

### 纯阴纯阳定义
- **纯阳唯乾卦**(六爻全阳)；**纯阴唯坤卦**(六爻全阴)；非两阳卦/阴卦叠加。

### 勾陈青龙发动断验
- **勾陈**：临世发动或临忌神发动克世 → 主军役官司。
- **青龙**：临世/发动主喜事，**但临忌神克世不吉**；六神不直接定吉凶，**生克结果定吉凶**。

### 体用比和与卦象冲
- 乾兑/坤艮属比和，**单卦五行同即比和**；主卦吉祥，看动爻变卦。
- 坤艮方向虽冲，**不影响比和吉祥本质**。

### 暗动变爻层次
- 暗动变爻**不作第二层次**，随卦变而变，**仍属静爻范畴**。

### 找工作/生意项目决策卦
1. 世爻旺相有生克权为本。
2. 应爻为事/单位，生世吉、克世凶。
3. 财爻旺相生世吉。
4. 长期事看子孙爻旺衰。
5. 发动爻对世/财生克关系综合判。
6. **求财方向**：财爻/子孙爻方位，兼顾世爻。

### 测他人阳宅/烦恼喜事
- **阳宅**：世爻为穴，看人/财/官利弊(详《六爻特训班讲义》)。
- **烦恼喜事**：应爻为彼人，旺相生合为喜，休囚刑冲克害为忧；**结合六神参断**。

### 黄道吉日/十二值日实用性
- **民间简易择吉，用处不大**；同一天吉凶因人而异(失主凶、贼喜)。
- **真择吉**：针对个人八字用神，选宝日/意日(日干支生八字用神)，避冲克年月日时干支，**不用纳音**。

### 字划/一字起卦断法
- **写字起卦可用**；笔画以对方书写字体为准；**起卦法决定断法**(梅花易起卦用梅花易断，准确率高于六爻)。

### 学业/培训决策卦
- 世爻旺相无克、有生合 → 利学习。
- 父母爻/应爻(师)动生合世 → 有收获提高。
- 卦凶则守待机会，预测非万能，**正常途径能解决者勿测**。

### 房屋装修完工卦
- 二爻/父母爻为房：旺相生合 = 装好；刑冲克破动 = 未好。
- 完工期：用神逢冲破待合、空待出空、休囚待旺。

### 多爻发动断法
- **不用阳世顺行/阴世逆行**；**看发动爻最终生克到何爻**。

### 真假六亲边界案例
- 《地火明夷》(坎宫)测妹病：内卦兄弟亥水**非真六亲**；内卦有真六亲方可用。

### 卦爻旺衰与生克权关系
- **旺衰是根本因素，影响最大**；空/墓/合/破影响**暂时性**。
- 旺相被合 = **暂失权**，解合复权。

### 构成“制”的条件
1. 月日力量使受克爻一方休囚一方受冲克。
2. 多同五行动爻虽休囚仍构成强力制。
3. 三合局力量达制。

### 归魂/反吟/伏吟/游魂含义
- **归魂**：想变难变，恢复原状。
- **反吟**：事多反复不顺；上卦反外事，下卦反内事；用神不反吟不伤可成。
- **伏吟**：事不遂意，乱/不顺，如病人呻吟，忧虑象。
- **游魂**：变动不定，谋非长远，行人不归，宅多迁变，坟灵不宁。

### 合局成化/月破补救/制的条件
- 已在前文“刑冲合害深度解析”覆盖。

### 找事业/生意无目标摇卦
- **不可盲目无边际摇卦**；应有几个目标逐一测成败利弊。

### 测他人阴阳宅/烦恼检验水平
- 属高深知识，**非一两语可尽**；需系统学习《六爻特训班讲义》风水章节。

### 静爻入变爻墓
- **静爻不入变爻墓**；爻只入**高层次爻之墓**。

### 变爻泄动爻权力判例
- 未土动变申金：申金泄未土，**无生克合冲关系** → 申金得权冲主卦寅木。

### 月合爻解合
- 进行时日月可解，**冲被合之爻**解合(冲月建亦可但非主流)。
