## 索引定位与使用方法

本页把归档文章中的牌阵按牌数组织，作为查阅入口。牌数不是深浅的绝对标准，而是对应不同的提问方式：少牌适合即时、直接、二选一或短时间范围的问题；多牌适合重大转变、关系结构、法律与疾病、人生回顾等复杂议题。原文也强调，不同牌阵适合特定主题和生活领域，每张牌在牌阵中的位置代表疑问的不同层面。

解牌通用顺序是：洗牌时牌面朝下，按顺序翻牌，牌面朝上，一次只解读一张；解完当前牌后再翻下一张，直到解完整个牌阵。若为更了解答案而加牌，也同样先让牌面朝下。开放式牌阵不预设位置牌义，应更重视每张牌插画的含义与自身感受。

选择牌数时可先判断问题类型：

- 要立即得到“是／否”“去／留”“行动／等待”等答案：优先一张牌。
- 要在两个选项、两个日期、两个地点之间决定：优先两张牌；两个都不合适时，可先试加第三张看替代路径。
- 要三选项、过去现在未来、三阶段行动：三张牌。
- 涉及安全、稳定、财产、财务、家庭、房屋与保护：四张牌。
- 涉及改变、传达需求、展现才能、对抗霸凌、投机冒险、旅行计划：五张牌。
- 涉及和谐、谈判、和解、亲密关系、家庭、健康、自信与成长：六张牌。
- 涉及好运、生育、灵性疑问、人生回顾、一周计划或长假：七张牌。
- 涉及重大转变、名誉财富、事业、自主创业、重大决定：八张牌。
- 涉及法律、正义、严重疾病、虐待情境、自由与终结局面：九张牌。
- 错综复杂的问题或未来十二个月概览：十张以上，如凯尔特十字与年轮牌阵。

通用准备物品包括：整副七十八张牌、二十二张大牌、四十张小牌（每种花色一号至十号）、十六张宫廷牌，或大牌加宫廷牌、小牌加宫廷牌等组合。具体牌阵以原文标注为准。相关基础理念、洗切抽牌与伦理边界，参见[[塔罗牌阵基础与解牌流程]]。

## 一张牌

### 适用情境

一张牌适合需要立即解牌、问题直接而明确的时候，尤其是“是或不是”“去或留”“说话或保持沉默”“行动或等待”。也适合特定日期或时间的问题，例如“我什么时候会、我该、我能够……？”若过度思考，或外界证据与直觉不一致，也可用一张牌澄清对某人或某情况的疑问。单张解牌还可作为三张、六张或九张牌阵的第一张牌。

### 位置与代表牌阵

| 牌阵 | 用途或情境 | 位置／结构 |
|---|---|---|
| 当天的牌 | 每日提醒当天该注意的事 | 单张随机抽；答案不明确或当天重要时再加一张 |
| 一个问题 | 任何需要直接回答“是／不是”的简单问题 | 单张；不明确时加一张 |
| 行动、公开声明或全力以赴的时机 | 不确定是否该行动、发言或加把劲 | 二十二张大牌抽一张 |
| 我该采取什么策略 | 有需要解决的问题，但不确定如何处理 | 四十张小牌一至十号抽一张，注意花色与数字 |
| 我最大的优势 | 遇到或预期有好机会，想看清盟友与致胜优势 | 二十二张大牌加十六张宫廷牌抽一张；可与“最大挑战”结合 |
| 我面临的最大挑战 | 有已知或潜在反对者、组织阻碍机会 | 大牌抽一张；与优势牌阵结合时，用第一张确定障碍，第二张看盟友或优势 |
| 考试、驾照测验或面试 | 取得肯定或否定答案，并思考如何让事情更顺利 | 小牌中每种花色只取一至十号，抽一张；答案不明确时放回重洗再抽，而不是多抽一张 |
| 这个人或情况靠得住吗 | 直觉提醒要看清某人的真面目或投资真相 | 针对人用十六张宫廷牌；针对情势用四十张小牌；抽一张 |
| 多久能卖掉房子或谈成生意 | 房子或生意已在市场上却无动静 | 先定时间范围，再用四十张小牌一至十号抽一张 |
| 以后都不会再联络了吗 | 熟人失联，试过改善却被忽视或拒绝 | 七十八张牌抽一张 |
| 该不该搬到向往的地点 | 有機會住到嚮往地點，但搬家意味离开久居之地 | 二十二张大牌抽一张 |
| 新饮食或健身计划能否持久 | 已试过许多方法却效果有限 | 整副牌抽一张 |

### 选择建议

一张牌的关键是“直截了当”。若答案模糊，优先加一张牌，而不是强行解释；时间问题用四十张小牌的一至十号，并先界定几天、几周或几个月。单张牌也可作为更大牌阵的起点或摘要牌。若同一张牌经常出现，可记录在塔罗日记中，并把它当作后续牌阵的第一张牌以扩展解牌广度。

## 两张牌

### 适用情境

两张牌适合匆忙时、需要突破优柔寡断时，或要在两个选项、两个人、两种情况之间做非此即彼的决定。也适合问未来两天、两周或两个月，指出哪两天、哪两个时段适合特殊场合或面试，或哪两个地点适合度假。若两个选项都不合适，答案可能是“等待”；可先在第二张牌右边加第三张，看是否出现替代选项。若愿意结合两种牌义，两项也可能都恰当，只是涉及折衷。

### 位置与代表牌阵

| 牌阵 | 用途或情境 | 位置／结构 |
|---|---|---|
| 继续存钱买房，还是休假出国 | 为第一间房或扩张土地储蓄，但生活失去乐趣 | 为每个选项各抽一张，从左到右解 |
| 创意写作当职业，还是继续正职 | 需养活自己，又担心不投入创作会失去发挥机会 | 整副牌；左右两个选项 |
| 争取重大升迁，还是追求工作外幸福 | 升迁或培训带来更长工时与周末工作，但有美好前景 | 整副牌；左右两个选项 |
| 独立创业，还是与伙伴共事 | 想独立创业，但同事、朋友或家人希望一起创业 | 整副牌；左右两个选项 |
| 名校，还是在职培训学校 | 在两种教育机构或进修课程间选择 | 整副牌；两个以上选项时，每增加一个选项加一张牌，由左往右 |
| 继续长期伴侣，还是与第三者约会 | 长期关系得不到满足，需要刺激又不想分手 | 二十二张大牌加十六张宫廷牌；左右两个选项；必要时加第三张 |
| 重大财务问题找人协商，还是忽略 | 接到债权人恐吓电话或信件 | 二十二张大牌；左右两个选项 |
| 未来两天、两周或两个月的运势 | 短期内会面临重大变化、机遇或挑战 | 二十二张大牌加四十张小牌；按两个时段或两段运势解 |
| 在两个日期之间决定婚礼或家庭庆祝 | 两个日期各有优缺点 | 四十张小牌；左右两个日期；有第三个日期可再加第三张 |
| 在两个场地之间决定家庭庆祝地点 | 价格与设备相似，难以决定 | 二十二张大牌；左右两个场地 |
| 同伴不愿旅行，独自前行还是坚持说服 | 找到合适度假地点，但同伴不想参与 | 整副牌；左右两个选项 |
| 职场被霸凌，辞职还是表达不满 | 害怕上班，人资团队又不愿查明原因 | 二十二张大牌加十六张宫廷牌；左右两个选项 |

### 选择建议

两张牌的重点是“比较”。先明确左边与右边各代表什么，再按顺序解。若有第三个选项，就再加第三张，而不是把两张牌硬套成三项。两个选项都不佳时，先考虑“等待”，或加第三张寻找意想不到的路径；也可以结合两张牌义，寻找折衷方案。

## 三张牌

### 适用情境

三张牌比一张或两张提供更多位置细节，适合三选项、三阶段、过去现在未来，以及开放式叙事。它也能用于具体或简单选择，并指出明确重点。若两个选项都不合适，第三张牌可透露意想不到的路径，或以前遭拒、没想到会发生的事。三张牌还可摆成开放式牌阵：不指定位置，每加一张牌就像人生故事继续发展，第三张可建立解决方案。

### 位置与代表牌阵

| 牌阵 | 用途或情境 | 位置／结构 |
|---|---|---|
| 开放式三张 | 回答任何主题的疑问 | 无指定位置，逐张感受并串联；没把握时可在第二张正上方加第四张作王牌或摘要 |
| 未来三天、三周或三个月概况 | 所选时段重要但有未知因素 | 第一张：有助益的因素或人；第二张：可能阻碍你的因素或人；第三张：结束前可做什么达到预期结果 |
| 过去、现在及未来 | 想从过去经验做规划与改变 | 第一张：需舍弃或已退出生活的事；第二张：目前影响与已存在因素；第三张：行动结果与执行后会发生的事 |
| 重大休闲娱乐支出 | 有机会投入休闲活动且有几种选择 | 第一张：可能是露营车；第二张：可能是游艇；第三张：可能是长途旅行；更多选项加额外牌 |
| 疗愈牌阵 | 医疗检查无大问题，却常感不适与疲惫 | 第一张：必要的生活方式变化；第二张：减轻心理压力；第三张：出乎意料的有益资源或积极投入 |
| 克服爱情关系中的冲突 | 一直为同样问题争吵却未解决 | 第一张：真正潜在问题；第二张：使问题酝酿已久的原因；第三张：克服问题的方式 |
| 搬到新家或新地区 | 不确定正确做法 | 第一张：搬到附近；第二张：搬到外地；第三张：待在原地 |
| 改善财务状况 | 重大支出需紧急资金审查，或收支失衡 | 第一张：最严重的财务漏洞；第二张：获利最高的金融资产；第三张：收支平衡方法 |
| 是什么阻碍你实现目标 | 有计划或抱负，却常遇第一个障碍就失败 | 第一张：你的抱负；第二张：阻挡你的事物或人；第三张：避开障碍的方法 |
| 凝聚力牌阵 | 两边孩子卷入新关系，或有姻亲、祖父母、前任出席的场合 | 第一张：你的家人；第二张：伴侣的家人；第三张：如何让两边家庭聚在一起 |
| 你想尽力达到最佳结果 | 知道即将有不可避免的变化 | 第一张：改变后可能最佳结果；第二张：可能最坏结果；第三张：如何缓和糟糕后果，使最好结果有可能实现 |
| 适应新工作环境 | 了解新工作运作模式与权力关系 | 第一张：谁是我的盟友；第二张：我该提防谁；第三张：刚开始该如何行动或反应 |

### 选择建议

除非牌阵另有说明，三张牌用横排，从左到右，一次翻一张、解一张。若抽到阴郁的宝剑牌，原文提醒这不代表预测灾难，而是反映恐惧；可用另一张牌取代反映恐惧的牌，直到恐惧烟消云散。三张牌也适合扩展两张牌的选择结构：第三张可代表额外考虑、替代路径或解决方案。

## 四张牌

### 适用情境

在西方，“四”是可靠的数字。四张牌对安全、稳定性、财产、财务、家庭、房屋、保护等实际状况和疑问特别有助益。除非牌阵另有说明，使用横排，从左到右，一次翻一张、解一张。

### 位置与代表牌阵

| 牌阵 | 用途或情境 | 位置／结构 |
|---|---|---|
| 开放式四张 | 不指定具体牌义，回答任何问题 | 前三张以开放式三张扩展，第四张以王牌形成答案并结合前三张 |
| 未来一个月 | 规划一个月内机会与挑战 | 第一至第四张分别代表第一至第四周；每周开端解一张，再放回牌组，留意重复牌 |
| 突破恐惧障碍 | 恐惧或恐惧症限制生活方式 | 第一张：真正恐惧原因；第二张：坏事真的可能发生，还是只是担心；第三张：什么使恐惧更严重；第四张：可采取什么行动防止或克服恐惧 |
| 财产或事业进展 | 买不起梦想房屋，或创业资金不足 | 原文以例子呈现，未列固定位置；例中权杖六为目标与六个月内可能实现、权杖四为住处让步、权杖七为土地范围、钱币三为三年分阶段自建 |
| 人生旅程 | 想了解更长远的人生之路 | 第一张：现在身份与阶段；第二张：谁或什么能帮助你；第三张：谁或什么会阻碍你；第四张：即将或能够成为什么样的人 |
| 对抗债务 | 债务与还款压力越来越大 | 第一张：最主要财务负担；第二张：可减少款项的实用资源；第三张：短期如何赚更多钱；第四张：如何防止同样问题再发生 |
| 克服坏运气 | 卡在一个接一个不幸的恶性循环 | 第一张：最初厄运的原因；第二张：如何突破厄运循环；第三张：如何吸引好运气；第四张：什么意外因素能延续新的好运气 |
| 二十四小时预测 | 未来有一个十分重要的日子 | 第一张：醒来或天亮时，早上会发生什么；第二张：中午或休息时，还需努力的方向与警告；第三张：黄昏、傍晚或回家时，实现了什么目标；第四张：睡前或半夜，当天全面评估 |
| 世界旅游四角式 | 计划环游世界或到新地方长途旅行 | 第一张：准备好迎接大冒险了吗；第二张：该独自去还是找同伴；第三张：只旅行还是边旅行边赚钱；第四张：旅途中绝不能错过什么 |
| 名声与财富 | 有成名梦想与才华，但怕失败 | 第一张：有什么特殊才能；第二张：该不该不遗余力发挥才华；第三张：如何获得必要培训；第四张：可在哪里或如何公开推销自己 |

### 选择建议

四张牌适合“实际落地”的问题。若想把开放式三张收束成答案，第四张可作王牌总结；若是时间型牌阵，如未来一个月或二十四小时，则按周或按时段逐张解，并注意牌组放回后可能抽到重复牌。涉及财产与事业进展的牌阵，原文以案例示范，未给出统一位置表，使用时不宜硬套固定位置。

## 五张牌

### 适用情境

五张牌适合快速又有明确目标时，也适合更复杂状况下的过渡期。原文特别指出，改变、传达需求、展现才能、战胜欺诈、霸凌与恶意等疑问适合五张牌；财务上的失而复得、投机与冒险、旅行计划，以及从不顺利局面中挽回有利部分并积极向前，也适合五张牌。

### 位置与代表牌阵

| 牌阵 | 用途或情境 | 位置／结构 |
|---|---|---|
| 培养通灵能力的五个步骤 | 别人说你有通灵能力，但你觉得发展受限 | 第一张：目前能力如何展现在生活中；第二张：什么阻碍发展；第三张：是否需透过阅读、上课加强；第四张：希望发展到什么程度；第五张：想成为专家帮助别人，还是用天赋改善生活 |
| 马蹄形牌阵 | 可回答任何问题，有几项因素发挥影响力时 | 第一张：选择、困境或主要疑问；第二张：影响目前职位的势力、人及境遇；第三张：潜在影响，包括过去讯息与视野外事物；第四张：建议行动；第五张：可能结果 |
| 五芒星牌阵 | 想谋求更高职位或展现才能 | 第一张：最终目标；第二张：如何让本人或工作引起能帮助提升形象者注意；第三张：下一步培养动力；第四张：努力达到巅峰；第五张：未知因素 |
| 应付派系斗争和霸凌 | 在办公室或社交场合被排挤、酸言酸语或羞辱 | 第一张：谁最明显排斥我，或什么最显得格格不入；第二张：动机；第三张：能或应该忽略吗；第四张：应表达不满或直接面对吗；第五张：应设停损点离开吗 |
| 五年的计划 | 为生活中任何事情制定长期计划 | 第一张：现在处于哪个阶段；第二张：五年后想达到的位置；第三张：需要哪些额外资源、培训或实习；第四张：需克服哪些潜在挑战；第五张：为远程目标，现在应扩大业务、展开新活动还是维持现状 |
| 收购牌阵（原文标题缺失） | 收购不可避免，想了解影响与应对 | 第一张：收购对我有好处吗，是什么；第二张：该不该换职务作预防；第三张：收购时如何尽量保护职位或部门；第四张：应培养哪些新技能；第五张：错过了哪些情报 |
| 搬迁牌阵（原文标题缺失） | 为工作搬迁，或因家人伴侣搬家而被迫迁徙 | 第一张：有其他可行办法避免搬迁吗；第二张：搬迁缺点及如何大幅减少；第三张：搬迁对本人或家庭的好处；第四张：新地点有不能妥协的方面吗；第五张：愿意在哪方面让步 |
| 每周五天工作日 | 一般公司上班或自己创业，提前计划一周 | 第一张：下周想达成什么目标；第二张：需避开哪些预期挑战或陷阱；第三张：可能或即将出现的新机会；第四张：需给谁留下好印象；第五张：根据本周实现目标，下周该有什么打算 |
| 需要寻求其他资金来源 | 无法取得金援，出现现金流或资源危机 | 第一张：谁或什么资源能帮助；第二张：能自行处理吗，如何处理；第三张：有无新官方来源，行得通吗；第四张：有无非官方来源，可靠吗；第五张：理想结果 |

### 选择建议

五张牌适合“有明确目标但过程复杂”的过渡问题。它比四张更能展开行动步骤，又不像六张以上那样需要处理过多层次。遇到霸凌、派系斗争或收购等权力议题时，五张牌可把“动机—应对—停损”分开看；但若涉及法律、严重身心风险或重大组织变动，也应同时参考九张牌与专业意见。

## 六张牌

### 适用情境

六张牌能详细探讨如何循序渐进设计有组织的解决方案。若困境或机会涉及密切相关、相互依赖的不同层面，这种牌阵具有足够灵活性。原文特别列出和谐、谈判与和解、家庭事务、爱情、婚姻、忠贞、生育、友谊、自我形象、健康与体能、自信，以及其他关于成长和环境的疑问；也可评估未来六天、六周或六个月的情况。

### 位置与代表牌阵

| 牌阵 | 用途或情境 | 位置／结构 |
|---|---|---|
| 开放式六张 | 回答任何主题，像说故事一样逐步揭晓答案 | 无固定位置；逐张结合感受与图像；第六张时答案揭晓；牌上人物多代表你或影响问题的人 |
| 维持远距离恋爱 | 自己或伴侣离家工作，或迫于情势暂时分居 | 第一张：信任或关系稳定足够吗；第二张：有明确长期计划尽快在一起吗；第三张：能一起度过异地恋，或重排见面时间表吗；第四张：能透过网络或电话设日常互动时段吗；第五张：能事先讲好如何调整误解或缺乏交流吗；第六张：各自有丰富嗜好与可靠社交圈，避免孤独陷阱吗 |
| 我能找到灵魂伴侣吗 | 对寻找理想伴侣感到绝望；心形牌阵 | 第一张：该不该放弃寻找顺其自然；第二张：该不该网络交友或参加联谊；第三张：该不该加入面对面交流或单身团体；第四张：该不该参加新活动；第五张：该不该搬迁或换工作；第六张：会遇到另一半或为对的人稳定下来吗 |
| 应付难缠家人或熟识同事 | 如何应付很难相处的人 | 第一张：麻烦起因；第二张：他对所有人都难和睦，还是只把怨气宣泄在我身上；第三张：如何避开他的心机或操纵；第四张：什么正向情绪或活动能培养更愉快关系；第五张：我的态度该更强硬、更不宽容吗；第六张：该不该断绝联系 |
| 未来六周或六个月 | 预测六周或六个月，制定策略、迎接挑战、避开陷阱 | 第一张：希望实现什么目标；第二张：在寻找哪些明确机会；第三张：担心哪些挑战；第四张：希望哪些方面维持不变；第五张：想改变什么或改变谁；第六张：长远在追求什么 |
| 克服羞怯、变得更受欢迎 | 想交朋友但太害羞，不敢接近别人 | 第一张：羞怯是否破坏社交或职业，或其实享受独处；第二张：别人跟我说话时最害怕什么阻挡接近或回应；第三张：需要专业协助，还是可靠自己克服；第四张：可采取哪些初步措施；第五张：跟谁相处最自在；第六张：在什么情况下能放松练习社交 |
| 谈判与调解 | 家庭或朋友争吵，也可修补伴侣不和睦 | 第一张：什么或谁是阻碍争端解决的症结；第二张：有相关证据，还是太意气用事或擅自揣测；第三张：其他人或对方是否准备妥协；第四张：我愿意妥协或提出折衷吗；第五张：什么不该忽略或不该接受；第六张：哪方面有办法解决，哪方面难以解决 |
| 他是真诚朋友还是虚假朋友 | 揭露一个人的真实自我，也适用于爱情、成功、财富及名誉 | 第一张：什么原因让我质疑他的忠诚；第二张：内心疑虑是否因为担心自己不讨喜；第三张：我们和其他人在一起时，他让我不自在或被冷落吗；第四张：他曾出卖别人秘密吗；第五张：这段关系中我付出比得到更多吗；第六张：如果我遇到麻烦，他愿意帮我吗 |

### 选择建议

六张牌适合需要“分层推进”的关系与成长议题。它能把信任、计划、沟通、外部影响、行动与结果拆开，尤其适合远距离恋爱、谈判调解、真假朋友、家庭摩擦与自信问题。若问题只涉及两个选项，不必用六张；若涉及密切相关的多个层面，六张比少牌更能呈现结构。

## 七张牌

### 适用情境

“七”在神秘传统中很特别，对应七个古老行星、七种彩虹颜色、七个主要脉轮或体内通灵能量中心，以及一周七天。七张牌能深入解读影响核心的问题，又不会像更多牌那样资讯过量。原文特别提到海外旅游或长途旅行、好运气、生育（尤其不容易怀孕）、神秘或灵性疑问、人生回顾，以及分辨切实可行的目标和不切实际的梦想。

### 位置与代表牌阵

| 牌阵 | 用途或情境 | 位置／结构 |
|---|---|---|
| 有两个选项的牌阵 | 有两个主要选项，需判断何者最有利；也可用于两个以上选项 | 第一张：要做的选择可能与自觉疑问不同；第二、四、六张：选项一的建议行动、意外状况、可能结果；第三、五、七张：选项二的建议行动、无法预料状况、可能结果 |
| 七张牌的脉轮或能量中心牌阵 | 重大人生回顾，重新评估人生之路 | 第一张：海底轮，现在位置；第二张：本我轮，最渴望的事；第三张：太阳轮，最大强项与优势；第四张：心轮，心声是什么；第五张：喉轮，最想和世界或重要的人分享什么、说什么；第六张：眉心轮，潜在天赋（特别与心灵有关）；第七张：顶轮，想达到什么位置、实现什么目标 |
| 神秘的七张牌牌阵 | 心灵或精神方面疑问，或信息尚未得到、被刻意隐瞒 | 开放式；最后翻到的第七张揭露即将发生或被隐瞒的事，并为困境解惑 |
| 获得好运气牌阵 | 冒险活动部分仰赖运气，或生活各方面需要幸运机遇 | 第一张：哪方面最需要好运；第二张：好运何时来、从哪来；第三张：什么或谁阻碍拖延好运；第四张：好运会在哪方面出现、如何出现；第五张：如何让好运更快到来；第六张：谁或什么能帮助；第七张：通往未来好运的秘诀 |
| 七天牌阵 | 提前计划重要的一周，或了解未来七天概况 | 第一张：星期日，前置作业与准备；第二张：星期一，潜在趋势或因素；第三张：星期二，需要哪些优势或争取什么；第四张：星期三，查核事实数据或观察表里不一；第五张：星期四，展现领导权威或专业知识；第六张：星期五，应付情绪问题或谈判；第七张：星期六，巩固收益、评估和减少损失 |
| 长假、公休或特休牌阵 | 计划长期旅行，又担心离开生活状态太久 | 第一张：现在是否适合展开大冒险；第二张：如何准备资金、是否边休假边工作；第三张：能否不破坏职涯而暂缓未来规划；第四张：出发前制定明确行程，还是途中观察新机会；第五张：如何与关心的人保持联系、是否有人同行；第六张：真正需求是新地方，还是从目前生活抽离；第七张：这是否重大转捩点，回来后能否踏上不同道路 |

### 选择建议

七张牌适合“核心问题＋多阶段行动”的议题。两个选项牌阵把两排路径并置，能看出行动、意外与结果；脉轮牌阵适合整个人生回顾；七天牌阵适合把一周按日子拆解。原文常为七张牌指定满月、星期一晚上或月相时机；若时间不许可，可按问题性质选择，但不宜忽略牌阵原有的时机提示。

## 八张牌

### 适用情境

八张牌在重要性或复杂度上都适合重大事件，使用时不该操之过急。它可用于重大转变、生活变迁、人生回顾、成功、名誉、财富、事业、自主创业、获胜、自由，以及拓展各方面视野。当受到掌权者、顽固守旧组织或官方机构威胁，或需要对抗社区邻居敌意时，也可使用，并可一并参考九张牌。

### 位置与代表牌阵

| 牌阵 | 用途或情境 | 位置／结构 |
|---|---|---|
| 克服强权或组织恐吓的八个步骤 | 情势不利，担心被击垮；八边形阵形，每张牌朝中心靠拢 | 第一张：谁或什么组织设法击垮你；第二张：肇事者动机或实权；第三张：你有什么证据支持自己；第四张：谁会支持你；第五张：能或应该离开，还是继续战斗；第六张：威胁者有什么弱点或缺陷；第七张：可用哪些积极宣传或曝光机会巩固志业；第八张：理想结果 |
| 你们应该试着生孩子吗 | 生理时钟运作，衡量生孩子利弊与生活方式改变；也适用于重大利弊问题 | 第一张：现在想要孩子，还是未来才想要；第二张：若尝试，多快能怀孕；第三张：有孩子后自由或财务最大损失；第四张：组成家庭最大收获；第五张：有孩子后如何维持彼此吸引力；第六张：本人或配偶如何改善健康提高受孕机会；第七张：新生儿带来哪些实际生活方式变化；第八张：该顺其自然吗，这样会降低机会吗 |
| 一周七天加一张 | 寻找日常策略确保未来一周结果，并看策略后的较长期发展 | 第一至七张分别对应星期日发展新策略、星期一预期别人反应、星期二实施行动、星期三检查细节并找可信任者、星期四主动带头、星期五妥协谈判、星期六评估有效与重试舍弃；第八张：采用策略后未来几周的新机会或可挽回机会 |
| 做出孤注一掷的决定 | 重大或复杂决定，答案只有是／不是、行动／等待、离开／留下、说话／沉默 | 第一张：这是真心想要的吗；第二张：做出后会有严重不利后果吗；第三张：准备好全心投入吗；第四张：其他优先事项与承诺怎么办；第五张：生活方式会更好吗；第六张：能不伤害别人或不离开在乎的人而做到吗；第七张：最棒结果；第八张：最糟结果 |
| 开始实现最大的抱负或梦想 | 机会开启通往渴望契机，即使知道这条路有破坏性 | 第一张：这是等待的契机吗；第二张：这步切实可行吗；第三张：准备好了吗，还没的话何时准备好；第四张：谁或什么能帮助；第五张：谁会反对或什么会阻碍；第六张：应调整梦想或让步以降低破坏性吗；第七张：短期结果（未来六个月）；第八张：长期结果（未来五年） |
| 从事或拓展大型商业冒险 | 有准备执行的计划却踌躇不前 | 第一张：现在有足够精力或适当��机执行，还是应等待；第二张：计划行得通吗，有什么风险；第三张：应单独行动、邀请伙伴或寻求多元意见；第四张：计划实施的最大优势；第五张：有无需考量的对手或类似业务；第六张：现在行动后三到六个月前景；第七张：现在行动后十二个月及更长远情况；第八张：忽略了哪些注意事项 |

### 选择建议

八张牌用于“不能轻率”的重大议题。若问题涉及权力压迫、组织恐吓或社区敌意，八张牌能把对手动机、证据、支持者、战斗或离开、宣传曝光与理想结果拆开；若涉及个人抱负与创业，则同时看短期与长期结果。原文提醒八张牌不该操之过急，适合在时间与心理空间充足时使用。

## 九张牌

### 适用情境

九张牌提供深入研究和冷静反思的机会，适合全面人生回顾与正义议题，包括法律、官方制度或个人道德。也适用于继承纠纷、完成项目、终结不满意的情况、从艰难情境中找解决办法、国际议题、严重疾病或慢性病。

### 位置与代表牌阵

| 牌阵 | 用途或情境 | 位置／结构 |
|---|---|---|
| 自由之塔 | 想摆脱不再快乐的事，却不敢放手；九张牌往上斜排成塔形 | 第一张：寻求什么自由或独立，以何种方式追求；第二张：什么或谁限制自由；第三张：现在时机合适，还是应等待；第四张：通往自由或独立的第一步；第五张：实现后对本人或家庭的直接正面影响；第六张：迈向自由初期需克服的反对或障碍；第七张：为实现自由必须牺牲什么；第八张：六到十二个月内新自由状态的长期正面影响；第九张：踏上这条路后五年内能达到什么位置 |
| 逃离虐待或有害情境 | 感到无助且知道自己需要离开现场；也适用于改变人生事件、重大人生回顾或需要奇迹的情况 | 第一张：关于自我和风险；第二张：处理恐惧感、阻碍你的有害侮辱情形或人；第三张：可采取的行动；第四张：谁会拯救或帮助你；第五张：什么使你犹豫；第六张：第一步；第七张：迈出第一步的风险；第八张：还必须考虑谁或拯救谁；第九张：新生活开端 |
| 克服或处理严重疾病或慢性病 | 康复变慢或恶化时 | 第一张：病情最糟局面是什么；第二张：有其他传统疗法吗；第三张：替代医疗或能量疗法能减轻症状吗；第四张：有无新研究报告，哪里取得；第五张：有哪些可实施方法让生活好过一点；第六张：如何尽量减少压力；第七张：有哪些不明积极因素开始起作用；第八张：可申请或取得哪些额外资源；第九张：可能最好结果是什么 |
| 官方、法律或赔偿牌阵 | 任何官方、法律或赔偿问题，尤其不公平、贪汗或谎言阻碍去路 | 第一张：什么或谁造成不公平；第二张：什么或谁阻挡揭露真相；第三张：对手弱点；第四张：你的最大优势；第五张：有无意外新实情或证据对你有利；第六张：可做得更多还是应等待；第七张：有不錯代理人吗，还是需找新的；第八张：能或应在庭外和解或找人调解吗；第九张：理想结果 |
| 神谕占卜 | 一般人生回顾，或重要职涯与爱情问题；牌卡组成三乘三，每排主题不同 | 第一排：目前人生道路、关系或职涯——过去事件与教训、目前症结疑虑、最想保留的部分；第二排：外界影响——有益方面与人、潜在反对意见、为积极改变必须克服什么；第三排：行动与结果——建议行动、短期结果、长期结果 |
| 开放式九张 | 逐步建立完整情景，回答任何疑问 | 无固定位置；逐张建立故事；第九张仍无头绪时，可加第十张作王牌 |

### 选择建议

九张牌适合“需要冷静看清全貌”的议题，尤其是法律、疾病、虐待、自由与人生回顾。神谕占卜的3×3结构把人生道路、外界影响、行动结果分成三排，适合一般人生回顾与重要职涯爱情问题；官方法律牌阵则把对手、证据、代理人、调解与理想结果分开。涉及医疗、法律与安全风险时，牌阵用于梳理问题与行动方案，不宜取代专业判断；伦理边界参见[[塔罗牌阵基础与解牌流程]]。

## 多张牌

### 适用情境

第十章精选十张以上牌阵，包括十一张凯尔特十字牌阵，以及用于了解未来十二个月详细情况的年轮牌阵。牌数较多时，可使用两副相同牌组，从每副牌面朝下的牌组中轮流抽牌。原文提醒，这类牌阵适合错综复杂的问题、挑战、机遇及深入人生回顾。

### 凯尔特十字牌阵

凯尔特十字是复杂性上的“终极塔罗牌阵”热门版本，以凯尔特十字形状命名，适合解决错综复杂的问题。原文建议先在薄硬纸板上画好位置，练习时把牌放在各位置；先注意整体牌阵，观察如何从第一张进展到第十一张。发第一至第十一张后，依序翻开三个区域，解完一个区域再翻下一个区域；全部解完后，观察各区域如何拼成整体局面与答案。

| 区域 | 位置 | 含义 |
|---|---|---|
| 第一区：解牌中心 | 第一张 | 解牌的事件脉络，即提出问题的原因与引导解牌的潜在问题 |
| 第一区：解牌中心 | 第二张 | 目前的实际问题，或需透过解牌解决的议题 |
| 第一区：解牌中心 | 第三张 | 潜在障碍或相关情况，包括当事人不愿改变现状、他人使情况艰难，或生活即将受变化影响的人 |
| 第二区：周围区块 | 第四张 | 务实考量、问题根源，包括财务、家庭、日常事务或责任如何影响问题 |
| 第二区：周围区块 | 第五张 | 对照现实与假象，代表事件主题，从可达成梦想中区分愿望实现与错觉 |
| 第二区：周围区块 | 第六张 | 出乎意料，将看似没有希望的局面扭转成实际可能性；牌阵中最具预测特性 |
| 第二区：周围区块 | 第七张 | 感受牌，代表真实欲望与梦想，以及身边人可能带来的困惑信息 |
| 第三区：通往幸福 | 第八张 | 建议的行动，为解决或寻找解决办法而开始行动 |
| 第三区：通往幸福 | 第九张 | 有益的影響，与第三张的障碍抗衡，使行动或决定更可能成功的人或情况 |
| 第三区：通往幸福 | 第十张 | 短期的结果，制定计划或做出不同决定后的最初结果，有时会让人苦苦挣扎 |
| 第三区：通往幸福 | 第十一张 | 长期的结果，最可能发生的结果，也可能暗示解决方法 |

### 年轮牌阵

归档文章在“未来十二个月的年轮牌阵”处仅见标题与图示，未继续展开位置说明。本页只登记其索引位置：它用于了解未来十二个月的详细情况；具体位置释义待原文补全后再扩展，不在此虚构。

### 选择建议

十张以上牌阵适合时间充裕、问题确实复杂的情况。凯尔特十字把“事件脉络—实际问题—潜在障碍—务实根源—现实与假象—意外因素—感受—行动—助力—短期—长期”分成三区，适合挑战、机遇与深入人生回顾。解牌时按区推进，避免一次被十一张牌淹没；最后再回看整体拼合。若只想快速决定，不必使用多张牌；若问题牵涉多重因果与长期后果，多张牌的结构化位置更有帮助。
