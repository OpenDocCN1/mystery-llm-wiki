# 北歐神話概觀

北歐神話是流傳於斯堪的那維亞半島（挪威、瑞典、丹麥）及冰島等地的神話體系，其核心文獻為13世紀冰島詩人**史諾里·史特盧森**所著《散文愛達》（又稱《史諾里愛達》）與17世紀發現的《王室抄本》所收錄古詩群《詩歌愛達》。這套神話以**世界樹伊格德拉西爾**連結**九大世界**，講述阿薩神族與巨人族的衝突、諸神在「諸神黃昏」中毀滅重生的史詩。本頁依池上良太《圖解北歐神話》結構，整理宇宙觀、神祇譜系、核心神話與信仰演變，並建立與盧恩符文、元素魔法等相關頁面的交叉引用。

## 核心文獻與傳承

| 文獻 | 性質 | 關鍵說明 |
|------|------|----------|
| **《詩歌愛達》** | 古詩抄本群 | 17世紀發現《王室抄本》，收錄史諾里引用的古詩；學界亦稱「愛達神話」 |
| **《散文愛達》** | 詩歌入門書 | 史諾里·史特盧森編纂，系統化神話、隱喻與詩律 |
| **《日耳曼尼亞誌》** | 羅馬史料 | 塔西圖斯（約西元100年）記載日耳曼早期信仰，對應奧丁、提爾、索爾 |
| **《漢堡大主教史》** | 中世紀教會史 | 不來梅祭司亞當（11世紀）記載烏普薩拉信仰中心與三大神（奧丁、索爾、弗雷） |
| **薩迦文學** | 冰島散文傳說 | 保存後期口傳傳統，補充神話細節 |

> **術語釐清**：古諾爾斯語為1150–1350年通行於冰島的北日耳曼語，亦稱古冰島語；《愛達》原文多以此語書寫。

## 宇宙觀：九大世界與世界樹

北歐宇宙由**九大世界**與**世界樹伊格德拉西爾**構成，垂直軸向上為阿斯神域、中層為人類世界、下層為冥界與原初極地。

### 九大世界速覽

| 世界 | 原文 | 住民/特徵 | 關鍵地標 |
|------|------|-----------|----------|
| **阿斯神域** | Ásgarðr | 阿薩神族 | 格拉德海姆（男神殿）、瓦爾哈拉（英靈殿）、比弗洛斯特（彩虹橋） |
| **華納海姆** | Vanaheimr | 華納神族（豐饒/自然） | 諸神黃昏後倖存 |
| **米德加爾德** | Miðgarðr | 人類 | 由伊米爾睫毛圍成柵欄，受索爾庇護 |
| **約頓海姆** | Jötunheimr | 霜巨人/火巨人 | 密米爾之泉、埃利伐加爾毒河、鐵林 |
| **阿爾夫海姆** | Álfheimr | 光精靈（白妖精） | 弗雷乳牙禮物，疑在天界（維茲布拉茵） |
| **斯瓦爾特阿爾夫海姆** | Svartálfaheimr | 暗精靈/矮人 | 地底世界，技藝精湛鑄造寶物 |
| **尼弗海姆** | Niflheimr | 極寒霧國，原初世界 | 赫維爾蓋爾米爾泉（眾河源頭）、尼德霍格啃咬樹根 |
| **尼福爾海姆** | Niflhel | 死者國度 | 海爾統治，病逝/老死者歸處，吉歐爾河、加爾姆把守 |
| **穆斯貝海姆** | Múspellsheimr | 烈焰原初世界 | 蘇爾特統治，諸神黃昏率火巨人焚世 |

> **空間關係**：尼弗海姆（北/下）與穆斯貝海姆（南/上）對立，兩界氣流匯流於**金倫加鴻溝**誕生原初巨人伊米爾與母牛奧德姆拉。

### 世界樹伊格德拉西爾

- **名義**：「伊格（奧丁）之馬」，巨大**梣樹**，枝葉覆蓋九世界。
- **三根主根** 分別伸向：阿斯神域（烏爾德之泉）、約頓海姆（密米爾之泉）、尼弗海姆（赫維爾蓋爾米爾）。
- **守護者**：諾恩三女神（烏爾德、薇兒丹蒂、斯庫爾德）以白泥澆灌樹根延緩腐朽。
- **棲息生物**：
  - 樹頂老鷹（雙眼間停立小鷹，常視同赫拉斯瓦爾格爾）
  - 松鼠拉塔托斯克（在鷹與尼德霍格間傳遞惡語）
  - 四公鹿（達因、德瓦林、杜涅爾、杜拉索爾）啃食嫩葉
  - 尼德霍格（有翼黑龍）率毒蛇群啃咬尼弗海姆樹根
  - 烏爾德泉畔雙天鵝（白鳥始祖）
- **終局**：諸神黃昏時被「蘇爾特的親戚」（解釋為芬里爾或火焰）吞噬。

> **交叉引用**：世界樹原型在多文化中出現，參見 [[土元素神話存有與土元素神明#世界之軸]]、[[火系神話存有與火元素神明#神話火鄉]]。

## 創世與早期神話

### 原初誕生
1. **金倫加鴻溝** 深淵中央，熱風融霜 → **伊米爾**（原初巨人、霜巨人始祖）與 **奧德姆拉**（母牛）誕生。
2. 奧德姆拉舔鹽霜塊 → **布利** 出現。
3. 布利之子 **波爾** 娶霜巨人女貝絲特拉 → 生 **奧丁、維利、維** 三兄弟。

### 造世
- 奧丁三兄弟殺伊米爾 → 以屍體造世界：
  - 血 → 海洋填滿深淵
  - 肉 → 大地
  - 骨 → 山脈、牙齒 → 岩石、髮 → 樹木、腦 → 雲霧
  - 顱骨 → 天空，四矮人（諾爾德里、蘇德里、奧斯特里、韋斯特里）支撐四角
  - 穆斯貝火花 → 日、月、星辰
- 以伊米爾睫毛圍成 **米德加爾德** 保護人類。
- 世界中央築 **阿斯神域**。
- 海邊漂流木造首對人類 **阿斯克爾與埃姆布拉**（奧丁賜氣/命、維利賜智、維賜貌/感官）。

### 華納戰爭與阿斯神域城牆
- **魔女古爾維格**（「黃金戰爭」化身）三度死而復生，腐蝕阿薩神族慾望 → 引發 **阿薩-華納戰爭**。
- 和議：雙方交換人質。阿薩派海尼爾、密米爾往華納；華納派尼奧爾德、弗雷、弗蕾雅往阿薩。華納殺密米爾送首級，奧丁以草藥防腐保留首級諮詢智慧。
- **城牆建造**：巨人鐵匠以弗蕾雅、日、月為價碼半年建牆。洛基變公馬誘走母馬 → 鐵匠現巨人真身被歸來的索爾擊殺。阿薩得牆但背負違約罪名。
- **洛基產下八腳馬斯萊普尼爾**（由母馬所生）。

## 諸神黃昏與世界重生

### 諸神黃昏序曲
- 巴爾德爾死後世界加速毀滅：戰亂頻仍、日月被狼吞（斯科爾吞日、哈蒂吞月）、大地震動。
- 盜賊時代、斧劍時代、風狼時代、世界崩解。

### 維格利德決戰
| 神祇/陣營 | 對手 | 結果 |
|-----------|------|------|
| 奧丁 | 芬里爾 | 遭吞噬 |
| 維達 | 芬里爾 | 踏顎裂口殺狼（為父報仇） |
| 索爾 | 耶夢加得 | 殺蛇，退九步死於劇毒 |
| 提爾 | 加爾姆 | 同歸於盡 |
| 海姆達爾 | 洛基 | 同歸於盡 |
| 弗雷 | 蘇爾特 | 因無劍戰敗 |
| 蘇爾特 | — | 釋放火焰焚毀九世界，大地沉海 |

### 世界重生
- 大地自海中重現，綠意盎然、無需耕種自產穀物。
- 索爾之子 **馬尼、莫迪** 繼承雷神之鎚；奧丁之子 **維達、瓦利** 及復活的 **巴爾德爾、霍德爾** 會於阿斯神域舊址（伊達平原）。
- 太陽女兒接替母職照耀新世。
- 人類始祖 **利夫、利夫特拉西爾** 藏身霍德彌爾森林倖存，繁衍新人類。
- 新世界無憂患、無邪惡，唯喜樂與純真。

## 神族體系

### 阿薩神族——統治與戰爭
- **核心**：奧丁（主神）、弗蕾雅（正妻）、索爾（雷神）、提爾（戰神/法庭）、海姆達爾（守橋神）、巴爾德爾（光明）、布拉吉（詩神）、伊登（青春蘋果守護）等。
- **特徵**：食伊登金蘋果保持青春，非不死，可戰死。《散文愛達》列舉12–14位主神，含華納質子尼奧爾德父子與巨人血統洛基。
- **職能**：主權、祭祀、魔法、法律、知識、暴力、戰鬥；民間祈求極廣，超越分類。
- **外傳版本**：《丹麥人的業績》《挪威王列傳》將阿薩描述為擅長魔法的東方人類王族（特洛伊/拜占庭後裔）北遷建立統治。

### 華納神族——豐饒與自然
- **核心**：尼奧爾德（海/富足）、弗雷（豐收/和平）、弗蕾雅（愛/戰/魔法/塞伊德女主人）。
- **特徵**：掌管農作、生育、財富、塞伊德巫術；弗蕾雅將塞伊德傳授奧丁。
- **關係**：華納戰爭後以質子身份融入阿薩，弗蕾雅在阿斯神域擁有弗爾克凡格殿，分配半數戰死者。

### 巨人族——混沌與對立
- **分類**：霜巨人（約頓海姆）、火巨人（穆斯貝海姆）、女巨人（常與神通婚）。
- **關係**：神話始祖伊米爾為巨人；奧丁母親貝絲特拉為巨人女 → 奧丁半巨人血統。神巨通婚頻繁（索爾母約爾德、維達母格里德、弗雷妻格爾德等）。
- **本質**：非單純邪惡，代表原始自然力量與熵增；諸神黃昏由巨人軍團發動。

## 主要神祇檔案

### 奧丁 —— 獨眼全父
| 屬性 | 內容 |
|------|------|
| **神格** | 戰爭/死亡、知識/詩藝、塞伊德/符文魔法 |
| **標誌** | 獨眼、寬帽藍袍（人間）、黃金甲（神界）、永恆之槍、黃金戒特勞布尼爾、八腳馬斯萊普尼爾、雙狼弗雷基/蓋里、雙烏鴉胡金/穆寧、密米爾首級 |
| **核心神話** | 獻眼換密米爾泉智慧、世界樹倒掛九夜得魯納符文、奪詩蜜酒、化身流浪者蒐集英靈、為巴爾德爾死生子瓦利復仇、諸神黃昏戰芬里爾亡 |
| **性格** | 極度貪知、善謀多詐、善變庇佑（瓦爾基麗決定勝負）、挑起戰亂蒐羅英靈 |
| **女性關係** | 正妻弗蕾雅、愛人弗蕾雅（有爭議）、巨人女古德倫（得詩蜜酒）、琳德（生瓦利）、比林女兒（被拒）等 |
| **交叉引用** | [[盧恩符文核心體系#奧丁獻眼取符文]]、[[盧恩符文24符文詳解#安蘇茲]] |

### 索爾 —— 紅鬍雷神
| 屬性 | 內容 |
|------|------|
| **神格** | 雷電/天候/農耕、人類守護者、奴隸死後統治者 |
| **標誌** | 紅鬍、嵌額磨刀石、雷神之鎚、鐵手套、力量腰帶、雙山羊拉車（坦格尼斯特、坦格利斯尼爾）、殿邸畢爾斯基爾尼爾（540廳） |
| **核心神話** | 東征巨人國（烏特加爾洛基、蓋爾羅德、希米爾）、奪回被盜鎚（斯裡姆婚禮）、與耶夢加得三度交鋒（釣魚、烏特加爾假象、諸神黃昏同歸於盡） |
| **家族** | 妻希芙（金髮被洛基剃後換金髮）、妾雅爾恩薩克薩（生馬尼）、子馬尼/莫迪、女兒斯露德、僕人希亞費兄妹、繼子烏爾 |
| **民間信仰** | 晚期基督教傳入後仍獲農民崇拜，民間故事多為巨人剋星形象 |

### 洛基 —— 詭計之神
| 屬性 | 內容 |
|------|------|
| **出身** | 巨人法爾勃蒂與勞菲之子，與奧丁結血誓兄弟入阿薩 |
| **神格** | 詭計、變形、謀略、混沌催化劑 |
| **標誌** | 善變形（母馬、雌海豹、蒼蠅、老婦等）、言語犀利（洛基爭論） |
| **核心神話** | 導演巴爾德爾之死（誘霍德爾擲槲寄生）、埃吉爾宴會辱罵諸神出走、變鮭魚躲藏被捕、遭瓦利變狼咬死納里、以納里腸綁懸毒蛇滴毒、諸神黃昏率死者艦隊登陸、與海姆達爾同歸於盡 |
| **子女** | 與安格波達：芬里爾、耶夢加得、海爾；與西格寧：納里、瓦利；與斯瓦迪爾法利（母馬）：斯萊普尼爾 |
| **評價** | 非純粹邪惡，多次為神奪寶（鎚、斯萊普尼爾、伊登蘋果），但最終成為毀滅推手 |

### 提爾 —— 獨手戰神
- **地位**：最古老主神候選，名源「星期二」；早期為天空神/人類始祖圖伊斯科之子曼努斯後裔。
- **核心神話**：獻右手誘芬里爾上縛（格萊普尼爾）、諸神黃昏鬥加爾姆同歸於盡。
- **符文關聯**：「勝利符文」刻劍柄唤提爾名兩次求勝（《希格德裡法話語》）。

### 巴爾德爾 —— 光明貴公子
- **形象**：最美、最賢、最受愛；殿邸布雷達布利克無災禍。
- **死亡**：母弗蕾雅遍徵萬物不傷誓，漏槲寄生 → 洛基誘盲神霍德爾擲殺。
- **下葬**：巨輪靈柩船靈艇火葬，巨人女希爾羅金推船引震被索爾擊殺。
- **復活嘗試**：赫爾莫德騎斯萊普尼爾赴冥界，海爾設條件「萬物哭泣」→ 洛基化巨人女托克拒哭 → 失敗。
- **重生**：諸神黃昏後與霍德爾歸來共治新世。

### 維達 —— 沉默復仇者
- **出身**：奧丁與巨人女格里德之子；鞋底積集世人廢皮革成最堅固靴。
- **神格**：沉默、力量僅次索爾、芬里爾剋星。
- **諸神黃昏**：踏芬里爾下顎、撕裂顎骨為父報仇，倖存治世。

### 赫爾莫德 —— 敏捷使者
- 奧丁子，非十二主神列；巴爾德爾死後騎斯萊普尼爾九夜抵冥界交涉，取回特勞布尼爾與遺物。

### 費蕾雅/弗蕾雅 —— 塞伊德女主人
- **華納質子**，阿斯神域擁弗爾克凡格殿，分得半數英靈。
- **神格**：愛慾、戰死選擇（瓦爾基麗上級）、塞伊德魔法、項鍊布拉西嘉拉（四矮人鑄）、羽衣借洛基變形。
- **丈夫** 奧德（常離家流浪，弗蕾雅淚化紅金）。

### 弗雷 —— 和平豐收神
- **華納質子**，阿爾夫海姆領主（乳牙禮物）。
- **寶物**：自戰劍、折疊船斯基德布拉德尼爾、金豬古林布斯蒂。
- **神話**：愛上巨人女格爾德，僕人斯基尼爾持劍求婚；諸神黃昏因獻劍無力鬥蘇爾特戰死。

### 尼奧爾德 —— 海洋富足神
- **華納族長**，娶巨人女斯卡迪（以腳選夫誤嫁），因棲息偏好（海濱/山嶺）分居。
- **子女** 弗雷、弗蕾雅（與姐妹所生，華納許姊妹婚）。

### 海姆達爾 —— 彩虹橋守望者
- **出身**：九海女（埃吉爾女兒）與奧丁所生，九母養育。

## 盧恩符文與魔法體系

北歐魔法核心為**魯納符文**與**塞伊德**巫術。

- **符文起源**：奧丁世界樹倒掛九夜、獻眼得知 → 18/24 字符（古弗薩克）。
- **用途**：占卜、護符、詛咒、療癒、戰鬥增益（刻劍柄求勝）。
- **塞伊德**：華納傳統巫術，弗蕾雅傳授奧丁；含預言、變形、靈魂出竅、操控命運。
- **加德爾德**：男性禿髮巫術，社會地位較低，奧丁亦修習。

> **深度交叉**：完整符文體系、占卜法、製作儀式參見 [[盧恩符文核心體系]]、[[盧恩符文24符文詳解]]、[[盧恩符文應用對應]]。

## 信仰演變：從異教到基督教

| 階段 | 關鍵事件 |
|------|----------|
| **早期（~西元4世紀）** | 塔西圖斯記載奧丁/提爾/索爾三主神、活人獻祭、沼澤獻屍 |
| **維京時代（8–11世紀）** | 烏普薩拉大祭（冬至猶爾祭）、王權利用信仰鞏固統治、盧恩石碑紀功 |
| **基督教傳入（9–12世紀）** | 安斯加爾傳教、哈拉爾藍牙/奧拉夫一世強制改宗、廟宇拆毀改建教堂 |
| **轉型期** | 奧丁→幽獵/惡魔；索爾→巨人剋星民間故事殘留；弗蕾雅→女巫/妖精 |
| **近代復興** | 17世紀《王室抄本》發現 → 19世紀民族浪漫主義 → 現代新異教/阿薩特魯復興 |

> **文化殘留**：耶誕節（Yule）源自冬至祭；星期名（Tuesday提爾、Wednesday奧丁、Thursday索爾、Friday弗蕾雅）保留神名。
