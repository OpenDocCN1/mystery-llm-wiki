## 概述

印度占星學（Jyotish）獨特的核心技術之一即為**分宮圖系統**。秦瑞生《印度占星學》依循**帕拉薩拉系統**（Parasara Jyotish），以《Brihat Parasara Hora Sastra》（BPHS）為核心依據，系統闡述分宮圖的計算與應用。

書中指出：「印度占星學採用分宮圖輔助判斷人生各領域事項，因此，了解其由來及意義就相當重要」。分宮圖是將本命盤（D1）的每一星座進一步細分，對應至具體的人生事務領域（如婚姻、事業、子女、財富、業力等），使論斷能從宏觀格局進入微觀精準層面。

推薦序由林課震撰寫亦強調：「尚能參考 D₂、D₄、D₉ 等不同分盤，可以精準論斷各個不同人生事務領域，是其他祿命法所沒有的」。

> **交叉引用**：本頁為 [[indian-astrology-jyotish-overview]] 之專題深化頁面；分宮圖計算基於 [[zhanxing-tianwen-jichu-yu-huangdao-tixi]] 所述之恆星黃道體系；星宿劃分參見 [[nakshatra-27-lunar-mansions]]。

## 核心分圖深度解析與優先應用序

### D₁ Rasi（本命盤）—— 萬圖之母
- **定位**：人生總藍圖，十二宮位、行星配置、格局（Yoga）、大運（Dasa）基礎皆於此判定。
- **操作邏輯**：所有分圖推導源頭。行星在 D₁ 的星座、宮位、相映（Drishti）、吉凶性質（自然/功能）決定分圖推演的基礎參數。

### D₉ Navamsa（九分圖）—— 皇后地位，驗證與婚靈核心
- **優先序**：**僅次於 D₁，為第一優先參考分圖**。
- **核心功能**：
    1.  **驗證行星真實力量**：行星在 D₁ 雖落廟旺，若 D₉ 失陷，則力量大打折扣，反之亦然（「分圖驗證原則」）。
    2.  **論婚姻與伴侶**：第七宮、第七主星、金星、木星（女命）在 D₉ 狀態，定婚姻質量、配偶特質、結婚時機。
    3.  **論靈性與業力**：第九宮、第九主星、木星、凱龍星等在 D₉ 配置，顯示靈性傾向、上師緣、前世修行延續。
    4.  **晚年運勢**：大運後期、行星成熟度（35-42 歲後）多參照 D₉ 顯現。

### D₁₀ Dashamsa（十分圖）—— 事業與社會地位專圖
- **優先序**：**事業論斷第一專圖**。
- **核心功能**：
    1.  專斷第十宮事業、聲譽、權力、上司、政府關係。
    2.  D₁ 第十宮主星、土星、太陽、水星在 D₁₀ 之落宮、相位、吉凶，決定職業高峰與轉折。
    3.  配合 D₁ 大運、行運（Gochar）雙重驗證事業轉折點。

### D₃ Drekkana（三分圖）—— 手足與勇氣
- 專論第三宮：兄弟姊妹數量、關係、短途奔波、主動行動力、勇氣。

### D₇ Saptamsa（七分圖）—— 子女與創造
- 專論第五宮：子女緣分、生育時機、子女性別/特質、投機投資、創造表達。

### D₁₂ Dwadashamsa（十二分圖）—— 父母與血統
- 專論第四宮（母親/產業根基）、第九宮（父親/師長/福報）、祖先業力傳承。

### D₃₀ Trimsamsa（三十分圖）—— 災厄與隱疾
- **特殊性**：無吉星入廟，專論凶。行星落入 D₃₀ 之星座（僅五星掌管：火、土、水、金、火對應五行），揭示第六宮疾病/訴訟、第八宮意外/壽命、十二宮損耗/隱疾的具體質地與時機。

### D₆₀ Shastiamsa（六十分圖）—— 業力總結
- 最精微，論前世業力成熟度、命運最終定數、極細微吉凶轉折。常用於修正出生時間。

## 分宮圖操作邏輯與綜合判讀框架

### 一、 計算原理：均分黃道
- 以恆星黃道經度為基礎。
- 公式：`分圖星座 = (行星在星座內度數 ÷ 分圖單一度數) 的整數商 + 1`，落入第 N 個分格，對應第 N 個星座（按白羊座起算或特定規則如 Hora 依日夜分陽/陰星座）。
- 例：D₉ 每格 3°20′，行星在獅子座 10°，屬第 4 格 (10 ÷ 3.33 ≈ 3，整數 3 + 1 = 4)，對應天秤座（白羊起算第 4 宮）。

### 二、 「分圖驗證原則」（核心邏輯）
> **「行星在分圖中的廟旺失陷，決定其在該生活領域的真實交付能力。」**
- D₁ 顯示「潛力與格局」，D₉/D₁₀/其他分圖顯示「交付品質」。
- **操作步驟**：
    1.  先判 D₁ 格局、行星吉凶、大運主星。
    2.  查核該行星在相關分圖（D₉ 必看、D₁₀ 事業必看、D₇ 子女必看等）之星座狀態（廟/旺/平/陷/失）。
    3.  觀察分圖中相關宮位（如 D₉ 第七宮、D₁₀ 第十宮）之宮主星、吉凶星配置、行星組合。
    4.  綜合大運/行運觸發時機，給出具體領域預測。

### 三、 優先序與決策樹
1.  **D₁ 為體**：無 D₁ 格局支撐，分圖吉配難獨立成事。
2.  **D₉ 為用（通用）**：無論何事，行星 D₉ 狀態關鍵，關係靈性與婚姻核心。
3.  **專圖專用**：
    - 事業 → **D₁₀** 優先，輔 D₁、D₉。
    - 婚姻 → **D₉** 優先，輔 D₁、D₇、D₁₂、D₃₀。
    - 子女 → **D₇** 優先，輔 D₁、D₉、D₅（D₁ 第五宮）。
    - 財富 → **D₂** 輔 D₁、D₉、D₁₁。
    - 疾病/災厄 → **D₃₀、D₆、D₈、D₁₂**。
    - 靈性/解脫 → **D₂₀、D₉、D₁₂、D₆₀**。
4.  **Varga Vishwa（分圖綜合評分）**：傳統有一「十六分圖綜合評分法」，將行星在 16 分圖之吉凶加權總分，評估行星一生整體表現力。

### 四、 特殊應用：行星組合在分圖中的投影
- 書中提及「行星組合」與「行星相映」在分圖中同樣運作。
- 例：D₁ 形成「吉星合相」（如木金合），若在 D₉、D₁₀ 亦同落吉星星座或形成吉相，則該 Yoga 威力倍增，稱為「分圖確認」。

## 實務操作建議（依秦瑞生教學脈絡）

1.  **軟體輔助，人腦判讀**：「功能較完備的印度占星軟體，亦可以完整列出需要的分宮圖。然而……唯有了解其操作，才能體會在印度占星學裡使用分宮圖的奧祕。」
2.  **從 D₁、D₉、D₁₀ 入手**：初學者先精通此三圖交叉驗證，再擴展 D₃、D₇、D₁₂、D₃₀。
3.  **結合大運與行運**：分圖靜態配置需配合 Vimsottari 大運主星、次星，及土木火等慢行星行運觸發分圖敏感點（宮位、行星），始能定時精準。
4.  **修正出生時間**：利用 D₉、D₁₀、D₆₀ 宮位變動敏感度極高（幾分鐘換宮），回溯已知重大事件（婚姻、升遷、喪親、手術）微調出生時間至分鐘級。
