## 概述

**皇极六爻** 是由贾秉然（网名“秉然”，QQ 497399920）历时二十余年实战总结、以《黄金策》为理论主干、确立**二元定位·兼象定论**为核心判断法则、遵循**易法自然**为最高原则的高阶六爻预测体系。其著作序列包括：
- 《易法自然》（阐释基础原理与断卦程序）
- 《六爻洗髓》（详解卦身、世身起法及二元定位操作细则）
- 《皇极六爻系列教材·古今实例汇解第一辑·六爻病灾秘法》（以大量古今验证卦例通解灾祸预判）
- 《皇极六爻系列教材·古今实例汇解第二辑·六爻财运秘法》（本页面核心来源，专解终身财运与分项求财实战）
- 《六爻冰灾秘法》《六爻婚孕秘法》等专题实战册

该体系旨在解决传统六爻“一元定位”导致的理论自相矛盾、断验参半、初学者“无所措手足”的乱象，确立一套**逻辑自洽、可推演、可复核、可传承**的“可学之法”。

## 理论基石

### 以《黄金策》为主干
- 贾秉然认为《卜筮正宗》（即《黄金策》注本）是六爻预测唯一的**经典之作、大成之作**，其断语虽简但皆为实战总结，逻辑严密、普适性强。
- 批评《增删卜易》《易隐》等书掺杂主观臆想、逻辑混乱、实例与理论脱节，易使学人“越学越迷茫”。
- 主张初学者**唯读《黄金策》**，掌握正统原则后再览他书取长补短。

### 易法自然——最高原则
> “取法于上，得法于中；取法于中，得法于下；取法于自然，得法于上！”

- **自然状态为准**：现实中灾祸发生概率远低于用神受克概率，故断卦模型必须与自然概率契合。
- **随时变通**：古法无“车祸”象，现代预测必须增设车祸取象；现实变迁，断法随之修正。
- **逻辑推演优于“活变”**：真正高级的断法应能“通解古今一切卦例”，例外亦有确定条件，非凭直觉“活变”。

### 二元定位·兼象定论——核心创新

| 预测对象 | 定位要素（二元） | 判断逻辑 |
|----------|------------------|----------|
| **自测** | 世爻（精神/意识） + 卦身/世身（形体/肉身） | 世爻受伤仅代表精神痛苦/运气不顺；**世身/卦身同受伤，才确诊意外灾祸/死亡** |
| **测他人** | 用神爻（形体状况） + 应爻（精神状态） | 用神受伤仅为“可能性”；**应爻同受伤，才定论灾祸落实** |

- **破除“一元定位”弊端**：传统法仅看用神旺衰生克，导致“问平安则凶、问归期则吉”荒谬；二元定位使“占此应彼”在任意项目中均可优先拦截灾祸信息。
- **本体论依据**：人 = 意识思维（世/应） + 物质形体（身/用神）二元统一体；灾祸 = 精神与肉体**同时**陷入痛苦不安状态。

## 终身财运断法核心程序

> **点窍——以财爻断当前的财气，以财根（子孙爻）断以后财运。**

### 以财爻旺衰断目前财气
- **直接判断**：财爻旺相临月建 → 目前定是有钱人；财爻休囚失陷 → 目前财气窘迫。
- **生克修正**：财爻旺相遇日月动爻生助 → 财源不断、财气长久；财爻旺相被兄弟爻克制、官鬼爻泄气 → 破耗大、替他人赚钱（打工族）。
- **不看世爻生克**：判断“当前财气好坏”仅看财爻在卦中旺衰生克，**不看财爻与世爻生克关系**（后者用于判断财气对本人影响好坏）。

### 以子孙爻旺衰断将来财运（财根）
- **核心逻辑**：财爻为“果”（当前财气），子孙爻为“根”（求财途径/财源）。有根方能久远，无根则坐吃山空。
- **最佳**：财爻、子孙俱旺相无伤 → 目前有钱、以后更富（大富之命）。
- **次佳**：财爻不旺，子孙爻旺相有力 → 目前虽穷，等生旺之时必发财（后发制人）。
- **危险**：财爻旺相，子孙爻休囚空破失陷 → 当前旺财如秋叶春雪，一遇变故倾家荡产。建议买房置业保值。
- **最差**：财爻、子孙俱不旺 → 一生财运窘迫，难发家。

### 兄弟爻与官鬼爻的双重作用辨析
| 爻神 | 普通求财/终身财运中常态 | 特殊吉利条件 | 特殊项目（投资/赌博/物价） |
|------|---------------------------|--------------|----------------------------|
| **兄弟爻** | 破耗煞，克财爻。旺相不发动亦主破耗大（暗动）；发动更凶。唯休囚被克制最吉。 | 兄弟爻过旺（月日动变重叠） → 反不克财；兄弟爻动化财爻/生子孙爻 → 先散后聚/通关格局。 | **投资求财、赌博求财必须有兄弟爻发动**（代表本金投出/筹码）。无兄弟动 = 钱花不出去 = 投资失败。 |
| **官鬼爻** | 耗财神，泄财爻。不宜动，动则泄财（替他人赚钱/打工族）；不宜伏藏（无官则兄专权）。 | 官鬼爻发动**生合世爻** → 得贵人/官方帮助，利仕途；官鬼爻制伏兄弟爻 → 保护财爻。 | **九流术士/空手求财/公门求财以官鬼爻为主顾**（代表客户/雇主/官方）。无官难成。 |

### 财爻克世爻为煞——关键纠偏原则
- **传统误区**：古法多云“财爻动克世爻，财来就我，易求”。**此乃传统六爻重大错误**。
- **皇极铁律**：**用神克世爻皆为凶煞**（用神做煞基本原则）。此时财爻旺相反而为凶，克世力量大。
- **具体表现**：
  - 父母爻持世被财克 → 求财辛苦万分（父母主劳）。
  - 世爻有克无生，兼象爻（卦身/世身）同伤 → **因财致祸、因财亡身**（财命犯冲）。
  - 世爻入墓、被日冲、财爻临月建暗动克世 → 典型灾祸卦象。
- **反面**：财爻生合持世 → 求财容易，钱财来就我，旺相则必发大财。

## 实战验证路径

1. **古籍实例通解**：《财运秘法》收录 25 个古今验证卦例（野鹤、易隐、自测等），逐卦演示“列干支卦象 → 皇极通解(财/子/世/兄/官/兼象) → 验证反馈”全流程。
2. **自测卦例公开**：作者二十年实测卦例（如实例 2-1 友人自缢关联、2-3 89年起商92发财、2-22 大老板验证等）均附具体干支、卦身世身起法、验证时间。
3. **可复核标准**：同一套技法通解所有项目，**无“问法不同、断法天翻地覆”**之矛盾；初学者可按程序模拟练习，快速掌握高阶断卦。

## 与传统派别对照

| 维度 | 传统一元定位（增删卜易等） | 皇极六爻二元定位 |
|------|----------------------------|------------------|
| 核心判断 | 用神旺衰生克一元论 | 财爻(当前)+子孙爻(根)+世爻(主体)三元，二元定位兼象定论 |
| 财爻克世 | 财来就我，主易得 | **财爻为煞，旺相反凶，主辛苦/因财致祸** |
| 兄弟爻作用 | 专论劫财凶神 | 视项目而定：终身财运忌旺；投资/赌博**必须发动**代表本金投出 |
| 官鬼爻作用 | 专论耗财/官非 | 视项目而定：终身财运忌动泄财；九流/公门/空手求财**以官为主顾** |

## 学习路径建议

1. **先读《易法自然》** → 建立易法自然观、二元定位框架、卦身世身起法。
2. **精研《六爻洗髓》** → 掌握卦身世身多种起法细节、各预测项目二元定位实操。
3. **实战《病灾秘法》** → 按书中 28 卦逐步模拟：列原文 → 重组逻辑 → 二元定位 → 取象定类 → 对照验证。
4. **专攻《财运秘法》** → 重点掌握“财子世三元判断、兄弟官鬼分项目取用、财克世煞原则、25卦通解模板”。
5. **专题拓展** → 按需研习《婚孕秘法》《冰灾秘法》等，同一套体系横向迁移。

## 关键术语表

| 术语 | 定义 |
|------|------|
| **二元定位** | 以“精神爻+形体爻”双因素共同定位吉凶，单一因素受伤仅为可能性 |
| **兼象定论** | 引入第二定位因素（卦身/世身/应爻）与用神同审，二元俱伤始定论 |
| **卦身/世身** | 代表求测者肉体/形体的特定爻位，起法详见《六爻洗髓》 |
| **真空真破** | 旬空/月破且无日月动爻生助拱合、无冲填实，为失陷大凶 |
| **随鬼入墓** | 用神伏藏于官鬼爻之下入墓，主病灾入院或官灾入狱 |
| **易法自然** | 断卦模型必须与自然规律、现实概率、身心二元状态严格对应 |
| **占此应彼** | 在非灾祸项目预测中，因用神现凶兆而优先拦截判断灾祸信息 |
| **财爻** | 代表钱财、利息、当前财气之爻，旺衰直断目下富贫 |
| **子孙爻/财根** | 代表求财途径、财源根基、未来财运之爻，旺衰断后发潜力 |
| **兄弟爻/劫煞** | 克财爻，主破耗；视项目或旺衰程度可转吉(过旺反不克/投资必动) |
| **官鬼爻/耗神** | 泄财爻，主替人赚钱/工作；视项目可转吉(九流公门以之为主顾/制兄护财) |
| **财克世为煞** | 财爻动克世爻，用神化凶，旺相反凶，主求财辛苦、因财生灾、财命犯冲 |
