## 概述

《果老星宗》系唐代星命大师张果传授李憕之学，载入《古今图书集成》乾象典，为中国星命学集大成之作。其下部「七政四余」四卷（卷六星曜运行、卷七三辰通载上、卷八三辰通载二、卷九总论行限）确立了**十一曜（日月五星四余）**、**二十八宿**、**十二宫**、**行限流年**四大核心体系的交互判断框架。

> 交叉引用：[[chinese-star-divination]] 总览星命学全景与《果老星宗》在《四库全书》中的文献定位；[[guo-lao-xing-zong]] 详述张果老传说、果憕问答、上部先天后天心法及星格贵贱判断体系。

## 三、十二命宫主星断验细则

《果老星宗》卷六第二章以**身命二主**（太阴为身、太阳为命）为纲，逐宫论主星升殿入垣、明盛救助、退留受克、侵凌他宫之吉凶。

| 宫位 | 宫名 | 宫主星 | 核心断语要旨 |
|------|------|--------|--------------|
| 子/丑 | 命宫 | 土星 | 宫度二主皆强则贵富；身度主重于命主，昼生看命度，夜生看身度。 |
| 寅/亥 | 兄弟宫 | 木星 | 升殿入垣无干犯、有救助 → 棣萼联芳；侵官/财/田 → 争端；伤寿元 → 伤寿。 |
| 卯/戌 | 夫妻/妻妾宫 | 火星 | 升殿入垣有救助 → 贞顺偕和；余气盛 → 美妾；益官 → 因妻贵；犯官 → 讼；刑克 → 再婚或不娶。 |
| 辰/酉 | 子女/男女宫 | 金星 | 升殿入垣无犯有救 → 多育聪明贵子；余气胜 → 庶出贵子；受制凌犯有救 → 尚可；侵田财 → 破家；侵官 → 讼伤官；侵身命寿 → 悖逆反噬。双生看双鱼/双女/人马/阴阳四宫。 |
| 巳/申 | 疾厄宫 | 水星 | 明盛 → 无疾；受制/退留/凌犯 → 多病，随煞主病症（木→肝胆目筋、火→心血舌痔、土→脾胃四肢、金→肺大肠胃气、水→腰肾膀胱、日月→目）。刃煞同居 → 带疾破相。 |
| 午 | 奴仆宫 | 太阳 | 升殿入垣有救 → 多仆从；伤克身命/侵财官 → 不听驱策、反致祸；侵妻妾 → 隐害。 |
| 未 | 田宅/父母宫 | 太阴 | 升殿入垣强旺有救 → 成基业丰厚；退留受克无救 → 离祖破败。侵命主 → 讼服凶。论父母合日月：罗火克日/剑锋 → 克父；土侵月/剑锋 → 克母；昼生日落阴宫阴度 → 父先亡；夜生月落阳宫阳度 → 母先亡。 |
| 申/巳 | 迁移宫 | 水星 | 得度无凌救援盛 → 膺顺动荣；受制退留 → 进退趑趄、移根换叶、萍梗客。近君位 → 京畿；随禄马向断方位。 |
| 酉/辰 | 官禄宫 | 金星 | 升殿入垣明盛有救无犯余曜并强 → 穹隆之贵；援星依日月光 → 班侍荣；官星损用星 → 不吉；克田财 → 破家；克科星 → 难第；克子息 → 绝后；克兄弟 → 伤手足；克福寿 → 亏福伤年。益用星则吉。 |
| 戌/卯 | 福德宫 | 火星 | 盛 → 福厚；弱 → 福浅；升殿入垣救助明盛 → 莫大之福；失度退留凌犯 → 无纯福。德为福基，行善修德虽无福而有福。 |
| 亥/寅 | 相貌宫 | 木星 | 得度明盛有救 → 清秀；受制退留凌犯无救 → 容仪不美。十二宫论皆以宫主度主为准，生助救援为吉，克空亡劫为凶。 |

> **身命二主利害关系**  
> - 身命主救助科星/寿元/官福/田财诸用星 → 有益  
> - 身命主欺凌用星、或用星失躔入身命主宫殿 → 有害  
> - 身命二主自相克 → 不忌（如命在巳申水星、月在子丑土星同行不忌）  
> - 宫身与元守岁驾冲 → 离祖孤克  
> - 身命坐隔界/宿初末度/入奴宫/奴星拱夹 → 偏生庶出

## 四、纬克经 / 经克纬 交互判断法

**定义**  
- **纬** = 七政四余十一曜（横向运行）  
- **经** = 二十八宿（纵向分野）  
- **纬克经** = 十一曜克制度主（星主得所、度主受克）  
- **经克纬** = 度主克制十一曜（星主受制、躔度失色）

### 纬克经（曜克宿）判断口诀

| 用曜 | 忌曜侵犯 | 被克宿度（度主同宫主） |
|------|----------|------------------------|
| 木星 | 金星 | 斗、角、井、奎（木宿） & 寅亥（木垣） |
| 火星 | 水星、月孛 | 尾、翼、觜、室（火宿） & 卯戌（火垣） |
| 土星 | 木星、紫气 | 女、氐、柳、胃（土宿） & 子丑（土垣） |
| 金星 | 火星、罗睺 | 牛、亢、鬼、娄（金宿） & 辰酉（金垣） |
| 水星 | 土星、计都 | 箕、轸、参、壁（水宿） & 巳申（水垣） |
| 太阳 | 木星、紫气、罗睺 | 房、虚、昴、星（日宿） & 午（太阳正垣） |
| 太阴 | 土星、计都 | 心、危、张、毕（月宿） & 未（太阴正垣） |

**断则**  
1. 忌星就克、无援救 → 必凶  
2. 忌星坐垣殿而受强星凌制 → 反吉（害星受伤无力害人）

### 经克纬（宿克曜）判断口诀

| 受克曜 | 受克宿度（度主克曜） |
|--------|----------------------|
| 木星、紫气 | 牛、亢、鬼、娄（金宿） & 辰酉（金垣） |
| 火星、罗睺 | 箕、壁、参、轸（水宿）、心、危、毕、张（月宿） & 巳申未（水月垣） |
| 土星、计都 | 角、斗、奎、井（木宿） & 寅亥（木垣） |
| 金星 | 尾、室、翼、觜（火宿） & 卯戌（火垣） |
| 水星、月孛 | 女、氐、柳、胃（土宿） & 子丑（土垣） |

**断则**  
1. 用星躔受制度 → 颜色不正/隐不明、自救不及、虽有用力不及  
2. 生我之星复伤本殿本垣 → 表里遭伤、害重，须求救援星  
3. 害星躔受制度 → 反吉（受辱无凌人之势）  
4. **切忌**有星救害星 → 害星势复苏、为害益甚

## 五、太阴九道轨迹与吉凶断例

### 九道定义
- **黄道** 1 条（中道）  
- **青道** 2 条（黄道东）  
- **赤道** 2 条（黄道南）  
- **白道** 2 条（黄道西）  
- **黑道** 2 条（黄道北）  
共九道，月行于黄道两侧 ±6° 范围内。

### 四季月行九道对照（立春/立夏/立秋/立冬为界）

| 季节 | 黄道（中） | 青道（生我） | 白道（我生） | 赤道（克我） | 黑道（我克） |

| 春 | 角斗奎井（木） | 尾室觜翼房虚昴星（火/日） | 箕壁参轸心危毕张（水/月） | 亢牛娄鬼（金） | 氐女胃柳（土） |

| 秋 | 亢牛娄鬼（金） | 箕壁参轸心危毕张（水/月） | 氐女胃柳（土） | 尾室觜翼房虚昴星（火/日） | 角斗奎井（木） |
| 冬 | 箕壁参轸心危毕张（水/月） | 角斗奎井（木） | 亢牛娄鬼（金） | 氐女胃柳（土） | 尾室觜翼房虚昴星（火/日） |

> - 金度：亢牛鬼娄  
> - 水度：箕壁参轸  
> - 土度：氐女胃柳

> - 月度：心危毕张

### 九道性情与吉凶断语

| 道名 | 性情特征 | 吉凶倾向 | 特殊格局 |
|------|----------|----------|----------|
| **黄道** | 聪明清和、粹美春风、洒落通变 | 吉星得黄道 → 福；凶星见黄道 → 减力 | 黄道虽弱亦吉，最忌掩晦（片云蔽月） |
| **青道** | 清洁风节、廉操进退以礼 | 孤高；命局逢孤刑煞/空亡刃破 → 僧道 | 有吉局亦为贵中孤命 |
| **白道** | 同青道孤高清洁 | 同青道 | 逢阳刃空亡 → 僧道 |
| **赤道** | 太阳光辉所在、权略任势敢为 | 多权谋、胆大 | — |
| **黑道** | 愚而好自用、贱而好自专、心高无实、志大无成 | 甚凶；虽入吉局亦必自艰难中起 | — |

### 太阴度主说（以月所躔宿之度主论身命吉凶）
> 例：太阴度娄（金度）→ 以金星升殿入垣、夹拱、禄贵驾殿、土生金为吉；金星失躔/被火克/截脉/逢阳刃劫煞为贱。  
> 金见火得土挽回 → 转凶为吉（火生土、土生金）。  
> 金见水看水主何宫（田妻男吉、官福高）；金见木为财看木主何宫。

### 太阴引从夹拱说
- **引**：月度前 30° 内吉星，宜远  
- **从**：月度后 30° 内吉星，宜近  
- **夹**：前后匀停夹拱  
- **拱**：三合钓来  
- **望衙（望道）**：对宫对照，**必因人而成**  
- **合衙（合道）**：同宫合照，**非仰他人不可贵格**  
前主星与月相生无战克 → 贵富；前主星伤日月 → 贱。

### 太阴犯殿伤宿说
- **犯殿**：罗睺、计都、土星、火星占四日度（房虚昴星）或四月度（心危毕张）  
- **伤宿**：克身命二主之星居太阴前（如太阴在胃、身命子丑、木星在月前 → 木土相克伤身命）  
- 化解：坐禄马贵垣殿驾庙旺、日月联格可伏凶星。

### 太阴让殿/出垣/晦朔弦望
- **让殿**：月不居本月度、他星亦不居、空出一宿 → 让吉则吉、让凶则凶  
- **出垣**：太阴在罗计界外 → 登殿驾禄贵吉、居杀凶；日生宜木水气、夜生宜金孛火罗，最怕阴阳反背  
- **晦朔弦望**：月上弦生申酉戌亥时进气有余；下弦生亥子丑寅时退气不足；皆喜火罗侍卫、金水相助

## 六、百六限行限推演体系

《果老星宗》卷九「总论行限」建立**百六限**（160 限）作为人生大运推演核心框架。

### 限数来源（洞微百六限说）
- 河洛之数：一六为水、二七为火、三八为木、四九为金、五十为土  
- 五百六相乘：以五行生克乘除得 160 限为一周

### 限步详解（限步之说）
- 每限主一年，按**宫度主**、**行度假如**、**捷见限论（倒限直指）**推断  
- **倒限核心**：「逢生者吉，值克者凶」  
- **余奴伤主论**：余气刑伤命主  
- **划度元奥经**：本星受创化解之法

### 限度宜忌（二十八宿五行宜忌）
按宿五行分类，列**四日度、四月度、四木度、四火度、四土度、四金度、四水度**各自宜忌，作为行限到度时的判断准则。

### 倒限体系（星命独有）
- **倒限详论**：生死凶灾解疑  
- **倒限拾遗/总诀/诸煞倒限/杂论/要诀/论倒限歌**：忌星、夺星二煞凶死之祸  
- **太岁歌**：木星凶格  
- **论限附余**：限论补充

### 流年杂论
- **流年论**：命主行年祸福  
- **流年都天赋**：立命法则

### 行限歌赋总结
- **临行歌附余**：星格吉凶与命运  
- **乔庙歌**：星曜逢见吉凶格  
- **一寸金总诀/碎金诀**：行限实战、主死亡之煞
