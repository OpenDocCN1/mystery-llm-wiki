# 紫微斗數入門教材對照與選讀指南

> 本頁以 **鄭景峰《初學紫微斗數》** 為核心骨幹，增補 **勸學齋主《紫微階梯① 紫微初階》** 作為零基礎入門的另一經典選項，並對比兩書在排盤流程、星曜體系、格局分類、論命邏輯與實戰案例上的異同，構建交叉引用的知識地圖。

---

## 一、 兩大入門教材定位速覽

| 維度 | 鄭景峰《初學紫微斗數》 | 勸學齋主《紫微階梯① 紫微初階》 |
|------|------------------------|--------------------------------|
| **作者背景** | 實務命理師，強調統計屬性與多維驗證（八斗卦） | 古文學與企管雙背景，強調陳希夷傳承與「多態統一」美感 |
| **核心觀點** | 同命不同運、星曜個性分析具參考值、主張綜合斷驗 | 命理為擁抱生命喜悅、兼採各家論說、坦白指出可用星曜 |
| **排盤教學** | 圖文並茂，提供查表法與口訣，步驟清晰 | **極詳盡的查表大全**，涵蓋主星、輔星、煞星、雜星、流年、長生、博士、截空、旬空、大小限全流程 |
| **星曜體系** | 十四主星+輔煞祿馬四化+長生博士+流年，約 60 餘星 | **一百多顆星曜全收錄**，分甲乙丙丁四級，並列各家庙旺陷落異同 |
| **格局分析** | 百餘格局分類（紫府、日月、機月、武貪、四化、陷落、化忌） | 近四十大吉格局、十八壞格局，另列「格局活用」原則 |
| **特色篇章** | 實戰案例：副總統連戰命盤深度解析 | 五行局闡微（納音、聲音、個性）、五行干支命理基礎 |
| **適讀對象** | 想快速上手排盤、看懂核心格局、重視實戰案例者 | 想建立完整查表索引、研究星曜源流、兼顧理論與實務者 |
| **後續進階** | 隱含於書中進階斷驗法則 | 明確配套《紫微進階》掌上排盤與研究方向 |

> **結論**：兩書互補不互斥。鄭書適合「快速入門→實戰練習」；勸學齋書適合「建立完整工具書索引→深究源流細節」。建議**雙軌並行**：以鄭書練排盤與格局，以勸學齋書查星曜屬性與冷門星系。

## 二、 排盤流程異同細表

| 步驟 | 鄭景峰《初學》 | 勸學齋主《紫微初階》 | 差異重點 |
|------|----------------|----------------------|----------|
| **命盤格式** | 4×4 九宮格，中央留空 | 同，提供對折四次速繪法 |
| **宮干安法** | 年干定宮干，查「年干對照十二宮天干表」 | 同，提供五組年干分表與「五虎遁月」口訣 |
| **命身宮** | 月支時支查表（附閏月規則） | 同，附「寅正順數生月」歌訣與圖解 |
| **十二宮名** | 命宮起逆時針排十二宮 | 同，明確身宮必落六正宮之一 |
| **五行局** | 命宮干支查表（另附生年干對照表） | 同，**補充納音歌與六種細分**（如爐中火、大溪水） |
| **紫微星** | 五行局+生日查表 | 同，另附五局專屬口訣（水二順、木三逆等） |
| **主星系統** | 紫微系六星、天府系八星固定相對位置 | 同，提供「逆行隔一、空二、隔三」口訣 |
| **輔星/煞星** | 分類排布表（左輔右弼、擎羊陀羅、火鈴、地空地劫等） | **極詳盡**：時系、月系、日系、年干系、年支系、截路旬空、長生博士、天殤天使，**每類附口訣** |
| **四化星** | 年干四化固定表 | 同，提供星曜簡稱口訣（甲廉破武陽…） |
| **流年星** | 歲建斗君、干支流星、歲前將前 | 同，**細分流年斗君安法、將前十二星、歲前十二星表** |
| **大小限** | 五行局+陰陽男女查大限起宮表、小限順逆 | 同，表格更完整（含 112-121 歲區間） |
| **命主/身主** | 命宮地支定命主、生年支定身主 | 同，附雙口訣 |

> **關鍵補充**：《紫微初階》第 2 章第 4 節「其他星曜」將斗數各家所用星曜**全部羅列**（含台輔封誥、三台八座、恩光天貴、天刑天姚、天巫天月、陰煞、天哭天虛、華蓋、紅鸞天喜、化祿權科忌、天殤天使、截路空亡、旬空、咸池、解神、龍池鳳閣、破碎蜚廉、命主身主、長生博士、流年將前歲前），**即使作者不常用也收錄**，免學者翻查眾籍。

## 六、 學習路徑整合建議

### 階段 0：工具準備
- 安裝排盤軟體（如紫微排盤 APP、網站）驗證手工排盤。
- 準備《初學紫微斗數》（鄭）作為**主教材**，《紫微階梯① 初階》（勸學齋）作為**工具書/備查**。

### 階段 1：排盤肌肉記憶（2-4 週）
1. 依鄭書第 1 章手工排 5-10 盤，對照軟體校正。
2. 遇不明星曜（如天廚、台輔、恩光、天姚），翻閱勸學齋書第 2 章第 4 節「其他星曜」查安法與屬性。
3. 背誦**十四主星廟旺陷落表**（兩書一致）、**四化星口訣**（鄭書星曜簡稱版較易記）。

### 階段 2：宮位與格局建構（4-6 週）
1. 研讀鄭書第 4 章十二宮意涵 + 勸學齋書第 3 章第 1 節「十二宮基本認識」（補充身宮、三方四正、命宮陰陽類型）。
2. **格局雙軌**：
   - 先記鄭書「紫府、日月、機月、武貪、四化、陷落、化忌」七大類別邏輯。
   - 再閱勸學齋書經典格局名稱與「格局活用」原則，建立**格局非死板、須看星情四化流轉**的彈性思維。
3. 每週拆解 1-2 個格局，於親友命盤中尋找驗證。

### 階段 3：實戰複盤與專題深化（持續）
1. **鄭書連戰案例**為模板：自行排盤 → 十二宮佈局 → 大限流年疊加 → 寫出 500 字斷語 → 對照書中分析。
2. **財帛專題**：研讀鄭書第 7 章十四主星坐財帛表，結合勸學齋書財祿夾馬、祿馬配印格局。
3. **五行局研究**：有餘力者研讀勸學齋書第 5 章納音細分與個性/聲音對應，豐富論命厚度。
4. **跨體系驗證**：同一命盤分別用八字（[[bazi-mingli-xue-jichu-jiaocheng]]）、六爻（[[liuyao-jichu-rumen-qinglan]]）、奇門（[[qimen-jiangyi-yi]]）驗證，落實「八斗卦」多維思維。
