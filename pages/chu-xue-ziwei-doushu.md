# 初學紫微斗數

> 書名：**初學紫微斗數**  
> 作者：**鄭景峰**  
> 定位：紫微斗數入門教材，涵蓋排盤實務、星曜屬性、十二宮論斷、格局分析與實戰案例

---

## 書作緣起與核心觀點

### 自序關鍵論點
- **統計屬性**：紫微斗數為歷經千年演變的星曜符號統計體系，非單一人創作
- **同命不同運**：同年同月同日時出生者命盤相同，但命運截然不同，單一命盤無法完全決定命運
- **實務取向**：星曜個性分析（如七殺衝動、太陰求全、太陽外向）具備高參考價值，可作自我省思工具
- **綜合斷驗**：作者主張「八斗卦算命法」——結合八字、紫微、手相、面相、卜卦多維驗證

## 第一章 排命盤實務全流程

### 繪製命盤格式與填入十二地支
- 標準命盤為 4×4 九宮格，中央留空
- 十二地支按逆時針順序自左下角「寅」起排布：寅、卯、辰、巳、午、未、申、酉、戌、亥、子、丑

### 填入十二宮位天干（年干定宮干）
- 以出生年天干為起點，自「寅宮」順時針排布十天干（甲至癸）
- 因地支十二、天干十，子丑二宮天干與寅卯相同
- **查表法**：提供「年干對照十二宮天干」完整對照表

### 換算出生農曆年月日時
- 年月日查《標準萬年曆》
- 時辰對照表：子時 23:00-01:00、丑時 01:00-03:00……亥時 21:00-23:00

### 安命宮與身宮（月支時支定宮位）
- **命宮**：以農曆月份為行、出生時辰為列，查表得地支宮位
- **身宮**：同表第二欄
- **十二宮順序**（逆時針）：命宮 → 兄弟宮 → 夫妻宮 → 子女宮 → 財帛宮 → 疾厄宮 → 遷移宮 → 僕役宮（交友宮） → 官祿宮（事業宮） → 田宅宮 → 福德宮 → 父母宮
- **閏月規則**：閏月生人作下月論

### 陰陽男女判別
| 年干屬性 | 男性 | 女性 |
|----------|------|------|
| 陽年（甲丙戊庚壬） | 陽男 | 陽女 |
| 陰年（乙丁己辛癸） | 陰男 | 陰女 |
> 陽男陰女順行，陰男陽女逆行——贯穿排星、大限、流年、長生十二宮等所有順逆判斷

### 定五行局（生日定局數）
- 五行局數：水二局、木三局、金四局、土五局、火六局
- **查表法**：以「五行局/生日」對照表，依生日（1-30 日）與五行局查得紫微星落宮
- **三跳法口訣**：以命宮干支定局數，再由局數推算紫微星位（見第二章速排法）

### 安紫微星與十四主星
1. 依五行局與生日查表得「紫微星」落宮
2. **紫微為樞紐**，按固定相對位置排定其餘十三主星：
   - 紫微、天機、太陽、武曲、天同、廉貞、天府、太陰、貪狼、巨門、天相、天梁、七殺、破軍
3. **斗別與五行屬性**（節錄）：
   | 星名 | 斗別 | 五行 | 主掌 |
   |------|------|------|------|
   | 紫微 | 中天 | 土 | 帝座、官祿主 |
   | 天機 | 南斗三 | 木 | 智謀機變 |
   | 太陽 | 南斗四 | 火 | 爵祿、文昌 |
   | 武曲 | 北斗六 | 金 | 財帛主 |
   | 天同 | 南斗四 | 水 | 福德主、化福 |
   | 廉貞 | 北斗五 | 火 | 祿存、桃花 |
   | 天府 | 南斗一 | 土 | 田宅主、化祿 |
   | 太陰 | 南斗二 | 水 | 財帛、福德 |
   | 貪狼 | 北斗一 | 水 | 財帛、桃花 |
   | 巨門 | 北斗二 | 水 | 口才、是非 |
   | 天相 | 南斗五 | 水 | 印綬、官祿 |
   | 天梁 | 南斗二 | 土 | 蔭壽、父母 |

## 第二章 紫微斗數速排法與口訣體系

### 快速起盤三步驟
1. **年干定月干、時干**：甲己年起丙寅、乙庚年起戊寅……
2. **寅上起正月**，順數至生月，逆至生時得命宮，順至生時得身宮
3. **三跳法定五行局**：命宮干支 → 局數 → 紫微星落宮

### 核心口訣集萃
- **六十甲子納音歌**：甲子乙丑海中金、丙寅丁卯爐中火……
- **定生時訣**：髮旋、嬰兒睡相輔助判斷真太陽時
- **安流年斗君訣**：流年歲建起正月，逆逢生月順回程……
- **安十二宮訣**：命、兄弟、夫妻、子女、財帛、疾厄、遷移、僕役、官祿、田宅、福德、父母（逆時針）
- **百字千金訣**：樞庫坐命遇吉、機月樑同福壽、日月左右辰生……

> **三方四正**：命、財、官、遷四正宮；加上對宮與三方會照宮，為論命核心結構

### 身宮特殊論斷
- 命宮 = 先天本性；身宮 = 後天行為、後天運勢
- **身命同宮/同宮照應**：後天能補先天、或先天受後天拖累
- 必須與命、夫、財、官、遷、福六宮任一同宮/會照始具論斷效力

## 第六章 實戰案例——副總統連戰命盤解析

### 命盤基本資料
- **出生**：丙子年八月十一日戌時（農曆）
- **命宮**：亥宮（天同化祿+天魁）
- **身宮**：未宮（借對宮太陽太陰）
- **五行局**：水二局
- **陰陽男女**：陽男（順行）

### 十二宮星曜佈局要點
| 宮位 | 主星/重要星曜 | 關鍵論斷 |
|------|---------------|----------|
| 命宮(亥) | 天同化祿、天魁、天馬、天巫 | 雙祿交馳、祿馬交馳、無煞星、富貴極罕見 |
| 兄弟宮(戌) | 破軍 | 兄弟姐妹無傑出表現 |
| 夫妻宮(酉) | 天鉞、咸池、天喜 | 貴人星+桃花宮、娶選美冠軍方瑀 |
| 子女宮(申) | 廉貞化忌、鈴星 | 較弱宮位、子女能否光耀門楣存疑 |
| 財帛宮(未) | 無主星、借對宮太陽太陰 | 擁上億財富、祖蔭或自創待驗 |
| 疾厄宮(午) | 七殺、擎羊 | 膀胱、生殖系統需防範 |
| 遷移宮(巳) | 天梁、祿存、天官 | 出外運佳、代表政府出訪、名利雙收 |
| 僕役宮(辰) | 紫微、天相、陀羅 | 長輩提拔、有陀羅防小人朋友 |
| 官祿宮(卯) | 天機化權、巨門、右弼 | 一人之下萬人之上、難免被出賣 |

### 大限流年關鍵節點
- **33-42 歲（庚寅）**：大限命宮、文曲貪狼會照、左輔文昌同祿——學業仕途雙順
- **53-62 歲（壬辰）**：大限兄弟宮、紫微天相、陀羅、官府——副總統任內、部屬出賣
- **63-72 歲（癸巳）**：大限夫妻宮、祿存天梁、擎羊七殺、太陽化忌——**健康壽元關鍵期**
- **73-82 歲（甲午）**：大限子女宮、擎羊七殺、疾厄宮廉貞化忌沖——**極度險惡、賴科技延命**
- **結論**：仕途順遂源於祖蔭與早年大限極佳，晚年健康隱憂重重

## 第八章 一四四種命盤論斷（略表）

書第八章提供 144 種命盤快速查找表，每盤列舉十二宮主星組合與核心吉凶斷語，例：
- **僕役宮太陰陷**：貴人不多、加七吉有助、加六煞少助
- **遷移宮廉貞貪狼旺**：外緣佳、加吉貴人多、加煞防小人陷害
- **疾厄宮天同巨門陷**：防胃病耳病、加吉輕微、加煞防心臟血壓神經
- **財帛宮武曲平天相廟**：正常可大富、加祿更富、加空劫防破財、加煞防浪費破產
- **官祿宮天府廟廉貞旺**：經商有利、加吉有主管命、加煞防小人

> 完整 144 盤需配合四化星與所有星曜始能精準斷驗
