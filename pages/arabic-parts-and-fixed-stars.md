## 概述

本页面系统梳理传统占星学中除行星、星座、宫位之外的核心敏感点体系，聚焦两大支柱：**阿拉伯点**与**恒星**。内容涵盖敏感点分类（月球交点、小行星、假设行星）、点的应用技法（汉堡学派中点、映点/反映点）、阿拉伯点的计算公式与尊贵判断法则（瓦伦斯五法则、里利评分表）、实战案例验证（陈水扁、比尔·盖茨、希特勒等），以及恒星占星的岁差校正原则、四大皇冠星、三大星云盲点、中西恒星对照表与解读实例。

> **交叉引用**：本体系与 [[zhanxing-tianwen-jichu-yu-huangdao-tixi]]（岁差与黄道系统）、[[classical-astrology-three-step-analysis]]（古典三步分析法）、[[arroyo-astrology-karma-transformation]]（业力与月球交点）、[[planetary-condition-traditional-astrology]]（行星状态量化）构成传统占星技法的完整拼图。

## 一、 天宫图中的其他敏感点

### 月球交点

月球交点非实体星体，而是月球轨道面（白道）与地球公转轨道面（黄道）的两个交点：
- **北交点（升交点/龙头/Rahu）**：白道由南向北穿越黄道，代表灵魂进化方向、今生应开发的心理意识与生活领域。
- **南交点（降交点/龙尾/Ketu）**：白道由北向南穿越黄道，代表过去生经验、业力模式、应放下的无意识习性。

**核心原理**：
- 交点永远呈 180° 对冲，白道倾角约 5.9°。
- 日月食发生于太阳、地球、月球交点连线时，故交点承载“集体无意识”层面的命运转折符号。
- **论断重点**：星座 > 宫位。北交点落星座显示需开发的意识；南交点落星座显示需超越的惯性。
- **平均交点 vs 真交点**：差距不超 1°45'，实务常用真交点。
- **周期**：逆行周期约 18.6 年，财务占星中为重要经济周期指标。

> **关联**：演化占星视角下的交点详见 [[ming-wang-xing-ling-hun-yan-hua-zhi-lv-juan-yi]]、[[arroyo-astrology-karma-transformation]]。

### 小行星

主要位于火木轨道带。早期发现四大小行星（谷神星、智神星、朱诺、维斯塔）长期被忽视，1970 年代 Dobyns 等人推广星历表后逐步应用，1977 年 **凯龙星** 发现推动小行星热潮。

| **智神星** | 智慧策略、创造智性、父女关系 | 与婚神星对比详见 [[hun-shen-xing-jin-shen-xing-ai-shen-xing]] |

### 假设行星

汉堡学派（Alfred Witte 等）引入未经天文验证的假设行星（Cupido, Hades, Zeus, Kronos, Apollon, Admetos, Vulcanus, Poseidon 等），构建复杂中点体系。现代占星主流**不建议常规使用**，仅作了解。

## 二、 点的应用：中点、映点与反映点

### 汉堡学派中点理论

**核心公式**：`A + B - C = D`（行星图形/Planetary Pictures）
- A、B、C 为黄道经度（0° 白羊起算）。
- D 为敏感点，融合 A、B 能量并经 C 调节。
- **简化为中点**：`C = (A + B) / 2`，即 A、B 对称中点。若行星落于该中点或与轴点（ASC/MC/交点）合相，极具触发力。

> **工具参考**：`The Combination of Stellar Influences` (Ebertin)。

### 映点与反映点

基于夏至点（巨蟹 0°）与冬至点（摩羯 0°）的赤緯对称关系，对应中国“夏至一阴生，冬至一阳生”阴阳消长观。

| 概念 | 定义 | 吉凶性质 | 类比相位 |
| :--- | :--- | :--- | :--- |
| **映点** | 两星体距夏至/冬至点赤緯相等（如巨蟹 3° ↔ 双子 27°） | **吉**：如同 60° 六分相。吉星会合带来吉性转折；凶星会合减轻凶性。 | 赤緯平行 |
| **反映点** | 映点的对冲点（如巨蟹 3° 的反映点为射手 27°） | **凶**：如同 90°/180° 刑冲。凶星会合加重凶象；吉星会合吉象受损。 | 赤緯反平行 |

**星座映点对照表（固定）**：
- 摩羯 ↔ 射手
- 水瓶 ↔ 天蝎
- 双鱼 ↔ 天秤
- 白羊 ↔ 处女
- 金牛 ↔ 狮子
- 双子 ↔ 巨蟹

### 实战案例：映点/反映点验证

#### 案例：希特勒
- **土星** 升于 MC 狮子 13°27'，与 **火星/金星**（金牛 16°）形成 90° 刑相，**且互为映点**，火土凶恶叠加。
- 金星为命主星入庙，却卷入火土映点，火土皆落陷宫 → 极端暴戾命格。

#### 案例：1999/08/11 日食（集集大地震触发）
- 天王星（水瓶 14°40'）与火星（天蝎 14°40'）**互为映点**。
- 土星（金牛 16°52'）为天王星**反映点**。
- 三大凶星（天王/火星/土星）构成映点/反映点三刑会冲，加上日食太阳对冲天王 → 形成大十字凶相。
- 集集镇本命盘：冥王星合 MC，六、十二宫聚星 → 震央精准落于南投集集。

#### 案例：李远哲（诺奖得主）
- 木星（射手 27°13'）与金星（摩羯 3°29'）**互为映点**（双吉星）。
- 木星入庙射手，三合命度；金星三合天王（九宫），天王容纳金星 → 学术声望卓越。

## 三、 阿拉伯点核心体系

> **正名**：实为**希腊点**（Ptolemy《四书》、Valens 已用），因阿拉伯占星家大量整理传播（如《译天文书》称“箭”），误称阿拉伯点。Anthony Louis《Horary Astrology》附录收录 130+ 种。

### 计算核心：昼夜出生分异

**黄道经度换算**：白羊 0°=0°, 金牛 0°=30°, 双子 0°=60°, 巨蟹 0°=90°, 狮子 0°=120°, 处女 0°=150°, 天秤 0°=180°, 天蝎 0°=210°, 射手 0°=240°, 摩羯 0°=270°, 水瓶 0°=300°, 双鱼 0°=330°。

| 核心点 | 白昼出生公式 | 夜间出生公式 | 核心意涵 |
| :--- | :--- | :--- | :--- |
| **福点/幸运点 (⊗)** | `ASC + ☽ - ☉` | `ASC + ☉ - ☽` | **肉体、物质、财富、身体健康**。“象征贯穿一生之事，变为财富、声望、恩典”（Paul of Alexandria）。 |
| **精神点 (Ψ)** | `ASC + ☉ - ☽` | `ASC + ☽ - ☉` | **灵魂、心智、信仰、声望、宗教**。太阳点。从精神切入（父/阳），对应福点从物质切入（母/阴）。 |
| **基础点 (β)** | `ASC + ⊗ - Ψ` (恒落地平线下) | `ASC + ⊗ - Ψ` | 根基、潜意识基底，少用。 |
| **升度点** | `ASC + 白羊19° - ☉` | `ASC + 金牛3° - ☽` | **卓越才能、荣誉地位**。依太阳/月亮升度度数计算。 |

> **关键**：现代占星多忽略昼夜分异，导致福点/精神点无法区分，**必须回归古典昼夜区分**才能显现真髓。

### 瓦伦斯尊贵判断五法则

以**整宫制**计算，参考传统主星（兼顾现代行星），另加 ASC 主星落十宫亦为尊贵指标。

| 法则 | 判断标准 | 含义 |
| :--- | :--- | :--- |
| **1. 落轴心宫** | 福点、精神点、基础点、升度点 **或其主星** 落 1/4/7/10 宫（始宮/角宫） | 根基稳固，易获显达。 |
| **2. 主星落自宫十宫** | 该点主星位于**以该点为升度起算的第 10 宫** | 事业尊荣、社会地位高。 |
| **3. 主星落其他轴心宫** | 该点主星落以该点起算的 1/4/7 宫 | 带来一定程度卓越。 |
| **4. 主星互落对方宫** | 如 ☉主星落 Ψ 宫、Ψ主星落升度宫、升度主星落基础宫等链条 | 卓越指标的相互确证。 |
| **5. 合四大皇冠星** | 该点或其主星与 **轩轩十四、毕宿五、心宿二、北落师门** 合相 (1°内) | 极大提升格局层级，王者之相。 |

## 四、 恒星体系与岁差校正

### 理论基础与操作原则

1.  **仅取合相 (0°)**：恒星无光芒，不论 60°/90°/120°/180° 相位，容许度 **1° 内**。
2.  **岁差校正**：春分点每年退行 **50.2893''**。表列 2000.0 黄经，**必须换算至事件年份** 再判断。
    - 计算：`目标年黄经 = 2000黄经 + (目标年 - 2000) × 50.2893''`。
3.  **核心参照点**：**ASC、MC、☉、☽** 为第一优先级；次及 ☿、♀、♂、♃、♄、⊗ 等。
4.  **吉凶互动法则**：
    - 凶星合吉恒星：不夺吉星吉意，但**修饰减分**。
    - 吉星合凶恒星：不改凶星凶性，但**调节缓冲**。
    - 吉合吉：**加乘吉效**。
    - 凶合凶：**加乘凶效**。
5.  **恒星性质解读**：参考其“类似行星”组合（如织女星 ♀/☿/♆ = 艺术敏感科技表达）。
