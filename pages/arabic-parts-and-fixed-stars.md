## 一、 天宫图中的其他敏感点

### 月球交点

月球交点非实体星体，而是月球轨道面（白道）与地球公转轨道面（黄道）的两个交点：
- **北交点（升交点/龙头/Rahu）**：白道由南向北穿越黄道，代表灵魂进化方向、今生应开发的心理意识与生活领域。
- **南交点（降交点/龙尾/Ketu）**：白道由北向南穿越黄道，代表过去生经验、业力模式、应放下的无意识习性。

**核心原理**：
- 交点永远呈 180° 对冲，白道倾角约 5.9°。
- 日月食发生于太阳、地球、月球交点连线时，故交点承载“集体无意识”层面的命运转折符号。
- **论断重点**：星座 > 宫位。北交点落星座显示需开发的意识；南交点落星座显示需超越的惯性。
- **平均交点 vs 真交点**：差距不超 1°45'，实务常用真交点。
- **周期**：逆行周期约 18.6 年，财务占星中为重要经济周期指标。

> **关联**：演化占星视角下的交点详见 [[ming-wang-xing-ling-hun-yan-hua-zhi-lv-juan-yi]]、[[arroyo-astrology-karma-transformation]]。

### 假设行星

汉堡学派（Alfred Witte 等）引入未经天文验证的假设行星（Cupido, Hades, Zeus, Kronos, Apollon, Admetos, Vulcanus, Poseidon 等），构建复杂中点体系。现代占星主流**不建议常规使用**，仅作了解。

## 二、 点的应用：中点、映点与反映点

### 汉堡学派中点理论

**核心公式**：`A + B - C = D`（行星图形/Planetary Pictures）
- A、B、C 为黄道经度（0° 白羊起算）。
- D 为敏感点，融合 A、B 能量并经 C 调节。
- **简化为中点**：`C = (A + B) / 2`，即 A、B 对称中点。若行星落于该中点或与轴点（ASC/MC/交点）合相，极具触发力。

> **工具参考**：`The Combination of Stellar Influences` (Ebertin)。

### 映点与反映点

基于夏至点（巨蟹 0°）与冬至点（摩羯 0°）的赤緯对称关系，对应中国“夏至一阴生，冬至一阳生”阴阳消长观。

| 概念 | 定义 | 吉凶性质 | 类比相位 |
| :--- | :--- | :--- | :--- |
| **映点** | 两星体距夏至/冬至点赤緯相等（如巨蟹 3° ↔ 双子 27°） | **吉**：如同 60° 六分相。吉星会合带来吉性转折；凶星会合减轻凶性。 | 赤緯平行 |
| **反映点** | 映点的对冲点（如巨蟹 3° 的反映点为射手 27°） | **凶**：如同 90°/180° 刑冲。凶星会合加重凶象；吉星会合吉象受损。 | 赤緯反平行 |

### 实战案例：映点/反映点验证

#### 案例：希特勒
- **土星** 升于 MC 狮子 13°27'，与 **火星/金星**（金牛 16°）形成 90° 刑相，**且互为映点**，火土凶恶叠加。
- 金星为命主星入庙，却卷入火土映点，火土皆落陷宫 → 极端暴戾命格。

#### 案例：1999/08/11 日食（集集大地震触发）
- 天王星（水瓶 14°40'）与火星（天蝎 14°40'）**互为映点**。
- 土星（金牛 16°52'）为天王星**反映点**。
- 三大凶星（天王/火星/土星）构成映点/反映点三刑会冲，加上日食太阳对冲天王 → 形成大十字凶相。
- 集集镇本命盘：冥王星合 MC，六、十二宫聚星 → 震央精准落于南投集集。

#### 案例：李远哲（诺奖得主）
- 木星（射手 27°13'）与金星（摩羯 3°29'）**互为映点**（双吉星）。
- 木星入庙射手，三合命度；金星三合天王（九宫），天王容纳金星 → 学术声望卓越。

## 三、 阿拉伯点核心体系（依《占星诗集》第三册修正版）

> **正名**：实为**希腊点**（Ptolemy《四书》、Valens 已用），因阿拉伯占星家大量整理传播（如《译天文书》称“箭”），误称阿拉伯点。Anthony Louis《Horary Astrology》附录收录 130+ 种。
>
> **版本溯源**：本节核心数据源自西元一世纪西顿多罗修斯《占星诗集》（五经）第三册，经本杰明·戴克整合希腊、阿拉伯、拉丁文本并修正平格瑞译本错误后出版。平格瑞版误在夜间公式中加入“减去30度”及错误的动词“减掉”导致计算反向，戴克版已修正。

### 计算核心：昼夜出生分异与投射法

**黄道经度换算**：白羊 0°=0°, 金牛 0°=30°, 双子 0°=60°, 巨蟹 0°=90°, 狮子 0°=120°, 处女 0°=150°, 天秤 0°=180°, 天蝎 0°=210°, 射手 0°=240°, 摩羯 0°=270°, 水瓶 0°=300°, 双鱼 0°=330°。

**标准计算流程（阿拉伯文原意）**：
1.  依日/夜公式，按黄道顺序（逆时针）计算两行星/点之间的**弧度距离**。
2.  将该距离**加上**上升点（ASC）黄经。
3.  以 **30° 为单位（一个星座）** 从上升点起算（顺时针/黄道顺序）投射，超过 30° 进入下一宫/星座，直到用完该数值。
4.  终点即为该敏感点位置。

> **关键修正**：现代占星多忽略昼夜分异，或误用平格瑞版“夜间加、日間减”的错误指令，**必须回归古典昼夜区分与“加上上升度数再投射”的标准流程**。

## 四、 平格瑞译本错误与戴克修正详解

### 核心错误：母親點公式的“减法”陷阱

**平格瑞版 (I.14, 1) 译文**：
> “要计算母亲点，夜间盘是从月亮到金星，日間盘是从金星到月亮。**[夜间盘] 再加上上升点的度数，或 [日間盘] 从上升以 [一次] 30°的方式将 [其] 减掉**；计算结束的地方，即为母亲点所在。”

**阿拉伯文原文与戴克修正版**：
> “夜间盘从月亮到金星，日間盘从金星到月亮，**然后加上上升点的度数，以30°为一个单位，将[其]从上升投射**：当计算结束后，即为母亲点所在。”

**错误分析**：
1.  **增词**：平格瑞加入“不必要的括号字”、“原本不存在的动词‘减掉’”、“原本没有的日間/夜间盘分别说明”。
2.  **删词**：删去原本有的动词“投射”。
3.  **后果**：導致日間盤“先反向计算弧度，再从上升减去”，双重反向抵消，使日間盤结果错误地等同于夜间盘。
4.  **波及范围**：《诗集》中仅部分点明确说明治夜反转，平格瑞将此错误模式泛化至所有点，导致大量敏感点计算失真。

### 戴克修正原则总结

| 项目 | 平格瑞版错误 | 戴克版修正 (依阿拉伯文原意) |
| :--- | :--- | :--- |
| **计算方向** | 夜间順向、日間逆向并减去 | **日夜均為順向(逆时针)计算弧度，均加上升度数，均投射(順向)** |
| **公式反转** | 所有点日夜反转 | **仅行星-行星/行星-光體类点反转 (如福点、父母点)；宫位/星座类点 (资产点、死亡点、娱乐婚姻点) 不反转** |
| **基准点** | 混淆星座零度与宫头度数 | **严格区分：资产/死亡点用星座零度(整宫制宫位起点)；娱乐婚姻点用 DSC 尖軸度数** |

## 五、 资产点与死亡点：星座零度 vs 宫头度数之争

这是《诗集》文本传承中（阿拉伯文《诗集》vs 希腊文《五经》/《结果》）最核心的技术歧义，戴克在绪论与第三章详细论证。

### 资产点
- **《诗集》 (I.29, 17)**：“第二宫主星到第二宫” (απο τοῦ δευτέρου τοῦ δευτέρου)。
- **《结果》 (Apotelesmatics)**：“第二宫本身” (τῆς δευτέρας αὐτῆς)。
- **争议**：是计算“二宫主星 → 二宫星座零度(整宫制)”，还是“二宫主星 → 二宫尖軸度数(象限制)”，抑或仅看二宫落星座？
- **戴克定论**：主张**统一使用整宫制星座零度(0°)起算**。理由：古典占星以整宫制为本，且“宫”即“星座”；“第二宫本身”指第二星座起始度。若用尖軸度数，则需象限制支持，但多罗修斯未用象限制。

### 死亡点
- **《诗集》 (IV.3, 16)**：“月亮到第八宫，土星” (ἀπὸ τῆς ὀγδόης τῆς σελήνης κρόνος)。
- **《五经》 (Pentateuch/Fragments)**：“月亮到第八个星座，土星”。
- **争议**：“第八宫”指整宫制第八星座零度，还是象限制第八宫尖軸？
- **戴克定论**：同资产点，**以整宫制第八星座零度(星座起始度)为基准**。文本“第八个星座”印证此說。

### 娱乐与婚姻点 —— 特例
- **公式**：`金星 - 第七宫度数` (II.5, 4)。
- **定论**：**唯一使用尖軸度数 (DSC/下降点度数)**。因第七宫代表“伴侣/他人”，其尖軸为交接点，精确度数代表契约确切时刻，非模糊星座整体。此点不分日夜盘。

> **实务建议**：现代软件多默认象限制尖軸计算阿拉伯点，**须手动切换至整宫制星座零度模式**计算资产点、死亡点等核心点，方合古典法则。

## 六、 实务计算指引与鲁道夫《占星进阶辞典》公式补遗

### 绝对黄经对照表（0°-360°）

计算阿拉伯点第一步：将所有星体、宫位起点转为绝对黄经。

| 星座名稱 | 絕對度數 (起始) | 星座名稱 | 絕對度數 (起始) |
| :--- | :---: | :--- | :---: |
| 牡羊座 | 0° | 天秤座 | 180° |
| 金牛座 | 30° | 天蠍座 | 210° |
| 雙子座 | 60° | 射手座 | 240° |
| 巨蟹座 | 90° | 摩羯座 | 270° |
| 獅子座 | 120° | 水瓶座 | 300° |
| 處女座 | 150° | 雙魚座 | 330° |

> **用法**：某星座 15° = 星座起始绝对度数 + 15。例：狮子座 5° = 120° + 5° = 125°。

### 标准计算步骤实例：幸運點

**命例**：上升 狮子座 5°、月亮 牡羊座 12°、太阳 双鱼座 6°（白昼出生）。

1.  **换算绝对黄经**：
    - ASC = 120° + 5° = **125°**
    - ☽ = 0° + 12° = **12°**
    - ☉ = 330° + 6° = **336°**
2.  **套用白昼公式**：`ASC + ☽ - ☉`
    - 中间值 = 125° + 12° = **137°**
3.  **处理负值/循环**：137° - 336° = -199°（不足减）。
    - 加 360°：137° + 360° = **497°**
4.  **最终减法**：497° - 336° = **161°**
5.  **定星座度数**：
    - 161° 介于 150°(处女座) 与 180°(天秤座) 之间。
    - 星座：**处女座**
    - 度数：161° - 150° = **11°**
6.  **结果**：**幸運點 位于 处女座 11°**。

> **核心口诀**：**“加上升，减基准，不够减加三六零，查表定星座，余数定度数。”**

## 七、 恒星体系与岁差校正

### 理论基础与操作原则

1.  **仅取合相 (0°)**：恒星无光芒，不论 60°/90°/120°/180° 相位，容许度 **1° 内**。
2.  **岁差校正**：春分点每年退行 **50.2893''**。表列 2000.0 黄经，**必须换算至事件年份** 再判断。
    - 计算：`目标年黄经 = 2000黄经 + (目标年 - 2000) × 50.2893''`。
3.  **核心参照点**：**ASC、MC、☉、☽** 为第一优先级；次及 ☿、♀、♂、♃、♄、⊗ 等。
4.  **吉凶互动法则**：
    - 凶星合吉恒星：不夺吉星吉意，但**修饰减分**。
    - 吉星合凶恒星：不改凶星凶性，但**调节缓冲**。
    - 吉合吉：**加乘吉效**。
    - 凶合凶：**加乘凶效**。
5.  **恒星性质解读**：参考其“类似行星”组合（如织女星 ♀/☿/♆ = 艺术敏感科技表达）。

### 恒星实战案例

#### A. 陈水扁
1.  **☽ (天秤 24°06') 合 角宿一 (天秤 23°50')** → 大吉：好运、富有、胜利（母由农妇跃居国母）。

#### B. 希特勒
1.  **☽ (金牛 6°33') 合 人马座球形星团 Facies (摩羯 8°18' 岁差校正)** → 盲目、暴戾死、统御战争、冷酷分裂、地震。
2.  **☿ (双子 13°28') 合 天枢 Dubhe (双子 13°38')** → 凶：自大傲慢、破坏一生际遇、屠杀犹太人、发动战争。
3.  配合土星升中天、火土映点刑冲 → 混世魔王徵象毕现。

| 体系 | 核心公式/原则 | 关键判断点 | 实务提示 |
| :--- | :--- | :--- | :--- |
| **阿拉伯点** | 昼夜分异公式 (`ASC+☽-☉` / `ASC+☉-☽`) + **投射法(加30°单位)** | 瓦伦斯5法则 + 里利评分表 + 皇冠星合相 | **必须区分昼夜**，整宫制计算，主星落自宫十宫最尊贵。**资产/死亡点不分昼夜，以星座零度起算**；娱乐婚姻点用 DSC 度数。 |
| **平格瑞纠错** | 删除“日間减去”、“夜间加上”等错误指令 | 恢复阿拉伯文原意：日夜均“顺向算弧度+加上升度数+顺向投射” | 现代软件设置检查：若软件日夜盘阿拉伯点位置相同，即为平格瑞错误模式。 |
