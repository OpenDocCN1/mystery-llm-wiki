## 概述

《梅花易数》全名《邵康节先生观梅拆字数全书》，为北宋大儒**邵康节**（邵雍，1011–1077）所创。《图解〈易经〉中的数学·梅花易数》（汤行易编著，陕西师范大学出版社2008年版）以图解形式系统重构其理论与实操体系。梅花易数立足《周易》六十四卦，将天时、地理、声音、人物、颜色、形状、字义等万物现象转化为数，再以卦象推演吉凶趋势，因“闻梅上鸟鸣，循声掐指而悟”得名。其核心主张“万物皆备于我”，以象数贯通天地人三界，被誉为“《易经》中的数学”。

> 交叉引用：[[liuyao-qimeng-jieyao]]（六爻启蒙教程中的河图洛书、先天后天八卦）、[[qimen-dunjia-fundamentals]]（奇门遁甲基础中的九宫八卦）、[[ziwei-doushu-jie-ti-chu-jie]]（紫微斗数阶梯入门中的河图洛书体用）、[[zhanxing-tianwen-jichu-yu-huangdao-tixi]]（占星天文基础中的回归黄道与恒星黄道）

## 一、 创立缘起与历史定位

### 邵康节生平与哲学思想
- **身份**：北宋哲学家，字尧夫，谥康节，号安乐先生，范阳（今河北涿州）人，隐居苏门山百源，晚年居洛阳。
- **师承**：华山道士陈抟（陈希夷）三弟子，得先天象数图谱。
- **地位**：与周敦颐、张载、程颢、程颐并称“北宋五子”，为宋明理学主要奠基人；朱熹象数学理论亦源自邵雍。
- **核心思想**：太极为本体，动静生天地，阴阳刚柔生万物；“太极不动，性也；发则神，神则数，数则象，象则器，器之变，复归于神也”。
- **代表作**：《皇极经世》《渔樵问对》《伊川击壤集》《观物内外篇》。

### 梅花易数创立传说
邵康节游园听梅上鸟鸣，掐指一算，悟得起卦之法，遂著《梅花易数》。书分上下卷：上卷论卦象、起卦、体用、卦气、三要十应、占例；下卷专论测字法（五行笔式、六神笔法、神煞偏旁、玄黄笔法、五言/七言作用歌）。

## 三、 起卦法体系

梅花易数起卦法分两大类：**“先算数，后起卦”**与**“先起卦，后算数”**。核心口诀：**“卦以八除，爻以六除”**（上卦数÷8余数为上卦，下卦数÷8余数为下卦；动爻数÷6余数为动爻，余0作6）。

### 先算数后起卦类
| 方法 | 数字来源 | 组卦规则 |
|------|----------|----------|
| **时间起卦** | 年、月、日、时（农历） | 上卦=（年+月+日）÷8余；下卦=（年+月+日+时）÷8余；动爻=（年+月+日+时）÷6余 |
| **尺寸起卦** | 物体长宽高、直径等数值 | 以尺寸数直接作上/下卦数，或相加后除八 |
| **物数起卦** | 物品个数、人数、车数等 | 单数作上卦，双数作下卦；或总数除八 |
| **声音起卦** | 可数之声（敲击、脚步、鸟鸣等） | 声响次数作上卦，再听一次作下卦；总响数除六定动爻 |

### 先起卦后算数类
| 方法 | 起卦依据 | 转数规则 |
|------|----------|----------|
| **动物起卦** | 见到动物种类/行为 | 查动物属卦（如马→乾、牛→坤、鱼→坎、鸟→艮、羊→兑、鸡→巽、龙→震），得卦再转数 |
| **静物起卦** | 见到物品颜色/形状/材质 | 查静物属卦（如金玉→乾、布帛→坤、木竹→震、绳索→巽、酒器→坎、书甲→离、土石→艮、金刃→兑） |
| **字占起卦** | 汉字笔画、偏旁、结构 | 详见第六节“测字法” |

### 传统卜筮法（对比参考）
- **揲蓍成卦法**：五十蓍草，分二、挂一、揲四、归奇，十八变成卦。最古老、最典型，体现太极→两仪→四象→闰月全过程。
  - **具体流程**：准备50根蓍草→取1根不用（象太极）→余49根分二（象两仪）→挂一（象三才）→揲四（象四时）→归奇（象闰）→得一爻（三变成爻）→十八变成卦（六爻×三变）。
  - **画爻规则**：三变后剩蓍草数为36、32、28、24四种，除以4得9、8、7、6。9、7为阳爻（—）；8、6为阴爻（--）。9老阳、6老阴为动爻。
- **金钱卦法**：三枚铜钱，六次投掷。老阳（三正）O→变阴，老阴（三反）×→变阳，少阳（二正一反）—，少阴（一正二反）--。简便流传最广。

## 四、 体用生克理论与卦气衰旺

### 体用说核心框架
- **体（贞/主）**：所占之事、本人、动机发起方。
- **用（悔/客）**：所问之事、对方、外来影响方。
- **判断原则**：
  1. **用生体**（用卦五行生体卦五行）→ 吉，事成、得助。
  2. **用克体**（用卦五行克体卦五行）→ 凶，事阻、受害。
  3. **体生用**（体卦五行生用卦五行）→ 耗散、付出、主动给予。
  4. **体克用**（体卦五行克用卦五行）→ 克制、主动控制、反客为主。
  5. **体用同类**（比和）→ 平常、缓慢、需待时机。

### 体用总诀补充：衰旺论与内外论
| 维度 | 说明 |
|------|------|
| **卦气衰旺** | 依四时五行旺相休囚：春木旺（震巽）、夏火旺（离）、秋金旺（乾兑）、冬水旺（坎）、四季月土旺（坤艮）。旺则力强，衰则力弱，生克判断须结合旺衰。 |
| **内外论** | 内卦为体/主/内因，外卦为用/客/外因。动爻在内卦→主内部变动；在外卦→主外部介入。 |
| **动静之理** | 静卦看体用生克；动卦看变卦（之卦）与互卦（错卦、综卦），动爻所生之卦为变卦，变卦生体吉、克体凶。 |
| **克应时刻** | 应期以动爻五行、卦气旺衰、日辰冲合、月建断。旺相日应、月建冲动爻日应、日辰合动爻日应。 |
| **坐端方位** | 以八卦方位（后天定位）断事物所在方向、失物方向、行人方向。 |
| **观物洞玄歌** | 预测住宅吉凶准则：以卦象方位、形势、颜色、动静综合判断宅基凶吉。 |

## 五、 三要十应断验框架

### 三要：感官中的万物之理
1. **天时之要**：年月日时、节气、卦气旺衰。
2. **地理之要**：方位、山川、宅舍、物象方向。
3. **人事之要**：人物身份、动作、言语、面色、字画。

> “三要者，感官中之万物之理也。占者必先明三要，则万物皆吾卦中物矣。”

### 十应：出于三要，灵于三要
| 序 | 应类 | 断验要点 |
|----|------|----------|
| 1 | **天时之应** | 卦气旺衰、节气顺逆、日月冲合、风雨晴明 |
| 2 | **地理之应** | 卦象方位、山水形势、宅舍高低、物色方位 |
| 3 | **人品之应** | 贵贱、贤愚、寿夭、富贵、贫贱、吉凶（依八卦属人：乾父坤母震长男巽长女坎中男离中女艮少男兑少女） |
| 4 | **行为之应** | 动静、进退、语默、喜怒、来去、快慢 |
| 5 | **方卦之应** | 八卦方位、上下内外、前后左右、远近高低 |
| 6 | **动物之应** | 飞走、鸣叫、聚散、斗咬、惊怖、死生 |
| 7 | **静物之应** | 色泽、形状、新旧、成毁、得失、隐现 |
| 8 | **言语之应** | 音韵高低、语气缓急、词义吉凶、真假虚实 |
| 9 | **声色之应** | 声音清浊、面色红白青黄黑、光影明暗 |
| 10 | **文字之应** | 字画笔画、偏旁结构、字义吉凶、风骨神韵 |

> 实战口诀：“三要为体，十应为用；体用相资，吉凶立判。”

## 六、 测字法（字占）完整实操体系

梅花易数测字法为一书一大特色，分**总纲**（第七章）与**应用**（第八章）两章，共20节内容。

### 字占基本原理
- **汉字结构**：偏旁部首组合（左右、上下、包围、叠加等）。
- **六书**：象形、指事、会意、形声、转注、假借。
- **风骨神韵**：笔势、结构、气势、精神（参考古代书法名家）。

### 核心编码体系（第七章12节详解）
| 编码层 | 章节 | 内容 | 判断作用 |
|--------|------|------|----------|
| **五行笔式** | 第4节 | 笔画归五行：横/竖/撇/捺/钩/点 → 木/金/火/水/土 | 定字体五行属性，为生克基础 |
| **五行干支辨** | 第5节 | 笔画数配十天干、十二地支、纳音 | 精细化五行属性至干支层级 |
| **六神笔法** | 第6节 | 青龙/朱雀/勾陈/腾蛇/白虎/玄武 六神配笔画部位 | 定人事、吉凶、动静、远近、颜色、疾病 |
| **五行六神篇** | 第7节 | 五行六神综合测字准则 | 综合断验 |
| **甲子纳音歌** | 第8节 | 六十甲子纳音配字占 | 定年份、吉凶层次 |
| **神煞笔法诀** | 第9节 | 偏旁部首查神煞：天乙贵人、桃花、驿马、华盖、羊刃、劫煞等 | 判断贵人、桃花、移动、才艺、凶险 |
| **玄黄笔法** | 第10节 | 玄（阴/黑/水/北）、黄（阳/黄/土/中）二笔阴阳分野 | 总纲性判断阴阳、内外、上下、男女 |
| **五言作用歌** | 第11节 | 末笔判断：末笔五行、方位、吉凶、应期 | 细节定夺 |
| **七言作用歌** | 第12节 | 整体判断：全字结构、气势、主客、成败 | 综合定夺 |

### 测字实操流程
1. **观字形**：左右/上下/独体/包围/品字/叠字结构。
2. **拆偏旁**：查神煞偏旁歌，识别贵人、桃花、驿马、华盖、羊刃等。
3. **数笔画**：总笔画、偏旁笔画、独体笔画，配五行干支、纳音。
4. **辨笔式**：横竖撇捺钩点归五行，定字体五行。
5. **配六神**：按笔画部位（上/中/下/左/右/中宫）排青龙至玄武。
6. **判玄黄**：首笔/末笔/中锋定玄黄阴阳。
7. **诵作用歌**：五言定末笔，七言定全字。
8. **综合断验**：结合来人面色、言语、天时、地理、动静（三要十应）定吉凶、应期、事类。

### 第八章应用篇重点（8节）
1. **字画经验**：部分常见字测法速查。
2. **人如其字**：推断贫富要诀。
3. **字画指迷**：各种情况下的测字法（失物、行人、疾病等）。
4. **字与风格**：探玄赋测字法。
5. **以卦而断**：测字时的变通法（得卦后以卦象生克断验）。
6. **命中机缘/一心做事**：古人测字故事案例。
7. **易理玄微**：梅花易数占法总结。

### 常见字测法速查（节选）

|------|------|-----------------|----------|
| **西** | 独体 | 六笔、四点水、一横 | 西方兑金、四点水坎、横木震 → 金水相生、主西方来信、水路通 |
| **林** | 双木 | 八笔、双木 | 震巽双木、木旺生火、主文书、契约、林木之利 |
